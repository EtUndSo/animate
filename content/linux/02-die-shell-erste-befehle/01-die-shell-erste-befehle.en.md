## What this is about

At the end of [Chapter 1](/wissen/en/informatik/linux-und-kommandozeile/ein-linux-zum-uben-wsl-virtuelle-maschine-live-usb-stick/ein-linux-zum-ueben.html), you had a window with a blinking cursor: no buttons, no menus, just a line into which you type text. For many people, this is the moment when Linux starts to feel foreign. Yet this window is one of the most powerful tools on a computer. What you type there is precise; it can be repeated, written down and passed on to others, and a computer on another continent runs it just as one at your own desk does.

This chapter pursues one question: How do you talk to a computer that understands only text? It shows who is actually listening in the window, how a line must be built so that it is understood, how you find the instructions for any command yourself and how a few keys save you a lot of typing. Finally, you explore your own system: which kernel is running, who you are to the computer, how much memory is free. Afterward, you can read, understand and safely carry out any instructions that begin with a typed command.
