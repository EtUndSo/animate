## Worum es geht

Fast alle Server im Internet, viele Geräte vom WLAN-Router bis zum Fernseher und die meisten Werkzeuge für Datenanalyse, maschinelles Lernen und IT-Sicherheit laufen unter Linux. Wer damit arbeiten will, braucht ein Linux, an dem er üben kann. Auf den meisten Rechnern von Studierenden läuft aber Windows, und dieses Windows mit allen Dateien darauf soll heil bleiben.

Dieses Kapitel geht einer Frage nach: Wie kommt man an ein eigenes Linux zum Üben, ohne Windows oder seine Daten zu gefährden? Es gibt dafür drei Wege. Man kann Linux in Windows mitlaufen lassen, man kann es in einem nachgebildeten Rechner betreiben, oder man startet es von einem USB-Stick. Das Kapitel zeigt alle drei, erklärt, was dabei im Rechner geschieht, und sagt genau, wo die Risiken liegen und wie man sich gegen sie absichert. Am Ende hast du ein laufendes Linux und weißt, warum es funktioniert.

**So arbeitest du mit diesem Kapitel.** Die Abschnitte bauen aufeinander auf, jeder neue Begriff hat einen eigenen Unterabschnitt mit Beispiel. Kästen zum Aufklappen enthalten Hintergrund (warum etwas so ist und woher es kommt) und Herleitungen; zum Weiterlesen braucht man sie nicht. Kästen „Achtung“ nennen Regeln, die bei praktischen Übungen immer gelten. Versuche die Aufgaben (★ bis ★★★) zuerst selbst, die Lösung klappst du direkt unter der Aufgabe auf.
