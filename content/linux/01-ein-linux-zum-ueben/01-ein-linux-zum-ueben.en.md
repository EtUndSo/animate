## What this is about

Almost all servers on the internet, many devices from Wi-Fi routers to TVs and most tools for data analysis, machine learning and IT security run on Linux. If you want to work with them, you need a Linux to practice on. But most students' computers run Windows, and this Windows, with all the files on it, should stay intact.

This chapter pursues one question: How do you get a Linux of your own to practice on without putting Windows or its data at risk? There are three ways to do it. You can run Linux alongside Windows, you can operate it in a simulated computer, or you can start it from a USB stick. The chapter shows all three, explains what happens inside the computer along the way and says exactly where the risks lie and how to protect yourself against them. At the end, you have a running Linux and know why it works.
