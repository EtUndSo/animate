:::merke 三句话的答案
<ol>

<li>

__复数__是一对实数，写作 $z=x+\mathrm{i}y$。__虚数单位__ $\mathrm{i}$ 就是数对 $(0,1)$，它满足 $\mathrm{i}^2=-1$。所有数对合起来构成__复平面__，其中 $\mathbb{R}$ 是水平轴。

</li>

<li>

运算与在 $\mathbb{R}$ 中一样，只需把 $\mathrm{i}^2$ 换成 $-1$。因此 $\mathbb{C}$ 是一个__域__（四则运算遵循熟悉法则的集合）。失去的是序：复数之间没有“大于”。

</li>

<li>

__共轭复数__ $\overline{z}=x-\mathrm{i}y$ 是 $z$ 关于实轴的镜像，而 $z\overline{z}=x^2+y^2$ 是实数。由此得到除法、__绝对值__ $|z|=\sqrt{x^2+y^2}$（到原点的距离）和__三角不等式__ $|z+w|\le|z|+|w|$（绕路绝不会更短）。

</li>

</ol>
:::

:::kern 要点
<ul>

<li>

复数是一个数对：$z=x+\mathrm{i}y$，其中 $\mathrm{i}^2=-1$。运算与在 $\mathbb{R}$ 中一样。

</li>

<li>

加法就是平行四边形，乘以 $\mathrm{i}$ 就是旋转 $90^\circ$。

</li>

<li>

取共轭就是镜像：$\overline{z}=x-\mathrm{i}y$，且 $z\overline{z}=x^2+y^2=|z|^2$。

</li>

<li>

除法：分子分母同乘分母的共轭复数，$w/z=w\overline{z}/|z|^2$。

</li>

<li>

$\mathbb{C}$ 是域，但不是有序的。不等式只存在于实数量之间。

</li>

<li>

$|z|=\sqrt{x^2+y^2}$，$d(z,w)=|z-w|$，$|zw|=|z||w|$，$|z+w|\le|z|+|w|$。

</li>

<li>

$z^2+pz+q=0$ 在 $\mathbb{C}$ 中总有解：$z=-p/2\pm w$，其中 $w^2=p^2/4-q$。

</li>

</ul>
:::
