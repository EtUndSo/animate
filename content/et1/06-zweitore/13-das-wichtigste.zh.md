:::merke 三句话的答案
<ol>

<li>

在每个端口，从一个接线端流入的电流都从另一个接线端流出（__端口条件__）。因此从外部看只剩下两个电压和两个电流。

</li>

<li>

在不含自身电源的线性二端口网络中，这四个量中的两个决定另外两个。每个因变量都是两部分之和，所以四个数就够了，这就是__二端口参数__。

</li>

<li>

__阻抗形式__（给定电流）、__导纳形式__（给定电压）、__混合形式__（给定输入电流和输出电压）和__链式形式__（给定输出量）描述的是同一个二端口网络。开路和短路使某个给定量为零，从而逐个显露出各参数。

</li>

</ol>
:::

:::kern 要点
<ul>

<li>

二端口网络：四个接线端，端口条件 $I_{1'}=-I_1$，$I_{2'}=-I_2$。端口量 $U_1$、$I_1$、$U_2$、$I_2$，电流箭头指向内部。

</li>

<li>

线性且不含自身电源：两个量决定其余两个量，四个参数。

</li>

<li>

Z：$\mathbf U=\mathbf Z\,\mathbf I$，开路试验。Y：$\mathbf I=\mathbf Y\,\mathbf U$，短路试验。$\mathbf Y=\mathbf Z^{-1}$。

</li>

<li>

H：由 $(I_1,U_2)$ 得 $(U_1,I_2)$。A：由 $(U_2,-I_2)$ 得 $(U_1,I_1)$。

</li>

<li>

参数是结果与原因之商，另一个原因置零。$I=0$ 表示开路，$U=0$ 表示短路。

</li>

<li>

本端口电流给出电阻，另一端口的电流或电压给出受控源。电压在串联中相加，电流在并联中相加。

</li>

<li>

负载：$Z_1=Z_{11}-\frac{Z_{12}Z_{21}}{Z_{22}+Z_\mathrm{L}}$，$Y_1=Y_{11}-\frac{Y_{12}Y_{21}}{Y_{22}+Y_\mathrm{L}}$。

</li>

<li>

T：$\mathbf Z$ 含 $R_\mathrm{a}+R_\mathrm{b}$、$R_\mathrm{b}$、$R_\mathrm{b}+R_\mathrm{c}$。$\pi$：$\mathbf Y$ 含 $G_1+G_2$、$-G_2$、$G_2+G_3$。换算用星形-三角形变换。

</li>

<li>

串联，串联：Z 相加。并联，并联：Y 相加。串联，并联：H 相加。级联：A 相乘。前提：端口条件保持。

</li>

<li>

互易：$Z_{12}=Z_{21}$，$Y_{12}=Y_{21}$，$H_{12}=-H_{21}$，$\det\mathbf A=1$。无反向作用：$Z_{12}=Y_{12}=H_{12}=0$，$\det\mathbf A=0$。

</li>

<li>

功率：$P=U_1I_1+U_2I_2$，若可能有 $P<0$ 则为有源。

</li>

</ul>
:::
