:::zweck
两种方法的结果相同。本阶段说明哪种方法工作量更小，以及各自有什么做不到。
:::

**基本思路。** 计算工作量取决于矩阵的大小。网孔电流法需要 $z-k+1$ 个未知量，节点电位法需要 $k-1$ 个。支路多而节点少，意味着网孔多而节点少。长链则相反。

:::satz 定理 6.1 (方程数的比较)
<span class="anker" id="satz-6-1"></span>

节点电位法需要的方程较少，当且仅当 $k-1<z-k+1$，即

<span class="anker" id="gl-6-1"></span>
$$z>2k-2. \tag{6.1}$$
:::

⁠**如何理解：**平均每个节点上有 $2z/k$ 个支路端，因为每条支路有两端。在分界线上这个数是 $4-4/k$，即略小于四。如果平均每个节点连接的支路更多，节点电位法就胜出（图 [6](#abb-6)）。**适用条件：**每个实际电源计为一条支路，因为对网孔而言它变成电压源加串联电阻。变换不改变 $k-1$。

:::abbildung et1/k8zahl 6
每个点是一个网络。在 $z=k-1$ 以下，网络不连通。在红色直线 $z=2k-2$ 以上，节点电位法需要的方程较少，在其以下则是网孔电流法，在直线上两者相同。
:::

|  | 网孔电流法 | 节点电位法 |
|---|---|---|
| 未知量 | $z-k+1$ 个网孔电流 | $k-1$ 个节点电位 |
| 自动满足 | 节点定律 | 网孔定律 |
| 需要列出 | 网孔定律 | 节点定律 |
| 矩阵 | $\mathbf Z$，单位 $\Omega$ | $\mathbf Y$，单位 S |
| 对角线 | 网孔的电阻之和 | 节点上的电导之和 |
| 非对角元 | $\pm$ 公共电阻 | $-$ 互电导 |
| 右端 | 电源电压 | 电源电流 |
| 麻烦的元件 | 电流源 | 电压源 |
| 最小情形 | 串联，$m=1$ | 并联，$k-1=1$ |
| 用途 | 手算 | 手算和仿真器 |

这张表显示了一种__对偶性__，即一种镜像关系：把网孔与节点、电流与电压、串联与并联、电阻与电导互换，一种方法就变成另一种方法。原因在于基尔霍夫：两条定律都说“总和为零”，只是针对不同的集合。

**例。** 右边变换之后，模型电路有 $k=3$，$z=5$。由 $5>4$ 知它在直线上方，确实是三个网孔对两个节点。**极限情况：**[第 2 部分](/wissen/zh/elektrotechnik/1-semester/grundlagen-der-elektrotechnik/strom-widerstand-und-kirchhoff/strom-widerstand-und-kirchhoff.html)的电桥 $k=4$，$z=6$，恰好在直线上。这时由电源决定：理想电压源有利于网孔法，因为它在那里位于右端。

仿真器只使用节点电位。网络的网孔要由程序先去搜索，而且只有网络能画成无交叉的形式时才有窗口。节点则已经写在电路描述中（第 [7](stempel-und-netzliste.html#stufe-7) 阶段）。

:::frage 既然仿真器不用网孔电流法，它不就是多余的吗？
对大型网络来说是的。但手算时它常常更短，而且让人始终盯着电流回路：能看出哪些电流共用哪条路径。网孔少而节点多时，例如在由串联组成的长链中，它明显胜出。
:::

(a) $k=2$，$z=4$：$m=3$ 对 $k-1=1$，用节点电位。这里 $z=4>2$。
