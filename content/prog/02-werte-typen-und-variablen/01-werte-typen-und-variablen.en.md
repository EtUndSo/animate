## What this is about

A program handles very different things: item counts and prices, quantities between the thickness of a hair and the distance to the sun, text for output, and points in the plane that you want to shift and rotate. [Chapter 1](/wissen/en/informatik/programmieren/python/programme-und-der-python-interpreter/programme-und-der-python-interpreter.html) showed how to make Python calculate. Some observations remained unexplained along the way: `12 / 4` gives `3.0` and not `3`, and Heron's recipe ended up next to the built-in result in the last digit.

This chapter looks into which kinds of values Python knows, how the computer stores them and why Python calculates with them exactly the way it does. By the end, you can interpret results correctly, even those that look wrong at first glance. You can give names to values, rotate points in the plane with a single calculation and write small programs that ask for numbers and output the result neatly formatted.

Expandable boxes contain background (why a method works and where it comes from), derivations and proofs; you do not need them to read on. Try the exercises (★ to ★★★) yourself first and actually run the programs; the solution expands right below each exercise.
