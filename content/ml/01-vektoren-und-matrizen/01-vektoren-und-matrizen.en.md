## What this is about

A computer that is supposed to learn something from data sees no apartments, no texts and no images. It sees only numbers. Before we can talk about learning methods, it must therefore be clear how to describe a thing from the real world by numbers and which calculations with these numbers make sense.

This chapter pursues the question of how to write down many measured values of many things so that you can calculate with them: how to measure how similar two things are and how far apart they lie, how to turn several measured values into a single estimate and how to apply the same calculation to a thousand things at once. On top of that comes the question of when such a calculation destroys information and when it can be undone.

The payoff: the chapter establishes the language in which all further parts of the series are written. Once you master it, you can read every later method as a calculation with lists and tables of numbers.

**How to work with this chapter.** The sections build on each other, and every new term has its own subsection with an example. Expandable boxes contain background (why a method works and where it comes from), derivations and proofs; you do not need them to read on. Try the exercises (★ to ★★★) yourself first and actually run the programs; the solution expands right below each exercise.
