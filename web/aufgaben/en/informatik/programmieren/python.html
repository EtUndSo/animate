Exercise 1 ★ The recipe by hand

Use Heron's recipe and a calculator to compute the square root of 10. To do so, replace the number 2 in the recipe by 10, that is, $\textcolor{#1b7f4a}{g'}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac12(g+10/g)}$.

  1. Start with $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ and carry out three passes. Write down $g$ each time with six decimal places.

  2. Compute $g^2$ after each pass. How close is it to 10?

  3. In each pass, compare $g$ and $10/g$. Which of the two numbers is larger?

Solution

Here the recipe reads $\textcolor{#1b7f4a}{g'}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac12(g+10/g)}$; the true value is $\textcolor{#1b7f4a}{\sqrt{10}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3.162\,277\,66\ldots}$

Pass$g$ before$10/g$$g$ after$g^2$ after
1$3$$3.333\,333$$3.166\,667$$10.027\,778$
2$3.166\,667$$3.157\,895$$3.162\,281$$10.000\,019$
3$3.162\,281$$3.162\,275$$3.162\,278$$10.000\,000$

(a) After three passes, $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{3.162\,278}$; all six decimal places agree with $\sqrt{10}$.

(b) After the first pass, $g^2$ lies $0.028$ above 10, after the second $0.000\,019$, after the third less than $10^{-11}$. The gap shrinks drastically each time because, according to the Background box in Subsection 1.1, it is squared and divided: $\textcolor{#1b7f4a}{0.028^2/(4\cdot10.03)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0.000\,019}$.

(c) Before the first pass, $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ is smaller than $\textcolor{#1b7f4a}{10/g}\textcolor{#15633a}{=}\textcolor{#c2410c}{3.333}$: the starting estimate is too small. From then on, $g$ is always the larger number ($3.166\,667>3.157\,895$ and $3.162\,281>3.162\,275$). The reason: the product $g\cdot(10/g)$ is always 10, so $\sqrt{10}$ always lies between the two numbers; and after one pass, $g$ is never too small again, as the Background box in Subsection 1.1 shows.

Exercise 2 ★ Form or meaning?

For each case, decide whether the syntax is violated, whether an allowed text means something other than intended, or whether the text is ambiguous.

  1. In Python: (3 + 4 / 2.

  2. In Python, the mean of 3 and 4 is to be computed: 3 + 4 / 2.

  3. In Python: 3 + * 4.

  4. A request: “Photograph the woman with the camera.”

  5. A program in C contains 7 / 2 and is supposed to give 3.5.

Solution

(a) Syntax violated: the opened parenthesis is never closed.

(b) An allowed text that means something other than intended. Python does multiplication and division before addition and subtraction, so $\textcolor{#1b7f4a}{3+4/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. What was meant is (3 + 4) / 2, with the value 3.5.

(c) Syntax violated: after +, a number is missing before * follows.

(d) Ambiguous: is the woman holding a camera in her hand, or are you supposed to use the camera? A human asks back or decides from the context; in a programming language, there must be no such spot.

(e) An allowed text that means something other than intended. Under the semantics of C, 7 / 2 with whole numbers gives 3, not 3.5. If you want 3.5 in C, you have to write at least one of the numbers with a decimal place, for instance 7.0 / 2.

Exercise 3 ★★ A recipe in machine instructions

The mean of three numbers $a$, $b$ and $c$ that are stored in memory is to be computed and stored in memory. Break the calculation down into instructions of the kind “fetch a number from memory”, “add”, “divide by a number” and “store in memory”, as in the example in Subsection 1.2. How many instructions do you need? Fetch each number only once.

Solution

One possible sequence:

  1. Fetch $a$ from memory.

  2. Fetch $b$ from memory.

  3. Add the two numbers; result $a+b$.

  4. Fetch $c$ from memory.

  5. Add $c$; result $a+b+c$.

  6. Divide the result by 3.

  7. Store the result in memory.

These are seven instructions: three for fetching, two additions, one division, one store. A single line of source code such as (a + b + c) / 3 therefore becomes several machine instructions. Exactly how many depends on the processor family; some processors, for example, can fetch a number from memory and add it in the same instruction.

From source code to execution: compiler and interpreter

Exercise 4 ★ Compiler, interpreter or CPython?

To which of the three kinds of programs does each statement apply: a compiler such as gcc, an interpreter that, like a human interpreter, translates line by line and runs each line immediately, or CPython? Several answers are possible.

  1. A file is produced that runs without the translating program.

  2. The program has to be present at every start.

  3. The entire source code is translated before the first statement is run.

  4. The processor runs the translation of the source code directly.

Solution

(a) Only the compiler: it produces an executable file. CPython creates the bytecode only in main memory, and the line-by-line interpreter (the one that works like a human interpreter) produces no translation result at all.

(b) The line-by-line interpreter and CPython. Both run the program themselves and therefore have to be present at every start.

(c) The compiler and CPython. In its first phase, CPython translates the entire file into bytecode before the first line runs. Only the line-by-line interpreter translates each line only when it gets to it.

(d) Only the compiler: its executable file contains machine code that the processor runs directly. CPython's bytecode is run not by the processor but by the interpreter loop; meanwhile, the processor runs the machine code of CPython.

Exercise 6 ★★ When is the error noticed?

A Python program has 1000 lines. Line 1000 is missing a closing parenthesis; all other lines are fine.

  1. How many lines does CPython run before it reports the error? Justify your answer with the two phases.

  2. How many lines would an interpreter run that really works like a human interpreter, that is, translates each line only when it gets to it?

  3. Which behavior would you prefer if the program overwrites a file in line 500? Why?

Solution

(a) Not a single one. In the first phase, CPython translates the entire file. The syntax error in line 1000 prevents bytecode from being produced, and without bytecode the second phase does not begin. The message appears before line 1 runs.

(b) 999 lines. Such an interpreter notices the error only when it gets to line 1000; it has already run everything before it.

(c) The behavior of CPython. With a line-by-line interpreter, the file would already have been overwritten in line 500 when the program aborts in line 1000: a half-finished state would be left behind. With CPython, a program with a syntax error does not even start running and therefore cannot leave anything half done. This does not protect against runtime errors, though: they occur only during execution.

Exercise 8 ★ Ordering versions

Order the version numbers from oldest to newest: 3.14.10, 3.9.18, 3.13.9, 3.14.4, 3.12.0. Which of them meet the requirement “Python 3.12 or later”? Why is it misleading to read the numbers as decimal numbers?

Solution

From oldest to newest: 3.9.18, 3.12.0, 3.13.9, 3.14.4, 3.14.10. All except 3.9.18 meet the requirement “Python 3.12 or later”.

You compare part by part, starting from the left: the major version is 3 everywhere; for the minor version, 9 is smaller than 12, 13 and 14; with the same minor version 14, the third number decides, and 4 is smaller than 10. Exercise 10 ★ Python as a calculator

Calculate in interactive mode and give the results with a sensible number of digits and with a unit.

  1. A car needs 45 liters of gasoline for 750 km. How many liters does it need for one kilometer?

  2. A square room with a side length of 4.5 m is to be tiled. A tile of 60 cm by 60 cm covers $0.36\,\mathrm m^2$. What is the minimum number of tiles you need? Compute the area with **.

  3. A hair on your head grows about 0.35 mm per day. How much does it grow in a year of 365 days? Calculate in meters and write the 0.35 mm with e for this.

  4. Directly after (a), continue calculating with _ and give the consumption in liters per 100 kilometers.

Solution
Terminal
>>> 45 / 750
0.06
>>> _ * 100
6.0
>>> 4.5 ** 2 / 0.36
56.25
>>> 365 * 3.5e-4
0.12775

(a) Liters divided by kilometers: $\textcolor{#1b7f4a}{45/750}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.06}$ liters per kilometer.

(b) The area of the room is $\textcolor{#1b7f4a}{4.5^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{20.25\,\mathrm m^2}$, and $\textcolor{#1b7f4a}{20.25/0.36}\textcolor{#15633a}{=}\textcolor{#c2410c}{56.25}$. Python computes the power first, so parentheses are not needed. You cannot buy partial tiles: you need at least 57 tiles, and the ones at the edge are cut to size.

(c) $\textcolor{#1b7f4a}{0.35\,\mathrm{mm}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.000\,35\,\mathrm m}\textcolor{#15633a}{=}\textcolor{#c2410c}{3.5\cdot10^{-4}\,\mathrm m}$, in Python 3.5e-4. In one year, that makes $0.127\,75\,\mathrm m$, or just under 13 cm.

(d) Directly after (a), _ holds the value 0.06; _ * 100 gives 6.0, that is, 6 liters per 100 kilometers. If you calculate (b) or (c) first, _ holds their result, because _ always holds only the most recently displayed value.

A script strecke.py produced the following output (in German, Tempo means speed, Fahrzeit travel time and Strecke distance):

Exercise 18 ★★ Finding a logic error

Anna and Ben buy a lottery ticket together. Anna pays €1, Ben €2. The ticket wins €12, and the prize is divided in proportion to the stakes: Ben's share is the prize times Ben's stake divided by the sum of both stakes.

gewinn.pyPython
# Prize 12 euros; stakes: Anna 1 euro, Ben 2 euros
# Ben's share = prize * Ben's stake / (Anna's stake + Ben's stake)
print("Bens Anteil in Euro:", 12 * 2 / 1 + 2)

  1. The script outputs Bens Anteil in Euro: 26.0. How can you tell without calculating that this cannot be right?

  2. Find the error and correct the line.

  3. Check the corrected formula with a case whose result you know.

Solution

(a) A share can never be larger than the whole prize, here €12. €26 for Ben is therefore impossible.

(b) The denominator lacks parentheses. Python computes $\textcolor{#1b7f4a}{12\cdot2/1+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{24+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{26}$. Correct:

Python
print("Bens Anteil in Euro:", 12 * 2 / (1 + 2))

Output: Bens Anteil in Euro: 8.0. Ben gets €8, Anna the remaining €4; that fits, because Ben paid in twice as much.

(c) With equal stakes, each must get exactly half: 12 * 1 / (1 + 1) gives 6.0. A second known case: if Ben pays much more than Anna, he gets almost the whole prize; if he pays nothing, he gets nothing.

Solution

From $\textcolor{#1b7f4a}{T(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{T_\mathrm Z-(T_\mathrm Z-T_0)\,\mathrm{e}^{-t/\tau}}$, it follows that $\textcolor{#1b7f4a}{T_\mathrm Z-T(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(T_\mathrm Z-T_0)\,\mathrm{e}^{-t/\tau}}$, and therefore

$$\textcolor{#1b7f4a}{T(t+\Delta t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{T_\mathrm Z-(T_\mathrm Z-T_0)\,\mathrm{e}^{-t/\tau}\,\mathrm{e}^{-\Delta t/\tau}}\textcolor{#15633a}{=}\textcolor{#c2410c}{T_\mathrm Z-\bigl(T_\mathrm Z-T(t)\bigr)\,\mathrm{e}^{-\Delta t/\tau}.}$$

So the distance to room temperature decreases by the same factor in every step, as with the tea.

    schritte = schritte + 1

Bisection works for every continuous function with a sign change.

  1. Use bisection to find the number $x$ with $\textcolor{#1b7f4a}{\cos x}\textcolor{#15633a}{=}\textcolor{#c2410c}{x}$ in the interval $[0,1]$, that is, the zero of $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos x-x}$, with $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-12}}$.   2. Likewise, find the zero of $x^3-x-1$ in $[1,2]$.

Solution

(a) $\textcolor{#1b7f4a}{f(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos0-0}\textcolor{#15633a}{=}\textcolor{#c2410c}{1>0}$ and $\textcolor{#1b7f4a}{f(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos1-1}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{-0.46<0}$: there is a sign change. bisektion_cos.pyPython
# Bisection for cos(x) = x, that is, the zero of f(x) = cos(x) - x in [0, 1]; here f(lo) > 0
import math
lo = 0.0                                  # f(0) = 1 > 0
hi = 1.0                                  # f(1) = cos(1) - 1 < 0
eps = 1e-12
schritte = 0
while hi - lo > eps:
    mitte = (lo + hi) / 2
    if math.cos(mitte) - mitte > 0:       # f(mitte) > 0: the zero lies to the right of mitte
        lo = mitte
    else:
        hi = mitte
    schritte = schritte + 1
x = (lo + hi) / 2
print("x =", x, "nach", schritte, "Schritten, cos(x) - x =", math.cos(x) - x)

With $\textcolor{#1b7f4a}{f(g)}\textcolor{#15633a}{=}\textcolor{#c2410c}{g^3-10}$ and $\textcolor{#1b7f4a}{f'(g)}\textcolor{#15633a}{=}\textcolor{#c2410c}{3g^2}$, the step is $\textcolor{#1b7f4a}{g_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g_n-\dfrac{g_n^3-10}{3g_n^2}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\dfrac13\Bigl(2g_n+\dfrac{10}{g_n^2}\Bigr)}$.

# Cube root of 10 with Newton: f(g) = g**3 - a, f'(g) = 3*g**2
