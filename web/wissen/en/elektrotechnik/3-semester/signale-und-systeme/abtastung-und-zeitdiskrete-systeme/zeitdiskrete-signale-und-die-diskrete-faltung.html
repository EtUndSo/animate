Stage 5: Discrete-time signals and discrete convolution

What this stage is about:

From now on, all calculations use only the sequences of numbers $s(n)$. This stage carries convolution, elementary signals and LTI systems over to sequences.

Convolution of the samples. If the input $s$ and the impulse response $h$ of a system are low-pass signals and sampling is at the Nyquist rate, each can be written as an si series (3.3). Because $\textcolor{#1b7f4a}{\operatorname{si}(\pi t/T)*\operatorname{si}(\pi t/T)}\textcolor{#15633a}{=}\textcolor{#c2410c}{T\operatorname{si}(\pi t/T)}$ (Chapter 3), the samples of the output follow from the samples alone:

$$\textcolor{#1b7f4a}{g(nT)}\textcolor{#15633a}{=}\textcolor{#c2410c}{T\sum_{m=-\infty}^{\infty}s(mT)\,h\bigl((n-m)T\bigr).}$$

Normalized to $\textcolor{#1b7f4a}{T}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, this is the discrete convolution:

$$\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{m=-\infty}^{\infty}s(m)\,h(n-m)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)*h(n).}$$
(5.1)

Elementary sequences.

$$\textcolor{#1b7f4a}{\delta(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{cases}1&n=0\\0&n\neq0\end{cases},}$$
$$\textcolor{#1b7f4a}{\varepsilon(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{m=-\infty}^n\delta(m)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{cases}0&n<0\\1&n\ge0\end{cases},}$$
$$\varepsilon(n)\,a^n,$$
$$\mathrm{e}^{\mathrm{j}2\pi Fn}.$$

The unit impulse $\delta(n)$ is an ordinary sequence, not a distribution: it has the value 1 at $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. It is the identity element of discrete convolution, $\textcolor{#1b7f4a}{s(n)*\delta(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)}$. A rectangle of $2M+1$ ones around $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ is $\varepsilon(n+M)-\varepsilon(n-M-1)$.

Linear and shift-invariant. A discrete-time system is called linear if the superposition principle holds, and shift-invariant if $\textcolor{#1b7f4a}{\operatorname{Tr}\{s(n-m)\}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g(n-m)}$ for every integer $m$. A system with both properties is called an LSI system. With the impulse response $\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{Tr}\{\delta(n)\}}$ it follows, as in Chapter 1, that

$$\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{Tr}\Bigl\{\sum_ms(m)\delta(n-m)\Bigr\}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ms(m)\operatorname{Tr}\{\delta(n-m)\}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ms(m)\,h(n-m).}$$

No limit process is needed here: a sequence already is a sum of weighted, shifted unit impulses.

Difference and sum. The counterpart of the derivative is the difference $\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)-s(n-1)}$, so $\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\delta(n)-\delta(n-1)}$. The counterpart of the integral is the accumulation $\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{m\le n}s(m)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)*\varepsilon(n)}$. The two cancel each other: $\textcolor{#1b7f4a}{[\delta(n)-\delta(n-1)]*\varepsilon(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varepsilon(n)-\varepsilon(n-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\delta(n)}$.

Difference equations, FIR and IIR. Instead of differential equations, difference equations describe discrete-time systems:

$$\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\underbrace{\sum_{q=0}^{Q}a_q\,s(n-q)}_{\text{FIR part}}+\underbrace{\sum_{p=1}^{P}b_p\,g(n-p)}_{\text{IIR part}}.}$$
(5.2)

The output is a weighted sum of past input and output values. If it depends only on input values ($\textcolor{#1b7f4a}{b_p}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$), the impulse response ends after $Q+1$ values: an FIR filter (finite impulse response). With feedback ($b_p\neq0$) the impulse response can be infinitely long: an IIR filter (infinite impulse response). Both are built from delay elements (memory for one clock cycle), multipliers and adders (Fig. 4).

Exercise 4 ★ Discrete convolution by hand

Convolve $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,1,1)}$ with $\textcolor{#1b7f4a}{h}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,2)}$, both starting at $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. How long is the result, and why?

Solution

$\textcolor{#1b7f4a}{g(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{g(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot2+1\cdot1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{g(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{g(3)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$: $(1,3,3,2)$. Length $\textcolor{#1b7f4a}{3+2-1}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$: the last nonzero value arises when the last value of $h$ meets the last value of $s$.
