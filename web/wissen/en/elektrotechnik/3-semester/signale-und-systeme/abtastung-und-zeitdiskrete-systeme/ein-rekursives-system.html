What this stage is about:

The simplest IIR system shows how feedback produces an infinitely long impulse response and when the system is stable.

The system $\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)+b\,g(n-1)}$ adds the last output, weighted by $b$, to the input. For $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{\delta}$ and a system at rest before $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$:

$$\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\delta(n)+b\,h(n-1)\quad\Longrightarrow\quad h(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\ h(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{b,\ h(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{b^2,\dots\quad\Longrightarrow\quad h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varepsilon(n)\,b^n.}$$
(6.1)

The impulse circulates in the feedback loop again and again and is multiplied by $b$ each time. The system is causal ($\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for $n<0$). It is stable if $\sum_n|h(n)|<\infty$ (the discrete counterpart of Chapter 1), so here exactly for $|b|<1$, with $\textcolor{#1b7f4a}{\sum_n|b|^n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{1-|b|}}$.

Response to a rectangular sequence. Input $\textcolor{#1b7f4a}{s(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varepsilon(n)-\varepsilon(n-M)}$ ($M$ ones). With the convolution sum and the formula for the geometric sum $\textcolor{#1b7f4a}{\sum_{k=0}^nq^k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1-q^{n+1}}{1-q}}$:

$$\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{cases}0&n<0,\\[2pt]\displaystyle\sum_{m=0}^{n}b^{n-m}=\frac{1-b^{n+1}}{1-b}&0\le n<M,\\[8pt]\displaystyle\sum_{m=0}^{M-1}b^{n-m}=\frac{b^{n-M+1}-b^{n+1}}{1-b}&n\ge M.\end{cases}}$$
(6.2)

In the reference model ($\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6}$, $\textcolor{#1b7f4a}{M}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$): $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\ 1.6,\ 1.96,\ 2.176}$, then $1.306,\ 0.783,\ 0.470,\dots$, each value 0.6 times the previous one (Fig. 5). This is the discrete counterpart of the response of the RC circuit to a rectangular pulse in Chapter 1.

Exercise 5 ★★ Investigating the recursive system

  1. Confirm the first five values of $g(n)$ in the reference model directly with the recursion.

  2. What value does the output approach for an infinitely long sequence of ones ($M\to\infty$)? Compare with $\sum_nh(n)$.

  3. What does $h(n)$ look like for $\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{-0.6}$ and for $\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.1}$? Which system is stable?

Solution

(a) $\textcolor{#1b7f4a}{g(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{g(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+0.6}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.6}$, $\textcolor{#1b7f4a}{g(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+0.96}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.96}$, $\textcolor{#1b7f4a}{g(3)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+1.176}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.176}$, $\textcolor{#1b7f4a}{g(4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0+0.6\cdot2.176}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.306}$.

(b) $\textcolor{#1b7f4a}{\frac{1}{1-b}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.5}$. This is $\textcolor{#1b7f4a}{\sum_nh(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum0.6^n}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.5}$: for a constant input 1, the convolution sums all values of the impulse response. Also, $\textcolor{#1b7f4a}{H_\mathrm a(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.5}$.

(c) $\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{-0.6}$: $1,\ -0.6,\ 0.36,\ -0.216,\dots$, alternating sign, decaying, stable. $\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.1}$: $1,\ 1.1,\ 1.21,\dots$, growing, unstable.

Exercise 6 ★★ First-order system

$\textcolor{#1b7f4a}{g(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(n)+0.5\,s(n-1)+0.6\,g(n-1)}$ (Fig. 4 with $\textcolor{#1b7f4a}{a_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{a_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.5}$, $\textcolor{#1b7f4a}{b_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6}$).

  1. Compute $h(0)$ to $h(3)$ with the recursion.

  2. Show that $\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{11}{6}\,0.6^n\varepsilon(n)-\frac56\delta(n)}$.

Solution

(a) $\textcolor{#1b7f4a}{h(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{h(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.5+0.6\cdot1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.1}$, $\textcolor{#1b7f4a}{h(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6\cdot1.1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.66}$, $\textcolor{#1b7f4a}{h(3)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.396}$.

(b) The formula gives $\textcolor{#1b7f4a}{h(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{11}{6}-\frac56}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ and $\textcolor{#1b7f4a}{h(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{11}{6}\cdot0.6}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.1}$. From $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ on, the input is zero, the recursion reads $\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6\,h(n-1)}$, and the formula satisfies it, because $\textcolor{#1b7f4a}{\frac{11}{6}0.6^n}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6\cdot\frac{11}{6}0.6^{n-1}}$. (With the z-transform, the formula follows from the decomposition $\textcolor{#1b7f4a}{H(z)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\frac56+\frac{11/6}{1-0.6z^{-1}}}$.)

Summary

Terms
  • causal – The system is causal ($\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for $n<0$).
  • stable – The system is causal ($\textcolor{#1b7f4a}{h(n)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for $n<0$). It is stable if $\sum_n|h(n)|<\infty$ (the discrete counterpart of Chapter 1), so here exactly for $|b|<1$, with $\textcolor{#1b7f4a}{\sum_n|b|^n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{1-|b|}}$.
