Stage 9: Causal and stable

What this stage is about:

Two properties that every real system should have can be read directly from $h(t)$.

Definition 9.1 (Causal, stable)

A system is called causal if the output does not begin before the input. For an LTI system this means

$$\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0\quad\text{for }t<0.}$$
(9.1)

A system is called stable (more precisely, BIBO stable, bounded input, bounded output) if it responds to every bounded input $|s(t)|\le A<\infty$ with a bounded output.

Causal: an impulse at time 0 cannot have any effect before that time. In the convolution, only impulses from the past then contribute, $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_{-\infty}^ts(\tau)h(t-\tau)\mathrm{d}\tau}$.

Theorem 9.2 (Stability condition)

An LTI system is stable if and only if its impulse response is absolutely integrable:

$$\int_{-\infty}^{\infty}|h(\tau)|\,\mathrm{d}\tau<\infty.$$
(9.2)
Derivation: Stability condition

⁠Sufficient. With the triangle inequality for integrals and $|s|\le A$:

$$\textcolor{#1b7f4a}{|g(t)|}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl|\int h(\tau)\,s(t-\tau)\,\mathrm{d}\tau\Bigr|\le\int|h(\tau)|\,|s(t-\tau)|\,\mathrm{d}\tau\le A\int|h(\tau)|\,\mathrm{d}\tau.}$$

If the integral is finite, $g$ is bounded.

⁠Necessary. If $\textcolor{#1b7f4a}{\int|h|}\textcolor{#15633a}{=}\textcolor{#c2410c}{\infty}$, choose the least favorable bounded input: $\textcolor{#1b7f4a}{s(t_1-\tau)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{sign}h(\tau)}$, that is, always $\pm1$ with the sign of $h$. Then $\textcolor{#1b7f4a}{g(t_1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int|h(\tau)|\,\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{\infty}$, although $|s|\le1$.

Examples: the RC circuit has $\textcolor{#1b7f4a}{\int|h|}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ and is stable. The ideal delay element ($\textcolor{#1b7f4a}{\int|\delta(t-t_0)|\mathrm{d} t}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$) is stable. The integrator has $\textcolor{#1b7f4a}{\int_0^\infty\varepsilon\,\mathrm{d} t}\textcolor{#15633a}{=}\textcolor{#c2410c}{\infty}$ and is unstable: it responds to the bounded step with the unbounded ramp $t\,\varepsilon(t)$.

Exercise 10 ★★ Causal? Stable?

Examine (a) $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-2t}\varepsilon(t)}$, (b) $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{t}\varepsilon(t)}$, (c) $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varepsilon(t)-\varepsilon(t-1)}$, (d) $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-|t|}}$, (e) $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\delta(t+1)}$. For each unstable system, give a bounded input that produces an unbounded output.

Solution

(a) Causal, $\textcolor{#1b7f4a}{\int|h|}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}$: stable.

(b) Causal, $\textcolor{#1b7f4a}{\int_0^\infty\mathrm{e}^t\mathrm{d} t}\textcolor{#15633a}{=}\textcolor{#c2410c}{\infty}$: unstable. The step $\varepsilon(t)$ produces $\textcolor{#1b7f4a}{\int_0^t\mathrm{e}^\tau\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^t-1}$, which is unbounded.

(c) Causal, $\textcolor{#1b7f4a}{\int|h|}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$: stable. The system forms the integral of the input over the last second (sliding window).

(d) Not causal, because $h(t)\neq0$ for $t<0$. $\textcolor{#1b7f4a}{\int\mathrm{e}^{-|t|}\mathrm{d} t}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$: stable.

(e) $\delta(t+1)$ acts at $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{-1<0}$: $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(t+1)}$; the system “sees” the input one second in advance. Not causal, but stable ($\textcolor{#1b7f4a}{\int|h|}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$).
