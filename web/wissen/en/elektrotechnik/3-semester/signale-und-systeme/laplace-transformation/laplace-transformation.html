What this is about#

The reference model for this chapter

All examples use the same two ingredients:

  • an RC low-pass filter with $\textcolor{#1b7f4a}{RC}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ s (for example $\textcolor{#1b7f4a}{R}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\,\mathrm{M\Omega}}$, $\textcolor{#1b7f4a}{C}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\,\mu\text{F}}$). Its impulse response and its transfer function are

    $$\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{RC}\,\mathrm{e}^{-t/RC}\varepsilon(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-t}\varepsilon(t),}$$
    $$\textcolor{#1b7f4a}{H(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{1+pRC}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{p+1},\quad \operatorname{Re} p>-1,}$$

    with $t$ in s and $p$ in $1/\mathrm{s}$;

  • the unit step $\textcolor{#1b7f4a}{s(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varepsilon(t)}$ with $\textcolor{#1b7f4a}{S(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/p}$ for $\operatorname{Re} p>0$.

The script rechnung_kap2.py recomputes the numbers and curves.
