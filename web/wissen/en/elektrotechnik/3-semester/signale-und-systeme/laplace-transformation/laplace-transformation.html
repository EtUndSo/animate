What this is about

QuestionI understand the calculation that leads from the convolution integral with an eigenfunction to $H(p)$. But I think there is much more behind the Laplace transform than this rule of calculation: that any function can be written as a sum of complex exponentials.

This conjecture goes to the heart of the matter. Without it, the eigenfunction calculation would be a mere curiosity, because by itself it holds only for the one signal $\mathrm{e}^{pt}$. Only because (almost) every signal can be built from such building blocks does it tell us something about every input signal. Three refinements make the conjecture exact:

  1. In general it is not a sum but an integral: infinitely many building blocks $\mathrm{e}^{pt}$, each with an infinitesimal weight. The building blocks lie on a vertical line $\textcolor{#e5383b}{\operatorname{Re} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma}$ in the $p$-plane (Stage 2).

  2. Not every function, but every function for which a region of convergence exists: it may grow at most exponentially on each side of the time axis, and a single damping must tame both sides at once (Section 2.3).

  3. If $S(p)$ is a ratio of polynomials, the integral really does become a finite sum $\sum_r A_r\,\mathrm{e}^{p_r t}$. The exponents $p_r$ are the poles of $S(p)$ (Stage 4).

The answer in three sentences (by the end of the article they should feel obvious)

  1. An LTI system can only multiply the building block $\mathrm{e}^{pt}$ by a number $H(p)$, because for $\mathrm{e}^{pt}$ shifting is the same as multiplying.

  2. Every signal with a region of convergence is a superposition of such building blocks. $S(p)$ gives the weight with which the building block $\mathrm{e}^{pt}$ is contained in the signal.

  3. This is why convolution becomes multiplication, $\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(p)\,S(p)}$. If $S(p)$ is rational, the signal is a finite sum $\sum_r A_r\mathrm{e}^{p_r t}$ with the poles as exponents.

The reference model for this article

All examples use the same two ingredients:

  • an RC low-pass filter with $\textcolor{#e5383b}{RC}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ s (for example $\textcolor{#e5383b}{R}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1\,\mathrm{M\Omega}}$, $\textcolor{#e5383b}{C}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1\,\mu\text{F}}$). Its impulse response and its transfer function are

    $$\textcolor{#e5383b}{h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{RC}\,\mathrm{e}^{-t/RC}\varepsilon(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-t}\varepsilon(t),}$$

  • the unit step $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\varepsilon(t)}$ with $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/p}$ for $\operatorname{Re} p>0$.

Stage 1: Why $\mathrm{e}^{pt}$ in particular

What this stage is about:

If you insert $\mathrm{e}^{pt}$ into the convolution integral, the result is $H(p)\,\mathrm{e}^{pt}$: $\mathrm{e}^{pt}$ is an eigenfunction. This stage asks which property of $\mathrm{e}^{pt}$ forces this and why the building blocks have to be complex.

The idea. The convolution integral

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}h(\tau)\,s(t-\tau)\,\mathrm{d}\tau}$$

reads as follows: the output is a sum of delayed copies of the input. The copy with delay $\tau$ enters with the weight $h(\tau)\,\mathrm{d}\tau$. For an arbitrary signal shape, each delayed copy looks different from the original, and the sum has a new shape. Not so for $\mathrm{e}^{pt}$:

$$\textcolor{#e5383b}{\mathrm{e}^{p(t-\tau)}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-p\tau}\cdot\mathrm{e}^{pt}.}$$

A delay by $\tau$ acts like multiplication by the constant number $\mathrm{e}^{-p\tau}$. All copies are multiples of the same function $\mathrm{e}^{pt}$, and so is their sum:

$$\textcolor{#e5383b}{\mathrm{e}^{pt}*h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{pt}\underbrace{\int_{-\infty}^{\infty}h(\tau)\,\mathrm{e}^{-p\tau}\,\mathrm{d}\tau}_{H(p)}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(p)\,\mathrm{e}^{pt}.}$$
(1.1)

⁠In short: $\mathrm{e}^{pt}$ is an eigenfunction because for $\mathrm{e}^{pt}$ shifting is the same as multiplying.

What $p$ means. With $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma+\mathrm{j}2\pi f}$ the building block splits into two factors:

$$\textcolor{#e5383b}{\mathrm{e}^{pt}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{\sigma t}\cdot\mathrm{e}^{\mathrm{j}2\pi ft}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{\sigma t}\bigl[\cos(2\pi ft)+\mathrm{j}\sin(2\pi ft)\bigr].}$$

The real part $\sigma$ (in $1/\mathrm s$) is the growth rate: for $\sigma<0$ the building block decays, for $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ it oscillates with constant amplitude, for $\sigma>0$ it grows. The imaginary part $2\pi f$ sets the frequency of the oscillation. So every point of the $p$-plane is a building block, and the position of the point tells you what it looks like (Fig. 1).

QuestionWhy complex? A sine is a simple signal too.

When a sine is shifted, it is not just scaled. With $\textcolor{#e5383b}{\omega_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2\pi f_0}$,

$$\textcolor{#e5383b}{\sin\bigl(\omega_0(t-\tau)\bigr)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\cos(\omega_0\tau)\,\sin(\omega_0t)-\sin(\omega_0\tau)\,\cos(\omega_0t).}$$

A cosine component appears, so the delayed copy has a different shape. This is why a system responds to $\sin(\omega_0t)$ with $|H|\sin(\omega_0t+\varphi)$: amplitude and phase change. A phase shift cannot be written as multiplication by a real number, but it can be written as multiplication by the complex number $\mathrm{e}^{\mathrm{j}\varphi}$. That is why the building blocks are complex: the single number $H(p)$ carries magnitude and phase. A real sine consists of two building blocks, $\textcolor{#e5383b}{\sin(\omega_0t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\bigl(\mathrm{e}^{\mathrm{j}\omega_0t}-\mathrm{e}^{-\mathrm{j}\omega_0t}\bigr)/(2\mathrm{j})}$, and each of them is multiplied by its own number (Exercise 1d).

QuestionWhy is $\mathrm{e}^{pt}$ an eigenfunction of every LTI system, even though the systems are so different?

The form of the eigenfunction follows from time invariance alone (shifting = multiplying), and all LTI systems share that property. Only the factor $H(p)$ depends on the system, because the weights $h(\tau)$ enter into it. So one set of building blocks serves all LTI systems at once. That is what makes the Laplace transform universal.

Going deeper, not needed for the rest: Only exponential functions have this property

We look for a differentiable function $x(t)$ with $\textcolor{#e5383b}{x(0)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ whose shifted copies are multiples of itself: $\textcolor{#e5383b}{x(t+u)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{c(u)\,x(t)}$ for all $t,u$. Setting $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ gives $\textcolor{#e5383b}{c(u)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{x(u)}$, so $\textcolor{#e5383b}{x(t+u)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{x(t)\,x(u)}$. Differentiating with respect to $u$ at $\textcolor{#e5383b}{u}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ gives $\textcolor{#e5383b}{x'(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{x'(0)\,x(t)}$. This is the differential equation $\textcolor{#e5383b}{x'}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{p\,x}$ with $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{x'(0)}$, and its solution with $\textcolor{#e5383b}{x(0)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ is $\textcolor{#e5383b}{x(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{pt}}$. So there are no other building blocks with this property.

QuestionAre exponential functions the only possible eigenfunctions of LTI systems?

Two questions have to be kept apart.

⁠**Eigenfunction of all LTI systems at once: yes, only $c\,\mathrm{e}^{pt}$.** The ideal delay element $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{s(t-u)}$ is itself an LTI system, for every delay $u$. A function that is an eigenfunction of every LTI system must therefore turn into a multiple of itself under every shift. By the box above, only $\mathrm{e}^{pt}$ does that.

⁠**Eigenfunction of one particular system: not only.** The system multiplies each building block $\mathrm{e}^{p_kt}$ by its own number $H(p_k)$. A sum $\sum_kc_k\mathrm{e}^{p_kt}$ stays a multiple of itself exactly when all these factors are equal, $\textcolor{#e5383b}{H(p_k)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\lambda}$. The common factor $\lambda$ is then the eigenvalue. Two examples:

  • Ideal delay element by $T$: $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-pT}}$ has the same value 1 at all points $\textcolor{#e5383b}{p_k}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{j}2\pi k/T}$. Every signal with period $T$ is an eigenfunction with eigenvalue 1, because $\textcolor{#e5383b}{s(t-T)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{s(t)}$.

  • Ideal low-pass filter without delay, $\textcolor{#e5383b}{H(f)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ in the whole passband: every signal whose spectrum lies entirely in the passband comes out unchanged and is an eigenfunction with eigenvalue 1.

For the RC circuit, on the other hand, $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/(1+pRC)}$ takes each value only once. There the single $c\,\mathrm{e}^{pt}$ (with $p$ in the region of convergence) are the only eigenfunctions that can be built from building blocks.

⁠In short: $\mathrm{e}^{pt}$ is the only eigenfunction that every LTI system has. A single system can also have mixtures of building blocks as eigenfunctions if it multiplies all of these building blocks by the same number.

Exercise 1 ★ Eigenfunction or not?

Use the RC low-pass filter of the reference model, $\textcolor{#e5383b}{h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-t}\varepsilon(t)}$.

  1. Compute $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int h(t)\,\mathrm{e}^{-pt}\mathrm{d} t}$. For which $p$ does the integral converge, and why does this depend only on $\operatorname{Re} p$?

  2. Input $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-t/2}}$ for all $t$. Compute the output once directly with the convolution integral and once with $H(p)$. Which $p$ does this building block have?

  3. Input $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{t}$ for all $t$. Use the convolution integral to show that the output is $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{t-1}$. Why is $t$ not an eigenfunction, even though the output looks similar? What does the $-1$ mean for the capacitor?

  4. Input $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\cos t}$ (so $\textcolor{#e5383b}{\omega_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/\mathrm s}$). Decompose the cosine into two building blocks, multiply each by its $H(p)$ and put them back together. Show that $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{A\cos(t+\varphi)}$, and find $A$ and $\varphi$. Is $\cos t$ an eigenfunction?

⁠Hint for (c): $\textcolor{#e5383b}{\int_0^\infty\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ and $\textcolor{#e5383b}{\int_0^\infty\tau\,\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$.

Solution

(a) $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_0^\infty\mathrm{e}^{-\tau}\mathrm{e}^{-p\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_0^\infty\mathrm{e}^{-(p+1)\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{1}{p+1}}$. The integral converges if and only if $\textcolor{#e5383b}{|\mathrm{e}^{-(p+1)\tau}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-(\sigma+1)\tau}}$ decays, that is, for $\operatorname{Re} p>-1$. The magnitude depends only on $\sigma$ because $\textcolor{#e5383b}{|\mathrm{e}^{-\mathrm{j}2\pi f\tau}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$.

(b) Directly:

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_0^\infty\mathrm{e}^{-\tau}\,\mathrm{e}^{-(t-\tau)/2}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-t/2}\int_0^\infty\mathrm{e}^{-\tau/2}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2\,\mathrm{e}^{-t/2}.}$$

With $H(p)$: the building block has $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\tfrac12}$ (real, no oscillation). This value lies in the region of convergence, $\textcolor{#e5383b}{H(-\tfrac12)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/(\tfrac12)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2}$, so $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2\,\mathrm{e}^{-t/2}}$. Both routes agree (numerically: $\textcolor{#e5383b}{g(1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1.2131}$).

(c) $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_0^\infty\mathrm{e}^{-\tau}(t-\tau)\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{t\int_0^\infty\mathrm{e}^{-\tau}\mathrm{d}\tau-\int_0^\infty\tau\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{t-1}$. This is not a multiple of $t$: the delayed copies $t-\tau$ are not multiples of $t$ (the factor $1-\tau/t$ depends on $t$ itself). The output is the shifted ramp: the capacitor voltage follows the input ramp with a delay of $\textcolor{#e5383b}{RC}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ s. Same shape, but shifted instead of scaled, so not an eigenfunction.

(d) $\textcolor{#e5383b}{\cos t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\tfrac12\mathrm{e}^{\mathrm{j} t}+\tfrac12\mathrm{e}^{-\mathrm{j} t}}$, building blocks at $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\pm\mathrm{j}}$, both in the region of convergence ($\textcolor{#e5383b}{\operatorname{Re} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0>-1}$).

$$\textcolor{#e5383b}{H(\mathrm{j})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{1+\mathrm{j}}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{\sqrt2}\,\mathrm{e}^{-\mathrm{j}\pi/4},}$$
$$\textcolor{#e5383b}{H(-\mathrm{j})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(\mathrm{j})^*}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{\sqrt2}\,\mathrm{e}^{+\mathrm{j}\pi/4}.}$$

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\tfrac12H(\mathrm{j})\mathrm{e}^{\mathrm{j} t}+\tfrac12H(-\mathrm{j})\mathrm{e}^{-\mathrm{j} t}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\operatorname{Re}\bigl\{H(\mathrm{j})\mathrm{e}^{\mathrm{j} t}\bigr\}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{\sqrt2}\cos\Bigl(t-\frac\pi4\Bigr).}$$

So $\textcolor{#e5383b}{A}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/\sqrt2}\textcolor{#2b6def}{\approx}\textcolor{#ff9f1c}{0.707}$ and $\textcolor{#e5383b}{\varphi}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-45^\circ}$ (numerically: $\textcolor{#e5383b}{g(1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.6909}$). Each of the two complex building blocks is an eigenfunction, but their sum $\cos t$ is not: the two building blocks are multiplied by different numbers, $H(\mathrm{j})\neq H(-\mathrm{j})$. This shifts the phase.

Stage 2: A signal made entirely of building blocks

What this stage is about:

Stage 1 applies to a single building block. It becomes useful only if every signal can be built from building blocks $\mathrm{e}^{pt}$. This stage shows that this works, what the weights are called and where the limits lie.

Starting point $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$: pure oscillations

On the imaginary axis ($\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$) the building blocks are pure oscillations $\mathrm{e}^{\mathrm{j}2\pi ft}$. An absolutely integrable signal ($\int|s(t)|\,\mathrm{d} t<\infty$, so it decays fast enough on both sides) can be built from them. This is the Fourier representation, which is treated in detail in the part on the Fourier transform:

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}\mathcal{F}\{s\}(f)\,\mathrm{e}^{\mathrm{j}2\pi ft}\,\mathrm{d} f,}$$
$$\textcolor{#e5383b}{\mathcal{F}\{s\}(f)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}s(t)\,\mathrm{e}^{-\mathrm{j}2\pi ft}\,\mathrm{d} t.}$$

For many signals in system theory this is not enough. The step $\varepsilon(t)$ does not decay, and $\mathrm{e}^{2t}\varepsilon(t)$ (the impulse response of an unstable system) even grows. A signal that grows without bound cannot be built from oscillations of constant amplitude.

The trick: damp, decompose, multiply back

The idea. First make the signal decomposable, then undo the change afterwards:

  1. ⁠Damp. Multiply by $\mathrm{e}^{-\sigma t}$. If a right-sided signal grows at most like $\mathrm{e}^{\alpha t}$, then $s(t)\,\mathrm{e}^{-\sigma t}$ decays for every $\sigma>\alpha$ and is absolutely integrable.

  2. ⁠Decompose. The damped signal is a superposition of pure oscillations. Its Fourier spectrum is exactly the Laplace transform $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int s(t)\,\mathrm{e}^{-pt}\mathrm{d} t}$ on the line $\textcolor{#e5383b}{\operatorname{Re} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma}$ (Exercise 2):

    $$\textcolor{#e5383b}{\mathcal{F}\bigl\{s(t)\,\mathrm{e}^{-\sigma t}\bigr\}(f)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(\sigma+\mathrm{j}2\pi f).}$$

  3. ⁠Multiply back. Multiply the decomposition by $\mathrm{e}^{\sigma t}$. The factor does not depend on $f$ and may be moved inside the integral. There it turns each oscillation $\mathrm{e}^{\mathrm{j}2\pi ft}$ into the building block $\textcolor{#e5383b}{\mathrm{e}^{(\sigma+\mathrm{j}2\pi f)t}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{pt}}$.

The result is the conjectured superposition.

Theorem 2.1 (Inversion formula of the Laplace transform)

If $\sigma$ lies in the region of convergence of $S(p)$, then

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}S(p)\,\mathrm{e}^{pt}\,\mathrm{d} p }\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}S(\sigma+\mathrm{j}2\pi f)\,\mathrm{e}^{(\sigma+\mathrm{j}2\pi f)t}\,\mathrm{d} f.}$$
(2.1)

⁠How to read it:

  • The path of integration is the vertical line $\textcolor{#e5383b}{\operatorname{Re} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma}$ in the $p$-plane, traversed from bottom to top ($f$ from $-\infty$ to $+\infty$, Fig. 2).

  • $\mathrm{e}^{pt}$ is the building block, and $\textcolor{#e5383b}{S(p)\,\mathrm{d} p/(2\pi\mathrm{j})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(\sigma+\mathrm{j}2\pi f)\,\mathrm{d} f}$ is its complex weight. $S(p)$ itself is a density: weight per frequency interval. If $s$ is a voltage in V, $S$ has the unit V s.

  • The integral is meant as the limit $\lim_{F\to\infty}\int_{-F}^{F}\dots\mathrm{d} f$. It returns $s(t)$ at every point where $s$ is continuous, and at a jump it returns the mean of the left-hand and right-hand limits.

⁠Limiting case $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$: If the imaginary axis lies in the region of convergence, you may choose $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$. Then $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{j}2\pi f}$, and (2.1) becomes the Fourier inversion formula. The Laplace transform contains the Fourier transform as a special case.

Derivation: Inversion formula from the Fourier inversion formula

By step 2, $S(\sigma+\mathrm{j}2\pi f)$ is the Fourier spectrum of $s(t)\mathrm{e}^{-\sigma t}$. The Fourier inversion formula gives

$$\textcolor{#e5383b}{s(t)\,\mathrm{e}^{-\sigma t}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}S(\sigma+\mathrm{j}2\pi f)\,\mathrm{e}^{\mathrm{j}2\pi ft}\,\mathrm{d} f.}$$

Multiply by $\mathrm{e}^{\sigma t}$, which does not depend on $f$:

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_{-\infty}^{\infty}S(\sigma+\mathrm{j}2\pi f)\,\mathrm{e}^{(\sigma+\mathrm{j}2\pi f)t}\,\mathrm{d} f.}$$

Substitute $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma+\mathrm{j}2\pi f}$ with $\sigma$ fixed: $\textcolor{#e5383b}{\mathrm{d} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{j}2\pi\,\mathrm{d} f}$, so $\textcolor{#e5383b}{\mathrm{d} f}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{d} p/(2\pi\mathrm{j})}$. The limits $\textcolor{#e5383b}{f}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mp\infty}$ become $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma\mp\mathrm{j}\infty}$:

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}S(p)\,\mathrm{e}^{pt}\,\mathrm{d} p.}$$

Example: the step from building blocks. For $\varepsilon(t)$, $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/p}$ with $\operatorname{Re} p>0$. We choose $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.5/\mathrm s}$ (Fig. 2). Figure 3 shows the result of superposing only the building blocks with $|f|\le F$. Already at $\textcolor{#e5383b}{F}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.25}$ Hz the shape of the step is recognizable. As $F$ grows, the edge becomes steeper; at $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ the curve tends to the mean value $\tfrac12$ (0.40, 0.47, 0.49), and at $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-1}$ s it tends to zero (0.053, 0.029, 0.008).

QuestionAll building blocks are complex. Why does a real curve come out?

The building blocks come in pairs: $f$ goes with $-f$, so $p$ goes with the conjugate point $p^*$. For a real signal the weight there is the complex conjugate, $\textcolor{#e5383b}{S(p^*)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(p)^*}$ (computing $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int s(t)\mathrm{e}^{-pt}\mathrm{d} t}$ with real $s$ shows this). Each pair gives $\textcolor{#e5383b}{S\mathrm{e}^{pt}+(S\mathrm{e}^{pt})^*}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2\operatorname{Re}\{S(p)\mathrm{e}^{pt}\}}$, a real damped or growing oscillation. The imaginary parts cancel in pairs.

QuestionSo is it a sum or an integral?

In general an integral: the line carries a continuum of building blocks, each with an infinitesimal weight $S\,\mathrm{d} f$. A true sum with finitely many terms arises in one important case: when $S(p)$ is a ratio of polynomials. Then the signal is a sum of building blocks at the poles (Stage 4). A sum with infinitely many terms is the Fourier series of a periodic signal.

Region of convergence: which damping rates work

The idea. The factor $\mathrm{e}^{-\sigma t}$ acts on both sides of the time axis, but in opposite ways. For $t\to+\infty$ it damps more strongly the larger $\sigma$ is. For $t\to-\infty$, $\textcolor{#e5383b}{\mathrm{e}^{-\sigma t}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{\sigma|t|}}$, so there a large $\sigma$ amplifies. This gives the three shapes of the region of convergence:

  • ⁠right-sided signal, $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ for $t<0$, growing at most like $\mathrm{e}^{\alpha t}$: every $\sigma>\alpha$ works. Region of convergence: the half-plane to the right of a boundary.

  • ⁠left-sided signal: only the side $t\to-\infty$ matters, and small $\sigma$ help. Region of convergence: a half-plane to the left of a boundary.

  • ⁠two-sided signal: both conditions must hold at once. Region of convergence: a strip, which may also be empty.

Why are the boundaries always vertical? Because $\textcolor{#e5383b}{|\mathrm{e}^{-pt}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-\sigma t}}$. Whether $\int|s(t)\mathrm{e}^{-pt}|\mathrm{d} t$ is finite depends only on $\sigma$, never on $f$.

⁠In short: The region of convergence is the set of all damping rates $\sigma$ for which $s(t)\,\mathrm{e}^{-\sigma t}$ becomes absolutely integrable.

The basic transform pairs (used throughout the article)

For any complex number $p_0$:

$$\begin{aligned} \mathrm{e}^{p_0t}\,\varepsilon(t)\quad&\longleftrightarrow\quad\frac{1}{p-p_0},&&\operatorname{Re} p>\operatorname{Re} p_0,\\ -\mathrm{e}^{p_0t}\,\varepsilon(-t)\quad&\longleftrightarrow\quad\frac{1}{p-p_0},&&\operatorname{Re} p<\operatorname{Re} p_0,\\ \delta(t)\quad&\longleftrightarrow\quad1,&&\text{all }p,\\ t\,\varepsilon(t)\quad&\longleftrightarrow\quad\frac{1}{p^2},&&\operatorname{Re} p>0. \end{aligned}$$
(2.2)(2.3)(2.4)(2.5)

With $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$, (2.2) gives the step: $\varepsilon(t)\leftrightarrow1/p$ for $\operatorname{Re} p>0$. The first two lines have the same expression and different regions of convergence: only the expression and the region of convergence together determine the signal.

Derivation: Basic transform pairs

(2.2): $\textcolor{#e5383b}{\int_0^\infty\mathrm{e}^{-(p-p_0)t}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\Bigl[\frac{-\mathrm{e}^{-(p-p_0)t}}{p-p_0}\Bigr]_0^\infty}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{p-p_0}}$. The value at the upper limit vanishes if and only if $\operatorname{Re}(p-p_0)>0$.

(2.3): $\textcolor{#e5383b}{-\int_{-\infty}^0\mathrm{e}^{-(p-p_0)t}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\Bigl[\frac{-\mathrm{e}^{-(p-p_0)t}}{p-p_0}\Bigr]_{-\infty}^0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{p-p_0}}$. The value for $t\to-\infty$ vanishes if and only if $\operatorname{Re}(p-p_0)<0$.

(2.4): sifting property, $\textcolor{#e5383b}{\int\delta(t)\mathrm{e}^{-pt}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{0}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$.

(2.5): integration by parts, $\textcolor{#e5383b}{\int_0^\infty t\,\mathrm{e}^{-pt}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\Bigl[\frac{-t\,\mathrm{e}^{-pt}}{p}\Bigr]_0^\infty+\frac1p\int_0^\infty\mathrm{e}^{-pt}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0+\frac{1}{p^2}}$ for $\operatorname{Re} p>0$.

QuestionWhy do the exponential terms drop out when evaluating $\int_0^\infty\mathrm{e}^{-bt}\mathrm{e}^{-pt}\mathrm{d} t$, and why is the result $\frac{1}{b+p}$ and not $\frac{1}{-(b+p)}$?

Both come from inserting the limits. The antiderivative of $\mathrm{e}^{-(b+p)t}$ is $-\frac{\mathrm{e}^{-(b+p)t}}{b+p}$, with a minus sign because differentiating produces the factor $-(b+p)$. Then you compute “upper limit minus lower limit”:

$$\textcolor{#e5383b}{\int_0^\infty\mathrm{e}^{-(b+p)t}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\underbrace{\lim_{t\to\infty}\Bigl(-\frac{\mathrm{e}^{-(b+p)t}}{b+p}\Bigr)}_{=\,0}-\Bigl(-\frac{\mathrm{e}^{0}}{b+p}\Bigr)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{b+p}.}$$

  • ⁠Upper limit: $\textcolor{#e5383b}{|\mathrm{e}^{-(b+p)t}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-(\operatorname{Re} b+\sigma)t}}$ tends to zero if and only if $\operatorname{Re} p>-\operatorname{Re} b$. This condition is the region of convergence. Outside it, the exponential term would remain and grow without bound.

  • ⁠Lower limit: $\textcolor{#e5383b}{\mathrm{e}^0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$, so no exponential term is left there.

  • ⁠Sign: The minus sign of the antiderivative meets the minus sign with which the lower limit is subtracted. Minus times minus gives plus.

For the left-sided pulse $\mathrm{e}^{-bt}\varepsilon(-t)$ it is the other way round. The integral runs from $-\infty$ to $0$, so now $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ is the upper limit. Its contribution $-\frac{1}{b+p}$ is not subtracted, so the minus sign remains. The lower limit $t\to-\infty$ vanishes only for $\operatorname{Re}(b+p)<0$, which is why this region of convergence lies on the left. With $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-b}$ these are the basic transform pairs (2.2) and (2.3).

QuestionDo we look at the real parts of $b$ and $p$ because the decay of the integrand decides integrability? For some $b$ the signal decays, for others it grows and does not fall to zero, and the integral does not converge because something keeps being added.

Yes, exactly. The magnitude of the integrand is

$$\textcolor{#e5383b}{\bigl|\mathrm{e}^{-(b+p)t}\bigr|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-\operatorname{Re}(b+p)\,t}\cdot\underbrace{\bigl|\mathrm{e}^{-\mathrm{j}\operatorname{Im}(b+p)\,t}\bigr|}_{=\,1}.}$$

The imaginary part only makes the integrand rotate in the complex plane; it does not change the magnitude. Growth or decay is decided by the real part alone. Three refinements:

  • What counts is the sum $\operatorname{Re} b+\sigma$. The signal itself may grow ($\operatorname{Re} b<0$) as long as the damping $\sigma$ is stronger. This is the “damp” trick from Section 2.2.

  • “Tends to zero” alone is not enough. $1/t$ also tends to zero, but $\textcolor{#e5383b}{\int_1^\infty\frac{\mathrm{d} t}{t}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\infty}$, because the contributions shrink too slowly. Exponential decay is fast enough: $\textcolor{#e5383b}{\int_0^\infty\mathrm{e}^{-\operatorname{Re}(b+p)t}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{\operatorname{Re}(b+p)}}$ is finite.

  • On the boundary $\textcolor{#e5383b}{\operatorname{Re}(b+p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ the integrand has the constant magnitude 1 and only rotates. The integral then oscillates instead of approaching a value, and exactly at the pole it even grows linearly (Exercise 3a). This is why the boundary line does not belong to the region of convergence.

QuestionSo does this hold for any function at all?

No, only for functions with a non-empty region of convergence. Three counterexamples:

  • $\mathrm{e}^{t^2}\varepsilon(t)$ grows faster than any exponential function. $\mathrm{e}^{t^2-\sigma t}\to\infty$ for every $\sigma$, so no damping is enough.

  • $\mathrm{e}^{|t|}$: the right half requires $\sigma>1$, the left half $\sigma<-1$. Both at once is impossible.

  • Even the constant $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ for all $t$: on the right $\sigma>0$, on the left $\sigma<0$. The Fourier transform still covers such signals, with a Dirac impulse in the spectrum.

For right-sided signals with at most exponential growth it always works. This includes every signal that is switched on in a circuit at $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$.

QuestionWhy is a single line enough when the $p$-plane is two-dimensional?

Every line in the region of convergence gives the same $s(t)$: with a larger $\sigma$ you damp more strongly in step 1 and multiply back more strongly in step 3, and the two cancel. Numerically confirmed: with $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.2}$ and $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/\mathrm s}$, the step gives $\textcolor{#e5383b}{s(1\,\mathrm{s})}\textcolor{#2b6def}{\approx}\textcolor{#ff9f1c}{1.00}$ and $\textcolor{#e5383b}{s(-1\,\mathrm{s})}\textcolor{#2b6def}{\approx}\textcolor{#ff9f1c}{0.00}$ both times. So the plane contains more than you need for the superposition. Its use lies elsewhere: in the plane, $S(p)$ can be described by a few numbers, the poles and zeros. (Aside: $S(p)$ is complex differentiable in the region of convergence, so its values on one line determine the function in the whole region.)

Exercise 3a ★★ What happens on the boundary

  1. For which $\sigma$ does $\int_0^\infty s(t)\,\mathrm{e}^{-pt}\mathrm{d} t$ converge? What role does the 3 play?

  2. Set $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1+\mathrm{j}\omega}$, exactly on the boundary, and compute $\int_0^T s(t)\,\mathrm{e}^{-pt}\mathrm{d} t$. What happens as $T\to\infty$? Distinguish $\omega\neq3$ and $\textcolor{#e5383b}{\omega}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{3}$. Where is the pole?

Solution

(a) $\textcolor{#e5383b}{b+p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{(\sigma-1)+\mathrm{j}(\omega-3)}$ with $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma+\mathrm{j}\omega}$. The magnitude of the integrand is $\mathrm{e}^{-(\sigma-1)t}$, so the integral converges if and only if $\sigma>1$. The 3 (the angular frequency of the signal) does not appear in the magnitude. It only determines where on the boundary line the pole sits: $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{p-(1+3\mathrm{j})}}$, pole at $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1+3\mathrm{j}}$.

(b) With $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1+\mathrm{j}\omega}$, $\textcolor{#e5383b}{b+p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{j}(\omega-3)}$.

  • $\omega\neq3$: $\textcolor{#e5383b}{\displaystyle\int_0^T\mathrm{e}^{-\mathrm{j}(\omega-3)t}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1-\mathrm{e}^{-\mathrm{j}(\omega-3)T}}{\mathrm{j}(\omega-3)}}$. As $T$ grows, the numerator runs around a circle centered at 1 and approaches no value. The integral stays bounded but has no limit.

  • $\textcolor{#e5383b}{\omega}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{3}$, that is, exactly at the pole $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1+3\mathrm{j}}$: the integrand is constantly 1, the integral equals $T$ and grows without bound.

So the integral converges nowhere on the boundary line. The region of convergence is the open half-plane $\operatorname{Re} p>1$.

Exercise 4 ★ True or false? Give reasons

  1. Every function has a Laplace transform.

  2. Whether $p$ lies in the region of convergence depends only on $\operatorname{Re} p$.

  3. If the imaginary axis lies in the region of convergence, $S(\mathrm{j}2\pi f)$ is the Fourier transform of $s(t)$.

  4. In the inversion formula, $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/\mathrm s}$ gives a different signal than $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2/\mathrm s}$ if both lie in the region of convergence.

  5. $\cos(2\pi f_0t)$ is an eigenfunction of every LTI system.

Solution

(a) False. Counterexamples: $\mathrm{e}^{t^2}\varepsilon(t)$, $\mathrm{e}^{|t|}$, the two-sided constant.

(b) True. $\textcolor{#e5383b}{|s(t)\mathrm{e}^{-pt}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{|s(t)|\mathrm{e}^{-\sigma t}}$; the frequency $f$ does not appear in the magnitude. This is why the region of convergence consists of whole vertical lines.

(c) True. With $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$, $\textcolor{#e5383b}{S(\mathrm{j}2\pi f)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int s(t)\mathrm{e}^{-\mathrm{j}2\pi ft}\mathrm{d} t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathcal{F}\{s\}(f)}$.

(d) False. Every line in the region of convergence gives the same signal, because the damping by $\mathrm{e}^{-\sigma t}$ and the multiplication back by $\mathrm{e}^{\sigma t}$ cancel.

(e) False. The output is $|H|\cos(2\pi f_0t+\varphi)$ with $\textcolor{#e5383b}{H}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(\mathrm{j}2\pi f_0)}$. It is a multiple of $\cos(2\pi f_0t)$ only if $\textcolor{#e5383b}{\varphi}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ or $\textcolor{#e5383b}{\varphi}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\pi}$, that is, only if $H(\mathrm{j}2\pi f_0)$ is real. For the RC low-pass filter this is not the case at any frequency $f_0>0$.

Stage 3: Convolution becomes multiplication

What this stage is about:

Stage 1 says what the system does to one building block. Stage 2 says that every signal consists of building blocks. Together they give the most important theorem of the Laplace transform.

The idea. An LTI system is linear: it processes each building block of the input separately and adds the results. It multiplies each building block $\mathrm{e}^{pt}$ by $H(p)$. So the output consists of the same building blocks as the input, except that each weight is multiplied by $H(p)$. Figure 4 shows the two routes to the output.

Theorem 3.1 (Convolution theorem)
$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{s(t)*h(t)\quad\Longleftrightarrow\quad G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(p)\,H(p),}$$
(3.1)

valid for all $p$ that lie in the regions of convergence of both $S$ and $H$.

⁠How to read it: $S(p)$ is the weight of the building block $\mathrm{e}^{pt}$ in the input, $H(p)$ is the factor by which the system multiplies this building block, and $G(p)$ is the weight in the output. The condition on $p$ arises because the line of the inversion formula must run through both regions of convergence: the input must be decomposable into building blocks, and the system must be able to process each of them.

Derivation: Convolution theorem from superposition and eigenfunction

Insert the input as the superposition (2.1) into the convolution, using a line $\textcolor{#e5383b}{\operatorname{Re} p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma}$ that lies in both regions of convergence:

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{s(t)*h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\left[\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}S(p)\,\mathrm{e}^{pt}\,\mathrm{d} p\right]*h(t).}$$

Linearity: the convolution may be moved inside the integral, where it acts on each building block separately:

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}S(p)\,\bigl[\mathrm{e}^{pt}*h(t)\bigr]\,\mathrm{d} p.}$$

Eigenfunction (1.1): $\textcolor{#e5383b}{\mathrm{e}^{pt}*h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(p)\,\mathrm{e}^{pt}}$.

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}\bigl[S(p)H(p)\bigr]\,\mathrm{e}^{pt}\,\mathrm{d} p.}$$

This is the inversion formula for $g$ with the weight $S(p)H(p)$. Since the weights of a signal are unique, $\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(p)H(p)}$.

⁠In short: Convolution becomes multiplication because the system only multiplies each building block $\mathrm{e}^{pt}$ by the number $H(p)$.

Analogy (a picture for orientation, not mathematics)

A graphic equalizer splits music into frequency bands, multiplies each band by the setting of its slider and puts the bands back together. An LTI system does the same with the building blocks $\mathrm{e}^{pt}$, and the slider setting is $H(p)$. The analogy breaks down in two places: an equalizer has finitely many bands with real slider settings. Here there is a continuum of building blocks, which can also grow or decay, and each “slider” is a complex number that also shifts the phase.

The same mechanism explains derivatives, integrals and differential equations.

  • ⁠Differentiation. $\textcolor{#e5383b}{\frac{\mathrm{d}}{\mathrm{d} t}\mathrm{e}^{pt}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{p\,\mathrm{e}^{pt}}$. The differentiator is an LTI system, and each building block is an eigenfunction of it with the eigenvalue $p$. So each weight is multiplied by $p$: $\textcolor{#e5383b}{\mathcal{L}\{\dot s\}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{p\,S(p)}$.

  • ⁠Integration. $\textcolor{#e5383b}{\int_{-\infty}^{t}\mathrm{e}^{p\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{pt}/p}$, but only for $\operatorname{Re} p>0$; otherwise the integral diverges at $-\infty$. Hence $\textcolor{#e5383b}{\mathcal{L}\{\int_{-\infty}^t s\,\mathrm{d}\tau\}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(p)/p}$ with the additional condition $\operatorname{Re} p>0$.

  • ⁠Cascade. Two systems in series multiply first by $H_1(p)$ and then by $H_2(p)$, together by $H_1H_2$. The order does not matter, because numbers commute.

  • ⁠Differential equation. Each derivative becomes a factor $p$. A linear differential equation with constant coefficients

    $$\textcolor{#e5383b}{\sum_{r=0}^{R}\alpha_r\frac{\mathrm{d}^r g}{\mathrm{d} t^r}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sum_{q=0}^{Q}\beta_q\frac{\mathrm{d}^q s}{\mathrm{d} t^q} \quad\text{becomes}\quad \Bigl(\sum_{r}\alpha_rp^r\Bigr)G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\Bigl(\sum_q\beta_qp^q\Bigr)S(p),}$$

    that is, an algebraic equation, and $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{G/S}$ is a ratio of polynomials.

Example: the step response of the RC low-pass filter. Input $\varepsilon(t)$ with $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/p}$ ($\operatorname{Re} p>0$), system $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/(p+1)}$ ($\operatorname{Re} p>-1$). The common region is $\operatorname{Re} p>0$:

$$\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{p}\cdot\frac{1}{p+1}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac1p-\frac{1}{p+1}\quad\Longrightarrow\quad g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\bigl(1-\mathrm{e}^{-t}\bigr)\varepsilon(t).}$$

The inverse transform of the two terms follows from (2.2) with $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ and $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-1}$. Checked directly: $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int_0^t\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1-\mathrm{e}^{-t}}$ for $t>0$. The inversion formula (2.1), evaluated numerically on the line $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.5/\mathrm s}$, also gives $\textcolor{#e5383b}{g(0.5\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.3935}$, $\textcolor{#e5383b}{g(1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.6321}$, $\textcolor{#e5383b}{g(3\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.9502}$ and $\textcolor{#e5383b}{g(-1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$, exactly $\bigl(1-\mathrm{e}^{-t}\bigr)\varepsilon(t)$.

Stage 4: The integral becomes a sum

What this stage is about:

The conjecture taken literally: for the signals that system theory almost always deals with, the signal is a finite sum of complex exponentials. The poles are the exponents.

The idea. For networks of $R$, $L$, $C$ and for all systems described by a differential equation, $S(p)$ is a ratio of polynomials. For simple poles, the partial fraction expansion writes it as

$$\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{A_0+\sum_{r=1}^{R}\frac{A_r}{p-p_r},}$$
$$\textcolor{#e5383b}{A_r}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\lim_{p\to p_r}(p-p_r)\,S(p).}$$

Each term is the transform of a single building block: by (2.2), $A_r/(p-p_r)$ belongs to $A_r\,\mathrm{e}^{p_r t}\varepsilon(t)$ if the region of convergence lies to the right of the pole, and by (2.4) the constant term $A_0$ belongs to $A_0\,\delta(t)$. So for a right-sided signal

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{A_0\,\delta(t)+\sum_{r=1}^{R}A_r\,\mathrm{e}^{p_r t}\,\varepsilon(t).}$$
(4.1)

⁠In short: A right-sided signal with a rational Laplace transform is a finite sum of building blocks $\mathrm{e}^{p_r t}$. The poles are the exponents, and the partial fraction coefficients are the weights.

This means you can read off any such signal from its poles, using the map from Fig. 1: $\operatorname{Re} p_r$ tells you whether the building block decays or grows, and $\operatorname{Im} p_r$ how fast it oscillates. A conjugate pair of poles $p_r,p_r^*$ together gives a real damped oscillation. This is also the core of stability: a causal building block $\mathrm{e}^{p_r t}\varepsilon(t)$ decays if and only if $\operatorname{Re} p_r<0$. A causal system is therefore stable if all poles of $H(p)$ lie in the left half-plane.

Example. The step response from Stage 3 has the poles $0$ and $-1$:

$$\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\underbrace{1\cdot\mathrm{e}^{0\cdot t}}_{\text{pole }0\text{ (from }S)}\;\underbrace{-\;1\cdot\mathrm{e}^{-t}}_{\text{pole }-1\text{ (from }H)}}$$
$$(t>0).$$

The pole of the input gives the part that the input forces (the final voltage 1). The pole of the system gives the natural response of the RC circuit, the decay with $\textcolor{#e5383b}{RC}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ s. This holds in general: the output $\textcolor{#e5383b}{G}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{SH}$ contains the poles of the input and the poles of the system.

Going deeper, not needed for the rest: Why the integral collapses into a sum: the residue theorem

This section needs the residue theorem from complex analysis. It explains why (2.1) and (4.1) are the same and why the region of convergence decides the signal.

Let $S(p)$ be a ratio of polynomials whose numerator degree is lower than its denominator degree, with simple poles.

  • ⁠$t>0$: Close the line of integration with a large semicircle to the left. There $\operatorname{Re} p\to-\infty$, so $\textcolor{#e5383b}{|\mathrm{e}^{pt}|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{\operatorname{Re} p\,t}\to0}$, and $S(p)\to0$. In the limit the semicircle contributes nothing (Jordan's lemma). The closed path runs counterclockwise, and the residue theorem gives

    $$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sum_{\text{poles left of the line}}\operatorname*{Res}_{p=p_r}\bigl[S(p)\,\mathrm{e}^{pt}\bigr]}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sum_{\text{left}}A_r\,\mathrm{e}^{p_r t}.}$$

    The residue at a simple pole is $\textcolor{#e5383b}{\lim_{p\to p_r}(p-p_r)S(p)\mathrm{e}^{pt}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{A_r\mathrm{e}^{p_rt}}$: exactly the partial fraction coefficient.

  • ⁠$t<0$: Now $\mathrm{e}^{pt}$ vanishes for $\operatorname{Re} p\to+\infty$. Close to the right; the path runs clockwise, which gives a minus sign:

    $$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\sum_{\text{poles right of the line}}A_r\,\mathrm{e}^{p_r t}.}$$

⁠Consequence: The position of the line, that is, the region of convergence, decides which poles give causal building blocks (left of the line) and which give anticausal ones (right of the line). Example: $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{(p+1)(p+2)}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{p+1}-\frac{1}{p+2}}$ (Fig. 5). If the line lies between the poles, $-2<\sigma<-1$, then $-2$ acts for $t>0$ and $-1$ for $t<0$:

$$\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\mathrm{e}^{-2t}\varepsilon(t)-\mathrm{e}^{-t}\varepsilon(-t).}$$

Evaluated numerically on the line $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-1.5/\mathrm s}$: $\textcolor{#e5383b}{s(1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-0.1353}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\mathrm{e}^{-2}}$ and $\textcolor{#e5383b}{s(-1\,\mathrm{s})}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-2.7183}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-\mathrm{e}^{1}}$. If the line lies to the right of both poles, the same formula gives the causal signal $(\mathrm{e}^{-t}-\mathrm{e}^{-2t})\varepsilon(t)$; if it lies to the left of both, it gives the anticausal signal $-(\mathrm{e}^{-t}-\mathrm{e}^{-2t})\varepsilon(-t)$.

Stage 5: Why the input is transformed too

QuestionIt makes sense to transform $h(t)$, so that I can multiply eigenfunctions by $H(p)$ and find the output. But transforming $s(t)$ doesn't seem to make sense at first; from a system-theory point of view I can't do anything with it. Sure, $\textcolor{#e5383b}{s*h}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{h*s}$, but $h(t)$ is usually not an eigenfunction, so I can't write $h(t)\cdot S(p)$. What does it mean, in terms of the system, to transform an arbitrary signal?

⁠What is right about the question: $H(p)$ says what the system does to a building block $\mathrm{e}^{pt}$. And $h(t)\cdot S(p)$ indeed makes no sense.

⁠Where the reasoning goes wrong: The input is almost never an eigenfunction either. A step, a speech signal or a rectangular pulse is not a single building block $\mathrm{e}^{pt}$. So $H(p)\cdot s(t)$ makes just as little sense as $h(t)\cdot S(p)$: $H(p)$ may only be applied to a building block, and for an arbitrary $s(t)$ it is not even clear which $p$ is meant. Before $H(p)$ can do anything, the input must be decomposed into building blocks. That is exactly what $S(p)$ does.

⁠The correct view: In the convolution theorem $\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(p)\,S(p)}$, each factor has its own meaning in terms of the system:

  • $S(p)$ is the recipe of the input: how much of the building block $\mathrm{e}^{pt}$ the input contains;

  • $H(p)$ is the action of the system: the number by which it multiplies this building block;

  • $G(p)$ is the recipe of the output.

Without $S(p)$ you know only the action on individual building blocks, but not which building blocks arrive. $H(p)$ alone answers the question “What happens at the output?” only in the one special case where the input itself is a single building block.

⁠Example: step and RC low-pass filter. The step has the recipe $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1/p}$. On the line $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.5/\mathrm s}$, $\textcolor{#e5383b}{|S|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2}$ at $\textcolor{#e5383b}{f}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$, $0.16$ at 1 Hz and $0.016$ at 10 Hz. The fast building blocks are weak but present, and they form the sharp edge (Fig. 3: the more fast building blocks, the steeper the edge). The RC low-pass filter multiplies them by $\textcolor{#e5383b}{|H|}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.67}$, $0.15$ and $0.016$. In the output, the fast building blocks are therefore weaker by a further factor of roughly $2\pi f\cdot RC$ (for $\textcolor{#e5383b}{f\gg1/(2\pi RC)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.16}$ Hz), and the edge is gone: $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1-\mathrm{e}^{-t}}$ rises continuously. This explanation needs both transforms. $H$ alone only says “fast building blocks are weakened”; only $S$ says that the edge consists of fast building blocks.

⁠And the symmetry $\textcolor{#e5383b}{s*h}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{h*s}$? Mathematically the two signals are on an equal footing: you can also read $h$ as the input and $s$ as the “system”, and then $H(p)$ is the recipe and $S(p)$ the action. System theory assigns the roles only according to the physics: one signal comes from outside, the other describes the circuit. In the transform domain, both are always transformed.

Further reasons to transform a signal on its own.

  • ⁠Measuring a system. If you measure the input and output of an unknown system, $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{G(p)/S(p)}$ gives you the system. For this you transform two signals, each on its own (Exercise 9).

  • ⁠Understanding the signal itself. The sound of a struck bell is a sum of damped oscillations, each one a conjugate pair of poles. $\operatorname{Im} p_r$ is the pitch of a partial, $-\operatorname{Re} p_r$ its decay rate. A few poles describe the whole sound. An instrument that displays a spectrum does the same on the line $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$.

  • ⁠Convolution without a system. Convolution superposes shifted, weighted copies of a signal. The system is one interpretation of this operation, not the only one. An example with no system at all is the sum of two dice, treated in the article on convolution (Part 1).

Exercise 9 ★★ An unknown system from two measurements

A voltage of 1 V is applied to an unknown causal LTI system at time $\textcolor{#e5383b}{t}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$, $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\varepsilon(t)}$ in V. At the output one measures $\textcolor{#e5383b}{g(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\bigl(1-\mathrm{e}^{-2t}\bigr)\varepsilon(t)}$ in V ($t$ in s).

  1. Transform both signals, each on its own.

  2. Find $H(p)$ and from it $h(t)$.

  3. Which network could it be? What value do you get?

  4. Which pole in $G(p)$ comes from the input, and which from the system?

Solution

(a) $\textcolor{#e5383b}{S(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac1p}$ for $\operatorname{Re} p>0$. $\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac1p-\dfrac{1}{p+2}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{2}{p(p+2)}}$ for $\operatorname{Re} p>0$ (basic transform pair (2.2) with $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ and $\textcolor{#e5383b}{p_0}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-2}$).

(b) $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{G(p)}{S(p)}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{2}{p+2}}$. Since the system is causal, the region of convergence lies to the right of the pole: $\operatorname{Re} p>-2$. With (2.2): $\textcolor{#e5383b}{h(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{2\,\mathrm{e}^{-2t}\varepsilon(t)}$ in $1/\mathrm s$.

(c) An RC low-pass filter has $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{1}{1+pRC}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\dfrac{1/RC}{p+1/RC}}$. Comparing with $\dfrac{2}{p+2}$ gives $\textcolor{#e5383b}{RC}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0.5}$ s, for example $\textcolor{#e5383b}{R}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{500\,\mathrm{k\Omega}}$ and $\textcolor{#e5383b}{C}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{1}$ µ F. (Any other network with the same transfer function would behave identically at its terminals. Measurements at the input and output reveal only $H$, not the components.)

(d) The pole $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ comes from the input (the step), the pole $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{-2}$ from the system. In the division $G/S$, exactly the pole of the input cancels.

Key points so far

  • $\textcolor{#e5383b}{\mathrm{e}^{p(t-\tau)}}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathrm{e}^{-p\tau}\mathrm{e}^{pt}}$, hence $\textcolor{#e5383b}{\mathrm{e}^{pt}*h}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{H(p)\,\mathrm{e}^{pt}}$ with $\textcolor{#e5383b}{H(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\int h(t)\mathrm{e}^{-pt}\mathrm{d} t}$.

  • $\textcolor{#e5383b}{p}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\sigma+\mathrm{j}2\pi f}$: $\sigma$ is the growth rate, $f$ the frequency of the building block.

  • $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\frac{1}{2\pi\mathrm{j}}\int_{\sigma-\mathrm{j}\infty}^{\sigma+\mathrm{j}\infty}S(p)\mathrm{e}^{pt}\mathrm{d} p}$, $\sigma$ in the region of convergence; every such line gives the same $s(t)$.

  • $\textcolor{#e5383b}{S(\sigma+\mathrm{j}2\pi f)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{\mathcal{F}\{s(t)\mathrm{e}^{-\sigma t}\}}$; for $\textcolor{#e5383b}{\sigma}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{0}$ the Fourier transform.

  • Region of convergence: depends only on $\sigma$; right-sided: a right half-plane, left-sided: a left half-plane, two-sided: a strip.

  • $\mathrm{e}^{p_0t}\varepsilon(t)\leftrightarrow\frac{1}{p-p_0}$ for $\operatorname{Re} p>\operatorname{Re} p_0$; $-\mathrm{e}^{p_0t}\varepsilon(-t)\leftrightarrow\frac{1}{p-p_0}$ for $\operatorname{Re} p<\operatorname{Re} p_0$.

  • $\textcolor{#e5383b}{G(p)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{S(p)H(p)}$; differentiation $\to p$, integration $\to1/p$.

  • Rational and right-sided: $\textcolor{#e5383b}{s(t)}\textcolor{#2b6def}{=}\textcolor{#ff9f1c}{A_0\delta(t)+\sum_rA_r\mathrm{e}^{p_rt}\varepsilon(t)}$, poles = exponents. Causal and stable: all poles on the left.
