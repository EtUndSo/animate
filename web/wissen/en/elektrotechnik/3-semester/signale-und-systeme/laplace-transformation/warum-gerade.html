Stage 1: Why $\mathrm{e}^{pt}$ in particular

What this stage is about:

If you insert $\mathrm{e}^{pt}$ into the convolution integral, the result is $H(p)\,\mathrm{e}^{pt}$: $\mathrm{e}^{pt}$ is an eigenfunction. This stage asks which property of $\mathrm{e}^{pt}$ forces this and why the building blocks have to be complex.

The idea. The convolution integral

$$\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_{-\infty}^{\infty}h(\tau)\,s(t-\tau)\,\mathrm{d}\tau}$$

reads as follows: the output is a sum of delayed copies of the input. The copy with delay $\tau$ enters with the weight $h(\tau)\,\mathrm{d}\tau$. For an arbitrary signal shape, each delayed copy looks different from the original, and the sum has a new shape. Not so for $\mathrm{e}^{pt}$:

$$\textcolor{#1b7f4a}{\mathrm{e}^{p(t-\tau)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-p\tau}\cdot\mathrm{e}^{pt}.}$$

A delay by $\tau$ acts like multiplication by the constant number $\mathrm{e}^{-p\tau}$. All copies are multiples of the same function $\mathrm{e}^{pt}$, and so is their sum:

$$\textcolor{#1b7f4a}{\mathrm{e}^{pt}*h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{pt}\underbrace{\int_{-\infty}^{\infty}h(\tau)\,\mathrm{e}^{-p\tau}\,\mathrm{d}\tau}_{H(p)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{H(p)\,\mathrm{e}^{pt}.}$$
(1.1)

⁠In short: $\mathrm{e}^{pt}$ is an eigenfunction because for $\mathrm{e}^{pt}$ shifting is the same as multiplying.

What $p$ means. With $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sigma+\mathrm{j}2\pi f}$ the building block splits into two factors:

$$\textcolor{#1b7f4a}{\mathrm{e}^{pt}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{\sigma t}\cdot\mathrm{e}^{\mathrm{j}2\pi ft}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{\sigma t}\bigl[\cos(2\pi ft)+\mathrm{j}\sin(2\pi ft)\bigr].}$$

The real part $\sigma$ (in $1/\mathrm s$) is the growth rate: for $\sigma<0$ the building block decays, for $\textcolor{#1b7f4a}{\sigma}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ it oscillates with constant amplitude, for $\sigma>0$ it grows. The imaginary part $2\pi f$ sets the frequency of the oscillation. So every point of the $p$-plane is a building block, and the position of the point tells you what it looks like (Fig. 1).

QuestionWhy complex? A sine is a simple signal too.

When a sine is shifted, it is not just scaled. With $\textcolor{#1b7f4a}{\omega_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\pi f_0}$,

$$\textcolor{#1b7f4a}{\sin\bigl(\omega_0(t-\tau)\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos(\omega_0\tau)\,\sin(\omega_0t)-\sin(\omega_0\tau)\,\cos(\omega_0t).}$$

A cosine component appears, so the delayed copy has a different shape. This is why a system responds to $\sin(\omega_0t)$ with $|H|\sin(\omega_0t+\varphi)$: amplitude and phase change. A phase shift cannot be written as multiplication by a real number, but it can be written as multiplication by the complex number $\mathrm{e}^{\mathrm{j}\varphi}$. That is why the building blocks are complex: the single number $H(p)$ carries magnitude and phase. A real sine consists of two building blocks, $\textcolor{#1b7f4a}{\sin(\omega_0t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\mathrm{e}^{\mathrm{j}\omega_0t}-\mathrm{e}^{-\mathrm{j}\omega_0t}\bigr)/(2\mathrm{j})}$, and each of them is multiplied by its own number (Exercise 1d).

QuestionWhy is $\mathrm{e}^{pt}$ an eigenfunction of every LTI system, even though the systems are so different?

The form of the eigenfunction follows from time invariance alone (shifting = multiplying), and all LTI systems share that property. Only the factor $H(p)$ depends on the system, because the weights $h(\tau)$ enter into it. So one set of building blocks serves all LTI systems at once. That is what makes the Laplace transform universal.

Going deeper, not needed for the rest: Only exponential functions have this property

We look for a differentiable function $x(t)$ with $\textcolor{#1b7f4a}{x(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ whose shifted copies are multiples of itself: $\textcolor{#1b7f4a}{x(t+u)}\textcolor{#15633a}{=}\textcolor{#c2410c}{c(u)\,x(t)}$ for all $t,u$. Setting $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ gives $\textcolor{#1b7f4a}{c(u)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x(u)}$, so $\textcolor{#1b7f4a}{x(t+u)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x(t)\,x(u)}$. Differentiating with respect to $u$ at $\textcolor{#1b7f4a}{u}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ gives $\textcolor{#1b7f4a}{x'(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x'(0)\,x(t)}$. This is the differential equation $\textcolor{#1b7f4a}{x'}\textcolor{#15633a}{=}\textcolor{#c2410c}{p\,x}$ with $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{x'(0)}$, and its solution with $\textcolor{#1b7f4a}{x(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ is $\textcolor{#1b7f4a}{x(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{pt}}$. So there are no other building blocks with this property.

QuestionAre exponential functions the only possible eigenfunctions of LTI systems?

Two questions have to be kept apart.

⁠Eigenfunction of all LTI systems at once: yes, only $c\,\mathrm{e}^{pt}$. The ideal delay element $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(t-u)}$ is itself an LTI system, for every delay $u$. A function that is an eigenfunction of every LTI system must therefore turn into a multiple of itself under every shift. By the box above, only $\mathrm{e}^{pt}$ does that.

⁠Eigenfunction of one particular system: not only. The system multiplies each building block $\mathrm{e}^{p_kt}$ by its own number $H(p_k)$. A sum $\sum_kc_k\mathrm{e}^{p_kt}$ stays a multiple of itself exactly when all these factors are equal, $\textcolor{#1b7f4a}{H(p_k)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\lambda}$. The common factor $\lambda$ is then the eigenvalue. Two examples:

  • Ideal delay element by $T$: $\textcolor{#1b7f4a}{H(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-pT}}$ has the same value 1 at all points $\textcolor{#1b7f4a}{p_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{j}2\pi k/T}$. Every signal with period $T$ is an eigenfunction with eigenvalue 1, because $\textcolor{#1b7f4a}{s(t-T)}\textcolor{#15633a}{=}\textcolor{#c2410c}{s(t)}$.

  • Ideal low-pass filter without delay, $\textcolor{#1b7f4a}{H(f)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ in the whole passband: every signal made up only of oscillations with frequencies in the passband comes out unchanged and is an eigenfunction with eigenvalue 1.

For the RC circuit, on the other hand, $\textcolor{#1b7f4a}{H(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/(1+pRC)}$ takes each value only once. There the single $c\,\mathrm{e}^{pt}$ (with $p$ in the region of convergence) are the only eigenfunctions that can be built from building blocks.

⁠In short: $\mathrm{e}^{pt}$ is the only eigenfunction that every LTI system has. A single system can also have mixtures of building blocks as eigenfunctions if it multiplies all of these building blocks by the same number.

Exercise 1 ★ Eigenfunction or not?

Use the RC low-pass filter of the reference model, $\textcolor{#1b7f4a}{h(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-t}\varepsilon(t)}$.

  1. Compute $\textcolor{#1b7f4a}{H(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int h(t)\,\mathrm{e}^{-pt}\mathrm{d} t}$. For which $p$ does the integral converge, and why does this depend only on $\operatorname{Re} p$?

  2. Input $\textcolor{#1b7f4a}{s(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-t/2}}$ for all $t$. Compute the output once directly with the convolution integral and once with $H(p)$. Which $p$ does this building block have?

  3. Input $\textcolor{#1b7f4a}{s(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{t}$ for all $t$. Use the convolution integral to show that the output is $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{t-1}$. Why is $t$ not an eigenfunction, even though the output looks similar? What does the $-1$ mean for the capacitor?

  4. Input $\textcolor{#1b7f4a}{s(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos t}$ (so $\textcolor{#1b7f4a}{\omega_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/\mathrm s}$). Decompose the cosine into two building blocks, multiply each by its $H(p)$ and put them back together. Show that $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{A\cos(t+\varphi)}$, and find $A$ and $\varphi$. Is $\cos t$ an eigenfunction?

⁠Hint for (c): $\textcolor{#1b7f4a}{\int_0^\infty\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ and $\textcolor{#1b7f4a}{\int_0^\infty\tau\,\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$.

Solution

(a) $\textcolor{#1b7f4a}{H(p)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_0^\infty\mathrm{e}^{-\tau}\mathrm{e}^{-p\tau}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_0^\infty\mathrm{e}^{-(p+1)\tau}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{\dfrac{1}{p+1}}$. The integral converges if and only if $\textcolor{#1b7f4a}{|\mathrm{e}^{-(p+1)\tau}|}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-(\sigma+1)\tau}}$ decays, that is, for $\operatorname{Re} p>-1$. The magnitude depends only on $\sigma$ because $\textcolor{#1b7f4a}{|\mathrm{e}^{-\mathrm{j}2\pi f\tau}|}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$.

(b) Directly:

$$\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_0^\infty\mathrm{e}^{-\tau}\,\mathrm{e}^{-(t-\tau)/2}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathrm{e}^{-t/2}\int_0^\infty\mathrm{e}^{-\tau/2}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,\mathrm{e}^{-t/2}.}$$

With $H(p)$: the building block has $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\tfrac12}$ (real, no oscillation). This value lies in the region of convergence, $\textcolor{#1b7f4a}{H(-\tfrac12)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/(\tfrac12)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, so $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,\mathrm{e}^{-t/2}}$. Both routes agree (numerically: $\textcolor{#1b7f4a}{g(1\,\mathrm{s})}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.2131}$).

(c) $\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\int_0^\infty\mathrm{e}^{-\tau}(t-\tau)\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{t\int_0^\infty\mathrm{e}^{-\tau}\mathrm{d}\tau-\int_0^\infty\tau\mathrm{e}^{-\tau}\mathrm{d}\tau}\textcolor{#15633a}{=}\textcolor{#c2410c}{t-1}$. This is not a multiple of $t$: the delayed copies $t-\tau$ are not multiples of $t$ (the factor $1-\tau/t$ depends on $t$ itself). The output is the shifted ramp: the capacitor voltage follows the input ramp with a delay of $\textcolor{#1b7f4a}{RC}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ s. Same shape, but shifted instead of scaled, so not an eigenfunction.

(d) $\textcolor{#1b7f4a}{\cos t}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12\mathrm{e}^{\mathrm{j} t}+\tfrac12\mathrm{e}^{-\mathrm{j} t}}$, building blocks at $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{\pm\mathrm{j}}$, both in the region of convergence ($\textcolor{#1b7f4a}{\operatorname{Re} p}\textcolor{#15633a}{=}\textcolor{#c2410c}{0>-1}$).

$$\textcolor{#1b7f4a}{H(\mathrm{j})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{1+\mathrm{j}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{\sqrt2}\,\mathrm{e}^{-\mathrm{j}\pi/4},}$$
$$\textcolor{#1b7f4a}{H(-\mathrm{j})}\textcolor{#15633a}{=}\textcolor{#c2410c}{H(\mathrm{j})^*}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{\sqrt2}\,\mathrm{e}^{+\mathrm{j}\pi/4}.}$$

$$\textcolor{#1b7f4a}{g(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12H(\mathrm{j})\mathrm{e}^{\mathrm{j} t}+\tfrac12H(-\mathrm{j})\mathrm{e}^{-\mathrm{j} t}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{Re}\bigl\{H(\mathrm{j})\mathrm{e}^{\mathrm{j} t}\bigr\}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{\sqrt2}\cos\Bigl(t-\frac\pi4\Bigr).}$$

So $\textcolor{#1b7f4a}{A}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/\sqrt2}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0.707}$ and $\textcolor{#1b7f4a}{\varphi}\textcolor{#15633a}{=}\textcolor{#c2410c}{-45^\circ}$ (numerically: $\textcolor{#1b7f4a}{g(1\,\mathrm{s})}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6909}$). Each of the two complex building blocks is an eigenfunction, but their sum $\cos t$ is not: the two building blocks are multiplied by different numbers, $H(\mathrm{j})\neq H(-\mathrm{j})$. This shifts the phase.
