Stage 4: The two-port in operation

What this stage is about:

In operation, no port is open. This stage shows how the load acts back on the input through the parameter $Z_{12}$ and what the two-port is for the load.

The idea. The load draws a current from port 2, so $I_2\neq0$. Through the source $Z_{12}I_2$, this current appears as a voltage at the input. In the T two-port you can grasp this directly: Part of the current that would otherwise flow through $R_\mathrm{b}$ escapes through $R_\mathrm{c}$ to the load. Less drops across $R_\mathrm{b}$, $U_1$ falls, and the input looks lower in resistance. This effect of the output on the input is called reverse action.

Theorem 4.1 (Input resistance and output side)

With the load $Z_\mathrm{L}$ at port 2, $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-Z_\mathrm{L}I_2}$ and

$$\textcolor{#1b7f4a}{I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\frac{Z_{21}}{Z_{22}+Z_\mathrm{L}}\,I_1,}$$
$$\textcolor{#1b7f4a}{Z_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{U_1}{I_1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{11}-\frac{Z_{12}Z_{21}}{Z_{22}+Z_\mathrm{L}}.}$$
(4.1)

The limiting cases are the open-circuit and the short-circuit input resistance:

$$\textcolor{#1b7f4a}{Z_{1,\mathrm{OC}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{11},}$$
$$\textcolor{#1b7f4a}{Z_{1,\mathrm{SC}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{11}-\frac{Z_{12}Z_{21}}{Z_{22}}.}$$
(4.2)

If a source $U_\mathrm{q}$, $R_\mathrm{q}$ feeds port 1, port 2 acts as an equivalent voltage source (Chapter 5) with

$$\textcolor{#1b7f4a}{U_\mathrm{i}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{Z_{21}}{Z_{11}+R_\mathrm{q}}\,U_\mathrm{q},}$$
$$\textcolor{#1b7f4a}{R_\mathrm{i}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{22}-\frac{Z_{12}Z_{21}}{Z_{11}+R_\mathrm{q}}.}$$
(4.3)

⁠How to read it: $Z_\mathrm{L}$ is the load, here a resistor. The minus sign in $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-Z_\mathrm{L}I_2}$ is there because $I_2$ points into the two-port and so against the current through the load. The fraction in (4.1) is the amount by which the load changes the input resistance. If $\textcolor{#1b7f4a}{Z_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, it is zero: The input notices nothing of the load, and the two-port is called unilateral. Validity: The two-port must be linear; the formulas for the equivalent source assume a linear source.

Derivation: Input resistance and output side

Right mesh: $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{21}I_1+Z_{22}I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-Z_\mathrm{L}I_2}$; solving for $I_2$ gives the first part of (4.1). Substituting into the left mesh $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{11}I_1+Z_{12}I_2}$ and dividing by $I_1$ gives $Z_1$. For $Z_\mathrm{L}\to\infty$ the fraction vanishes; for $\textcolor{#1b7f4a}{Z_\mathrm{L}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, $Z_{1,\mathrm{SC}}$ follows with $\textcolor{#1b7f4a}{I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-Z_{21}I_1/Z_{22}}$.

For (4.3) you replace the load. The source imposes $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mathrm{q}-R_\mathrm{q}I_1}$. At $\textcolor{#1b7f4a}{I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, $\textcolor{#1b7f4a}{I_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mathrm{q}/(Z_{11}+R_\mathrm{q})}$ and $\textcolor{#1b7f4a}{U_\mathrm{i}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Z_{21}I_1}$. With $\textcolor{#1b7f4a}{U_\mathrm{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, port 1 is terminated by $R_\mathrm{q}$, and $R_\mathrm{i}$ is $Z_1$ with swapped indices.

Example

For the T two-port, $\textcolor{#1b7f4a}{Z_{1,\mathrm{OC}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{35\,\Omega}$ and $\textcolor{#1b7f4a}{Z_{1,\mathrm{SC}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{35\,\Omega-400\,\Omega^2/40\,\Omega}\textcolor{#15633a}{=}\textcolor{#c2410c}{25\,\Omega}$, which is $R_\mathrm{a}+R_\mathrm{b}\parallel R_\mathrm{c}$. With $\textcolor{#1b7f4a}{R_\mathrm{L}}\textcolor{#15633a}{=}\textcolor{#c2410c}{60\,\Omega}$,

$$\textcolor{#1b7f4a}{Z_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{35\,\Omega-\frac{400\,\Omega^2}{100\,\Omega}}\textcolor{#15633a}{=}\textcolor{#c2410c}{31\,\Omega,\quad I_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{9\,\mathrm{V}}{5\,\Omega+31\,\Omega}}\textcolor{#15633a}{=}\textcolor{#c2410c}{250\,\mathrm{mA},\quad I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\frac{20}{100}\,I_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{-50\,\mathrm{mA}.}$$

At the input, $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{9\,\mathrm{V}-5\,\Omega\cdot250\,\mathrm{mA}}\textcolor{#15633a}{=}\textcolor{#c2410c}{7.75}$ V, at the output $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{60\,\Omega\cdot50\,\mathrm{mA}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ V. In $R_\mathrm{b}$, $\textcolor{#1b7f4a}{I_1+I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{200}$ mA flows instead of 250 mA, which lowers $U_1$ by exactly 1 V (Fig. 5). Seen from the load: $\textcolor{#1b7f4a}{U_\mathrm{i}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{20}{40}\cdot9\,\mathrm{V}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4.5}$ V, $\textcolor{#1b7f4a}{R_\mathrm{i}}\textcolor{#15633a}{=}\textcolor{#c2410c}{40\,\Omega-400\,\Omega^2/40\,\Omega}\textcolor{#15633a}{=}\textcolor{#c2410c}{30\,\Omega}$. Then $\textcolor{#1b7f4a}{I}\textcolor{#15633a}{=}\textcolor{#c2410c}{4.5\,\mathrm{V}/90\,\Omega}\textcolor{#15633a}{=}\textcolor{#c2410c}{50}$ mA, the same current. So the equivalent source from Chapter 5 is contained in the four numbers.

⁠Limiting cases: $R_\mathrm{L}\to\infty$ gives $Z_1\to35\,\Omega$, $R_\mathrm{L}\to0$ gives $25\,\Omega$. Every load lies in between.

QuestionThe load is connected only to port 2. How does the input know about it?

Through the shared components. In the T two-port, both ports lead through $R_\mathrm{b}$, and its voltage drop depends on $I_1+I_2$. In general, $Z_{12}$ is the measure of this coupling. No signal transmission back is needed; the voltages in the network settle together.

Set RL=10 and check Exercise 4(a) and (c).

Exercise 4 ★★ The load on the T two-port

  1. What is $Z_1$ for $\textcolor{#1b7f4a}{R_\mathrm{L}}\textcolor{#15633a}{=}\textcolor{#c2410c}{10\,\Omega}$?

  2. At which load does the input show $\textcolor{#1b7f4a}{Z_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{30\,\Omega}$?

  3. For $\textcolor{#1b7f4a}{R_\mathrm{L}}\textcolor{#15633a}{=}\textcolor{#c2410c}{10\,\Omega}$ with the source connected, calculate the currents $I_1$, $I_2$ and $U_2$. Check the load current with the equivalent source.

Solution

(a) $\textcolor{#1b7f4a}{Z_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{35\,\Omega-400\,\Omega^2/50\,\Omega}\textcolor{#15633a}{=}\textcolor{#c2410c}{27\,\Omega}$. (b) $\textcolor{#1b7f4a}{400\,\Omega^2/(40\,\Omega+R_\mathrm{L})}\textcolor{#15633a}{=}\textcolor{#c2410c}{5\,\Omega}$, so $\textcolor{#1b7f4a}{R_\mathrm{L}}\textcolor{#15633a}{=}\textcolor{#c2410c}{40\,\Omega}$. (c) $\textcolor{#1b7f4a}{I_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{9\,\mathrm{V}/32\,\Omega}\textcolor{#15633a}{=}\textcolor{#c2410c}{281.25}$ mA, $\textcolor{#1b7f4a}{I_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\frac{20}{50}I_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{-112.5}$ mA, $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.125}$ V. The equivalent source gives $\textcolor{#1b7f4a}{4.5\,\mathrm{V}/(30\,\Omega+10\,\Omega)}\textcolor{#15633a}{=}\textcolor{#c2410c}{112.5}$ mA.
