Stage 6: Nodes, branches, meshes

What this stage is about:

A network has many unknowns. Before calculating, you count: How many currents and voltages are there, and how many independent equations are available for them?

The idea. For the number of equations, it does not matter which component sits in a branch. If every branch is replaced by a line, the skeleton of the network remains (Fig. 7). This skeleton determines the calculation.

Definition 6.1 (Basic topological terms)

Five terms describe the structure of a network:

  • A node is a point at which the current branches. $k$ is their number.

  • A branch connects two nodes via two-terminal elements, and a current flows in it. $z$ is their number.

  • The graph is the representation made of nodes and branches. It is connected: from every node, a path leads to every other. Each branch gets the direction of its current arrow.

  • A mesh is a closed path in which each node is connected to exactly two neighboring branches. No branch and no node is traversed more than once.

  • A tree is a connected subgraph that contains all nodes and forms no mesh. The remaining branches are called link branches.

Theorem 6.2 (Number of independent meshes)

Meshes are called linearly independent if they can be ordered so that each contains at least one branch missing from the previous ones. A graph with $k$ nodes and $z$ branches has exactly

$$\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{z-k+1}$$
(6.1)

independent meshes. They form a complete system: no further mesh adds anything new. Every tree defines such a system: each link branch closes exactly one mesh via the tree branches.

⁠How to read it: $m$ counts the meshes whose equations carry new information. All other meshes are composed of them. Validity: The graph must be connected.

Derivation: Why $z-k+1$

Build a tree: starting at one node, each new branch brings in exactly one new node; otherwise a mesh would arise. For $k$ nodes you need $k-1$ tree branches. That leaves $z-(k-1)$ link branches. In the tree, there is exactly one path between two nodes, so each link branch closes exactly one mesh. It contains no other link branch, which is why these meshes are independent.

Unknowns and equations. Each branch carries a current and a voltage, which makes $2z$ unknowns. Against them stand $z$ component equations (one per branch), $k-1$ node equations (Stage 7) and $z-k+1$ mesh equations (Stage 8). The sum is exactly $2z$. In short: Every network has exactly as many equations as unknowns.

Example

The network has $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$, so $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Its graph has 16 trees with three branches each. Fig. 7 chooses the star around $K_4$ with the branches 0, b and d. The link branches a, c and e close the meshes $M_1$, $M_2$ and $M_3$. The system comprises 12 unknowns and 12 equations.

⁠Limiting cases: A single loop has $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{k}$, so $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. A tree alone has $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{k-1}$, so $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$: without a closed path, no steady current flows.

QuestionIs the connection of two components without a junction a node?

According to the definition it is not, because nothing branches there. If you count it anyway, $m$ does not change: an additional node splits one branch into two, and $k$ and $z$ both grow by 1.

Exercise 6 ★★ Counting

Give $k$, $z$, $m$ and the number of tree branches in each case.

  1. A source feeds three resistors in parallel.

  2. $R_\mathrm e$ is removed from the network in Fig. 7.

  3. A network has 6 nodes and 10 branches. How many equations of which kind are needed?

Solution

(a) The two rails are the nodes: $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$, $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, one tree branch. (b) $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, one tree branch. Without $R_\mathrm e$ the current no longer branches at $K_2$ and $K_3$: $R_\mathrm a$ and $R_\mathrm b$ form one branch, $R_\mathrm c$ and $R_\mathrm d$ the other. (c) $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{10-6+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. You need 5 node equations, 5 mesh equations and 10 component equations for 20 unknowns. A tree has 5 branches.
