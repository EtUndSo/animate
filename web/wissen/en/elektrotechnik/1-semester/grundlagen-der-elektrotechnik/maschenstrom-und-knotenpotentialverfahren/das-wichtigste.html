The answer in three sentences

  1. A network with $z$ branches and $k$ nodes has $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{z-k+1}$ independent meshes and $k-1$ independent nodes. Of the $z$ currents only $m$ are free, of the $z$ voltages only $k-1$.

  2. Mesh current analysis calculates with the mesh current, an imagined circulating current for each mesh. It enters every node and leaves it again, so the node rule holds by itself. Node voltage analysis calculates with the node voltage, the voltage of each node against a freely chosen reference node. Every branch voltage is a difference, so the mesh rule holds by itself.

  3. The remaining equations can be read off the circuit as a matrix: in the resistance matrix, the diagonal holds the sum of the resistances of a mesh, and next to it stand the shared resistances of two meshes. In the conductance matrix, the diagonal holds the sum of the conductances at a node, and next to it stands the negative conductance between two nodes. Modified nodal analysis also takes the current of each voltage source as an unknown, and that is how SPICE calculates.

Key points

  • Of $z$ currents, $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{z-k+1}$ are free; of $z$ voltages, $k-1$. These are the sizes of the two methods. Node voltage analysis is smaller if $z>2k-2$.

  • Mesh currents run in circles; the node rule holds by itself. Branch current = sum of the mesh currents with signs. $\textcolor{#1b7f4a}{\mathbf Z\,\mathbf I}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf U_\mathrm q}$: diagonal sum of the resistances of the mesh, next to it $\pm$ shared resistances, on the right driving voltages.

  • Node voltages are heights; the mesh rule holds by itself. Branch voltage = difference. $\textcolor{#1b7f4a}{\mathbf Y\,\mathbf U}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf I_\mathrm q}$: diagonal sum of the conductances at the node, next to it the negative coupling conductance, on the right source currents flowing in.

  • Current sources disturb the meshes, voltage sources the nodes: real sources are converted beforehand. Internal quantities of the source are calculated in the original network.

  • Each component stamps independently: $G$ in four positions, current source only on the right, $g$ in the columns $p$, $q$. Delete the reference node. The matrix is sparse; controlled sources break the symmetry.

  • MNA: each voltage source brings along its current as an unknown and $\textcolor{#1b7f4a}{U_i-U_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mathrm q}$ as an equation. This is how SPICE calculates. A 0-V source measures current. The voltage gain is minus transconductance times load resistance.

One principle behind all the results. Kirchhoff demands two things: the node rule and the mesh rule. If you choose the unknowns so that one of the two rules holds for any numerical value, you only have to write down the other. The number of unknowns is then exactly the number of remaining equations.
