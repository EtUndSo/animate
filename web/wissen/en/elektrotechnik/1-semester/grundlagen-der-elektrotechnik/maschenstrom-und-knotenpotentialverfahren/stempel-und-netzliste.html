Stage 7: Stamps and netlist

What this stage is about:

A program sees no meshes and rearranges nothing. This stage shows how the matrix arises component by component, without any component having to know the others.

The idea. A component touches only its two nodes. Its current therefore appears in exactly two node equations, in one with plus, in the other with minus. So each component has a fixed entry pattern, its stamp (Fig. 7). You begin with a matrix full of zeros and add the stamps component by component. The order does not matter.

Theorem 7.1 (Stamps of conductance and current source)

Each row is the node rule “outgoing currents = impressed currents”.

  • A conductance $G$ between $i$ and $k$ carries the current $\textcolor{#1b7f4a}{I_Y}\textcolor{#15633a}{=}\textcolor{#c2410c}{G\,(U_i-U_k)}$ from $i$ to $k$. It adds $+G$ to the positions $(i,i)$ and $(k,k)$ and $-G$ to $(i,k)$ and $(k,i)$.

  • A fixed current source that pushes $I_\mathrm q$ through itself from $k$ to $i$ adds $+I_\mathrm q$ in row $i$ and $-I_\mathrm q$ in row $k$ of the right-hand side. It enters nothing in $\mathbf Y$, because its current depends on no voltage.

⁠How to read it: First, each of the $k$ nodes gets a row and a column, including the reference node. This full matrix has determinant zero, because all rows have the sum zero: if you raise all potentials together, no additional current flows anywhere. Physically, a network determines only differences. Only fixing $\textcolor{#1b7f4a}{U_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ makes the solution unique: you delete column 0 because its unknown is zero, and row 0 because it follows from the other node rules (Chapter 2). What remains is $\mathbf Y$ from Stage 5. Validity: The stamps apply to linear components. Voltage sources follow in Stage 9.

Netlist. A circuit diagram is stored as a netlist: one line per component, consisting of name, nodes and value. In SPICE, R3 1 2 2k means: resistor between the nodes 1 and 2. I2 0 2 4m means: 4 mA through the source from node 0 to node 2. The program goes through the list line by line and stamps. If a new node name appears, the matrix grows by one row and one column. Nobody has to know its size beforehand. The rigid format dates from the 1970s, when SPICE was written in FORTRAN and each line occupied a punched card.

With the rows and columns in the order 0, 1, 2 this gives

$$\textcolor{#1b7f4a}{\begin{pmatrix}1.55&-1.25&-0.3\\-1.25&1.75&-0.5\\-0.3&-0.5&0.8\end{pmatrix} \begin{pmatrix}U_0\\U_1\\U_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}-13\\9\\4\end{pmatrix}.}$$

Each row sums to zero. If you delete row and column 0, the system from Stage 5 remains. Check: In the reduced $\mathbf Y$, the row sum is the conductance to ground: $\textcolor{#1b7f4a}{1.75-0.5}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.25}\textcolor{#15633a}{=}\textcolor{#c2410c}{G_1+G_2}$ and $\textcolor{#1b7f4a}{0.8-0.5}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.3}\textcolor{#15633a}{=}\textcolor{#c2410c}{G_4+G_5}$.

⁠Limiting case: A node without a branch to ground has the row sum zero.

Large networks. A node is usually connected to only two to five neighbors, so almost all positions of a large matrix are zero. It is called sparse. The simulator stores only the nonzero entries and solves the system by stepwise elimination. Cramer's rule would be useless for this: a determinant with 20 rows has around $2.4\cdot10^{18}$ products following the pattern of (0.1).

Going deeper, not needed for the rest: Alternating current, capacitor, diode

With sinusoidal quantities you calculate with complex conductances, the admittances. That is where the letters $Y$ and $Z$ come from. A capacitor has the same stamp as a conductance. An impedance $Z$ can be entered only as $\textcolor{#1b7f4a}{Y}\textcolor{#15633a}{=}\textcolor{#c2410c}{1/Z}$ as long as it is not zero; a coil at frequency zero breaks this. Stage 9 solves this problem. The simulator replaces nonlinear components such as diodes (Chapter 9) by the tangent of their characteristic curve, stamps it and repeats this until nothing changes any more.

QuestionWhy may you delete precisely the row of the reference node?

Each of the $k$ node equations follows from the others (Chapter 2). You could delete any of them. You delete the row of the reference node because, together with its column, a symmetric matrix results again and because the current into ground is rarely of interest.

Exercise 9 ★★ From the netlist to the solution

The list R1 1 0 1k, R2 1 2 2k, R3 2 0 2k, I1 0 1 7m, I2 2 1 1m is given.

  1. Stamp the full $3\times3$ matrix and the right-hand side. Check the row sums.

  2. Delete the reference node and solve.

  3. Check: Which current flows through the resistors into ground, and which comes out of it?

Solution

(a) With the conductances 1, 0.5, 0.5 mS and rows 0, 1, 2:

$$\textcolor{#1b7f4a}{\begin{pmatrix}1.5&-1&-0.5\\-1&1.5&-0.5\\-0.5&-0.5&1\end{pmatrix}\begin{pmatrix}U_0\\U_1\\U_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}-7\\8\\-1\end{pmatrix}.}$$

I2 2 1 1m pushes 1 mA from 2 to 1, so $+1$ in row 1 and $-1$ in row 2. All row sums are zero, and the sum on the right is zero too.

(b) $\textcolor{#1b7f4a}{\begin{pmatrix}1.5&-0.5\\-0.5&1\end{pmatrix}\begin{pmatrix}U_1\\U_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}8\\-1\end{pmatrix}}$ with $\textcolor{#1b7f4a}{D}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.25}$, $\textcolor{#1b7f4a}{D_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{7.5}$, $\textcolor{#1b7f4a}{D_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.5}$. So $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$ V, $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ V.

(c) Through R1 flow 6 mA into ground, through R3 1 mA, together 7 mA. I1 takes exactly 7 mA out of ground.
