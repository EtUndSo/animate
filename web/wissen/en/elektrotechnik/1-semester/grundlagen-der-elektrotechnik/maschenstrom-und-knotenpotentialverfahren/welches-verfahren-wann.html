What this stage is about:

Both methods deliver the same result. This stage clarifies which one takes less work and what each one cannot do.

The idea. The computational work lies in the size of the matrix. Mesh current analysis needs $z-k+1$ unknowns, node voltage analysis $k-1$. Many branches at few nodes mean many meshes but few nodes. Long chains mean the opposite.

Theorem 6.1 (Comparison of the number of equations)

Node voltage analysis needs fewer equations exactly when $k-1<z-k+1$, that is,

$$z>2k-2.$$
(6.1)

⁠How to read it: On average, $2z/k$ branch ends meet at a node, because every branch has two ends. On the boundary that is $4-4/k$, so just under four. If on average more branches meet at the nodes, node voltage analysis wins (Fig. 6). Validity: Each real source counts as one branch, because for the meshes it becomes a voltage source and a series resistor. The conversion does not change $k-1$.

The table shows a duality, a mirroring: if you swap mesh and node, current and voltage, series and parallel, resistance and conductance, one method turns into the other. The reason lies in Kirchhoff: both rules say “the sum is zero”, only over different sets.

Example

After the conversion on the right, the model network has $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ and $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. With $5>4$ it lies above the line, and indeed there were three meshes against two nodes.

⁠Limiting case: The bridge from Chapter 2 with $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ and $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$ lies exactly on the line. Then the sources decide: an ideal voltage source speaks for meshes, because there it stands on the right-hand side.

Simulators use only node voltages. A program must first search for the meshes of a network, and windows exist only if the network can be drawn without crossings. Nodes, on the other hand, are already in the circuit description (Stage 7).

QuestionIsn't mesh current analysis superfluous if simulators don't use it?

For large networks, yes. By hand it is often shorter, and it keeps your eye on the current loops: you see which currents share which path. With few meshes and many nodes, for instance in long chains of series connections, it clearly wins.

Exercise 8 ★ Choosing the method

Which method needs fewer equations? Give both numbers.

  1. Three real voltage sources lie in parallel across a load, each as one branch.

  2. A ring of six components.

  3. Five nodes, all connected to each other.

  4. Show: if in a network you combine two components in series together with the node between them, $k$ and $z$ decrease by 1 and $m$ stays the same.

Solution

(a) $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ against $\textcolor{#1b7f4a}{k-1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, node voltages. Here $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{4>2}$.

(b) $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ against 5, mesh currents.

(c) $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$ against 4, node voltages.

(d) The node between them disappears and two branches become one, so $\textcolor{#1b7f4a}{m'}\textcolor{#15633a}{=}\textcolor{#c2410c}{(z-1)-(k-1)+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{z-k+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$. The count from Chapter 2 reaches the same conclusion.
