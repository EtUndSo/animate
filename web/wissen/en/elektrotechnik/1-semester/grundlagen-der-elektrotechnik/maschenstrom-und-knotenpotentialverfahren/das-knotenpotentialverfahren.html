Stage 5: Node voltage analysis

  • Deutsch
  • English
  • Español
  • Français
  • Türkçe
  • 中文
What this stage is about:

The mesh rule is taken care of; $k-1$ node rules with $k-1$ unknowns remain. This stage sets them up and solves the same network a second time.

The idea. The current that flows away through a conductance $G$ from node $\mu$ to neighbor $\nu$ is $G\,(U_\mu-U_\nu)$. If you add all outgoing currents of a node and sort by potentials, the sum of all conductances at the node stands in front of the node's own potential. In front of another node's potential stands only the conductance leading to that node, with a minus: if you raise the neighbor, less flows away. Fig. 5 shows this as an experiment.

Definition 5.1 (Node voltage analysis)

The method has four steps:

  1. Convert real voltage sources into real current sources: $\textcolor{#1b7f4a}{I_\mathrm q}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mathrm q/R}$, the same resistor in parallel (Chapter 5).

  2. Fix a reference node and enter the potentials of the other nodes as voltages against it. Write resistors as conductances.

  3. Set up the node rule for the $k-1$ remaining nodes or read the matrix off directly.

  4. Solve the system for the node voltages and calculate branch voltages and branch currents from them.

Theorem 5.2 (Matrix form of node voltage analysis)

With $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{k-1}$, the node voltages satisfy $\textcolor{#1b7f4a}{\mathbf Y\,\mathbf U}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf I_\mathrm q}$:

$$\textcolor{#1b7f4a}{\begin{pmatrix}Y_{11}&Y_{12}&\dots&Y_{1n}\\Y_{21}&Y_{22}&\dots&Y_{2n}\\\vdots&\vdots&\ddots&\vdots\\Y_{n1}&Y_{n2}&\dots&Y_{nn}\end{pmatrix} \begin{pmatrix}U_1\\U_2\\\vdots\\U_n\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{ \begin{pmatrix}I_\mathrm{q1}\\I_\mathrm{q2}\\\vdots\\I_{\mathrm qn}\end{pmatrix}.}$$
(5.1)

  • $Y_{\mu\mu}$ is the sum of all conductances connected to node $\mu$.

  • $\textcolor{#1b7f4a}{Y_{\mu\nu}}\textcolor{#15633a}{=}\textcolor{#c2410c}{Y_{\nu\mu}}$ is the negative coupling conductance, that is, minus the sum of the conductances lying directly between the nodes $\mu$ and $\nu$. Without a direct connection, the entry is zero.

  • $I_{\mathrm q\mu}$ is the sum of the source currents at the node, positive if they flow into the node.

Derivation: From the node rule to the matrix

At node $\mu$, the current $G_a\,(U_\mu-U_\nu)$ flows away through each conductance $G_a$ to the neighbor $\nu$, and $G_a\,U_\mu$ to the reference node. The sum of these currents equals the injected $I_{\mathrm q\mu}$. Sorting gives the sum of all $G_a$ in front of $U_\mu$ and minus the sum of the conductances between $\mu$ and $\nu$ in front of $U_\nu$. Node $\nu$ receives the same entry, because a conductance has no direction. That is why $\mathbf Y$ is symmetric.

⁠How to read it: Row $\mu$ is the node rule: on the left stand all currents flowing away through conductances, on the right what the sources push in. Column $\nu$ says: if you hold node $\nu$ at 1 V and all others at 0 V, you must inject the current $Y_{\nu\nu}$ at node $\nu$ and draw the current $-Y_{\mu\nu}$ at each neighbor $\mu$. That is exactly the short-circuit test from Chapter 6. Validity: The network contains conductances and fixed current sources. An ideal voltage source does not fit in, because it has no finite conductance (Stage 9).

Example

On the left, $\textcolor{#1b7f4a}{I_\mathrm{q1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mathrm q/R_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{9}$ mA with $\textcolor{#1b7f4a}{G_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mS in parallel. The conductances are $\textcolor{#1b7f4a}{G_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.25}$ mS, $\textcolor{#1b7f4a}{G_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.5}$ mS, $\textcolor{#1b7f4a}{G_4}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.1}$ mS and $\textcolor{#1b7f4a}{G_5}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.2}$ mS (Fig. 5). The node rules read

$$\begin{aligned} \text{Node 1:}\quad&(G_1+G_2)\,U_1+G_3\,(U_1-U_2)-I_\mathrm{q1}=0,\\ \text{Node 2:}\quad&G_3\,(U_2-U_1)+(G_4+G_5)\,U_2-I_\mathrm q=0. \end{aligned}$$

Sorted, in mS, V and mA:

$$\textcolor{#1b7f4a}{\begin{pmatrix}G_1+G_2+G_3&-G_3\\-G_3&G_3+G_4+G_5\end{pmatrix}\begin{pmatrix}U_1\\U_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{ \begin{pmatrix}1.75&-0.5\\-0.5&0.8\end{pmatrix}\begin{pmatrix}U_1\\U_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}9\\4\end{pmatrix}.}$$

With $\textcolor{#1b7f4a}{D}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.4-0.25}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.15}$, $\textcolor{#1b7f4a}{D_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{7.2+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{9.2}$ and $\textcolor{#1b7f4a}{D_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{7+4.5}\textcolor{#15633a}{=}\textcolor{#c2410c}{11.5}$, it follows that $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ V and $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$ V. This is the same result as from the three meshes, with a $2\times2$ instead of a $3\times3$ calculation.

The currents come from the differences, and in the original network: $\textcolor{#1b7f4a}{(U_\mathrm q-U_1)/R_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mA, $\textcolor{#1b7f4a}{U_1/R_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ mA, $\textcolor{#1b7f4a}{(U_2-U_1)/R_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mA, $\textcolor{#1b7f4a}{U_2/R_4}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mA, $\textcolor{#1b7f4a}{U_2/R_5}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ mA. Checks: At node 2, $\textcolor{#1b7f4a}{4}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+1+2}$ mA. The sources deliver $\textcolor{#1b7f4a}{9\,\mathrm{V}\cdot1\,\mathrm{mA}+10\,\mathrm{V}\cdot4\,\mathrm{mA}}\textcolor{#15633a}{=}\textcolor{#c2410c}{49}$ mW, the resistors absorb $\textcolor{#1b7f4a}{1+16+2+10+20}\textcolor{#15633a}{=}\textcolor{#c2410c}{49}$ mW.

⁠Limiting case: For $G_3\to0$ the off-diagonal entries vanish, and the two sides calculate separately (Exercise 7).

QuestionIn $\mathbf Z$ the sign depends on the arrows. Why is there always a minus in $\mathbf Y$?

Mesh currents have a direction that you choose, and so there are two possibilities in the shared branch. Node voltages have no direction; all count toward the same reference node. At the conductance between two nodes there is therefore always the difference, and the other node's potential always carries a minus.

QuestionAfter the conversion, 2 mA flow upward through $R_5$ in the mesh picture, but 2 mA downward in the original network. Which is right?

The original network. Equivalent sources agree only at the terminals (Chapter 5). At node 2 and at ground both forms deliver the same; inside the source the current means different things. That is why you calculate internal quantities in the original network from the terminal voltages.

Exercise 6 ★★ Three nodes and a reference

A network has the nodes 0 (reference), 1, 2, 3. Resistors: 1 k$\Omega$ from 1 to 0, 1 k$\Omega$ from 1 to 2, 500 $\Omega$ from 2 to 0, 1 k$\Omega$ from 2 to 3, 1 k$\Omega$ from 3 to 0. Current sources push 6 mA into node 1 and 3 mA into node 2.

  1. Read off $\mathbf Y$ and $\mathbf I_\mathrm q$. Why is $\textcolor{#1b7f4a}{Y_{13}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$?

  2. Calculate the node voltages with Cramer's rule.

  3. Calculate all resistor currents and do the check at node 2.

  4. How many mesh currents do you need after converting the two sources? Which method would be shorter here?

Solution

(a) With 1 mS, 1 mS, 2 mS, 1 mS, 1 mS:

$$\textcolor{#1b7f4a}{\mathbf Y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2&-1&0\\-1&4&-1\\0&-1&2\end{pmatrix}\mathrm{mS},}$$
$$\textcolor{#1b7f4a}{\mathbf I_\mathrm q}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}6\\3\\0\end{pmatrix}\mathrm{mA}.}$$

$\textcolor{#1b7f4a}{Y_{13}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, because there is no resistor between 1 and 3.

(b) $\textcolor{#1b7f4a}{D}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\cdot7+1\cdot(-2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{12}$, $\textcolor{#1b7f4a}{D_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{48}$, $\textcolor{#1b7f4a}{D_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{24}$, $\textcolor{#1b7f4a}{D_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{12}$. So $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ V, $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ V, $\textcolor{#1b7f4a}{U_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ V.

(c) $\textcolor{#1b7f4a}{I_{10}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ mA, $\textcolor{#1b7f4a}{I_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ mA, $\textcolor{#1b7f4a}{I_{20}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ mA, $\textcolor{#1b7f4a}{I_{23}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mA, $\textcolor{#1b7f4a}{I_{30}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ mA. Node 2: $\textcolor{#1b7f4a}{3+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{4+1}$ mA.

(d) Each current source becomes one branch with its parallel resistor. Then $\textcolor{#1b7f4a}{z}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ and $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$, so $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ against $\textcolor{#1b7f4a}{k-1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Mesh current analysis would be shorter with two equations. Node 3 is in truth not a node, but a series connection.

Exercise 7 ★★ Limiting cases of the coupling conductance

  1. $R_3$ in the model network is removed ($\textcolor{#1b7f4a}{G_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$). What becomes of $\mathbf Y$? Calculate $U_1$ and $U_2$.

  2. Prediction: $R_3$ is replaced by a wire. Why does this not work directly in $\mathbf Y$? Merge the nodes and determine the common voltage and the current in the wire.

Solution

(a) The off-diagonal entries become zero and the equations decouple: $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{9\,\mathrm{mA}/1.25\,\mathrm{mS}}\textcolor{#15633a}{=}\textcolor{#c2410c}{7.2}$ V and $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\,\mathrm{mA}/0.3\,\mathrm{mS}}\textcolor{#15633a}{=}\textcolor{#c2410c}{13.3}$ V. These are two separate networks.

(b) $G_3\to\infty$ cannot be entered as a number. The wire turns both nodes into one: $\textcolor{#1b7f4a}{U}\textcolor{#15633a}{=}\textcolor{#c2410c}{(9+4)\,\mathrm{mA}/(1+0.25+0.1+0.2)\,\mathrm{mS}}\textcolor{#15633a}{=}\textcolor{#c2410c}{8.39}$ V. The current in the wire follows from node 2: $\textcolor{#1b7f4a}{4\,\mathrm{mA}-0.3\,\mathrm{mS}\cdot8.39\,\mathrm{V}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.48}$ mA from 2 to 1. Stage 9 solves the same situation with a 0-V source.
