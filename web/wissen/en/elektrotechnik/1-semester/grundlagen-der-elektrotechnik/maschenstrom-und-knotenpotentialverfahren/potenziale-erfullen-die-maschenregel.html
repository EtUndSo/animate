Stage 4: Potentials satisfy the mesh rule

What this stage is about:

Of $z$ voltages only $k-1$ are free. This stage shows why the potentials of the nodes take on this role and why the mesh rule then holds by itself.

The idea. Each node has a potential (Chapter 1), just as each point of a landscape has a height. The voltage of a branch is the height difference between its ends. Anyone who walks in a circle arrives back at the starting height, whatever heights have been assigned to the nodes (Fig. 4). So the mesh rule cannot be violated at all. Since only differences count, you may fix one height freely. That saves one unknown, and $k-1$ remain.

Definition 4.1 (Reference node and node voltage)

A freely chosen node 0 is the reference node; its potential is $\textcolor{#1b7f4a}{\varphi_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. The node voltage of another node $\mu$ is its voltage against the reference node:

$$\textcolor{#1b7f4a}{U_\mu}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varphi_\mu-\varphi_0.}$$
(4.1)

The voltage of a branch between the nodes $\mu$ and $\nu$ is $\textcolor{#1b7f4a}{U_{\mu\nu}}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mu-U_\nu}$; toward the reference node it is $\textcolor{#1b7f4a}{U_{\mu0}}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_\mu}$.

Theorem 4.2 (Node voltages)

For any values of the $k-1$ node voltages, every mesh rule is satisfied. Conversely, every voltage distribution that satisfies the mesh rule has exactly one set of node voltages.

Derivation: Why this always works

⁠Mesh rule. Along a mesh through the nodes $1,2,\dots,N$, $\textcolor{#1b7f4a}{(U_1-U_2)+(U_2-U_3)+\dots+(U_N-U_1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Each potential appears once with $+$ and once with $-$.

⁠Completeness. Choose a tree. In it there is exactly one path between the reference node and each node. The sum of the branch voltages along this path defines the node voltage uniquely. With this, all differences are correct for the tree branches. For each link branch the difference is correct because it closes a mesh with tree branches, whose rule holds by assumption.

⁠How to read it: $U_\mu$ is a voltage with an arrow from node $\mu$ to the reference node, unit volt. In a circuit diagram, the ground symbol marks the reference node; in SPICE it is always called 0. You choose the reference node where most branches meet, which makes the equations shortest. Validity: The field must be curl-free. A changing magnetic field through a mesh destroys the potentials (Chapter 1); in circuits it sits in coils.

Example

In the model network, $\textcolor{#1b7f4a}{U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ V and $\textcolor{#1b7f4a}{U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$ V, as Stage 3 showed. The voltage across $R_3$ is $\textcolor{#1b7f4a}{U_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{U_1-U_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2}$ V, so node 2 lies higher, and the current runs from 2 to 1. With $\textcolor{#1b7f4a}{R_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,\mathrm{k\Omega}}$ that is the 1 mA from Stage 3. The round trip gives $\textcolor{#1b7f4a}{(U_1-U_2)+U_2-U_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for any other pair of numbers too.

⁠Limiting case: A network with $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ has a single node voltage. That is the common voltage of a parallel connection.

QuestionSo is the node voltage a potential or a voltage?

Both. A potential by itself has a value only relative to a zero point (Chapter 1). The node voltage is the voltage against the chosen zero point, which is why it carries the symbol $U$. Changing the reference node changes all node voltages, but not a single branch voltage.

Exercise 5 ★ Changing the reference

In the model network, choose node 2 as the reference node. (a) What node voltages do the lower line and node 1 have? (b) From these, calculate the voltage between node 1 and the lower line. (c) Why does no current change?

Solution

(a) All potentials drop by 10 V: lower line $-10$ V, node 1 $-2$ V, node 2 0 V.

(b) $\textcolor{#1b7f4a}{-2\,\mathrm{V}-(-10\,\mathrm{V})}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ V, as before.

(c) Currents depend only on differences, and those stay the same.
