What this stage is about:

The definition says what a function is, but not what it looks like. Three properties save computation: Symmetry halves the work, monotonicity orders the values, boundedness limits them.

The idea. If $f(x)$ depends only on the distance from zero, the values on the left are a mirror image of the values on the right (Fig. 3). If $f$ grows with $x$, then $x<y$ already tells you something about the values without computing them. If $f$ stays below a fixed number, nothing can grow beyond all bounds.

Definition 2.1 (Symmetry, monotonicity, boundedness)

Let $f$ be a real function. If $\mathcal D(f)$ contains $-x$ along with $x$, then $f$ is called even if $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(-x)}$ for all $x\in\mathcal D(f)$, and odd if $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-f(-x)}$ for all $x\in\mathcal D(f)$. Further, $f$ is called, in each case for all $x,y\in\mathcal D(f)$,

  1. monotonically increasing if $x<y$ implies $f(x)\le f(y)$;

  2. strictly monotonically increasing if $x<y$ implies $f(x)<f(y)$;

  3. monotonically decreasing if $x<y$ implies $f(x)\ge f(y)$;

  4. strictly monotonically decreasing if $x<y$ implies $f(x)>f(y)$.

$f$ is called bounded above (below) if there is a number $K$ with $f(x)\le K$ ($f(x)\ge K$) for all $x\in\mathcal D(f)$, that is, if the set $\mathcal W(f)$ is bounded above (below). If both hold, $f$ is called bounded.

⁠How to read it: Even means: Reflection in the $y$-axis maps the graph onto itself. Odd means: Point reflection through the origin maps it onto itself. The names come from the powers: $\textcolor{#1b7f4a}{(-x)^{2n}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^{2n}}$ and $\textcolor{#1b7f4a}{(-x)^{2n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-x^{2n+1}}$. It is therefore enough to know the values on $\mathcal D(f)\cap\mathbb{R}_0^+$; the reflection supplies the rest. Decreasing and increasing are linked: $f$ is (strictly) monotonically decreasing if and only if $-f$ is (strictly) monotonically increasing, because multiplication by $-1$ flips the inequality.

Theorem 2.2 (Powers are monotonic)

Let $n\in\mathbb{N}$. For odd $n$, $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^n}$ is strictly monotonically increasing on $\mathbb{R}$; for even $n$, on $\mathbb{R}_0^+$.

Proof: Powers

⁠Case $0\le x<y$, every $n$: Induction on $n$. For $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ there is nothing to show. From $x^n<y^n$ follows $\textcolor{#1b7f4a}{x^{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\cdot x^n\le y\cdot x^n<y\cdot y^n}\textcolor{#15633a}{=}\textcolor{#c2410c}{y^{n+1}}$. The first step uses $x<y$ and $x^n\ge0$, the second $y>0$. This settles even $n$. Case $x<y\le0$, $n$ odd: We have $0\le-y<-x$, by the first case $(-y)^n<(-x)^n$, and because $n$ is odd, $-y^n<-x^n$, so $x^n<y^n$. Case $x<0<y$, $n$ odd: $x^n<0<y^n$.

⁠How to read it: $n$ is the fixed power. Why “on $\mathbb{R}_0^+$” is needed: For even $n$, $f$ is not monotonic on all of $\mathbb{R}$: $-2<-1$, but $(-2)^2>(-1)^2$.

Examples

$h$ is bounded below by $-1$, but not above. The bell is bounded and strictly decreasing on $\mathbb{R}_0^+$: From $0\le x<y$ follows $1+x^2<1+y^2$, so $b(x)>b(y)$. Sum and product of bounded functions are again bounded: From $|f|\le K$ and $|g|\le L$ follow $|f+g|\le K+L$ and $|f\cdot g|\le K\,L$.

⁠Limiting cases: A constant function is monotonically increasing and decreasing at the same time, but not strictly. $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ is even and odd at the same time.

QuestionIs a function that is not even automatically odd?

For numbers that is true; for functions it is not: $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^2+x}$ has $\textcolor{#1b7f4a}{f(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ and $\textcolor{#1b7f4a}{f(-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$: neither equal nor opposite. Most functions are neither.

Exercise 2 ★★ Symmetry and bounds

(a) Even, odd or neither: $\textcolor{#1b7f4a}{f_1(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^4-3x^2}$, $\textcolor{#1b7f4a}{f_2(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^3+x}$, $\textcolor{#1b7f4a}{f_3(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^2+x}$, $\textcolor{#1b7f4a}{f_4(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\,|x|}$? (b) Show: The product of two odd functions is even. (c) For $\textcolor{#1b7f4a}{v(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{3/(2+x^2)}$, determine bounds and the range, and show that $v$ is strictly decreasing on $\mathbb{R}_0^+$.

Solution

(a) $\textcolor{#1b7f4a}{f_1(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{f_1(x)}$: even. $\textcolor{#1b7f4a}{f_2(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-x^3-x}\textcolor{#15633a}{=}\textcolor{#c2410c}{-f_2(x)}$: odd. $\textcolor{#1b7f4a}{f_3(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{f_3(-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$: neither. $\textcolor{#1b7f4a}{f_4(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-x\,|x|}\textcolor{#15633a}{=}\textcolor{#c2410c}{-f_4(x)}$: odd. (b) With $\textcolor{#1b7f4a}{f(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-f(x)}$ and $\textcolor{#1b7f4a}{g(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-g(x)}$ we get $\textcolor{#1b7f4a}{(f\cdot g)(-x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-f(x))(-g(x))}\textcolor{#15633a}{=}\textcolor{#c2410c}{(f\cdot g)(x)}$. (c) Because $2+x^2\ge2$, we have $0<v(x)\le\frac32$. Every $y\in(0,\frac32]$ is hit by $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sqrt{3/y-2}}$, so $\textcolor{#1b7f4a}{\mathcal W(v)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\frac32]}$. For $0\le x<y$ the denominator grows and the fraction falls.
