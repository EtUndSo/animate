Chapter 1: A Linux to Practice On: WSL, Virtual Machine, Live USB Stick

  1. Termoperating system
    The operating system is the software that manages a computer's hardware, makes it available to the other programs through uniform services and keeps the programs apart from one another.
    Operating system, kernel and distribution
  2. Termapplication program
    A program that runs under an operating system and performs a task for the user is called an application program, or program for short.
    Operating system, kernel and distribution
  3. Termkernel mode
    In kernel mode, the running program may execute any instruction of the processor.
    Operating system, kernel and distribution
  4. Termuser mode
    In user mode, certain instructions are blocked, such as direct access to devices and setting which program may use which part of main memory.
    Operating system, kernel and distribution
  5. Termprivileged instruction
    Such a blocked instruction is called a privileged instruction.
    Operating system, kernel and distribution
  6. Termkernel
    The kernel (the core of the system) is the part of the operating system that runs in kernel mode.
    Operating system, kernel and distribution
  7. Termdrivers
    The drivers also belong to the kernel: pieces of software that can control a particular device, such as a particular network card or a particular SSD.
    Operating system, kernel and distribution
  8. Termsystem call
    A system call is a request from a program to the kernel to perform a particular service, for example to open a file, read data or provide memory.
    Operating system, kernel and distribution
  9. Termdistribution
    A distribution is a complete operating system that a vendor or a community assembles from the Linux kernel, tools, application programs and default settings and maintains as a whole.
    Operating system, kernel and distribution
  10. Termpackage manager
    Every distribution comes with a package manager: a program with which you install, update and remove software from the distribution's sources.
    Operating system, kernel and distribution
  11. TermLTS release
    Every two years in April, an LTS release (Long Term Support) appears, for which Canonical supplies security fixes and bug fixes for five years.
    Operating system, kernel and distribution
  12. Termpoint release
    A number like 26.04.1 denotes a point release: the same system with the fixes collected up to that point and new installation media.
    Operating system, kernel and distribution
