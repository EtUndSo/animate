What this is about#

A lot of everyday data comes as plain text: the runs of a running club, the transactions of a bank account as a file from online banking, weather readings, the entries of a log that a program writes line by line. Often you have a simple question about such a file. Who ran most often? Which run was the longest? How many kilometers does a run cover on average? Which lines come from a particular week?

This chapter pursues one question: How do you answer such questions on the command line without writing a program of your own? It shows small tools that select lines, cut out columns, sort, count, transform and calculate, and a notation with which you search not for fixed words but for the form of a text. Afterward, you can analyze a file with many lines in a few steps, and you know why the tools sometimes behave differently than you would first expect.

How to work with this chapter. The sections build on each other, and every new term has its own subsection with an example. Expandable boxes contain background (why something is the way it is and where it comes from) and derivations; you do not need them to read on. Boxes marked “Caution” state rules that always apply to practical exercises. Try the exercises (★ to ★★★) yourself first; the solution expands right below each exercise.
