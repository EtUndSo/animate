The technical terms of this module with their definitions. Selecting a term takes you to the place where it is introduced.

Flashcards

0–9ABCDEFGHIKLMNOPRSTUVWX
169 terms

0–9

!
A ! in front of a test negates it. Chapter 3 · Finding files and measuring space

A

absolute path
An absolute path begins with /. Chapter 3 · The working directory and paths
action
What find does with a match is determined by an action; if none is given, it is -print, which prints the path. Chapter 3 · Finding files and measuring space
address
Every device in a network has a number under which others reach it, its address. Chapter 1 · Virtual machines: the computer within the computer
alias
An alias is a name that the shell replaces with a stored text while reading a command line if the name stands at the start as a command. Chapter 2 · Kinds of commands
AND list
The notation command1 && command2 is an AND list: the shell runs command2 only if command1 ended with exit status 0. The exit status of the AND list is that of the last command executed. Chapter 4 · Chaining commands
appending
The notation command >> file connects standard output to the file for appending: every byte written goes after the existing contents, and nothing is deleted. Chapter 4 · Redirecting output
application program
A program that runs under an operating system and performs a task for the user is called an application program, or program for short. Chapter 1 · Operating system, kernel and distribution
apropos
The command apropos searches the names and short descriptions of all manual pages for a keyword and lists the hits with their section. Chapter 2 · Finding help
argument
Every word of the command line after the command is an argument. Chapter 2 · The structure of a command line
argument list limit
The kernel limits how many bytes all the arguments of a program start may have together; getconf ARG_MAX shows this argument list limit. Chapter 4 · Turning output into arguments

B

bash
On Ubuntu, Debian and Fedora, the terminal opens the shell bash, short for “Bourne-Again Shell”. Chapter 2 · Terminal and shell
BitLocker
BitLocker is the drive encryption of Windows; in Windows Home, it is called device encryption. Chapter 1 · How a PC starts
boot loader
A boot loader is the boot program that the firmware loads and that in turn loads the kernel of the operating system into main memory and starts it. Chapter 1 · How a PC starts
boot menu
The boot menu is a selection that the firmware displays when you press a key at power-on; in it, you choose an entry once, without changing the boot order. Chapter 1 · How a PC starts
boot order
The boot order is the list of boot entries in the order in which the firmware tries them at power-on. Chapter 1 · How a PC starts
builtin command
A builtin command is a command that the shell runs itself, without starting another program. Chapter 2 · Kinds of commands

C

cat
The command cat reads the files given as arguments in turn and writes out their bytes unchanged, one after the other. Chapter 3 · Viewing files
cd
The builtin command cd (short for “change directory”) makes the directory that its argument denotes the shell's new working directory. Chapter 3 · The working directory and paths
checksum
A checksum is a short value that a fixed method calculates from the contents of a file. Chapter 1 · Storage device, image and checksum
command
The first word of a command line is the command: the name of what is to be run. Chapter 2 · The structure of a command line
command line
A command line is everything you type after the prompt before you press Enter. Chapter 2 · The structure of a command line
Completion
Completion finishes a partly typed word as soon as you press the Tab key. Chapter 2 · Working faster: completion, history, keyboard shortcuts
copy
The notation n>&m makes descriptor $n$ a copy of descriptor $m$: afterward, $n$ leads to the same open file as $m$ at that moment. Chapter 4 · Redirecting output
coreutils
The coreutils (“core utilities”) are a collection of over a hundred basic commands for files, text and system information, including ls, cat, head, cp, uname, date and df. Chapter 2 · Two implementations of the core commands: GNU and uutils
cp
The command cp (short for “copy”) copies a file: cp source target creates a new file with the same contents under the name target. Chapter 3 · Copying, moving, deleting
Ctrl+C
The key combination Ctrl+C asks the program that is currently running in the terminal to stop immediately; almost all programs then stop, and the shell shows the prompt again. Chapter 2 · Working faster: completion, history, keyboard shortcuts
Ctrl+D
The key combination Ctrl+D at the start of a line tells the program that is currently reading that no more input follows. Chapter 2 · Working faster: completion, history, keyboard shortcuts
current folder
The shell always works in a particular folder. This folder is called the current folder. Chapter 2 · Terminal and shell

D

device file
A device file is an entry in the directory tree behind which there are no stored contents but a device that a driver in the kernel manages. Chapter 3 · The directory structure of Linux
df
If df receives paths as arguments, it shows for each path the file system in which it is located, with size, used and free space. Chapter 3 · Storage devices and mounting
digital signature
Chapter 1 · Storage device, image and checksum
directory
A directory is a list of entries. Chapter 3 · Files, directories and the directory tree
directory tree
The directories of a Linux system form a single directory tree: every directory except one is entered under its name in exactly one other directory. Chapter 3 · Files, directories and the directory tree
distribution
A distribution is a complete operating system that a vendor or a community assembles from the Linux kernel, tools, application programs and default settings and maintains as a whole. Chapter 1 · Operating system, kernel and distribution
drivers
The drivers also belong to the kernel: pieces of software that can control a particular device, such as a particular network card or a particular SSD. Chapter 1 · Operating system, kernel and distribution
du
The command du (short for “disk usage”) adds up, for each given directory and each subdirectory in it, the space that the files occupy on the storage device, in units of 1024 bytes. Chapter 3 · Finding files and measuring space

E

EFI system partition
A UEFI firmware reads its boot programs from a small, dedicated partition with a FAT file system, the EFI system partition; it is the first of the four partitions from the example in subsection 5.2. Chapter 1 · How a PC starts
end of the stream
If nothing more arrives during reading and nothing more can arrive, the end of the stream has been reached; the kernel tells the reading process by having a read request return zero bytes. Chapter 4 · Processes and their three streams
/etc
The directory /etc contains the configuration that applies to the whole system. Chapter 3 · The directory structure of Linux
exit status
When it ends, every process leaves behind an integer from 0 to 255, its exit status. Chapter 4 · The exit status

F

-F
Chapter 3 · Showing the contents of a directory
Fast Startup
Chapter 1 · The live USB stick: preparing, writing, starting
file
A file is a sequence of bytes that is stored permanently under a name. Chapter 3 · Files, directories and the directory tree
file descriptor
A file descriptor, descriptor for short, is a small integer under which the kernel keeps track of an open file for a process. Chapter 4 · Processes and their three streams
Filesystem Hierarchy Standard
The Filesystem Hierarchy Standard, FHS for short, specifies which directories a Linux system should have and which kind of files belongs in which of them. Chapter 3 · The directory structure of Linux
filter
A filter is a program that reads data from its standard input, transforms it and writes the result to its standard output. Chapter 4 · Pipes and filters
find
The command find walks through the subtree below each given starting directory, entry by entry and level by level. Chapter 3 · Finding files and measuring space
findmnt
The command findmnt lists the mounted file systems with mount point (TARGET), source (SOURCE), type (FSTYPE) and options (OPTIONS). Chapter 3 · Storage devices and mounting
firmware
The firmware is a program that is stored permanently in a memory chip on the main circuit board (the motherboard) and runs first when the computer is switched on. Chapter 1 · How a PC starts

G

GRUB
Linux distributions usually use the GRUB boot loader. Chapter 1 · How a PC starts
guest
The guest is the operating system that runs in the virtual machine. Chapter 1 · Virtual machines: the computer within the computer

H

-h
Together with -l, the option -h (short for “human-readable”) makes ls print each size in the largest suitable unit: K for 1024 bytes, M for $1024^2$ bytes, G for $1024^3$ bytes. Chapter 3 · Showing the contents of a directory
hard link
A hard link is a further directory entry for an existing inode, that is, an additional name for the same file. Chapter 3 · Inodes and links
Hardware virtualization
Chapter 1 · Virtual machines: the computer within the computer
head
The command head writes out the first lines of a file, the command tail the last ones. Chapter 3 · Viewing files
help
The builtin command help shows the instructions for the shell's builtin commands. Chapter 2 · Finding help
here document
A here document is a redirection of the form command <<ENDMARKER, followed by lines of text and finally a line that contains only the end marker. Chapter 4 · Redirecting input
here string
A here string is a redirection of the form command <<< "text". Chapter 4 · Redirecting input
hidden file
A hidden file is a file or directory whose name begins with a dot. Chapter 3 · Showing the contents of a directory
history
The history is the numbered list of recently typed command lines that the shell keeps in its memory. Chapter 2 · Working faster: completion, history, keyboard shortcuts
/home
The directory /home contains a home directory for each ordinary user, named after that user. Chapter 3 · The directory structure of Linux
home directory
A user's home directory is the directory that belongs to them for their own files. Chapter 3 · The working directory and paths
host
The host is the real computer with the operating system under which the virtual machine runs. Chapter 1 · Virtual machines: the computer within the computer
hypervisor
A hypervisor is the software that creates and runs virtual machines. Chapter 1 · Virtual machines: the computer within the computer

I

image
An image is a file that contains the contents of an entire storage device sector by sector, with partition table, file systems and boot files. Chapter 1 · Storage device, image and checksum
inode
An inode is the administrative record of a file in the file system. Chapter 3 · Inodes and links
integrity
So the checksum proves the integrity of the file with respect to the list, not its origin. Chapter 1 · Storage device, image and checksum
ISO image
An ISO image is an image in the format of a CD or DVD; it has the extension .iso. Chapter 1 · Storage device, image and checksum

K

kernel
The kernel (the core of the system) is the part of the operating system that runs in kernel mode. Chapter 1 · Operating system, kernel and distribution
kernel mode
In kernel mode, the running program may execute any instruction of the processor. Chapter 1 · Operating system, kernel and distribution
keyboard shortcut
A keyboard shortcut of the command line is a key combination that the shell does not write into the line as a character but carries out as an instruction to edit the line or the window. Chapter 2 · Working faster: completion, history, keyboard shortcuts

L

-l
Chapter 3 · Showing the contents of a directory
less
If less receives a file as an argument, it shows the file's contents page by page. Chapter 3 · Viewing files
library
A library is a file with program parts that many programs share instead of each containing them itself. Chapter 3 · The directory structure of Linux
link count
The inode keeps count of how many entries point to it; this number is called the link count. Chapter 3 · Inodes and links
Linux
Chapter 1 · Operating system, kernel and distribution
live system
A live system is an operating system that starts and runs entirely from a removable storage device without mounting the computer's built-in storage devices. Chapter 1 · The live system
log files
An important part of it is /var/log with the log files: files to whose end a program continuously writes what happens, each entry with the date and time. Chapter 3 · The directory structure of Linux
long option
A long option begins with two minus signs followed by a whole word, such as --kernel-release. Chapter 2 · The structure of a command line
ls
The command ls prints, for each directory given as an argument, the names of its entries, sorted by name, and for every other file its name. Chapter 3 · Showing the contents of a directory
lsblk
Chapter 3 · Storage devices and mounting
LTS release
Every two years in April, an LTS release (Long Term Support) appears, for which Canonical supplies security fixes and bug fixes for five years. Chapter 1 · Operating system, kernel and distribution

M

man
The command man with the name as an argument displays it. Chapter 2 · Finding help
manual page
A manual page, or man page for short, is the detailed description of a command, a file format, a system call or another part of the system, collected in the manual that every Linux comes with. Chapter 2 · Finding help
-maxdepth n
The option -maxdepth n directly after the starting directories limits the search to n levels below the starting directory. Chapter 3 · Finding files and measuring space
mkdir
The command mkdir (short for “make directory”) creates a new, empty directory for each argument. Chapter 3 · Creating files and directories
/mnt/c
Under WSL 2, the Windows drive C: is mounted at /mnt/c, as a file system of type 9p. Chapter 3 · Storage devices and mounting
-mtime n
The test -mtime n compares the age of the last modification in whole days of 24 hours with n; partial days are dropped, and +n and -n mean more and less, as with -size. Chapter 3 · Finding files and measuring space
mv
The command mv (short for “move”) gives a file or a directory a new name or a new location: mv source target renames source to target. Chapter 3 · Copying, moving, deleting

N

-name pattern
The test -name pattern passes if the name of an entry, that is, the last part of its path, matches the pattern; the pattern follows the same rules as in subsection 6.6. Chapter 3 · Finding files and measuring space
nano
… nano is a simple text editor that runs in the terminal and constantly shows the most important shortcuts at the bottom edge. Chapter 3 · Creating files and directories
NAT mode
In NAT mode (Network Address Translation), the hypervisor works like a router for the VM. Chapter 1 · Virtual machines: the computer within the computer

O

operating system
The operating system is the software that manages a computer's hardware, makes it available to the other programs through uniform services and keeps the programs apart from one another. Chapter 1 · Operating system, kernel and distribution
option
