Chapter 1: Programs and the Python Interpreter

Key points so far

Programs and programming languages

Terms
  • program – A program is a sequence of unambiguously described steps that a computer carries out one after another, without asking questions.
  • statement – A single step of a program is called a statement.
  • processor – In a computer, the steps of a program are carried out by the processor, a chip that calculates and controls the sequence of steps.
  • machine instruction – A machine instruction is an instruction that the processor can carry out directly.
  • machine code – A program that consists only of machine instructions is called machine code.
  • programming language – A programming language is an artificial language in which it is precisely defined which texts are allowed and what each allowed text does.
  • syntax – The syntax of a programming language is the set of all rules that determine which texts are allowed in it.
  • semantics – The semantics of a programming language determines what an allowed text means, that is, what happens when it is run.
  • source code – The source code of a program is its text in a programming language, the way people write and read it.
Key relationships
  • A program is a recipe of unambiguous steps that a computer can carry out without asking back.
  • The processor understands only very simple machine instructions, which are stored as numbers in memory, and each processor family has its own.
  • A programming language is an artificial language without ambiguity in which programs are written down.
  • The syntax determines the allowed form, regardless of what a text means.
  • The semantics determines what an allowed text does.
  • Source code is the program in the form in which people write it; the processor cannot run it directly.

From source code to execution: compiler and interpreter

Terms
  • compiler – A compiler is a program that translates a source code completely into machine code before that code is run.
  • executable file – Such a file is called an executable file.
  • interpreter – An interpreter is a program that reads a source code and itself carries out the steps described in it.
  • Python – Python is a programming language; its syntax and semantics are laid down in the Python Language Reference.
  • CPython – CPython is the program that runs Python source code and is offered on python.org; it is itself written in the C language.
  • Bytecode – Bytecode is a sequence of simple instructions into which CPython translates the entire source code before it begins running it.
  • interpreter loop – A part of CPython then works through the bytecode instruction by instruction: the interpreter loop.
Key relationships
  • A compiler translates the whole source code once, in advance, into an executable file of machine code.
  • An interpreter runs the source code itself, without producing an executable file.
  • Python is the language; CPython is the program that runs it.
  • CPython first translates the whole file into bytecode and then runs this bytecode instruction by instruction.

Setting up Python

Terms
  • Python install manager – The Python install manager is a program for Windows that downloads, installs, lists, removes and starts Python versions.
  • version number – A Python version number has the form 3.14.4 and consists of three parts.
Key relationships
  • On Windows, you install the Python install manager and then start Python with py.
  • On Linux, Python is usually already there and is called python3.
  • The version number tells you which Python you have; version numbers are compared part by part.

Interactive mode

Terms
  • interactive mode – In interactive mode, Python reads an input, runs it, displays the result and then waits for the next input.
  • value – A value is a single piece of data that Python works with, for example the number 42 or the number 0.5.
  • expression – An expression is a piece of source code that Python can compute to a value.
  • evaluation – Computing the value of an expression is called evaluation.
  • string – A string is a value that consists of text.
  • function – A function is a ready-made subprogram with a name that you can have run when needed.
  • function call – A function call has a function run.
Key relationships
  • In interactive mode, you type a line after >>>, and Python answers immediately.
  • A value is a piece of data such as the number 42; in Python, decimal places come after a point.
  • An expression is source code that yields a value; the interactive mode displays this value immediately.
  • Python calculates with + - * / ** and round parentheses according to the rules of mathematics; decimal places come after a point, and it knows no units.
  • Heron's recipe runs in interactive mode pass by pass and, after five passes, arrives at the built-in result of 2 ** 0.5 except for the last digit.
  • Text in straight quotation marks is a string, that is, a value that Python does not calculate with.
  • A function is a ready-made subprogram with a name.
  • You call a function with its name and round parentheses; print writes the values in the parentheses to the terminal.

Writing and running scripts

Terms
  • editor – An editor is a program with which you write and save plain text files.
  • script – A script is a text file with Python source code whose name ends in .py.
  • comment – A comment begins with the character # and extends to the end of the line.
Key relationships
  • You write programs with an editor that saves plain text, ideally with an editor for programmers such as VS Code or IDLE.
  • A script is a .py file that you run with py datei.py or python3 datei.py; only what print outputs becomes visible in it.
  • A comment begins with #, applies up to the end of the line and is there only for humans.

Reading and understanding errors

Terms
  • syntax error – A syntax error is a place in the source code that violates the syntax of the language.
  • runtime error – A runtime error is an error that occurs only when a line is run.
  • exception – An exception is the event with which Python reports an error.
  • traceback – The traceback is the report that Python outputs when an exception aborts a program while it is running.
  • logic error – A logic error is an error in which a program runs without an error message but does not compute what was intended.
Key relationships
  • A syntax error violates the form; Python reports it before the start, and no line of the file runs.
  • A runtime error occurs when a line is run; everything before it has run, nothing after it has.
  • An exception reports an error with a type and a description; while the program is running, it aborts the program.
  • A traceback names the location and the type of an exception; you read it from the bottom.
  • A logic error runs without a message and yields a wrong result; you find it only by checking results.

Chapter 2: Values, Types and Variables

Key points so far

Objects and types

Terms
  • object – An object is a piece of main memory in which Python stores a value, together with the information about what kind of value is stored there.
  • type – The type of an object is the kind of its value.
  • identity – The identity of an object is an integer that distinguishes the object from all other objects that exist at the same time.
  • method – A method is a function that belongs to a type.
Key relationships
  • An object is a value in main memory that carries the information about its kind with it.
  • The type says what kind of value an object contains and what you can do with it; type displays it.
  • The identity is the fixed number of an object; id displays it.
  • A method is a function of a type; you call it with objekt.name().

Integers and arithmetic operators

Terms
  • operator – An operator is a symbol that computes a new value from values.
  • operands – The values an operator acts on are called its operands.
  • floor division, remainder – The operator // is called floor division; the operator % returns the remainder.
  • precedence – The precedence of the operators determines which operator in an expression without parentheses is carried out first.
Formulas
  • Theorem 2.5 (Floor division and remainder) (2.1)
    $$\textcolor{#1b7f4a}{a }\textcolor{#15633a}{=}\textcolor{#c2410c}{ (a\,/\!/\,b)\cdot b + a\,\%\,b .}$$
Key relationships
  • An int is an integer of arbitrary size; Python calculates with it exactly.
  • An operator computes a new value from its operands; if one operand is a float, so is the result.
  • / divides as in mathematics and always returns a float.
  • // rounds the quotient down, toward $-\infty$; % is the matching remainder and has the sign of the right operand.
  • ** binds more tightly than a minus sign in front of it and is evaluated from right to left; a negative exponent returns a float.
  • Power before sign before multiplication and division (* / // %) before addition and subtraction; parentheses come first, and when in doubt, you add them.

Numbers in the binary system

Terms
  • base – Let $B\ge2$ be a natural number, the base.
  • binary number – A binary number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$.
  • bit – A digit of a binary number is called a bit, short for binary digit.
  • byte – A byte is a group of 8 bits.
  • hexadecimal number – A hexadecimal number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$.
  • binary fraction – A binary fraction is a number in the binary system with digits to the right of the point, the binary point.
  • doubling method – For $0\le x<1$, the doubling method determines the binary digits of $x$: you double $x$.
Formulas
  • Definition 3.1 (Positional numeral system)
    $$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$
  • Definition 3.5 (Binary fraction)
    $$\textcolor{#1b7f4a}{0.b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$
Key relationships
  • In a positional numeral system, each digit is multiplied by the place value of its position, and everything is added up.
  • A binary number has only the digits 0 and 1, the bits; each bit counts $2^i$.
  • A byte is 8 bits; it can take 256 different values, the numbers 0 to 255.
  • Repeated division by 2 yields the bits as remainders, the last bit first; ready-made, bin and format do the job.
  • Hexadecimal is base 16; each digit stands for four bits, a byte for two digits.
  • A binary fraction terminates exactly when the denominator in lowest terms is a power of two; $0.1$ does not terminate.
  • Doubling moves the next binary digit in front of the point; for $0.1$, this gives the infinite sequence $0.0\,0011\,0011\ldots{}_2$.

Floating-point numbers: the type float

Terms
  • floating-point number – A floating-point number with $p$ binary digits is a number of the form $\pm\,m\cdot2^E$.
  • significand – Here, the significand $m$ (also called the mantissa) is a binary number with $p$ digits and exactly one digit before the point, which is 1: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.\ldots{}_2}$, so $1\le m<2$.
  • exponent – The exponent $E$ is an integer from a fixed range.
  • exponent field – The exponent field $c$ of a float stores the exponent shifted by 1023.
  • significand field – The significand field $t$ of a float contains the 52 binary digits of the significand after the point.
  • representation error – If $x$ lies exactly halfway between two float values, Python takes the one whose last significand bit is 0. The difference between the stored value and $x$ is called the representation error.
Formulas
  • Definition 4.3 (Exponent field)
    $$\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{E+1023,}$$
    $$\textcolor{#1b7f4a}{E}\textcolor{#15633a}{=}\textcolor{#c2410c}{c-1023 .}$$
  • Definition 4.4 (Significand field)
    $$\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+\frac{t}{2^{52}} .}$$
  • The significand field (4.1)
    $$\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s\cdot\Bigl(1+\frac{t}{2^{52}}\Bigr)\cdot2^{\,c-1023}.}$$
Key relationships
  • A floating-point number is a significand times a power of two; with a fixed number of digits, the spacing of neighboring numbers grows with their magnitude.
  • A float is a floating-point number with a significand of 53 binary digits, stored in 64 bits: sign, exponent field, significand field.
  • The exponent field stores $E+1023$; this way, it does without a sign.
  • The significand field stores the 52 digits after the point; you add the leading 1 when reading it.
  • hex shows a float as $\pm$0x1.significand fieldpexponent.
  • Python stores the nearest float; for 0.1, that is $\frac{3602879701896397}{2^{55}}$, too large by about $5.6\cdot10^{-18}$.
  • What is displayed is the shortest decimal number that gives the same float; displayed is not the same as stored.

Calculating with floating-point numbers

Terms
  • rounding error – The difference that arises is called the rounding error of the calculation.
  • Machine epsilon – Machine epsilon $\varepsilon_{\mathrm M}$ is the distance from 1 to the next larger float.
  • absorbed – If $|b|$ is smaller than half the spacing of the float values near $a$, then $a+b$ gives $a$ again: the small summand is lost completely. It is said to be absorbed.
  • Cancellation – Cancellation is the loss of significant digits when you subtract two almost equal numbers that already carry rounding errors.
  • overflow – If the rounded result of a calculation is larger, this is called overflow, and the result is the special value inf (infinity), for negative results -inf.
Formulas
  • Definition 5.2 (Machine epsilon)
    $$\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2.22\cdot10^{-16}.}$$
  • Theorem 5.3 (Size of the rounding error)
    $$\textcolor{#1b7f4a}{|\tilde x-x|\le\frac{\varepsilon_{\mathrm M}}{2}\,|x|}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}\,|x|}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1.11\cdot10^{-16}\,|x| .}$$
Key relationships
  • Every calculation is computed exactly and then rounded; the errors of individual steps can add up over many steps.
  • $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}$ is the distance from 1 to the next float; each rounding changes a number by at most the fraction $\varepsilon_{\mathrm M}/2$ of its magnitude.
  • A summand that is smaller than half the spacing of the float values near the other summand disappears in the addition.
  • When you subtract almost equal, rounded numbers, only the erroneous trailing digits remain.
  • Results above $1.797\cdot10^{308}$ become inf; Python continues to calculate with inf as with $\infty$, only ** raises an OverflowError.
  • nan is the result of invalid calculations and infects every further calculation.

Variables: names for objects

Terms
  • assignment – An assignment is a statement of the form …
  • variable – A name that is bound to an object is called a variable.
  • augmented assignment – For an arithmetic operator $\circ$ from + - * / // % **, the augmented assignment name $\circ$= expression means the same for numbers as name = name $\circ$ (expression).
Key relationships
  • name = ausdruck evaluates the expression and binds the name to the result.
  • A variable is a name that is bound to an object; it comes into being with the first assignment.
  • An assignment attaches a tag to an object or moves the tag to another object; it copies nothing.
  • Names consist of letters, digits and _, do not begin with a digit and are not keywords; you should not rebind built-in names.
  • For numbers, x += a is the short form of x = x + (a); likewise -=, *=, /=, //=, %= and **=.
  • Variables turn fixed numbers into named assumptions; the formulas below them calculate with the names.

Truth values and comparisons

Terms
  • comparison operators – The comparison operators compare two values and return a bool.
  • equal up to the relative tolerance – Two numbers $a$ and $b$ are equal up to the relative tolerance $r$ if …
Formulas
  • Definition 7.4 (Comparison with a relative tolerance)
    $$|a-b|\le r\cdot\max(|a|,|b|) .$$
Key relationships
  • bool has the values True and False; in calculations, they count as 1 and 0.
  • ==, !=, <, <=, >, >= compare two values and return True or False.
  • Never compare results of floating-point calculations with ==.
  • You compare floating-point numbers with a relative tolerance, $|a-b|\le r\max(|a|,|b|)$; near 0, you additionally need an absolute tolerance.
  • is asks whether two names mean the same object; == asks whether two values are equal.
  • None means “no value”; you test for it with is None.

Modules: math and sys

Terms
  • module – A module is a file with ready-made Python definitions, such as functions and values.
Key relationships
  • import modul loads a module and binds its name; modul.name accesses its contents.
  • math contains the calculator functions for float; angles are given in radians.
  • math.isclose is the ready-made tolerance comparison with $\textcolor{#1b7f4a}{r}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-9}}$ and no absolute tolerance.
  • sys.float_info describes the type float, math.ulp the spacing of neighboring float values; both confirm the calculations by hand.

Complex numbers

Terms
  • attribute – An attribute is a name that is attached to an object and accessed with a dot: object.name.
Key relationships
  • complex stores the real and imaginary parts as two float values; the imaginary unit is written 1j.
  • An attribute is a name attached to an object; z.real and z.imag return the real and imaginary parts.
  • cmath is math for complex numbers; there, even $\sqrt{-1}$ has a result.
  • The absolute value by hand with Pythagoras, the phase with math.atan2(y, x); ready-made with abs, cmath.phase and cmath.polar.
  • z * cmath.rect(1, alpha) rotates the point $z$ by the angle $\alpha$ about the origin; abs and cmath.phase show its distance and direction.

Strings, input and output

Terms
  • concatenation – For strings, + means joining end to end, called concatenation: "Regen" + "schirm" is "Regenschirm" (German for “umbrella”).
  • f-string – An f-string is a string with an f before the opening quotation mark.
  • type conversion – The functions int, float and str create a new object from a value, with the type of their name. This is called type conversion.
Key relationships
  • For strings, + concatenates, * repeats, and len counts the characters.
  • An f-string inserts the values in {...} into a text; after the colon, a format specifier determines the digits and the form.
  • input asks for a line and returns it as a str.
  • int, float and str convert explicitly; int cuts off the decimal places.
  • round rounds to the nearest number and, for exact halves, to the even one; int(x + 0.5) works only for positive numbers and always rounds halves up.
  • float(input(...)) reads a number, and an f-string outputs the result with a suitable number of digits.

Chapter 3: Decisions and Loops

Key points so far

Conditions: comparisons and logical operators

Terms
  • chained comparison – If several comparison operators stand one after another, such as a < b <= c, the expression is called a chained comparison.
  • short-circuit evaluation – In a and b, b is evaluated only if a is true; in a or b, only if a is false. This rule is called short-circuit evaluation.
  • truth value – Every object has a truth value, True or False; the type conversion bool(x) shows it.
Key relationships
  • A comparison is an expression whose value is True or False.
  • a <= x <= b checks, as in mathematics, whether x lies between a and b.
  • Python compares strings character by character by their numbers; "10" < "9" is true, so convert inputs first, then compare.
  • not negates a truth value.
  • a and b is true only if both are true.
  • a or b is true as soon as one of the two is true.
  • not before and before or, all after the comparisons; when in doubt, use parentheses.
  • and and or evaluate the right operand only if it can still change the result; the protecting condition therefore belongs on the left.
  • Of the values known so far, zero, None, False and the empty string count as false, and all others as true.
  • and and or return one of their operands; wert or ersatz replaces every false value, even a genuine zero.

Decisions: if, elif and else

Terms
  • conditional statement – A conditional statement has the form …
  • header line – The first line is called the header line; it begins with if and ends with a colon.
  • block – A block is a sequence of statements that are all indented by the same amount and follow a header line, that is, a line with a colon at the end.
Key relationships
  • if Bedingung: executes the indented lines below it only if the condition is true.
  • The indentation determines which lines belong to a header line; a block ends where a line starts further to the left again.
  • else specifies the block that runs if the condition is false.
  • With if, elif and else, exactly the block of the first true condition runs, otherwise the else block.
  • == instead of =, a colon at the end, every partial condition written out in full, floating-point numbers with a tolerance, inputs converted first.
  • Three mutually exclusive ranges of a quantity call for if, elif and else.

Repeating with while

Terms
  • loop – A statement that repeats a block is called a loop.
  • while loop – A while loop has the form …
  • iteration – A single execution of the block is called an iteration.
  • infinite loop – An infinite loop is a loop whose condition never becomes false.
Key relationships
  • while Bedingung: repeats the block as long as the condition is true before the iteration.
  • If the block changes nothing the condition depends on, the loop runs forever; Ctrl+C interrupts it with KeyboardInterrupt.
  • Never let a loop wait for a float with != or ==; count with integers and calculate the float from the counter.
  • while is the right loop when you do not know the number of iterations beforehand, only the goal.

Counting with for and range

Terms
  • for loop – A for loop has the form …
  • loop variable – The name is called the loop variable.
Formulas
  • Definition 4.2 (range)
    $$\textcolor{#1b7f4a}{\mathtt{len}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\max\Bigl(0,\Bigl\lceil\frac{\mathtt{stop}-\mathtt{start}}{\mathtt{schritt}}\Bigr\rceil\Bigr).}$$
Key relationships
  • for k in range(n): executes the block for $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{0,1,\ldots,n-1}$.
  • range(start, stop, schritt) counts from start in steps up to just before stop; the stop is never included.
  • For steps with floating-point numbers, range counts with integers, and you calculate the value from the counter.
  • for when the sequence of values is known beforehand; while when only the goal is known.

Controlling loops, nesting them and collecting results

Terms
  • nested – If one loop stands in the block of another, the two are called nested.
  • accumulator – An accumulator is a name that is bound to a starting value before a loop and combined with the new value in every iteration, for example with summe = summe + wert.
Key relationships
  • break ends a loop immediately, typically after a find.
  • continue skips the rest of the current iteration; the loop keeps running.
  • In nested loops, the inner loop runs all the way through in each iteration of the outer one; break leaves only the inner loop.
  • An accumulator starts before the loop with 0 (sum, count) or 1 (product) and takes in one value in every iteration.
  • The mean is a sum accumulator divided by the count; the maximum is an accumulator that is replaced only by a larger value.

Solutions by trying: guess and check, approximation with a tolerance

Terms
  • Guess and check, exhaustive search – Guess and check, also called exhaustive search, goes through the possible solutions in a fixed order and checks each one.
  • approximation – A number $g$ is an approximation of $\sqrt a$ with the tolerance $\varepsilon>0$ if $|g^2-a|<\varepsilon$.
  • stepping method – The simplest method for finding such an approximation is called the stepping method here: you start at $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ and increase $g$ in fixed steps of step size $h$ until $|g^2-a|<\varepsilon$.
Key relationships
  • Guess and check is certain to find a solution or to show that there is none, but it needs as many steps as there are candidates.
  • With floating-point numbers, you do not look for an exact solution but for one that meets a tolerance.
  • The step size must be smaller than the range the tolerance allows, and that is why the number of steps grows with $a/\varepsilon$.

Bisection

Terms
  • Bisection – Bisection repeats the following as long as $\mathit{hi}-\mathit{lo}>\varepsilon$.
Formulas
  • Theorem 7.3 (Number of steps of bisection)
    $$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$
Key relationships
  • In every step, bisection replaces the endpoint that lies on the same side of the zero as the midpoint by the midpoint.
  • With the starting interval $[0,\max(1,a)]$, bisection finds $\sqrt2$ to twelve digits in 41 steps.
  • Bisection needs $\lceil\log_2(L/\varepsilon)\rceil$ steps; every tenfold increase in accuracy costs only about 3.3 more steps.

Newton's method

Terms
  • Newton's method – Newton's method for a zero of a differentiable function $f$ starts with a starting value $g_0$ and from it computes one after another …
  • quadratic convergence – If $\delta_n$ is about $10^{-p}$, so that $g_n$ has about $p$ significant decimal digits, then $\delta_{n+1}$ is at most about $10^{-2p}/2$: $p$ significant digits become about $2p$. This property is called quadratic convergence.
Formulas
  • Definition 8.1 (Newton's method)
    $$\textcolor{#1b7f4a}{g_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g_n-\frac{f(g_n)}{f'(g_n)},}$$
  • Theorem 8.2 (Error of the Newton step for the square root)
    $$\textcolor{#1b7f4a}{d_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{d_n^2}{2g_n}.}$$
Key relationships
  • In every step, Newton's method jumps to the zero of the tangent line.
  • For the square root, the Newton step is Heron's recipe $\frac12(g+a/g)$, and it needs five steps for $\sqrt2$.
  • With Newton's method, the error is squared in every step, and the number of significant digits doubles.
  • Newton needs a nonzero derivative, a starting value close to the solution and a suitable tolerance; then it is very fast, otherwise it can cycle, crawl or run forever.
  • math.sqrt delivers in one call the result that the methods by hand reach only approximately and with a carefully chosen tolerance.

Application: the interest rate of an installment loan

Key relationships
  • The interest rate sought is the only zero of the remaining balance $f(r)$ between 0 and $R/K$.
  • Bisection reliably finds the monthly interest rate of 0.6183 % in 35 steps.
  • Started close to the solution, Newton needs 5 steps; far away, it crawls, because $q$ decreases in every step only by about one $n$-th, and it is then slower than bisection.
