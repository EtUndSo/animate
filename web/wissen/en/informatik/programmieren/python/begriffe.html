approximation
A number $g$ is an approximation of $\sqrt a$ with the tolerance $\varepsilon>0$ if $|g^2-a|<\varepsilon$. Chapter 3 · Solutions by trying: guess and check, approximation with a tolerance
assignment
An assignment is a statement of the form … Chapter 2 · Variables: names for objects
attribute
An attribute is a name that is attached to an object and accessed with a dot: object.name. Chapter 2 · Complex numbers
augmented assignment
For an arithmetic operator $\circ$ from + - * / // % **, the augmented assignment name $\circ$= expression means the same for numbers as name = name $\circ$ (expression). Chapter 2 · Variables: names for objects

base
Let $B\ge2$ be a natural number, the base. Chapter 2 · Numbers in the binary system
binary fraction
A binary fraction is a number in the binary system with digits to the right of the point, the binary point. Chapter 2 · Numbers in the binary system
binary number
A binary number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. Chapter 2 · Numbers in the binary system

bit
A digit of a binary number is called a bit, short for binary digit. Chapter 2 · Numbers in the binary system
block
A block is a sequence of statements that are all indented by the same amount and follow a header line, that is, a line with a colon at the end. Chapter 3 · Decisions: if, elif and else
byte
A byte is a group of 8 bits. Chapter 2 · Numbers in the binary system
Bytecode
Bytecode is a sequence of simple instructions into which CPython translates the entire source code before it begins running it. Chapter 1 · From source code to execution: compiler and interpreter

Cancellation
Cancellation is the loss of significant digits when you subtract two almost equal numbers that already carry rounding errors. Chapter 2 · Calculating with floating-point numbers

comment
A comment begins with the character # and extends to the end of the line. Chapter 1 · Writing and running scripts
comparison operators
The comparison operators compare two values and return a bool. Chapter 2 · Truth values and comparisons
compiler
A compiler is a program that translates a source code completely into machine code before that code is run. Chapter 1 · From source code to execution: compiler and interpreter
concatenation
For strings, + means joining end to end, called concatenation: "Regen" + "schirm" is "Regenschirm" (German for “umbrella”). Chapter 2 · Strings, input and output
conditional statement
A conditional statement has the form … Chapter 3 · Decisions: if, elif and else
CPython
CPython is the program that runs Python source code and is offered on python.org; it is itself written in the C language. Chapter 1 · From source code to execution: compiler and interpreter

D

doubling method
For $0\le x<1$, the doubling method determines the binary digits of $x$: you double $x$. Chapter 2 · Numbers in the binary system

editor
An editor is a program with which you write and save plain text files. Chapter 1 · Writing and running scripts

evaluation

exception

executable file

exhaustive search
Guess and check, also called exhaustive search, goes through the possible solutions in a fixed order and checks each one. Chapter 3 · Solutions by trying: guess and check, approximation with a tolerance

The exponent $E$ is an integer from a fixed range. Chapter 2 · Floating-point numbers: the type float

expression
An expression is a piece of source code that Python can compute to a value. Chapter 1 · Interactive mode

f-string
An f-string is a string with an f before the opening quotation mark. Chapter 2 · Strings, input and output
floating-point number

floor division
The operator // is called floor division; the operator % returns the remainder. Chapter 2 · Integers and arithmetic operators

A for loop has the form … Chapter 3 · Counting with for and range

H

header line
The first line is called the header line; it begins with if and ends with a colon. Chapter 3 · Decisions: if, elif and else
hexadecimal number
A hexadecimal number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$. Chapter 2 · Numbers in the binary system

I

identity
The identity of an object is an integer that distinguishes the object from all other objects that exist at the same time. Chapter 2 · Objects and types
infinite loop

In interactive mode, Python reads an input, runs it, displays the result and then waits for the next input. Chapter 1 · Interactive mode

iteration

A logic error is an error in which a program runs without an error message but does not compute what was intended. Chapter 1 · Reading and understanding errors
loop
A statement that repeats a block is called a loop. Chapter 3 · Repeating with while
loop variable
The name is called the loop variable. Chapter 3 · Counting with for and range

machine instruction
A machine instruction is an instruction that the processor can carry out directly. Chapter 1 · Programs and programming languages
method
A method is a function that belongs to a type. Chapter 2 · Objects and types
module

O

object

operands
The values an operator acts on are called its operands. Chapter 2 · Integers and arithmetic operators
operator
An operator is a symbol that computes a new value from values. Chapter 2 · Integers and arithmetic operators
overflow
If the rounded result of a calculation is larger, this is called overflow, and the result is the special value inf (infinity), for negative results -inf. Chapter 2 · Calculating with floating-point numbers

P

precedence
The precedence of the operators determines which operator in an expression without parentheses is carried out first. Chapter 2 · Integers and arithmetic operators
processor
In a computer, the steps of a program are carried out by the processor, a chip that calculates and controls the sequence of steps. Chapter 1 · Programs and programming languages
program
A program is a sequence of unambiguously described steps that a computer carries out one after another, without asking questions. Chapter 1 · Programs and programming languages
programming language
A programming language is an artificial language in which it is precisely defined which texts are allowed and what each allowed text does. Chapter 1 · Programs and programming languages
Python
Python is a programming language; its syntax and semantics are laid down in the Python Language Reference. Chapter 1 · From source code to execution: compiler and interpreter
Python install manager
The Python install manager is a program for Windows that downloads, installs, lists, removes and starts Python versions. Chapter 1 · Setting up Python

Q

quadratic convergence
If $\delta_n$ is about $10^{-p}$, so that $g_n$ has about $p$ significant decimal digits, then $\delta_{n+1}$ is at most about $10^{-2p}/2$: $p$ significant digits become about $2p$. This property is called quadratic convergence. Chapter 3 · Newton's method

The operator // is called floor division; the operator % returns the remainder. Chapter 2 · Integers and arithmetic operators
representation error
If $x$ lies exactly halfway between two float values, Python takes the one whose last significand bit is 0. The difference between the stored value and $x$ is called the representation error. Chapter 2 · Floating-point numbers: the type float
rounding error
The difference that arises is called the rounding error of the calculation. Chapter 2 · Calculating with floating-point numbers
runtime error
A runtime error is an error that occurs only when a line is run. Chapter 1 · Reading and understanding errors

semantics

In a and b, b is evaluated only if a is true; in a or b, only if a is false. This rule is called short-circuit evaluation. Chapter 3 · Conditions: comparisons and logical operators
