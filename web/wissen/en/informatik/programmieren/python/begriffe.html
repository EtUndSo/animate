assignment
An assignment is a statement of the form … Chapter 2 · Variables: names for objects
attribute
An attribute is a name that is attached to an object and accessed with a dot: object.name. Chapter 2 · Complex numbers
augmented assignment
For an arithmetic operator $\circ$ from + - * / // % **, the augmented assignment name $\circ$= expression means the same for numbers as name = name $\circ$ (expression). Chapter 2 · Variables: names for objects

base
Let $B\ge2$ be a natural number, the base. Chapter 2 · Numbers in the binary system
binary fraction
A binary fraction is a number in the binary system with digits to the right of the point, the binary point. Chapter 2 · Numbers in the binary system
binary number

bit
A digit of a binary number is called a bit, short for binary digit. Chapter 2 · Numbers in the binary system
block
A block is a sequence of statements that are all indented by the same amount and follow a header line, that is, a line with a colon at the end. Chapter 3 · Decisions: if, elif and else
byte
A byte is a group of 8 bits. Chapter 2 · Numbers in the binary system
Bytecode
Bytecode is a sequence of simple instructions into which CPython translates the entire source code before it begins running it. Chapter 1 · From source code to execution: compiler and interpreter

comparison operators
The comparison operators compare two values and return a bool. Chapter 2 · Truth values and comparisons

conditional statement
A conditional statement has the form … Chapter 3 · Decisions: if, elif and else

If $\delta_n$ is about $10^{-p}$, so that $g_n$ has about $p$ significant decimal digits, then $\delta_{n+1}$ is at most about $10^{-2p}/2$: $p$ significant digits become about $2p$. This property is called quadratic convergence. Chapter 3 · Newton's method
