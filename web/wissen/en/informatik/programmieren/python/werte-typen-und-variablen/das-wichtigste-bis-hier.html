Key points so far

  • Every value is an object with a type, an identity and a value; type and id show the type and identity. The type determines what is allowed; you call methods with objekt.name().

  • int is exact and of arbitrary size. / always returns a float; // rounds toward $-\infty$, and $\textcolor{#1b7f4a}{a}\textcolor{#15633a}{=}\textcolor{#c2410c}{(a\,/\!/\,b)\cdot b+a\,\%\,b}$ holds, with the remainder taking the sign of $b$. ** comes before the sign and groups from the right.

  • Binary number: $\sum b_i2^i$; bit, byte (8 bits, 0 to 255), hexadecimal (4 bits per digit). A fraction terminates in binary exactly when its denominator in lowest terms is a power of two; $\textcolor{#1b7f4a}{0.1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.0\,0011\,0011\ldots{}_2}$.

  • float = binary64: $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s(1+t/2^{52})\cdot2^{c-1023}}$, 53 digits of significand, range up to $1.8\cdot10^{308}$. What is stored is the nearest float, in a tie the one with the even significand; 0.1 is $3602879701896397/2^{55}$. What is displayed is the shortest decimal number that gives the same float.

  • Every calculation is rounded, relatively by at most $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}}$; $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2.2\cdot10^{-16}}$. Errors add up, small summands are absorbed, almost equal numbers cancel. Overflow gives inf, invalid calculations give nan.

  • An assignment binds a name to an object and copies nothing. Names: letters, digits, _, no digit at the start, no keyword. x += a means x = x + (a).

  • Comparisons return bool. You compare floating-point numbers with a tolerance, $|a-b|\le\max(r\max(|a|,|b|),t_{\mathrm{abs}})$, ready-made with math.isclose. is checks the identity, for example x is None.

  • import modul binds a module name; math for real functions, cmath for complex ones, sys.float_info for the limits of the float.

  • complex: two float values, imaginary unit 1j, attributes real and imag; absolute value abs, phase cmath.phase or, by hand, math.atan2(y, x).

  • Text: + concatenates, * repeats, len counts; f-strings with format specifiers; input always returns str; int, float, str convert; round rounds to the nearest number, for halves to the even one.

The answer in three sentences

  1. Every value is an object whose type determines how the value is stored and what you can do with it; names are only tags that an assignment attaches to objects.

  2. An int stores integers exactly with any number of digits, while a float stores every number as a binary fraction with 53 digits times a power of two; that is why even $0.1$ is only approximated and every result of a calculation is rounded, relatively by up to $2^{-53}$.

  3. From this follow the working rules: compare floating-point numbers with a tolerance, expect rounding errors over many steps and when subtracting almost equal numbers, and convert text and numbers into each other explicitly.

One principle behind all the results. Almost everything in this chapter follows from the fact that the type of an object determines how its value is stored in memory: as a sequence of digits of any length, as a binary fraction with 53 digits and an exponent, as a pair of such binary fractions or as a sequence of characters. The rules of calculation follow from this representation.
