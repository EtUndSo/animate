What this is about#

A calculator computes exactly what you are typing in at the moment. If you want the same calculation for twenty prices, you type it twenty times, and each time a typo can happen. A program, on the other hand, computes what you have written down for it once: as often as you like, with as many numbers as you like and without new typos, once it is correct.

This chapter explores how to write down such a list of instructions for a computer and how to get the computer to carry it out. By the end, Python runs on your own computer, on Windows or on Linux. You can use it to calculate, write and start small programs, and you can read the messages with which Python points out errors.

How to work with this chapter. The sections build on each other, and every new term has its own subsection with an example.
