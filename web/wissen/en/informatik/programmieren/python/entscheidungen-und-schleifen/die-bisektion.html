What this stage is about:

The stepping method feels its way toward the solution with fixed steps and is therefore slow. This section shows a method that halves the range in which the solution must lie in every step, and determines how many steps it needs.

What you need for thisthe intermediate value theorem

The square root $\sqrt a$ is the positive zero of the function $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^2-a}$, because $\textcolor{#1b7f4a}{f(\sqrt a)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. So instead of searching for a square root, you can search for a zero. How do you recognize that an interval contains a zero?

A function is called continuous on an interval $[x_1,x_2]$ if its graph runs there without a jump, that is, if you can draw it without lifting the pen. For such functions, the following holds:

Theorem 7.1 (Intermediate value theorem, version for zeros)

If $f$ is continuous on $[x_1,x_2]$ and $f(x_1)$ and $f(x_2)$ have different signs, then there is at least one number $x^*$ with $x_1<x^*<x_2$ and $\textcolor{#1b7f4a}{f(x^*)}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Intuitively: if you draw from below the $x$-axis to above it without lifting the pen, you have to cross it somewhere. The theorem is covered in detail in HöMa1, Chapter 5, Section 8.

Example

$\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{x^2-2}$ is continuous, and $\textcolor{#1b7f4a}{f(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2<0}$ and $\textcolor{#1b7f4a}{f(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2>0}$. So $f$ has a zero between 0 and 2, namely $\sqrt2$.

⁠In short: If a continuous function changes sign between two points, there is a zero in between.

The bisection method#

The intermediate value theorem says that there is a zero in the interval, but not where. Bisection finds it by dividing the interval again and again.

Guessing a number with “higher or lower”. Someone thinks of a number between 1 and 100 and answers only with “higher” or “lower”. If you always guess the middle of the range that is still possible, you halve it with every answer and have the number after at most 7 questions, because $\textcolor{#1b7f4a}{2^7}\textcolor{#15633a}{=}\textcolor{#c2410c}{128\ge100}$. Bisection guesses in the same way; the sign of $f$ at the midpoint gives it the answer (Fig. 8).

Definition 7.2 (Bisection)

Given are a continuous function $f$, two numbers $\mathit{lo}<\mathit{hi}$ with $f(\mathit{lo})<0\le f(\mathit{hi})$ and a tolerance $\varepsilon>0$. Bisection repeats the following as long as $\mathit{hi}-\mathit{lo}>\varepsilon$:

  1. Compute the midpoint $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathit{lo}+\mathit{hi})/2}$.

  2. If $f(m)<0$, set $\textcolor{#1b7f4a}{\mathit{lo}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$, otherwise $\textcolor{#1b7f4a}{\mathit{hi}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$.

The result is the midpoint of the last interval. If the signs are the other way around, $f(\mathit{lo})>0\ge f(\mathit{hi})$, you swap the two cases in step 2.

After every step, $f(\mathit{lo})<0\le f(\mathit{hi})$ holds again: the endpoint that is replaced by the midpoint is always the one with the same sign as $f(m)$. By the intermediate value theorem, the interval therefore always contains a zero, or its right endpoint is one itself.

⁠In short: In every step, bisection replaces the endpoint that lies on the same side of the zero as the midpoint by the midpoint.

BackgroundWhy bisection cannot miss: the loop invariant

To show that a loop computes the right thing, you look for a statement that holds before the first iteration and that every iteration preserves. Such a statement is called a loop invariant. For bisection, it is “$f(\mathit{lo})<0\le f(\mathit{hi})$”. It holds at the start by assumption, and every iteration preserves it, as shown above. So it also holds after the last iteration. In addition, the stopping condition then holds, $\mathit{hi}-\mathit{lo}\le\varepsilon$. Together, the two say: the interval $(\mathit{lo},\mathit{hi}]$ of width at most $\varepsilon$ contains a zero, and the midpoint is at most $\varepsilon/2$ away from it. That the loop ends at all follows from a second observation: the width halves in every iteration and therefore at some point becomes smaller than any positive $\varepsilon$. This approach, an invariant plus a quantity that is certain to decrease, is the usual way of justifying loops, not only for bisection.

The square root by bisection#

As a script, bisection for $\sqrt a$ needs a starting interval with a sign change. On the left, $\textcolor{#1b7f4a}{\mathit{lo}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ always works, because $\textcolor{#1b7f4a}{f(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-a<0}$. On the right, $\textcolor{#1b7f4a}{\mathit{hi}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\max(1,a)}$ works: for $a\ge1$, $a^2\ge a$, so $f(a)\ge0$; for $a<1$, $\textcolor{#1b7f4a}{f(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1-a>0}$.

wurzel_bisektion.pyPython
# Square root by bisection: zero of f(x) = x*x - a in the interval [lo, hi]
a = float(input("a = "))
eps = float(input("Toleranz eps = "))     # desired width of the interval
lo = 0.0                                  # f(lo) < 0
hi = max(1.0, a)                          # f(hi) >= 0, since the root never lies above max(1, a)
schritte = 0
while hi - lo > eps:
    mitte = (lo + hi) / 2
    if mitte * mitte < a:                 # f(mitte) < 0: zero lies right of the midpoint mitte
        lo = mitte
    else:                                 # otherwise it lies left of mitte or exactly there
        hi = mitte
    schritte = schritte + 1
print("Näherung:", (lo + hi) / 2, "nach", schritte, "Schritten")
print("Intervall:", lo, "bis", hi)

The tolerance means something different here than there: it limits the width of the interval for $g$, not the distance of $g^2$ from $a$.

⁠In short: With the starting interval $[0,\max(1,a)]$, bisection finds $\sqrt2$ to twelve digits in 41 steps.

The number of steps of bisection#

41 and 12: these numbers can be calculated before the start.

Theorem 7.3 (Number of steps of bisection)

If bisection starts with an interval of width $\textcolor{#1b7f4a}{L}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathit{hi}-\mathit{lo}}$, the interval is $L/2^n$ wide after $n$ steps. If $L>\varepsilon$, bisection ends after

$$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$

steps, and the midpoint it returns is at most $\varepsilon/2$ away from a zero.

Proof: Halving

Every step replaces an endpoint by the midpoint, so the interval becomes exactly half as wide. After $n$ steps, it is $L/2^n$ wide. The loop runs as long as the width is greater than $\varepsilon$, and it ends after the first $n$ with $L/2^n\le\varepsilon$, that is, with $2^n\ge L/\varepsilon$ or $n\ge\log_2(L/\varepsilon)$. The smallest such $n$ is the rounded-up number $\lceil\log_2(L/\varepsilon)\rceil$. By the loop invariant, the last interval contains a zero, and the midpoint is at most half the width, that is, at most $\varepsilon/2$, away from every point of the interval.

The proof calculates with exact midpoints. In the examples of this section, the midpoints can be represented exactly as float, because they are fractions with powers of two in the denominator and have fewer than 53 binary digits. With endpoints such as 0.02, which are already stored rounded themselves, the midpoint is rounded, too, but by at most one smallest step of the floating-point numbers. The number of steps from the theorem then still holds, except when $L/2^n$ is almost exactly $\varepsilon$.

Example

For $\sqrt2$ with $[0,2]$ and $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-12}}$, $\textcolor{#1b7f4a}{L/\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\cdot10^{12}}$ and $\textcolor{#1b7f4a}{\log_2(2\cdot10^{12})}\textcolor{#15633a}{=}\textcolor{#c2410c}{40.86}$, rounded up 41. For $\sqrt{25}$ with $[0,25]$ and $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.01}$, $\textcolor{#1b7f4a}{\log_2 2500}\textcolor{#15633a}{=}\textcolor{#c2410c}{11.29}$, rounded up 12. Both are exactly the numbers of steps of the scripts.

⁠In short: Bisection needs $\lceil\log_2(L/\varepsilon)\rceil$ steps; every tenfold increase in accuracy costs only about 3.3 more steps.

BackgroundWhy halving is so much faster than scanning

The stepping method from Section 6 shrinks the range in which the solution can still lie by a fixed amount $h$ in every step; the number of steps therefore grows like $L/h$. Bisection halves the range. With $n$ steps, it distinguishes $2^n$ subintervals of equal width, and the $n$ yes-no answers determine which of them contains the solution. Ten steps already distinguish $\textcolor{#1b7f4a}{2^{10}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1024}$, that is, about $10^3$ subintervals, which is three decimal places. For twelve digits, you need about $\textcolor{#1b7f4a}{4\cdot10}\textcolor{#15633a}{=}\textcolor{#c2410c}{40}$ steps, instead of $2\cdot10^{12}$ when scanning with step size $\varepsilon$.

You can see what these answers are in the table in subsection 7.2. If you write a 1 for “the midpoint becomes the left endpoint” and a 0 for “the midpoint becomes the right endpoint”, the first twelve steps for $\sqrt2$ give the sequence 1 0 1 1 0 1 0 1 0 0 0 0. These are exactly the first twelve binary digits of $\textcolor{#1b7f4a}{\sqrt2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.01101010000\ldots_2}$ (Chapter 2, Section 3.6). So every step of bisection determines one more bit of the solution, no more and no less.

BackgroundHow small the tolerance may be

The width of the interval cannot fall below the spacing of adjacent float values. For $\sqrt2$, this spacing is $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2.2\cdot10^{-16}}$. If you ask for $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-17}}$, $\mathit{lo}$ and $\mathit{hi}$ are neighbors after 53 steps, 1.414213562373095 and 1.4142135623730951. Their rounded midpoint is again one of the two, the interval no longer gets smaller, and the condition hi - lo > eps stays true forever: an infinite loop. The remedy is either a tolerance that fits the size of the solution, such as hi - lo > 1e-15 * hi as in the comparison with a relative tolerance in Chapter 2, Section 7.4, or a maximum number of steps as an emergency brake.

Exercise 29 ★★ Zeros without a square root

Bisection works for every continuous function with a sign change.

  1. Use bisection to find the number $x$ with $\textcolor{#1b7f4a}{\cos x}\textcolor{#15633a}{=}\textcolor{#c2410c}{x}$ in the interval $[0,1]$, that is, the zero of $\textcolor{#1b7f4a}{f(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos x-x}$, with $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-12}}$. Check the sign change first. Caution: here, $f(\mathit{lo})>0$.

  2. Likewise, find the zero of $x^3-x-1$ in $[1,2]$.

Solution

(a) $\textcolor{#1b7f4a}{f(0)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos0-0}\textcolor{#15633a}{=}\textcolor{#c2410c}{1>0}$ and $\textcolor{#1b7f4a}{f(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\cos1-1}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{-0.46<0}$: there is a sign change. Because $f(\mathit{lo})>0$, lo is replaced if $f$ is still positive at the midpoint:

bisektion_cos.pyPython
# Bisection for cos(x) = x, that is, the zero of f(x) = cos(x) - x in [0, 1]; here f(lo) > 0
import math
lo = 0.0                                  # f(0) = 1 > 0
hi = 1.0                                  # f(1) = cos(1) - 1 < 0
eps = 1e-12
schritte = 0
while hi - lo > eps:
    mitte = (lo + hi) / 2
    if math.cos(mitte) - mitte > 0:       # f(mitte) > 0: the zero lies to the right of mitte
        lo = mitte
    else:
        hi = mitte
    schritte = schritte + 1
x = (lo + hi) / 2
print("x =", x, "nach", schritte, "Schritten, cos(x) - x =", math.cos(x) - x)

(b) $\textcolor{#1b7f4a}{f(1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-1<0}$, $\textcolor{#1b7f4a}{f(2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{5>0}$, as with the square root:

Exercise 30 ★★★ A tolerance that is too small

Start bisection for $\sqrt2$ with $\textcolor{#1b7f4a}{\varepsilon}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-17}}$ and an emergency brake after 200 steps. After the loop, print lo, hi, hi - lo and the number of steps. Explain the result. Then replace the condition by hi - lo > 1e-15 * hi and determine the number of steps, also with Theorem 7.3.

Solution

# Bisection for the square root of 2 with a tolerance that is too small, with an emergency brake after 200 steps
lo = 0.0
hi = 2.0
eps = 1e-17
schritte = 0
while hi - lo > eps and schritte < 200:
    mitte = (lo + hi) / 2
    if mitte * mitte < 2:
        lo = mitte
    else:
        hi = mitte
    schritte = schritte + 1
print("lo =", lo, " hi =", hi)
print("hi - lo =", hi - lo, " Schritte:", schritte)

hi = 2.0
schritte = 0
while hi - lo > 1e-15 * hi:
    mitte = (lo + hi) / 2
    if mitte * mitte < 2:
        lo = mitte
    else:
        hi = mitte
    schritte = schritte + 1

The approximation 1.4142135623730954 is the neighbor above math.sqrt(2), that is, one step away from the best value and well within the required accuracy.

The bisection method
Definition 7.2 (Bisection)

Given are a continuous function $f$, two numbers $\mathit{lo}<\mathit{hi}$ with $f(\mathit{lo})<0\le f(\mathit{hi})$ and a tolerance $\varepsilon>0$. Bisection repeats the following as long as $\mathit{hi}-\mathit{lo}>\varepsilon$:

  1. Compute the midpoint $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathit{lo}+\mathit{hi})/2}$.

  2. If $f(m)<0$, set $\textcolor{#1b7f4a}{\mathit{lo}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$, otherwise $\textcolor{#1b7f4a}{\mathit{hi}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$.

The result is the midpoint of the last interval. If the signs are the other way around, $f(\mathit{lo})>0\ge f(\mathit{hi})$, you swap the two cases in step 2.

Theorem 7.3 (Number of steps of bisection)

If bisection starts with an interval of width $\textcolor{#1b7f4a}{L}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathit{hi}-\mathit{lo}}$, the interval is $L/2^n$ wide after $n$ steps. If $L>\varepsilon$, bisection ends after

$$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$

steps, and the midpoint it returns is at most $\varepsilon/2$ away from a zero.

Summary

Terms
  • Bisection – Bisection repeats the following as long as $\mathit{hi}-\mathit{lo}>\varepsilon$.
Formulas
  • Theorem 7.3 (Number of steps of bisection)

Key relationships
  • On “The bisection method”: In every step, bisection replaces the endpoint that lies on the same side of the zero as the midpoint by the midpoint.
  • On “The square root by bisection”: With the starting interval $[0,\max(1,a)]$, bisection finds $\sqrt2$ to twelve digits in 41 steps.
  • On “The number of steps of bisection”: Bisection needs $\lceil\log_2(L/\varepsilon)\rceil$ steps; every tenfold increase in accuracy costs only about 3.3 more steps.
