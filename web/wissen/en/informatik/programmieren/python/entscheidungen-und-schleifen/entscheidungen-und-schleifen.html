What this is about#

The scripts from Chapter 1 and Chapter 2 run from top to bottom, and each line runs exactly once. For most tasks, that is not enough. A program should print a warning only if a room is too warm, and it should repeat a calculation step until a result is accurate enough.

This chapter pursues two questions. How do you get a program to take different paths depending on the data and to repeat steps? And how does a program use this to find the square root of 2 to twelve digits when it can only add, multiply and compare, and how many steps does it need for that? The answer to the second question reaches far beyond the square root: with the same means, you calculate quantities for which there is no formula, such as the interest rate hidden in an installment loan.

How to work with this chapter. The sections build on each other, and every new term has its own subsection with an example. Expandable boxes contain background (why a method works and where it comes from), derivations and proofs; you do not need them to read on. Try the exercises (★ to ★★★) yourself first and actually run the programs; the solution expands right below each exercise.
