Chapter 1: Programs and the Python Interpreter

Programs and programming languages

The program
Definition 1.1 (Program)

A program is a sequence of unambiguously described steps that a computer carries out one after another, without asking questions.

What the processor understands: machine instructions
Definition 1.2 (Machine instruction)

A machine instruction is an instruction that the processor can carry out directly. It is stored in memory as a number; from this number the processor recognizes what to do.

The programming language
Definition 1.3 (Programming language)

A programming language is an artificial language in which it is precisely defined which texts are allowed and what each allowed text does.

Syntax
Definition 1.4 (Syntax)

The syntax of a programming language is the set of all rules that determine which texts are allowed in it.

Semantics
Definition 1.5 (Semantics)

The semantics of a programming language determines what an allowed text means, that is, what happens when it is run.

Source code
Definition 1.6 (Source code)

The source code of a program is its text in a programming language, the way people write and read it.

From source code to execution: compiler and interpreter

The compiler
Definition 2.1 (Compiler)

A compiler is a program that translates a source code completely into machine code before that code is run. The result is saved as a separate file that runs without the compiler.

The interpreter
Definition 2.2 (Interpreter)

An interpreter is a program that reads a source code and itself carries out the steps described in it. It produces no executable file and therefore has to be present every time the program is started.

Python and CPython
Definition 2.3 (Python and CPython)

Python is a programming language; its syntax and semantics are laid down in the Python Language Reference. CPython is the program that runs Python source code and is offered on python.org; it is itself written in the C language.

Bytecode
Definition 2.4 (Bytecode)

Bytecode is a sequence of simple instructions into which CPython translates the entire source code before it begins running it. The instructions are designed for an imaginary machine, not for a real processor.

Setting up Python

Python on Windows: the Python install manager
Definition 3.1 (Python install manager)

The Python install manager is a program for Windows that downloads, installs, lists, removes and starts Python versions. You operate it in the terminal with the command py.

The version number
Definition 3.2 (Version number)

A Python version number has the form 3.14.4 and consists of three parts:

  • the major version, here 3;

  • the minor version, here 14; every year in October, a new minor version with new language features is released;

  • the bugfix number, here 4; it increases when a minor version receives fixes without the language changing.

Interactive mode

Interactive mode
Definition 4.1 (Interactive mode)

In interactive mode, Python reads an input, runs it, displays the result and then waits for the next input.

The value
Definition 4.2 (Value)

A value is a single piece of data that Python works with, for example the number 42 or the number 0.5.

The expression
Definition 4.3 (Expression)

An expression is a piece of source code that Python can compute to a value.

Calculating as on a calculator
>>> 2,5 * 2
↗
The recipe in interactive mode: first by hand, then ready-made
>>> (1 + 2/1) / 2
>>> (_ + 2/_) / 2
↗
>>> 2 ** 0.5
↗
Text as a value: the string
Definition 4.4 (String)

A string is a value that consists of text. In source code, it stands between two straight quotation marks, "Hallo", or between two apostrophes, 'Hallo'.

The function
Definition 4.5 (Function)

A function is a ready-made subprogram with a name that you can have run when needed.

The function call: print
Definition 4.6 (Function call)

A function call has a function run. You write its name, followed by round parentheses, and inside the parentheses the values that the function is to work with, separated by commas.

Writing and running scripts

The editor
Definition 5.1 (Editor)

An editor is a program with which you write and save plain text files. An editor for programmers also helps you write source code: it colors the code according to its syntax, marks violations of the syntax while you type and can run a program at the push of a button.

The script
Definition 5.2 (Script)

A script is a text file with Python source code whose name ends in .py. Python runs a script by translating the file and then running each of its lines once, from top to bottom.

$ python3 ausdruck.py
↗
The comment
Definition 5.3 (Comment)

A comment begins with the character # and extends to the end of the line. Python skips it completely.

Reading and understanding errors

The syntax error
Definition 6.1 (Syntax error)

A syntax error is a place in the source code that violates the syntax of the language. Python reports it before any line of the file is run.

The runtime error
Definition 6.2 (Runtime error)

A runtime error is an error that occurs only when a line is run. All lines before it have already run; the program aborts at this point.

The exception
Definition 6.3 (Exception)

An exception is the event with which Python reports an error. It has a type, for example ZeroDivisionError, and a description, for example division by zero. If it occurs while the program is running, it aborts the program at that point.

The traceback
Definition 6.4 (Traceback)

The traceback is the report that Python outputs when an exception aborts a program while it is running. It names the place in the source code where the exception occurred and, in its last line, the type and the description of the exception.

>>> 5 / 0
↗
The logic error
Definition 6.5 (Logic error)

A logic error is an error in which a program runs without an error message but does not compute what was intended.

Key points so far

The answer in three sentences

  1. A program is a recipe of unambiguous steps that you write down as source code in a programming language, because the processor understands only machine instructions and everyday language is ambiguous.

  2. You either type Python source code line by line in interactive mode, which displays every value immediately, or you save it as a script, which you start with py or python3 and which outputs something only with print.

  3. CPython first translates the whole file and then runs it; that is why a syntax error prevents any execution, a runtime error aborts only in its own line, and a logic error is noticed only if you check the result.

Chapter 2: Values, Types and Variables

Objects and types

The object
Definition 1.1 (Object)

An object is a piece of main memory in which Python stores a value, together with the information about what kind of value is stored there.

The type
Definition 1.2 (Type)

The type of an object is the kind of its value. It determines which values the object can have and what you can do with it. The function type returns the type of an object.

The identity
Definition 1.3 (Identity)

The identity of an object is an integer that distinguishes the object from all other objects that exist at the same time. It does not change as long as the object exists. The function id returns it.

The method
Definition 1.4 (Method)

A method is a function that belongs to a type. You call it for an object by writing a dot, the name of the method and parentheses after the object.

Integers and arithmetic operators

The type int
Definition 2.1 (The type int)

The type int comprises the integers $\ldots,-2,-1,0,1,2,\ldots$ An object of type int has no fixed size: it grows as large as the number requires and is limited only by main memory. Adding, subtracting and multiplying two int values always yields the exact result as an int.

Operator and operand
Definition 2.2 (Operator and operand)

An operator is a symbol that computes a new value from values.

The values an operator acts on are called its operands.

>>> 7 + 2
>>> 7 + 0.5
>>> 2 * 3.0
↗
Division
Definition 2.3 (Division)

The operator / divides the left operand by the right one. The result is always a float, even if both operands are an int and the division leaves no remainder.

Floor division and remainder
Definition 2.4 (Floor division and remainder)

For integers $a$ and $b\ne0$, a // b is the largest integer that is not greater than $a/b$. This is the quotient rounded down, that is, toward $-\infty$.

The remainder is a % b $=a-(a\,/\!/\,b)\cdot b$.

Theorem 2.5 (Floor division and remainder)

For all integers $a$ and $b\ne0$,

$$\textcolor{#1b7f4a}{a }\textcolor{#15633a}{=}\textcolor{#c2410c}{ (a\,/\!/\,b)\cdot b + a\,\%\,b .}$$
(2.1)

For $b>0$, the remainder lies in the range $0\le a\,\%\,b<b$; for $b<0$, in the range $b<a\,\%\,b\le0$. So the remainder always has the sign of $b$ or is zero.

>>> divmod(125, 60)
>>> divmod(-7, 2)
>>> 7.5 // 2
>>> 7.5 % 2
↗
The power
Definition 2.6 (Power)

a ** b is $a$ to the power of $b$. If $a$ and $b$ are an int and $b\ge0$, the result is an int; if $b$ is a negative int, it is a float. If one of the operands is a float, the result is also a float; only a negative base with a non-integer exponent returns something else. In addition:

  • ** binds more tightly than a minus sign to its left: -2 ** 2 is $\textcolor{#1b7f4a}{-(2^2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-4}$.

  • Python evaluates several ** from right to left: 2 ** 3 ** 2 is $\textcolor{#1b7f4a}{2^{(3^2)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^9}\textcolor{#15633a}{=}\textcolor{#c2410c}{512}$.

Precedence
Definition 2.7 (Precedence)

The precedence of the operators determines which operator in an expression without parentheses is carried out first. For the arithmetic operators, from strongest to weakest:

RankOperatorsfor equal rank
1**from right to left
2unary + and -
3* / // %from left to right
4binary + and -from left to right

Parentheses take precedence over everything.

Numbers in the binary system

The positional numeral system
Definition 3.1 (Positional numeral system)

Let $B\ge2$ be a natural number, the base. In the positional numeral system with base $B$, a sequence of digits $z_{n-1}\ldots z_1z_0$ with $0\le z_i<B$ stands for the number

$$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$

The number $B^i$ is called the place value of position $i$. Positions are counted from the right, starting at $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

The binary number
Definition 3.2 (Binary number)

A binary number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. Its digits are 0 and 1.

>>> 0b10011
>>> type(0b10011)
↗
>>> (19).bit_length()
↗
The byte
Definition 3.3 (Byte)

A byte is a group of 8 bits.

Converting to binary: first by hand, then ready-made
>>> divmod(19, 2)
>>> divmod(9, 2)
>>> divmod(4, 2)
>>> divmod(2, 2)
>>> divmod(1, 2)
↗
>>> bin(19)
>>> format(19, "b")
>>> format(19, "08b")
>>> int("10011", 2)
>>> bin(-19)
↗
The hexadecimal number
Definition 3.4 (Hexadecimal number)

A hexadecimal number is a number in the positional numeral system with base $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$. The digits are 0 to 9 and a to f for the values 10 to 15.

Binary fractions
Definition 3.5 (Binary fraction)

A binary fraction is a number in the binary system with digits to the right of the point, the binary point. Position $k$ to the right of the point has the place value $2^{-k}$:

$$\textcolor{#1b7f4a}{0.b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$

Theorem 3.6 (Finite binary fractions)

A number $x$ can be written as a binary fraction with finitely many digits exactly when there is an integer $p\ge0$ such that $x\cdot2^p$ is an integer.

The doubling method
Definition 3.7 (Doubling method)

For $0\le x<1$, the doubling method determines the binary digits of $x$: you double $x$. The integer part of the result, 0 or 1, is the next digit; you continue with the part to the right of the point. The method ends when this part is 0.

Floating-point numbers: the type float

The floating-point representation
Definition 4.1 (Floating-point number)

A floating-point number with $p$ binary digits is a number of the form $\pm\,m\cdot2^E$.

Here, the significand $m$ (also called the mantissa) is a binary number with $p$ digits and exactly one digit before the point, which is 1: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.\ldots{}_2}$, so $1\le m<2$.

The exponent $E$ is an integer from a fixed range.

The type float
Definition 4.2 (The type float)

An object of type float stores a floating-point number in the binary64 format of the IEEE 754 standard. The significand has $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{53}$ binary digits, and the exponent lies in the range $-1022\le E\le1023$. The number occupies 64 bits, divided into three fields:

  • a 1-bit sign $s$: $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for positive, $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ for negative numbers;

  • an 11-bit exponent field $c$;

  • a 52-bit significand field $t$.

The exponent field
Definition 4.3 (Exponent field)

The exponent field $c$ of a float stores the exponent shifted by 1023:

$$\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{E+1023,}$$
$$\textcolor{#1b7f4a}{E}\textcolor{#15633a}{=}\textcolor{#c2410c}{c-1023 .}$$

Ordinary numbers have $1\le c\le2046$. The values $\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ and $\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{2047}$ are reserved for special cases.

The significand field
Definition 4.4 (Significand field)

The significand field $t$ of a float contains the 52 binary digits of the significand after the point. If you read them as an integer $t$, the significand is

$$\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+\frac{t}{2^{52}} .}$$

$$\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s\cdot\Bigl(1+\frac{t}{2^{52}}\Bigr)\cdot2^{\,c-1023}.}$$
(4.1)
Splitting a float into its fields
>>> (6.5).hex()
>>> (-0.75).hex()
↗
The representation error
Definition 4.5 (Rounding and representation error)

If a number $x$ cannot be represented as a float, Python stores the float closest to $x$. If $x$ lies exactly halfway between two float values, Python takes the one whose last significand bit is 0. The difference between the stored value and $x$ is called the representation error.

>>> (0.1).hex()
>>> (0.1).as_integer_ratio()
>>> 2 ** 55
↗
>>> 3602879701896397 * 5 ** 55
↗
The shortest representation
Definition 4.6 (Shortest representation)

Interactive mode and print display a float as the shortest decimal number that gives exactly this float when typed in.

Calculating with floating-point numbers

The rounding error of a calculation
Definition 5.1 (Correctly rounded calculation)

For the basic arithmetic operations $+$, $-$, $\cdot$, $/$ and the square root, IEEE 754 requires: the result is the exact result of the stored values, rounded by the same rule as when storing, that is, to the nearest float and, in a tie, to the even significand. The difference that arises is called the rounding error of the calculation.

Machine epsilon
Definition 5.2 (Machine epsilon)

Machine epsilon $\varepsilon_{\mathrm M}$ is the distance from 1 to the next larger float:

$$\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2.22\cdot10^{-16}.}$$

Theorem 5.3 (Size of the rounding error)

If a number $x\ne0$ lies in the range of the ordinary float values, the rounded value $\tilde x$ differs from $x$ by at most

$$\textcolor{#1b7f4a}{|\tilde x-x|\le\frac{\varepsilon_{\mathrm M}}{2}\,|x|}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}\,|x|}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1.11\cdot10^{-16}\,|x| .}$$

So a float has about 16 significant decimal digits.

>>> 1.4142135623730951 - 1.414213562373095
↗
Absorption
Definition 5.4 (Absorption)

If $|b|$ is smaller than half the spacing of the float values near $a$, then $a+b$ gives $a$ again: the small summand is lost completely. It is said to be absorbed.

Cancellation
Definition 5.5 (Cancellation)

Cancellation is the loss of significant digits when you subtract two almost equal numbers that already carry rounding errors. The subtraction itself is often exact; but the existing errors become large relative to the small result.

Overflow: inf
Definition 5.6 (Overflow and inf)

The largest float is $\textcolor{#1b7f4a}{(2-2^{-52})\cdot2^{1023}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1.797\cdot10^{308}}$. If the rounded result of a calculation is larger, this is called overflow, and the result is the special value inf (infinity), for negative results -inf.

The invalid result: nan
Definition 5.7 (nan)

nan (short for not a number) is the float that a calculation without a meaningful result returns, for example $\infty-\infty$ or $0\cdot\infty$. Almost every calculation with nan gives nan again.

Variables: names for objects

The assignment
Definition 6.1 (Assignment)

An assignment is a statement of the form

⁠name = expression

Python evaluates the expression on the right and then connects the name on the left with the object that has been created in the process. The name is said to be bound to the object.

The variable
Definition 6.2 (Variable)

A name that is bound to an object is called a variable. The value of the variable is the value of this object.

Rebinding instead of copying
Theorem 6.3 (Assignment does not copy)

An assignment never creates a copy of an object. y = x binds y to the same object to which x is bound. A later assignment to x rebinds only x; y stays with its object.

The naming rules
Definition 6.4 (Naming rules)

A name consists of letters, digits and the underscore _. It must not begin with a digit and must not be a keyword. Uppercase and lowercase letters are different: Wert and wert are two names.

>>> print = 5
>>> print("Hallo")
↗
The augmented assignment
Definition 6.5 (Augmented assignment)

For an arithmetic operator $\circ$ from + - * / // % **, the augmented assignment name $\circ$= expression means the same for numbers as name = name $\circ$ (expression).

Variables in a script
PS> py rezept_variablen.py
↗
$ python3 rezept_variablen.py
↗

Truth values and comparisons

The type bool
Definition 7.1 (The type bool)

The type bool has exactly two values, True and False. Both are keywords.

The comparison operators
Definition 7.2 (Comparison operators)

The comparison operators compare two values and return a bool:

==equal to!=not equal to
<less than<=less than or equal to
>greater than>=greater than or equal to

They have a lower rank than all arithmetic operators: Python first calculates both sides and then compares.

Do not test floating-point numbers for equality
Theorem 7.3 (Equality of float values)

For ==, two float values are equal if and only if they have the same value, that is, agree down to the last binary digit. Two ways of calculating that give the same result mathematically often return different float values because of rounding. And nan is not equal to any value, not even to itself.

Comparison with a tolerance
Definition 7.4 (Comparison with a relative tolerance)

Two numbers $a$ and $b$ are equal up to the relative tolerance $r$ if

$$|a-b|\le r\cdot\max(|a|,|b|) .$$

>>> abs(-3.5)
>>> max(2, 7.5, 3)
>>> a = 0.1 + 0.2
>>> b = 0.3
>>> abs(a - b) <= 1e-9 * max(abs(a), abs(b))
↗
The identity comparison
Definition 7.5 (Identity comparison)

The operator is returns True if its two operands are the same object, that is, have the same identity. is not is its negation.

The value None
Definition 7.6 (None)

None is the only value of the type NoneType. It stands for “no value”. Functions without an actual result, such as print, return None.

The module and import
Definition 8.1 (Module)

A module is a file with ready-made Python definitions, such as functions and values. The statement import math loads the module math and binds the name math to the module object. You access its contents with a dot: math.sqrt is the function sqrt from the module math.

Complex numbers

The type complex
Definition 9.1 (The type complex)

An object of type complex stores a complex number as a pair of two float values, the real part and the imaginary part. A number with an appended j is imaginary: 4j means $4\mathrm j$. The function complex(x, y) creates $x+\mathrm jy$.

The attribute: real and imaginary part
Definition 9.2 (Attribute)

An attribute is a name that is attached to an object and accessed with a dot: object.name. Methods are attributes that you call; other attributes are simply values.

The module cmath
Definition 9.3 (The module cmath)

The module cmath contains mathematical functions for complex numbers, among them sqrt, exp, log, sin, cos as well as phase, polar and rect for the polar form. The functions that calculate a value return a complex; phase returns a float, and polar two float values.

>>> cmath.phase(z)
>>> cmath.phase(w)

Strings, input and output

Concatenating and repeating strings
Definition 10.1 (Operators and length of strings)

For strings, + means joining end to end, called concatenation: "Regen" + "schirm" is "Regenschirm" (German for “umbrella”). * with an int repeats the string. The built-in function len returns the number of characters.

The f-string
Definition 10.2 (f-string)

An f-string is a string with an f before the opening quotation mark. Every expression in curly braces {...} is evaluated, and its value is inserted as text at this position.

>>> f"{0.1:.20f}"
>>> f"{0.1:.55f}"
↗
Input with input
Definition 10.3 (input)

The built-in function input writes the text in its parentheses to the terminal as a question, waits until the user types a line and presses Enter, and returns this line as a string, without the Enter.

Type conversion
Definition 10.4 (Type conversion)

The functions int, float and str create a new object from a value, with the type of their name. This is called type conversion.

  • int(text) and float(text) read a number from a string; spaces at the edges are allowed. If the text does not fit, they raise a ValueError.

  • int(x) turns a float into an integer by cutting off the decimal places, that is, by rounding toward zero.

  • str(x) returns the text that print would output for $x$.

Rounding: first by hand, then ready-made
>>> int(2.7 + 0.5)
>>> int(2.5 + 0.5)
>>> int(3.5 + 0.5)
>>> int(-2.7 + 0.5)
↗
Definition 10.5 (round)

round(x) returns the integer closest to $x$. If $x$ lies exactly halfway between two integers, round returns the even one of the two. round(x, n) rounds to $n$ decimal places and returns a float.

>>> round(2.7)
>>> round(-2.7)
>>> round(2.5)
>>> round(3.5)
>>> round(-2.5)
>>> round(3.14159, 2)
>>> round(2.675, 2)
>>> f"{2.675:.20f}"
↗
Application: a running pace calculator
PS> py tempo.py
↗
$ python3 tempo.py
↗

Key points so far

The answer in three sentences

  1. Every value is an object whose type determines how the value is stored and what you can do with it; names are only tags that an assignment attaches to objects.

  2. An int stores integers exactly with any number of digits, while a float stores every number as a binary fraction with 53 digits times a power of two; that is why even $0.1$ is only approximated and every result of a calculation is rounded, relatively by up to $2^{-53}$.

  3. From this follow the working rules: compare floating-point numbers with a tolerance, expect rounding errors over many steps and when subtracting almost equal numbers, and convert text and numbers into each other explicitly.

Chapter 3: Decisions and Loops

Conditions: comparisons and logical operators

Review: truth values and comparisons
>>> temp = 21.5
>>> temp > 20
>>> type(temp > 20)
>>> 0.1 + 0.2 == 0.3
↗
Chained comparisons
Definition 1.1 (Chained comparison)

If several comparison operators stand one after another, such as a < b <= c, the expression is called a chained comparison. It yields True if and only if each of the individual comparisons a < b and b <= c yields True. Python evaluates the middle expression b only once, and if an earlier comparison already yields False, it does not evaluate the remaining ones.

Comparing strings
Definition 1.2 (Comparison of strings)

Two strings are equal (==) if they consist of the same characters in the same order; uppercase and lowercase letters are different characters. For < and the other order comparisons, Python goes through the two strings character by character from the left. At the first character in which they differ, the number of the character decides: the string with the smaller number is the smaller one. If one string is the beginning of the other, it is the smaller one.

The operator not
Definition 1.3 (not)

not is a unary operator. not x yields True if x has the value False, and False if x has the value True.

The operator and
Definition 1.4 (and)

and is a binary operator. a and b yields True if and only if a and b are both True.

The operator or
Definition 1.5 (or)

or is a binary operator. a or b yields True if and only if at least one of the two operands is True.

The precedence of the logical operators
Definition 1.6 (Precedence)

From tighter to looser binding: arithmetic operators, then comparisons, then not, then and, and finally or. So and binds more tightly than or, just as times binds more tightly than plus.

Short-circuit evaluation
Definition 1.7 (Short-circuit evaluation)

Python evaluates a and b and a or b from the left and stops as soon as the result is certain. In a and b, b is evaluated only if a is true; in a or b, only if a is false. This rule is called short-circuit evaluation.

The truth value of objects
Definition 1.8 (Truth value)

Every object has a truth value, True or False; the type conversion bool(x) shows it. Of the values known so far, exactly these have the truth value False: False, None, the zero of every number type (0, 0.0, -0.0, 0j) and the empty string "". All others have the truth value True. Where Python expects a condition, for example with not, it uses the truth value of the object.

What and and or return as a result
Definition 1.9 (Result of and and or)

a and b yields a itself if a is false, and b otherwise. a or b yields a itself if a is true, and b otherwise. So the result is always one of the two operands, unchanged. not x, in contrast, always yields True or False.

Decisions: if, elif and else

The conditional statement if
Definition 2.1 (Conditional statement)

A conditional statement has the form

if Bedingung: Anweisungen

The first line is called the header line; it begins with if and ends with a colon. Below it are one or more statements, indented further than the header line. Python evaluates the condition and determines its truth value (Subsection 1.9). If it is True, Python executes the indented statements; otherwise it skips them. In both cases, execution then continues with the next line that again starts as far to the left as the header line.

The block and indentation
Definition 2.2 (Block)

A block is a sequence of statements that are all indented by the same amount and follow a header line, that is, a line with a colon at the end. It ends before the first line that is indented less. A block may itself contain header lines with their own blocks, indented even further. Four spaces per level are usual; this is what the style guide for Python, PEP 8, recommends.

The alternative else
Definition 2.3 (else)

The block of a conditional statement may be followed by a line else:, indented exactly as far as the corresponding if, and then by a block of its own. This block runs if and only if the condition is false. So of the two blocks, exactly one always runs.

Several cases: elif
Definition 2.4 (elif)

Between the block of an if and an optional else, any number of lines elif Bedingung: may stand, each with a block, all indented as far as the if. elif is short for “else if”. Python checks the conditions from top to bottom. It executes the block of the first condition that is true and skips all the others. If none is true, the block after else runs, if there is one.

Repeating with while

The while loop
Definition 3.1 (while loop)

A while loop has the form

while Bedingung: Block

Python checks the truth value of the condition. If it is True, Python executes the block and then returns to the header line to check the condition again. If it is False, execution continues with the first line after the block. A single execution of the block is called an iteration. The condition is checked before each iteration; if it is already false the first time, the block does not run even once.

The infinite loop
Definition 3.2 (Infinite loop)

An infinite loop is a loop whose condition never becomes false. You interrupt a program in an infinite loop with Ctrl+C, that is, by holding down the Control key and pressing C. Python then ends the program with the exception KeyboardInterrupt and a traceback (Chapter 1, Sections 6.3 and 6.4).

Counting with for and range

The for loop
Definition 4.1 (for loop)

A for loop has the form

for name in range(n): Block

Here, for an integer $n$, range(n) yields the integers $0, 1, \ldots, n-1$ in order. The loop binds name to each of these numbers in turn and executes the block each time; after the last number, execution continues after the block. The name is called the loop variable. In general, in is followed by an object that yields values one after another; in this section, it is always a range.

The sequence of numbers range
Definition 4.2 (range)

range exists with one, two or three integer arguments: range(stop), range(start, stop) and range(start, stop, schritt) (schritt is German for “step”). If start is missing, it is 0; if schritt is missing, it is 1. The sequence consists of the numbers $\mathtt{start}$, $\mathtt{start}+\mathtt{schritt}$, $\mathtt{start}+2\cdot\mathtt{schritt}$, …, as long as they are less than stop for a positive step and greater than stop for a negative step. stop itself never belongs to it. If start is already not before stop, the sequence is empty. len returns the number of elements; for a positive step, it is

$$\textcolor{#1b7f4a}{\mathtt{len}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\max\Bigl(0,\Bigl\lceil\frac{\mathtt{stop}-\mathtt{start}}{\mathtt{schritt}}\Bigr\rceil\Bigr).}$$

Controlling loops, nesting them and collecting results

Breaking out with break
Definition 5.1 (break)

The statement break in the block of a loop ends this loop immediately. The rest of the block is skipped, as are all further iterations, and the program continues with the first line after the loop.

Skipping with continue
Definition 5.2 (continue)

The statement continue in the block of a loop ends only the current iteration. The rest of the block is skipped. A for loop continues with the next value, a while loop with the next check of its condition.

Nested loops
Definition 5.3 (Nested loop)

If one loop stands in the block of another, the two are called nested. The loop in the block is called the inner loop, the other one the outer loop. In each iteration of the outer loop, the inner loop runs completely. If the outer loop has $m$ iterations and the inner one $n$ each time, the block of the inner loop runs $m\cdot n$ times. break and continue act only on the innermost loop whose block contains them.

The accumulator pattern
Definition 5.4 (Accumulator)

An accumulator is a name that is bound to a starting value before a loop and combined with the new value in every iteration, for example with summe = summe + wert. After the loop, it is bound to the result. The starting value is the result for the case in which the loop does not have a single iteration: 0 for a sum and a count, 1 for a product.

Solutions by trying: guess and check, approximation with a tolerance

Guess and check
Definition 6.1 (Guess and check)

Guess and check, also called exhaustive search, goes through the possible solutions in a fixed order and checks each one. It stops as soon as a candidate fits or it is certain that none of the remaining ones can fit.

Definition 6.2 (Approximation with a tolerance)

A number $g$ is an approximation of $\sqrt a$ with the tolerance $\varepsilon>0$ if $|g^2-a|<\varepsilon$. The tolerance $\varepsilon$ determines how close “close enough” is; it is a freely chosen number and has nothing to do with the machine epsilon $\varepsilon_{\mathrm M}$.

Bisection

The bisection method
Definition 7.2 (Bisection)

Given are a continuous function $f$, two numbers $\mathit{lo}<\mathit{hi}$ with $f(\mathit{lo})<0\le f(\mathit{hi})$ and a tolerance $\varepsilon>0$. Bisection repeats the following as long as $\mathit{hi}-\mathit{lo}>\varepsilon$:

  1. Compute the midpoint $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathit{lo}+\mathit{hi})/2}$.

  2. If $f(m)<0$, set $\textcolor{#1b7f4a}{\mathit{lo}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$, otherwise $\textcolor{#1b7f4a}{\mathit{hi}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$.

The result is the midpoint of the last interval. If the signs are the other way around, $f(\mathit{lo})>0\ge f(\mathit{hi})$, you swap the two cases in step 2.

The number of steps of bisection
Theorem 7.3 (Number of steps of bisection)

If bisection starts with an interval of width $\textcolor{#1b7f4a}{L}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathit{hi}-\mathit{lo}}$, the interval is $L/2^n$ wide after $n$ steps. If $L>\varepsilon$, bisection ends after

$$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$

steps, and the midpoint it returns is at most $\varepsilon/2$ away from a zero.

Newton's method

Newton's method
Definition 8.1 (Newton's method)

Newton's method for a zero of a differentiable function $f$ starts with a starting value $g_0$ and from it computes one after another

$$\textcolor{#1b7f4a}{g_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g_n-\frac{f(g_n)}{f'(g_n)},}$$

as long as $|f(g_n)|$ is greater than a tolerance $\varepsilon$. $g_{n+1}$ is the zero of the tangent line at the point $g_n$; for this, $f'(g_n)\ne0$ must hold.

Key points so far

The answer in three sentences

  1. A program takes different paths depending on the data by checking the truth value of a condition and, depending on it, executing an indented block once (if) or again and again (while, for).

  2. The square root of 2 is the zero of $x^2-2$; bisection halves an interval with a sign change and needs 41 steps for twelve digits, while Newton's method follows the tangent line, squaring the error as it goes, and needs only 5.

  3. Because floating-point numbers are rounded, every such method ends not at equality but at a tolerance, and the tolerance must fit the size of the numbers, otherwise the loop runs forever.
