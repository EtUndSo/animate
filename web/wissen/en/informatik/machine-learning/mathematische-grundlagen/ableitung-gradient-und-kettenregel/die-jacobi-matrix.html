What this stage is about:

Many calculation steps produce not one number but several: a matrix–vector product turns one vector into another. For such functions, the Jacobian matrix collects the partial derivatives of all outputs with respect to all inputs. It is the matrix of the linear approximation, and for the two most common building blocks, linear maps and elementwise functions, it has a particularly simple form.

Functions with several outputs#

In Chapter 1, Section 8, a linear map $\mathbf{x}\mapsto\mathbf{A}\mathbf{x}$ mapped vectors of $\mathbb{R}^n$ to vectors of $\mathbb{R}^m$, and in Chapter 1, Section 15.2, a function was applied to each component of a vector separately. In both cases, several numbers come out of one vector. Each of them is, on its own, a function of several variables.

Definition 5.1 (Vector-valued function)

A function $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ that assigns to every $\mathbf{x}\in\mathbb{R}^n$ a vector

$$\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}g_1(\mathbf{x})\\ \vdots\\ g_m(\mathbf{x})\end{pmatrix}\in\mathbb{R}^m}$$

is called vector-valued. The functions $g_1,\dots,g_m:\mathbb{R}^n\to\mathbb{R}$ are called its components.

This chapter writes vector-valued functions in bold, like vectors; functions whose value is a number are written in non-bold type.

Worked example

Throughout Sections 5 and 6, we work with the function $\mathbf{g}:\mathbb{R}^2\to\mathbb{R}^2$ with

$$\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_1x_2\\ 2x_1+x_2^2\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{g}(1,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2\\6\end{pmatrix}.}$$
(5.1)

Its components are $\textcolor{#1b7f4a}{g_1(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1x_2}$ and $\textcolor{#1b7f4a}{g_2(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{2x_1+x_2^2}$.

⁠In short: A vector-valued function $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ consists of $m$ functions of $n$ variables, one for each output.

The Jacobian matrix#

Each component $g_i$ has $n$ partial derivatives, one with respect to each input. Together these are $m\cdot n$ numbers. You arrange them in a table with one row per output and one column per input.

Definition 5.2 (Jacobian matrix)

If all partial derivatives of the components of $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ exist at the point $\mathbf{x}$, then the $m\times n$ matrix

$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}\dfrac{\partial g_1}{\partial x_1}&\cdots&\dfrac{\partial g_1}{\partial x_n}\\ \vdots&&\vdots\\ \dfrac{\partial g_m}{\partial x_1}&\cdots&\dfrac{\partial g_m}{\partial x_n}\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\bigl(\mathbf{J}_{\mathbf{g}}(\mathbf{x})\bigr)_{ij}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{\partial g_i}{\partial x_j}(\mathbf{x}),}$$
(5.2)

is called the Jacobian matrix of $\mathbf{g}$ at the point $\mathbf{x}$.

Row $i$ belongs to the output $g_i$; it is its gradient, written as a row: $\nabla g_i(\mathbf{x})^{\top}$. Column $j$ belongs to the input $x_j$; it says how all outputs respond at once when you change only $x_j$. For a function $f:\mathbb{R}^n\to\mathbb{R}$ with a single output, the Jacobian matrix is a $1\times n$ matrix, namely the gradient as a row: $\textcolor{#1b7f4a}{\mathbf{J}_f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(\mathbf{x})^{\top}}$. The matrix is named after the mathematician Carl Gustav Jacob Jacobi.

Worked example

For $\mathbf{g}$ from (5.1),

$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_2&x_1\\2&2x_2\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(1,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2&1\\2&4\end{pmatrix}.}$$

The first column $(2,\,2)^{\top}$ says: if $x_1$ grows by a small $h$, both outputs grow by about $2h$. The second column $(1,\,4)^{\top}$ says: if $x_2$ grows, the second output responds four times as strongly as the first.

⁠In short: The Jacobian matrix has one row per output and one column per input; its entry $(i,j)$ is $\partial g_i/\partial x_j$.

The linear approximation with the Jacobian matrix#

Each component has its linear approximation (3.4). If you write all $m$ approximations one below the other, the components of $\mathbf{g}(\mathbf{x}+\mathbf{h})$ stand on the left and the rows of the Jacobian matrix times $\mathbf{h}$ on the right. By the row view from Chapter 1, Section 7.2, this is a matrix–vector product.

Theorem 5.3 (Linear approximation of a vector-valued function)

If every component of $\mathbf{g}$ is differentiable at the point $\mathbf{x}$, then

$$\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{g}(\mathbf{x})+\mathbf{J}_{\mathbf{g}}(\mathbf{x})\,\mathbf{h}+\mathbf{r}(\mathbf{h})}$$
$$\text{with}$$
$$\textcolor{#1b7f4a}{\lim_{\mathbf{h}\to\mathbf{0}}\frac{\lVert\mathbf{r}(\mathbf{h})\rVert}{\lVert\mathbf{h}\rVert}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0 .}$$
(5.3)
Proof: Linear approximation of a vector-valued function

Component $i$ of $\mathbf{J}_{\mathbf{g}}(\mathbf{x})\,\mathbf{h}$ is $\nabla g_i(\mathbf{x})^{\top}\mathbf{h}$. By the definition of differentiability (3.5), for every $i$ the quotient $r_i(\mathbf{h})/\lVert\mathbf{h}\rVert$ tends to $0$. Because $\lVert\mathbf{r}\rVert\le|r_1|+\dots+|r_m|$, $\lVert\mathbf{r}(\mathbf{h})\rVert/\lVert\mathbf{h}\rVert$ also tends to $0$.

Near $\mathbf{x}$, $\mathbf{g}$ therefore acts like the linear map $\mathbf{h}\mapsto\mathbf{J}_{\mathbf{g}}(\mathbf{x})\,\mathbf{h}$, and by Chapter 1, Section 8.2, every linear map has exactly one matrix. The Jacobian matrix is this matrix. Under the magnifying glass, $\mathbf{g}$ deforms a small grid around $\mathbf{x}$ the way the matrix $\mathbf{J}_{\mathbf{g}}(\mathbf{x})$ deforms the unit grid: it is rotated, stretched or sheared, but straight lines remain almost straight.

Worked example

For $\mathbf{g}$ from (5.1) at the point $(1,\,2)$ and $\textcolor{#1b7f4a}{\mathbf{h}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0.1,\ -0.1)^{\top}}$,

$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(1,2)\,\mathbf{h}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2\cdot0.1+1\cdot(-0.1)\\2\cdot0.1+4\cdot(-0.1)\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}0.1\\-0.2\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{g}(1.1,\ 1.9)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\begin{pmatrix}2.1\\5.8\end{pmatrix}.}$$

The exact value is $\textcolor{#1b7f4a}{\mathbf{g}(1.1,\ 1.9)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2.09,\ 5.81)^{\top}}$. Fig. 10 shows the product row by row.

⁠In short: Near $\mathbf{x}$, $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\mathbf{g}(\mathbf{x})+\mathbf{J}_{\mathbf{g}}(\mathbf{x})\,\mathbf{h}}$; the Jacobian matrix is the matrix of the linear map that $\mathbf{g}$ acts like on a small scale.

Two important Jacobian matrices#

Two building blocks occur all the time in calculations with data: the matrix–vector product and functions applied to each component separately. You need their Jacobian matrices again and again, and both can be stated without calculation.

Theorem 5.4 (Jacobian matrices of the building blocks)

  1. For $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}+\mathbf{b}}$ with $\mathbf{A}\in\mathbb{R}^{m\times n}$ and $\mathbf{b}\in\mathbb{R}^m$, $\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}}$ at every point.

  2. If $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^n$ applies a differentiable function $\varphi$ of one variable to each component, $\textcolor{#1b7f4a}{g_i(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varphi(x_i)}$, then

    $$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}\bigl(\varphi'(x_1),\,\dots,\,\varphi'(x_n)\bigr).}$$
    (5.4)
Proof: Jacobian matrices of the building blocks

(a) Component $i$ is $\textcolor{#1b7f4a}{g_i(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ka_{ik}x_k+b_i}$. Differentiating with respect to $x_j$, only the term with $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{j}$ remains, so $\textcolor{#1b7f4a}{\partial g_i/\partial x_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{a_{ij}}$. (b) The component $\textcolor{#1b7f4a}{g_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\varphi(x_i)}$ depends only on $x_i$. Its derivative with respect to $x_j$ is therefore $0$ for $j\ne i$ and $\varphi'(x_i)$ for $\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{i}$.

Both results have a simple reason. An affine map is already linear except for the shift $\mathbf{b}$; its best linear approximation is itself without $\mathbf{b}$. In an elementwise function, each input acts only on its own output; all entries off the diagonal are zero because there are no connections between different components.

Worked example

For $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&2\\0&-1\\3&1\end{smallmatrix}\bigr)}$, the Jacobian matrix of $\mathbf{x}\mapsto\mathbf{A}\mathbf{x}$ is $\mathbf{A}$ itself everywhere. If you square each component, $\textcolor{#1b7f4a}{\varphi(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{t^2}$, the Jacobian matrix at the point $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-2,\,3)^{\top}}$ is $\operatorname{diag}(2,\,-4,\,6)$. If you apply the logistic function to each component of $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,2)^{\top}}$, then by (2.4) it is $\textcolor{#1b7f4a}{\operatorname{diag}\bigl(\sigma'(0),\,\sigma'(2)\bigr)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\operatorname{diag}(0.25,\ 0.105)}$.

⁠In short: The Jacobian matrix of $\mathbf{x}\mapsto\mathbf{A}\mathbf{x}+\mathbf{b}$ is $\mathbf{A}$; that of an elementwise function is the diagonal matrix of the individual derivatives.

BackgroundThe determinant of the Jacobian matrix as an area factor

By Chapter 1, Section 14.3, a linear map multiplies the area of every figure by the same factor $|\det\mathbf{A}|$. Because $\mathbf{g}$ acts like $\mathbf{J}_{\mathbf{g}}(\mathbf{x})$ on a small scale, this also holds approximately for $\mathbf{g}$: a small square around $\mathbf{x}$ with area $F$ turns into a figure that is almost a parallelogram with area $|\det\mathbf{J}_{\mathbf{g}}(\mathbf{x})|\cdot F$. For $\mathbf{g}$ from (5.1), $\textcolor{#1b7f4a}{\det\mathbf{J}_{\mathbf{g}}(1,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\cdot4-1\cdot2}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$: near $(1,\,2)$, $\mathbf{g}$ enlarges areas by a factor of about six. Polar coordinates are a well-known example, $\textcolor{#1b7f4a}{\mathbf{g}(r,\varphi)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(r\cos\varphi,\ r\sin\varphi)^{\top}}$. Their Jacobian matrix has the columns $(\cos\varphi,\,\sin\varphi)^{\top}$ and $(-r\sin\varphi,\,r\cos\varphi)^{\top}$ and the determinant $\textcolor{#1b7f4a}{r\cos^2\varphi+r\sin^2\varphi}\textcolor{#15633a}{=}\textcolor{#c2410c}{r}$. A small rectangle with sides $\Delta r$ and $\Delta\varphi$ becomes a piece of an annulus with area about $r\,\Delta r\,\Delta\varphi$, because the arc for the angle $\Delta\varphi$ at distance $r$ has length $r\,\Delta\varphi$.

Exercise 17 ★ Computing Jacobian matrices

Compute the Jacobian matrix at the given point.

  1. $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1+x_2,\ x_1-x_2,\ x_1x_2)^{\top}}$ at the point $(3,\,1)$;

  2. $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathrm{e}^{x_1},\,\mathrm{e}^{x_2},\,\mathrm{e}^{x_3})^{\top}}$ at the point $(0,\,1,\,-1)$;

  3. $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1^2x_2+x_2^2}$ from (3.1) at the point $(1,\,2)$. What shape does the matrix have, and what is it?

Solution

(a) The Jacobian matrix has three rows and two columns:

$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1&1\\1&-1\\x_2&x_1\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(3,1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1&1\\1&-1\\1&3\end{pmatrix}.}$$

(b) The function is elementwise; by (5.4), $\textcolor{#1b7f4a}{\mathbf{J}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}(\mathrm{e}^0,\,\mathrm{e}^1,\,\mathrm{e}^{-1})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\operatorname{diag}(1,\ 2.718,\ 0.368)}$.

(c) A function with one output has a $1\times2$ Jacobian matrix, the gradient as a row: $\textcolor{#1b7f4a}{\mathbf{J}_f(1,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4\ \ 5)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(1,2)^{\top}}$.

Exercise 18 ★★ Linear approximation of a map of the plane

Let $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1^2-x_2,\ x_1x_2)^{\top}}$.

  1. Compute $\mathbf{J}_{\mathbf{g}}(2,1)$ and use it to find an approximate value for $\mathbf{g}(2.05,\ 0.9)$. Compare with the exact value.

  2. How must you shift the inputs so that the first output changes but the second, in linear approximation, does not change at all? Give such a displacement $\mathbf{h}$.

Solution

(a) $\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}2x_1&-1\\x_2&x_1\end{smallmatrix}\bigr)}$, so $\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(2,1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}4&-1\\1&2\end{smallmatrix}\bigr)}$, and $\textcolor{#1b7f4a}{\mathbf{g}(2,1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,2)^{\top}}$. With $\textcolor{#1b7f4a}{\mathbf{h}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0.05,\ -0.1)^{\top}}$,

$$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}\mathbf{h}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}0.2+0.1\\0.05-0.2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}0.3\\-0.15\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{g}(2.05,\ 0.9)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\begin{pmatrix}3.3\\1.85\end{pmatrix}.}$$

The exact value is $\textcolor{#1b7f4a}{\mathbf{g}(2.05,\ 0.9)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4.2025-0.9,\ 1.845)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3.3025,\ 1.845)^{\top}}$.

(b) In linear approximation, the second output changes by $h_1+2h_2$; this is zero for $\mathbf{h}$ in the direction $(2,\,-1)^{\top}$. For a step by exactly this vector, the first output then changes by $\textcolor{#1b7f4a}{4\cdot2-1\cdot(-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{9}$. So both inputs must change: $x_1$ grows and $x_2$ falls half as much, for example $\textcolor{#1b7f4a}{\mathbf{h}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0.02,\ -0.01)^{\top}}$ with the effect $(0.09,\ 0)^{\top}$.

Exercise 19 ★★★ How much $\mathbf{g}$ enlarges areas

Let $\mathbf{g}$ be as in (5.1).

  1. Compute the images of the four corners of the square with the corners $(1,\,2)$, $(1.1,\ 2)$, $(1.1,\ 2.1)$ and $(1,\ 2.1)$.

  2. The images almost form a parallelogram. Estimate its area using the images of the two edges that start at $\mathbf{g}(1,2)$, and compare with $|\det\mathbf{J}_{\mathbf{g}}(1,2)|\cdot0.01$.

Solution

(a) With $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1x_2,\ 2x_1+x_2^2)^{\top}}$:

$$\textcolor{#1b7f4a}{\mathbf{g}(1,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2\\6\end{pmatrix},\quad \mathbf{g}(1.1,\,2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2.2\\6.2\end{pmatrix},\quad \mathbf{g}(1.1,\,2.1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2.31\\6.61\end{pmatrix},\quad \mathbf{g}(1,\,2.1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2.1\\6.41\end{pmatrix}.}$$

(b) The images of the two edges that start at $\mathbf{g}(1,2)$ are $(0.2,\ 0.2)^{\top}$ and $(0.1,\ 0.41)^{\top}$. By Chapter 1, Section 14.1, the parallelogram they span has the area $\textcolor{#1b7f4a}{|0.2\cdot0.41-0.1\cdot0.2|}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.062}$. The Jacobian matrix predicts $\textcolor{#1b7f4a}{|\det\mathbf{J}_{\mathbf{g}}(1,2)|\cdot0.01}\textcolor{#15633a}{=}\textcolor{#c2410c}{6\cdot0.01}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.06}$. The discrepancy arises because the square is not arbitrarily small; the fourth corner, at $(2.31,\ 6.61)$, also lies only almost where a true parallelogram would have it, at $(2.3,\ 6.61)$.

    $$\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{g}}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}\bigl(\varphi'(x_1),\,\dots,\,\varphi'(x_n)\bigr).}$$
Key relationships
  • On “Functions with several outputs”: A vector-valued function $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ consists of $m$ functions of $n$ variables, one for each output.
  • On “The Jacobian matrix”: The Jacobian matrix has one row per output and one column per input; its entry $(i,j)$ is $\partial g_i/\partial x_j$.
  • On “The linear approximation with the Jacobian matrix”: Near $\mathbf{x}$, $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\mathbf{g}(\mathbf{x})+\mathbf{J}_{\mathbf{g}}(\mathbf{x})\,\mathbf{h}}$; the Jacobian matrix is the matrix of the linear map that $\mathbf{g}$ acts like on a small scale.
  • On “Two important Jacobian matrices”: The Jacobian matrix of $\mathbf{x}\mapsto\mathbf{A}\mathbf{x}+\mathbf{b}$ is $\mathbf{A}$; that of an elementwise function is the diagonal matrix of the individual derivatives.
