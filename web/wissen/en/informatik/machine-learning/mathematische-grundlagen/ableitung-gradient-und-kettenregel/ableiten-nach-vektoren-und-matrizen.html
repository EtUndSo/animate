What this stage is about:

Gradients of expressions such as $\mathbf{a}^{\top}\mathbf{x}$, $\mathbf{x}^{\top}\mathbf{A}\mathbf{x}$ or $\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2$ are needed again and again. This section first fixes the shape of each derivative and then derives the most important formulas componentwise. At the end come derivatives with respect to a matrix and the rule with which you compute a sensitivity backward through a matrix product.

The layout convention#

For functions of one variable, the derivative is a number, and there is nothing to arrange. For vectors and matrices, you have to decide in which shape the many partial derivatives are written down: as a column or as a row, as an $m\times n$ or as an $n\times m$ matrix. Such a decision is called a layout convention. Mathematically, every choice is equally good; you just have to stick to it, otherwise formulas suddenly appear transposed.

Definition 7.1 (Layout convention of this chapter)

  1. Vectors are columns. The gradient of a function $f:\mathbb{R}^n\to\mathbb{R}$ is a column with the same shape as $\mathbf{x}$.

  2. The Jacobian matrix of a function $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ is an $m\times n$ matrix: one row per output, one column per input.

  3. The derivative of a function $f:\mathbb{R}^{m\times n}\to\mathbb{R}$ with respect to a matrix $\mathbf{A}$ is an $m\times n$ matrix $\nabla_{\mathbf{A}}f$ with the entry $\partial f/\partial a_{ij}$ in position $(i,j)$, that is, with the same shape as $\mathbf{A}$.

Table 2 summarizes this. The chapter has already used two consequences: for a function with one output, the Jacobian matrix is the gradient as a row, $\textcolor{#1b7f4a}{\mathbf{J}_f}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f^{\top}}$. And the chain rule for gradients needs the transpose, $\textcolor{#1b7f4a}{\nabla(f\circ\mathbf{g})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{J}_{\mathbf{g}}^{\top}\nabla f}$. Rule (iii) is needed in Section 7.5: if you change a matrix by a small matrix $\mathbf E$, you want to be able to compare $\nabla_{\mathbf{A}}f$ and $\mathbf E$ entry by entry.

Table 2: The shape of the derivative depending on the type of function, in the convention of this chapter.

Worked example

For $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1^2x_2+x_2^2}$ at the point $(1,\,2)$, the gradient is the column $\textcolor{#1b7f4a}{\nabla f}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4,\,5)^{\top}}$ and the Jacobian matrix is the row $\textcolor{#1b7f4a}{\mathbf{J}_f}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4\ \ 5)}$. For $\mathbf{g}$ from (5.1), $\mathbf{J}_{\mathbf{g}}$ is a $2\times2$ matrix whose first row $(2\ \ 1)$ is the gradient of $\textcolor{#1b7f4a}{g_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1x_2}$ as a row.

⁠In short: In this chapter, a gradient has the shape of its variable, and a Jacobian matrix has one row per output; from this follow $\textcolor{#1b7f4a}{\mathbf{J}_f}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f^{\top}}$ and the transpose in the chain rule for gradients.

BackgroundOther conventions in the literature

Many books write the gradient as a row. Then it is the same as the Jacobian matrix of a function with one output, and the chain rule needs no transposing at all, because $\textcolor{#1b7f4a}{\nabla(f\circ\mathbf{g})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f\,\mathbf{J}_{\mathbf{g}}}$ is then a product of a row and a matrix. The price is that the gradient no longer has the shape of $\mathbf{x}$; the line $\mathbf{x}+t\,\nabla f$ in the direction of steepest ascent then needs a transpose. Two arrangements are distinguished. In the numerator layout, the rows follow the components of the function, as with the Jacobian matrix of this chapter. In the denominator layout, they follow the components of the variable; then the derivative of a vector-valued function is the transpose of the Jacobian matrix. This chapter uses a common mixed layout: gradient as a column and Jacobian matrix in numerator layout. You must therefore not combine formulas from different sources without checking them. A quick check is the shape: a gradient with respect to $\mathbf{x}\in\mathbb{R}^n$ must have $n$ entries in a column. A more reliable check is a small numerical example.

Linear functions#

The simplest function of many variables is the weighted sum. Its gradient is so simple that you can write it down immediately; the derivation shows the pattern by which all further formulas of this section arise.

Theorem 7.2 (Gradients of linear functions)

For fixed vectors $\mathbf{a},\mathbf{y}$ and a fixed matrix $\mathbf{A}$ of matching shape,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{a}^{\top}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla_{\mathbf{x}}(\mathbf{x}^{\top}\mathbf{a})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{a},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{y}^{\top}\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf{y} .}$$
(7.1)
Proof: Gradients of linear functions

We have $\textcolor{#1b7f4a}{\mathbf{a}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ja_jx_j}$. Differentiating with respect to $x_k$, only the term with $\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{k}$ remains, that is, $a_k$. Because $\textcolor{#1b7f4a}{\mathbf{x}^{\top}\mathbf{a}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{a}^{\top}\mathbf{x}}$, the same holds for $\mathbf{x}^{\top}\mathbf{a}$. For the second part, set $\textcolor{#1b7f4a}{\mathbf{a}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf{y}}$, because $\textcolor{#1b7f4a}{\mathbf{y}^{\top}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{\top}\mathbf{y})^{\top}\mathbf{x}}$.

Worked example

In Chapter 1, Section 2.2, the prediction for apartment 1 with $\textcolor{#1b7f4a}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}}$ and the weights $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ was $\textcolor{#1b7f4a}{\hat y_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{188}$. As a function of the weights, it has the gradient $\textcolor{#1b7f4a}{\nabla_{\mathbf{w}}\hat y_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}}$. If you increase $w_1$ by $0.1$, the prediction rises by $\textcolor{#1b7f4a}{60\cdot0.1}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$ to $194$; indeed, $\textcolor{#1b7f4a}{3.1\cdot60+10\cdot2-4\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{194}$. The reason is simple: each weight is multiplied by its feature, and therefore the sensitivity with respect to a weight is exactly the corresponding feature.

⁠In short: The gradient of $\mathbf{a}^{\top}\mathbf{x}$ with respect to $\mathbf{x}$ is $\mathbf{a}$; that of $\mathbf{y}^{\top}\mathbf{A}\mathbf{x}$ is $\mathbf{A}^{\top}\mathbf{y}$.

Quadratic forms#

Quadratic forms $\mathbf{x}^{\top}\mathbf{A}\mathbf{x}$ from Chapter 2, Section 5, appear wherever squares are summed. When you differentiate, $\mathbf{x}$ appears in two places, and both contribute, like the two paths in Section 6.2.

Theorem 7.3 (Gradient of a quadratic form)

For a matrix $\mathbf{A}\in\mathbb{R}^{n\times n}$,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{x}^{\top}\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}+\mathbf{A}^{\top})\,\mathbf{x} .}$$
(7.2)

If $\mathbf{A}$ is symmetric, this is $2\mathbf{A}\mathbf{x}$. In particular, $\textcolor{#1b7f4a}{\nabla\lVert\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla(\mathbf{x}^{\top}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{x}}$.

Proof: Gradient of a quadratic form

We have $\textcolor{#1b7f4a}{\mathbf{x}^{\top}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=1}^n\sum_{j=1}^nx_i\,a_{ij}\,x_j}$. Differentiating with respect to $x_k$, two groups of terms contribute: those with $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{k}$, whose derivative is $\textcolor{#1b7f4a}{\sum_ja_{kj}x_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}\mathbf{x})_k}$, and those with $\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{k}$, whose derivative is $\textcolor{#1b7f4a}{\sum_ix_ia_{ik}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{\top}\mathbf{x})_k}$. The term with $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{k}$ is $a_{kk}x_k^2$ and has the derivative $2a_{kk}x_k$; it is contained once in each of the two groups, with $a_{kk}x_k$. So component $k$ of the gradient is $(\mathbf{A}\mathbf{x})_k+(\mathbf{A}^{\top}\mathbf{x})_k$.

By Chapter 2, Section 5.2, the quadratic form depends only on the symmetric part $\textcolor{#1b7f4a}{\mathbf{S}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12(\mathbf{A}+\mathbf{A}^{\top})}$. The formula fits this: $\textcolor{#1b7f4a}{(\mathbf{A}+\mathbf{A}^{\top})\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{S}\mathbf{x}}$.

Worked example

For $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&2\\0&3\end{smallmatrix}\bigr)}$, $\textcolor{#1b7f4a}{\mathbf{x}^{\top}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1^2+2x_1x_2+3x_2^2}$, so at the point $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1)^{\top}}$ it is $6$. By (7.2),

$$\textcolor{#1b7f4a}{\nabla f(1,1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}+\mathbf{A}^{\top})\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2&2\\2&6\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2+2\\2+6\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}4\\8\end{pmatrix}.}$$

Check with the partial derivatives $\textcolor{#1b7f4a}{2x_1+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ and $\textcolor{#1b7f4a}{2x_1+6x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$. The formula $\textcolor{#1b7f4a}{2\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(6,\,6)^{\top}}$, which holds only for symmetric matrices, would be wrong here.

⁠In short: The gradient of $\mathbf{x}^{\top}\mathbf{A}\mathbf{x}$ is $(\mathbf{A}+\mathbf{A}^{\top})\mathbf{x}$, so $2\mathbf{A}\mathbf{x}$ for symmetric $\mathbf{A}$, and that of $\lVert\mathbf{x}\rVert^2$ is $2\mathbf{x}$.

The sum of squares of a residual#

In Chapter 2, Section 3, the residual $\textcolor{#1b7f4a}{\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}-\mathbf{A}\mathbf{x}}$ was the error vector of a system of equations $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ that has no solution, and we were looking for the $\mathbf{x}$ with the shortest residual. The sum of squares $\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2$ is a function of $\mathbf{x}$, and its gradient tells how it responds to a change in $\mathbf{x}$.

Theorem 7.4 (Gradient of the sum of squares)

For $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2}$ with $\mathbf{A}\in\mathbb{R}^{m\times n}$ and $\mathbf{y}\in\mathbb{R}^m$,

$$\textcolor{#1b7f4a}{\nabla f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\mathbf{A}^{\top}(\mathbf{y}-\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{A}^{\top}(\mathbf{A}\mathbf{x}-\mathbf{y}).}$$
(7.3)
Proof: Gradient of the sum of squares

The function is a composition: first the affine map $\textcolor{#1b7f4a}{\mathbf{r}(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}-\mathbf{A}\mathbf{x}}$ forms the residual, then $\mathbf{r}\mapsto\lVert\mathbf{r}\rVert^2$ forms its sum of squares. By Section 5.4, $\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\mathbf{A}}$; by (7.2), $\textcolor{#1b7f4a}{\nabla_{\mathbf{r}}\lVert\mathbf{r}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{r}}$. The chain rule (6.3) gives $\textcolor{#1b7f4a}{\nabla f}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-\mathbf{A})^{\top}\,2\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\mathbf{A}^{\top}\mathbf{r}}$.

Worked example

Let $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&2\\0&1\end{smallmatrix}\bigr)}$, $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,1)^{\top}}$. Then $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4,\,1)^{\top}}$, the residual is $\textcolor{#1b7f4a}{\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-3,\,-1)^{\top}}$ and $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{9+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$. With $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-3,\,-7)^{\top}}$,

$$\textcolor{#1b7f4a}{\nabla f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\mathbf{A}^{\top}\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\begin{pmatrix}-3\\-7\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}6\\14\end{pmatrix}}$$

(Fig. 13). Check: written out, $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1-x_1-2x_2)^2+x_2^2}$ with the partial derivatives $\textcolor{#1b7f4a}{-2\,(1-x_1-2x_2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$ and $\textcolor{#1b7f4a}{-4\,(1-x_1-2x_2)+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{12+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{14}$.

The formula connects with Chapter 2. There, the residual of the best approximate solution $\hat{\mathbf{x}}$ was perpendicular to all columns of $\mathbf{A}$, that is, $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\hat{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, and from this followed the normal equations $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\mathbf{A}\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf{y}}$. By (7.3), this means: at the point $\hat{\mathbf{x}}$, the gradient of the sum of squares is zero; there it rises or falls in no direction, apart from second-order terms. For the example from Chapter 2, Section 3.3, with the matrix $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl(\begin{smallmatrix}1&0\\0&1\\1&1\end{smallmatrix}\Bigr)}$, $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1,\,1)^{\top}}$ and $\textcolor{#1b7f4a}{\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac23,\,\tfrac23)^{\top}}$, we get $\textcolor{#1b7f4a}{\hat{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac13,\,\tfrac13,\,-\tfrac13)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\hat{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac13-\tfrac13,\ \tfrac13-\tfrac13)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

⁠In short: The gradient of $\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2$ is $-2\mathbf{A}^{\top}(\mathbf{y}-\mathbf{A}\mathbf{x})$; it vanishes exactly where the residual is perpendicular to the columns of $\mathbf{A}$.

Differentiating with respect to a matrix#

Sometimes the variable is not a vector but a whole matrix: how does a number change if you change one entry of a matrix? By rule (iii) of the convention, you arrange the $m\cdot n$ partial derivatives in the shape of the matrix. Then the linear approximation holds as usual, except that the dot product runs over all entries:

$$\textcolor{#1b7f4a}{f(\mathbf{A}+\mathbf E)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f(\mathbf{A})+\sum_{i=1}^m\sum_{j=1}^n\bigl(\nabla_{\mathbf{A}}f\bigr)_{ij}\,e_{ij}}$$
(7.4)

for a small matrix $\mathbf E$ with the entries $e_{ij}$. The double sum is the same as $\operatorname{tr}\bigl((\nabla_{\mathbf{A}}f)^{\top}\mathbf E\bigr)$ with the trace from Chapter 2, Section 6.5.

Theorem 7.5 (Two derivatives with respect to a matrix)

For fixed vectors $\mathbf{u}\in\mathbb{R}^m$, $\mathbf{v}\in\mathbb{R}^n$ and a matrix $\mathbf{A}\in\mathbb{R}^{m\times n}$,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}(\mathbf{u}^{\top}\mathbf{A}\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}\mathbf{v}^{\top},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\lVert\mathbf{A}\rVert_F^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{A} .}$$
(7.5)

Here $\lVert\mathbf{A}\rVert_F$ is the Frobenius norm from Chapter 2, Section 10.1.

Proof: Two derivatives with respect to a matrix

We have $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{A}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_i\sum_ju_i\,a_{ij}\,v_j}$. The entry $a_{ij}$ occurs in exactly one term, with the factor $u_iv_j$. So $\textcolor{#1b7f4a}{\partial(\mathbf{u}^{\top}\mathbf{A}\mathbf{v})/\partial a_{ij}}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_iv_j}$, and that is entry $(i,j)$ of the outer product $\mathbf{u}\mathbf{v}^{\top}$ from Chapter 1, Section 9.5. Likewise, $\textcolor{#1b7f4a}{\lVert\mathbf{A}\rVert_F^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i,j}a_{ij}^2}$, and $\partial/\partial a_{ij}$ of it is $2a_{ij}$.

Worked example

For $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,-1)^{\top}}$,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}(\mathbf{u}^{\top}\mathbf{A}\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}\mathbf{v}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}3&-1\\6&-2\end{pmatrix},}$$

at every point $\mathbf{A}$, because the function is linear in $\mathbf{A}$. For $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$, $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{A}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3-2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. If you increase the entry $a_{21}$ by $0.1$, the gradient predicts a change of $\textcolor{#1b7f4a}{6\cdot0.1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.6}$. Indeed, $a_{21}$ occurs only in the term $\textcolor{#1b7f4a}{u_2\,a_{21}\,v_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\cdot a_{21}\cdot3}$, and that term grows by $0.6$.

⁠In short: The derivative of a number with respect to a matrix has the shape of the matrix; for $\mathbf{u}^{\top}\mathbf{A}\mathbf{v}$ it is the outer product $\mathbf{u}\mathbf{v}^{\top}$, for $\lVert\mathbf{A}\rVert_F^2$ it is $2\mathbf{A}$.

Backward through a matrix product#

Often a matrix–vector product $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ is only an intermediate step of a longer calculation that ends with a number $f(\mathbf{y})$. If you already know how this number responds to $\mathbf{y}$, that is, $\nabla f(\mathbf{y})$, you want to read off from it how the number responds to $\mathbf{A}$ and to $\mathbf{x}$. This calculation backward through a building block is the pattern for reverse mode in Section 10.

Theorem 7.6 (Backward rule of the matrix product)

Let $f:\mathbb{R}^m\to\mathbb{R}$ be differentiable, $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ with $\mathbf{A}\in\mathbb{R}^{m\times n}$ and $\textcolor{#1b7f4a}{F(\mathbf{A},\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{A}\mathbf{x})}$. Then

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(\mathbf{y})\,\mathbf{x}^{\top},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\,\nabla f(\mathbf{y}).}$$
(7.6)

More generally, for $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{B}}$ and $\textcolor{#1b7f4a}{F(\mathbf{A},\mathbf{B})}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{C})}$: $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\nabla_{\mathbf{C}}f)\,\mathbf{B}^{\top}}$ and $\textcolor{#1b7f4a}{\nabla_{\mathbf{B}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\,(\nabla_{\mathbf{C}}f)}$.

Proof: Backward rule of the matrix product

We have $\textcolor{#1b7f4a}{y_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ka_{ik}x_k}$. The entry $a_{ij}$ affects only $y_i$, namely with the factor $\textcolor{#1b7f4a}{\partial y_i/\partial a_{ij}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_j}$. So there is only one path from $a_{ij}$ to $f$, and $\textcolor{#1b7f4a}{\partial F/\partial a_{ij}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{\partial f}{\partial y_i}\,x_j}$; that is entry $(i,j)$ of $\nabla f(\mathbf{y})\,\mathbf{x}^{\top}$. The variable $x_j$, on the other hand, affects every $y_i$, with the factor $a_{ij}$; summed over all paths, $\textcolor{#1b7f4a}{\partial F/\partial x_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_i\frac{\partial f}{\partial y_i}\,a_{ij}}$, component $j$ of $\mathbf{A}^{\top}\nabla f(\mathbf{y})$. The second statement follows in the same way, because $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{B}}$ is, column by column, a matrix–vector product.

Worked example

In Chapter 1, Section 7.1, we had $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl(\begin{smallmatrix}1&2\\0&-1\\3&1\end{smallmatrix}\Bigr)}$ and $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,1)^{\top}}$, so $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4,\,-1,\,7)^{\top}}$. Let $\textcolor{#1b7f4a}{f(\mathbf{y})}\textcolor{#15633a}{=}\textcolor{#c2410c}{y_1-y_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3}$, so $\textcolor{#1b7f4a}{\nabla f(\mathbf{y})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0,\,-1)^{\top}}$. By (7.6),

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1\\0\\-1\end{pmatrix}\begin{pmatrix}2&1\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2&1\\0&0\\-2&-1\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\begin{pmatrix}1\\0\\-1\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}-2\\1\end{pmatrix}}$$

(Fig. 14). Check: written out, $\textcolor{#1b7f4a}{F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1+2x_2)-(3x_1+x_2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2x_1+x_2}$ with the gradient $(-2,\,1)^{\top}$. The second row of $\nabla_{\mathbf{A}}F$ is zero because $y_2$ does not occur in $f$; the entries of the second row of $\mathbf{A}$ act only on $y_2$.

Caution: The shape check is a mnemonic, not a proof

The shapes almost determine (7.6): $\nabla_{\mathbf{A}}F$ must have the shape $m\times n$, and from the column $\nabla f(\mathbf{y})$ with $m$ entries and the column $\mathbf{x}$ with $n$ entries, only $\nabla f(\mathbf{y})\,\mathbf{x}^{\top}$ gives this shape. This is a way to remember the rule. But the shape check detects neither a wrong sign nor a missing factor nor a swapped order for square matrices. Only the calculation with the components justifies the rule.

⁠In short: Backward through $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$: the gradient with respect to $\mathbf{A}$ is $\nabla f(\mathbf{y})\,\mathbf{x}^{\top}$, the one with respect to $\mathbf{x}$ is $\mathbf{A}^{\top}\nabla f(\mathbf{y})$.

Exercise 25 ★★ The least-squares line from Chapter 2

In Chapter 2, Section 3.6, a line was fitted through the points $(0,\,1)$, $(1,\,2)$ and $(2,\,4)$, with $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl(\begin{smallmatrix}1&0\\1&1\\1&2\end{smallmatrix}\Bigr)}$ and $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,4)^{\top}}$.

  1. Compute $\textcolor{#1b7f4a}{f(\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2}$ and $\nabla f(\mathbf{x})$ at the point $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1)^{\top}}$.

  2. In which direction should you shift $\mathbf{x}$ a small step away from $(1,\,1)$ so that $f$ decreases fastest?

  3. Show that the gradient at the point $\textcolor{#1b7f4a}{\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac56,\,\tfrac32)^{\top}}$ from Chapter 2 is zero.

Solution

(a) $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,3)^{\top}}$, $\textcolor{#1b7f4a}{\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}-\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,0,\,1)^{\top}}$ and $\textcolor{#1b7f4a}{f}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. With $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0+0+1,\ 0+0+2)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}}$, we get $\textcolor{#1b7f4a}{\nabla f}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\mathbf{A}^{\top}\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-2,\,-4)^{\top}}$.

(b) $f$ decreases fastest in the direction $\textcolor{#1b7f4a}{-\nabla f/\lVert\nabla f\rVert}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,4)^{\top}/\sqrt{20}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}/\sqrt5}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{(0.447,\ 0.894)^{\top}}$: the intercept should grow a little, the slope twice as much. This fits the fact that the line $1+t$ misses the third point $(2,\,4)$ by $1$.

(c) $\textcolor{#1b7f4a}{\mathbf{A}\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac56,\ \tfrac73,\ \tfrac{23}6)^{\top}}$, so $\textcolor{#1b7f4a}{\hat{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\tfrac16,\ -\tfrac13,\ \tfrac16)^{\top}}$ and

$$\textcolor{#1b7f4a}{\mathbf{A}^{\top}\hat{\mathbf{r}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}\tfrac16-\tfrac13+\tfrac16\\0-\tfrac13+\tfrac26\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}0\\0\end{pmatrix}.}$$

The gradient is zero: at the best approximate solution, no small displacement changes the sum of squares to first order.

Exercise 26 ★★ Derivatives with respect to a matrix

  1. Show that $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\operatorname{tr}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$ for square $\mathbf{A}$.

  2. Use (7.6) and $\textcolor{#1b7f4a}{\nabla\lVert\mathbf{y}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{y}}$ to show that $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\lVert\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,(\mathbf{A}\mathbf{x})\,\mathbf{x}^{\top}}$, and compute this for $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}\in\mathbb{R}^{2\times2}}$ and $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}}$.

  3. Check (b) with the linear approximation (7.4): by about how much does $\lVert\mathbf{A}\mathbf{x}\rVert^2$ change if you increase $a_{12}$ from $0$ to $0.01$? Verify by calculation.

Solution

(a) $\textcolor{#1b7f4a}{\operatorname{tr}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ia_{ii}}$. The derivative with respect to $a_{ij}$ is $1$ for $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{j}$ and $0$ otherwise; arranged in the shape of $\mathbf{A}$, this is $\mathbf{I}$.

(b) We have $\textcolor{#1b7f4a}{\lVert\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{y})}$ with $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ and $\textcolor{#1b7f4a}{\nabla f(\mathbf{y})}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{y}}$. By (7.6), $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\lVert\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{y}\,\mathbf{x}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,(\mathbf{A}\mathbf{x})\,\mathbf{x}^{\top}}$. For $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$ and $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}}$:

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\lVert\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\begin{pmatrix}1\\2\end{pmatrix}\begin{pmatrix}1&2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2&4\\4&8\end{pmatrix}.}$$

(c) The entry $(1,2)$ of the gradient is $4$, so (7.4) predicts a change of about $\textcolor{#1b7f4a}{4\cdot0.01}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.04}$. Exactly: with $\textcolor{#1b7f4a}{a_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0.01}$, we have $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1.02,\ 2)^{\top}}$ and $\textcolor{#1b7f4a}{\lVert\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1.0404+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{5.0404}$, that is, a change of $0.0404$ compared with $5$.

Exercise 27 ★★★ The backward rule for a product of two matrices

Let $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{B}}$ and $\textcolor{#1b7f4a}{F(\mathbf{A},\mathbf{B})}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{C})}$ with $\textcolor{#1b7f4a}{\mathbf G}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla_{\mathbf{C}}f}$.

  1. Show componentwise that $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf G\mathbf{B}^{\top}}$ and $\textcolor{#1b7f4a}{\nabla_{\mathbf{B}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf G}$.

  2. Check both formulas for $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1\ \ 2)}$, $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}3\\4\end{smallmatrix}\bigr)}$ and $\textcolor{#1b7f4a}{f(\mathbf{C})}\textcolor{#15633a}{=}\textcolor{#c2410c}{c_{11}^2}$ by writing out $F$.

Solution

(a) We have $\textcolor{#1b7f4a}{c_{ik}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ja_{ij}b_{jk}}$. The entry $a_{ij}$ acts on all $c_{ik}$ of row $i$, with the factor $b_{jk}$; summed over these paths, $\textcolor{#1b7f4a}{\partial F/\partial a_{ij}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_kg_{ik}b_{jk}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf G\mathbf{B}^{\top})_{ij}}$. The entry $b_{jk}$ acts on all $c_{ik}$ of column $k$, with the factor $a_{ij}$; so $\textcolor{#1b7f4a}{\partial F/\partial b_{jk}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ia_{ij}g_{ik}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{\top}\mathbf G)_{jk}}$.

(b) $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot3+2\cdot4}\textcolor{#15633a}{=}\textcolor{#c2410c}{11}$, $\textcolor{#1b7f4a}{F}\textcolor{#15633a}{=}\textcolor{#c2410c}{121}$ and $\textcolor{#1b7f4a}{\mathbf G}\textcolor{#15633a}{=}\textcolor{#c2410c}{2c_{11}}\textcolor{#15633a}{=}\textcolor{#c2410c}{22}$. The formulas give $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{22\,(3\ \ 4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{(66\ \ 88)}$ and $\textcolor{#1b7f4a}{\nabla_{\mathbf{B}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}\cdot22}\textcolor{#15633a}{=}\textcolor{#c2410c}{(22,\,44)^{\top}}$. Written out, $\textcolor{#1b7f4a}{F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3a_{11}+4a_{12})^2}$, with the derivatives $\textcolor{#1b7f4a}{2\cdot11\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{66}$ and $\textcolor{#1b7f4a}{2\cdot11\cdot4}\textcolor{#15633a}{=}\textcolor{#c2410c}{88}$, and $\textcolor{#1b7f4a}{F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(b_{11}+2b_{21})^2}$, with the derivatives $22$ and $44$.

The layout convention
Definition 7.1 (Layout convention of this chapter)

  1. Vectors are columns. The gradient of a function $f:\mathbb{R}^n\to\mathbb{R}$ is a column with the same shape as $\mathbf{x}$.

  2. The Jacobian matrix of a function $\mathbf{g}:\mathbb{R}^n\to\mathbb{R}^m$ is an $m\times n$ matrix: one row per output, one column per input.

  3. The derivative of a function $f:\mathbb{R}^{m\times n}\to\mathbb{R}$ with respect to a matrix $\mathbf{A}$ is an $m\times n$ matrix $\nabla_{\mathbf{A}}f$ with the entry $\partial f/\partial a_{ij}$ in position $(i,j)$, that is, with the same shape as $\mathbf{A}$.

Theorem 7.2 (Gradients of linear functions)

For fixed vectors $\mathbf{a},\mathbf{y}$ and a fixed matrix $\mathbf{A}$ of matching shape,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{a}^{\top}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla_{\mathbf{x}}(\mathbf{x}^{\top}\mathbf{a})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{a},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{y}^{\top}\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf{y} .}$$
(7.1)
Quadratic forms
Theorem 7.3 (Gradient of a quadratic form)

For a matrix $\mathbf{A}\in\mathbb{R}^{n\times n}$,

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}(\mathbf{x}^{\top}\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}+\mathbf{A}^{\top})\,\mathbf{x} .}$$
(7.2)

Theorem 7.5 (Two derivatives with respect to a matrix)

For fixed vectors $\mathbf{u}\in\mathbb{R}^m$, $\mathbf{v}\in\mathbb{R}^n$ and a matrix $\mathbf{A}\in\mathbb{R}^{m\times n}$,

Backward through a matrix product
Theorem 7.6 (Backward rule of the matrix product)

Let $f:\mathbb{R}^m\to\mathbb{R}$ be differentiable, $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ with $\mathbf{A}\in\mathbb{R}^{m\times n}$ and $\textcolor{#1b7f4a}{F(\mathbf{A},\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{A}\mathbf{x})}$. Then

$$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(\mathbf{y})\,\mathbf{x}^{\top},}$$
$$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\,\nabla f(\mathbf{y}).}$$
(7.6)

More generally, for $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{B}}$ and $\textcolor{#1b7f4a}{F(\mathbf{A},\mathbf{B})}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{C})}$: $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\nabla_{\mathbf{C}}f)\,\mathbf{B}^{\top}}$ and $\textcolor{#1b7f4a}{\nabla_{\mathbf{B}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\,(\nabla_{\mathbf{C}}f)}$.

    $$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}(\mathbf{u}^{\top}\mathbf{A}\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}\mathbf{v}^{\top},}$$
    $$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}\lVert\mathbf{A}\rVert_F^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\mathbf{A} .}$$
  • Theorem 7.6 (Backward rule of the matrix product) (7.6)
    $$\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(\mathbf{y})\,\mathbf{x}^{\top},}$$
    $$\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\,\nabla f(\mathbf{y}).}$$
  • Differentiating with respect to a matrix (7.4)
    $$\textcolor{#1b7f4a}{f(\mathbf{A}+\mathbf E)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f(\mathbf{A})+\sum_{i=1}^m\sum_{j=1}^n\bigl(\nabla_{\mathbf{A}}f\bigr)_{ij}\,e_{ij}}$$
Key relationships
  • On “The layout convention”: In this chapter, a gradient has the shape of its variable, and a Jacobian matrix has one row per output; from this follow $\textcolor{#1b7f4a}{\mathbf{J}_f}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f^{\top}}$ and the transpose in the chain rule for gradients.
  • On “Linear functions”: The gradient of $\mathbf{a}^{\top}\mathbf{x}$ with respect to $\mathbf{x}$ is $\mathbf{a}$; that of $\mathbf{y}^{\top}\mathbf{A}\mathbf{x}$ is $\mathbf{A}^{\top}\mathbf{y}$.
  • On “Quadratic forms”: The gradient of $\mathbf{x}^{\top}\mathbf{A}\mathbf{x}$ is $(\mathbf{A}+\mathbf{A}^{\top})\mathbf{x}$, so $2\mathbf{A}\mathbf{x}$ for symmetric $\mathbf{A}$, and that of $\lVert\mathbf{x}\rVert^2$ is $2\mathbf{x}$.
  • On “The sum of squares of a residual”: The gradient of $\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2$ is $-2\mathbf{A}^{\top}(\mathbf{y}-\mathbf{A}\mathbf{x})$; it vanishes exactly where the residual is perpendicular to the columns of $\mathbf{A}$.
  • On “Differentiating with respect to a matrix”: The derivative of a number with respect to a matrix has the shape of the matrix; for $\mathbf{u}^{\top}\mathbf{A}\mathbf{v}$ it is the outer product $\mathbf{u}\mathbf{v}^{\top}$, for $\lVert\mathbf{A}\rVert_F^2$ it is $2\mathbf{A}$.
  • On “Backward through a matrix product”: Backward through $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$: the gradient with respect to $\mathbf{A}$ is $\nabla f(\mathbf{y})\,\mathbf{x}^{\top}$, the one with respect to $\mathbf{x}$ is $\mathbf{A}^{\top}\nabla f(\mathbf{y})$.
