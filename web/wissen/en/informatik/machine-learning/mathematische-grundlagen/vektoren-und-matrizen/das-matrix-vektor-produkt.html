What this stage is about:

The same weighted sum is to be computed for all examples of a dataset. For this purpose, this section introduces the product of a matrix and a vector and shows the two ways to read it: row by row or column by column.

Matrix times vector#

The real estate agent from Subsection 2.2 estimates each apartment with the same weighted sum. For four apartments she computes $\mathbf{w}^{\top}\mathbf{x}_i$ four times. If you write the apartments as rows of a matrix, you can express all four calculations in one step: each row of the matrix is multiplied by the same vector.

Definition 7.1 (Matrix–vector product)

For $\mathbf{A}\in\mathbb{R}^{m\times n}$ and $\mathbf{x}\in\mathbb{R}^n$, the matrix–vector product $\mathbf{A}\mathbf{x}$ is the vector in $\mathbb{R}^m$ with the components

$$\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{x})_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{n}a_{ij}\,x_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{a_{i1}x_1+a_{i2}x_2+\dots+a_{in}x_n ,}$$
$$\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,m .}$$
(7.1)

The product exists only if $\mathbf{x}$ has as many components as $\mathbf{A}$ has columns. The result has as many components as $\mathbf{A}$ has rows. From the rules for sums it follows that $\textcolor{#1b7f4a}{\mathbf{A}(\mathbf{u}+\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{u}+\mathbf{A}\mathbf{v}}$ and $\textcolor{#1b7f4a}{\mathbf{A}(c\,\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{A}\mathbf{x}}$.

Worked example

For

$$\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1&2\\0&-1\\3&1\end{pmatrix}\quad\text{and}\quad \mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2\\1\end{pmatrix}}$$
$$\text{we have}$$
$$\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}4\\-1\\7\end{pmatrix}.}$$

Each component is a sum according to (7.1) (Fig. 28). A $3\times2$ matrix times a vector with $2$ components gives a vector with $3$ components.

⁠In short: $\mathbf{A}\mathbf{x}$ is the vector whose component $i$ is the sum $\sum_ja_{ij}x_j$; an $m\times n$ matrix turns a vector in $\mathbb{R}^n$ into a vector in $\mathbb{R}^m$.

The row view: many dot products#

For each component, formula (7.1) says: row $i$ of the matrix, multiplied entry by entry by $\mathbf{x}$ and summed up. This is the dot product of row $i$ with $\mathbf{x}$ (Fig. 30, left).

Theorem 7.2 (Row view)

Component $i$ of $\mathbf{A}\mathbf{x}$ is the dot product of the $i$th row of $\mathbf{A}$ with $\mathbf{x}$. For a data matrix $\mathbf{X}$ with the rows $\mathbf{x}_i^{\top}$ and a weight vector $\mathbf{w}$, this means

$$\textcolor{#1b7f4a}{\mathbf{X}\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}\mathbf{x}_1^{\top}\mathbf{w}\\\vdots\\\mathbf{x}_N^{\top}\mathbf{w}\end{pmatrix}.}$$
(7.2)

So the matrix–vector product applies the weighted sum with the weights $\mathbf{w}$ to all examples at once and returns the vector of all predictions. In the picture of comparison with a pattern: each example is compared with the same pattern $\mathbf{w}$.

Worked example

For the apartment dataset and $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$,

$$\textcolor{#1b7f4a}{\hat{\mathbf{y}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{X}\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}60&2&3\\40&1&1\\90&4&6\\70&3&2\end{pmatrix}\begin{pmatrix}3\\10\\-4\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}188\\126\\286\\232\end{pmatrix},}$$

the real estate agent's four predictions in thousand euros. Each component is the dot product of a row with $\mathbf{w}$ (Fig. 29).

⁠In short: In the row view, $\mathbf{A}\mathbf{x}$ is a list of dot products, one per row; $\mathbf{X}\mathbf{w}$ is the list of predictions for all examples.

BackgroundHow much computational work a matrix–vector product costs

Each of the $m$ components needs $n$ multiplications and $n-1$ additions. In total that is $m(2n-1)$, or roughly $2mn$ basic arithmetic operations. For the four apartments with three features it is $\textcolor{#1b7f4a}{4\cdot5}\textcolor{#15633a}{=}\textcolor{#c2410c}{20}$. For a dataset with one million examples and one hundred features it is about $2\cdot10^8$. A modern processor carries out several billion such operations per second, so a single matrix–vector product of this size is done quickly. Such counts, however, only give the order of magnitude of the computing time, because how fast a computer actually is also depends on how fast it can fetch the numbers from memory.

The column view: a linear combination of the columns#

You can also order the same sum differently. Instead of proceeding row by row, you collect all contributions that belong to $x_1$, then all that belong to $x_2$, and so on. The contributions to $x_j$ are all in column $j$ of the matrix. The product then becomes a linear combination of the columns (Fig. 30, right).

Theorem 7.3 (Column view)

If $\mathbf{a}_1,\dots,\mathbf{a}_n$ are the columns of $\mathbf{A}\in\mathbb{R}^{m\times n}$, then

$$\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{a}_1+x_2\mathbf{a}_2+\dots+x_n\mathbf{a}_n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^nx_j\,\mathbf{a}_j .}$$
(7.3)

The matrix–vector product is the linear combination of the columns of $\mathbf{A}$ with the components of $\mathbf{x}$ as coefficients.

Proof: Column view

Component $i$ of the right-hand side is $\textcolor{#1b7f4a}{\sum_jx_j\,(\mathbf{a}_j)_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_jx_j\,a_{ij}}$, because the $i$th component of the column $\mathbf{a}_j$ is the entry $a_{ij}$. This is exactly component $i$ of $\mathbf{A}\mathbf{x}$ according to (7.1).

Worked example 1

For the product $\mathbf{A}\mathbf{x}$ from Subsection 7.1,

$$\textcolor{#1b7f4a}{\begin{pmatrix}1&2\\0&-1\\3&1\end{pmatrix}\begin{pmatrix}2\\1\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\begin{pmatrix}1\\0\\3\end{pmatrix}+1\begin{pmatrix}2\\-1\\1\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}4\\-1\\7\end{pmatrix}.}$$

Worked example 2

The real estate agent's predictions are $3$ times the column of floor areas plus $10$ times the column of rooms plus $(-4)$ times the column of distances (Fig. 31). As in Subsection 6.1, the columns of $\mathbf{X}$ are called $\mathbf{a}_1$, $\mathbf{a}_2$, $\mathbf{a}_3$. In this form you can see which part of each prediction comes from which feature: the first term contains the contributions of the floor area, the second those of the rooms, the third those of the distance.

⁠In short: In the column view, $\mathbf{A}\mathbf{x}$ is a linear combination of the columns of $\mathbf{A}$; the components of $\mathbf{x}$ say how much of each column is taken.

BackgroundWhy there are two views of the same calculation

Both views compute the same $m\cdot n$ products $a_{ij}x_j$ and add them up. The row view first combines them row by row, the column view first column by column; for finitely many terms the order does not matter, as with the double sum in Subsection 1.1. But each view answers a different question. The row view asks: what comes out in component $i$? The column view asks: which results can the matrix produce at all if you choose $\mathbf{x}$ freely? The second question leads directly to the next concept.

The column space#

If you let $\mathbf{x}$ run through all vectors of $\mathbb{R}^n$, then by the column view $\mathbf{A}\mathbf{x}$ runs through all linear combinations of the columns. In general, these are not all vectors of $\mathbb{R}^m$.

Definition 7.4 (Column space)

The column space of a matrix $\mathbf{A}\in\mathbb{R}^{m\times n}$ is the set of all vectors $\mathbf{A}\mathbf{x}$ with $\mathbf{x}\in\mathbb{R}^n$, that is, the set of all linear combinations of the columns of $\mathbf{A}$.

Worked example 1

The matrix $\bigl(\begin{smallmatrix}1&2\\2&4\end{smallmatrix}\bigr)$ has the columns $(1,\,2)^{\top}$ and $\textcolor{#1b7f4a}{(2,\,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2\,(1,\,2)^{\top}}$. Every linear combination is a multiple of $(1,\,2)^{\top}$. So the column space is only the line through the origin in the direction of $(1,\,2)^{\top}$, even though the results have two components. The vector $(3,\,6)^{\top}$ lies in it; the vector $(1,\,1)^{\top}$ does not.

Worked example 2

The matrix $\textcolor{#1b7f4a}{\mathbf{H}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl(\begin{smallmatrix}1&0\\0&1\\1&1\end{smallmatrix}\Bigr)}$ gives $\textcolor{#1b7f4a}{\mathbf{H}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1,\,x_2,\,x_1+x_2)^{\top}}$. Its column space consists of the vectors of $\mathbb{R}^3$ whose third component is the sum of the first two; this is a plane in space. The vector $\textcolor{#1b7f4a}{(1,\,2,\,3)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{H}\,(1,\,2)^{\top}}$ lies in it, but $(1,\,1,\,1)^{\top}$ does not, because $1+1\ne1$.

For a data matrix this means: the predictions $\mathbf{X}\mathbf{w}$ always lie in the column space of $\mathbf{X}$, no matter which weights you choose. With these features, only very specific lists of predictions can be produced at all.

⁠In short: The column space of a matrix is the set of all vectors $\mathbf{A}\mathbf{x}$, that is, everything that can be formed as a linear combination of its columns.

Exercise 16 ★ Two views of one product

  1. Compute $\mathbf{B}\mathbf{x}$ for $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&0&2\\2&1&0\end{smallmatrix}\bigr)}$ and $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,3,\,-1)^{\top}}$, once in the row view and once in the column view.

  2. Is $\mathbf{B}\,(1,\,2)^{\top}$ defined? And $\mathbf{B}\,(1,\,2,\,3)^{\top}$? Explain your answer using the sizes, and state how many components the result has if it is defined.

  3. Does $(2,\,0,\,2)^{\top}$ lie in the column space of the matrix $\mathbf{H}$ from Subsection 7.4? And $(2,\,1,\,2)^{\top}$?

Solution

(a) Row view: $\textcolor{#1b7f4a}{(1\cdot1+0\cdot3+2\cdot(-1),\ 2\cdot1+1\cdot3+0\cdot(-1))^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1,\,5)^{\top}}$. Column view: $\textcolor{#1b7f4a}{1\,(1,\,2)^{\top}+3\,(0,\,1)^{\top}-1\,(2,\,0)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1+0-2,\ 2+3-0)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1,\,5)^{\top}}$.

(b) $\mathbf{B}$ has three columns. $\mathbf{B}\,(1,\,2)^{\top}$ is not defined, because the vector has only two components. $\mathbf{B}\,(1,\,2,\,3)^{\top}$ is defined and has as many components as $\mathbf{B}$ has rows, namely two: $\textcolor{#1b7f4a}{(1+0+6,\ 2+2+0)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(7,\,4)^{\top}}$.

(c) The column space of $\mathbf{H}$ consists of the vectors whose third component is the sum of the first two. For $(2,\,0,\,2)^{\top}$, $\textcolor{#1b7f4a}{2+0}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$: yes, it is $\mathbf{H}\,(2,\,0)^{\top}$. For $(2,\,1,\,2)^{\top}$, $\textcolor{#1b7f4a}{2+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3\ne2}$: no.

Exercise 17 ★★ The monthly rent

A rent index estimates the monthly rent of an apartment with the weights $\textcolor{#1b7f4a}{\mathbf{w}_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(12,\,30,\,-8)^{\top}}$ in euros per square meter, per room and per kilometer.

  1. Compute the estimated rents of all four apartments as $\mathbf{X}\mathbf{w}_{\mathrm M}$, once in the row view and once in the column view.

  2. How many multiplications and additions did you need? How many would it be for $10\,000$ apartments with $20$ features?

Solution

(a) Row view, for apartment 1: $\textcolor{#1b7f4a}{12\cdot60+30\cdot2-8\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{720+60-24}\textcolor{#15633a}{=}\textcolor{#c2410c}{756}$, and likewise $502$, $1152$ and $914$ euros. Column view:

$$\textcolor{#1b7f4a}{12\begin{pmatrix}60\\40\\90\\70\end{pmatrix}+30\begin{pmatrix}2\\1\\4\\3\end{pmatrix}-8\begin{pmatrix}3\\1\\6\\2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}720\\480\\1080\\840\end{pmatrix}+\begin{pmatrix}60\\30\\120\\90\end{pmatrix}-\begin{pmatrix}24\\8\\48\\16\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}756\\502\\1152\\914\end{pmatrix}.}$$

(b) Each of the four components needs $3$ multiplications and $2$ additions, $\textcolor{#1b7f4a}{12+8}\textcolor{#15633a}{=}\textcolor{#c2410c}{20}$ in total. For $10\,000$ apartments with $20$ features, it is $\textcolor{#1b7f4a}{10\,000\cdot20}\textcolor{#15633a}{=}\textcolor{#c2410c}{200\,000}$ multiplications and $\textcolor{#1b7f4a}{10\,000\cdot19}\textcolor{#15633a}{=}\textcolor{#c2410c}{190\,000}$ additions, $\textcolor{#1b7f4a}{390\,000}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2mn}$ in total, with $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{10\,000}$, $\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{20}$.
