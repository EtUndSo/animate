What this stage is about:

So far the input $\mathbf{x}$ was given and the output $\mathbf{A}\mathbf{x}$ was sought. This section asks the reverse question: which input produces a given output? That is a system of linear equations. The section shows how to solve it and when it has no solution, exactly one solution or infinitely many solutions.

Systems of equations in matrix form#

From school you know problems like this: two numbers $x_1$ and $x_2$ satisfy $\textcolor{#1b7f4a}{2x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ and $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$; what are they? The left-hand sides are the components of a matrix–vector product. So the problem asks: which vector $\mathbf{x}$ is mapped by the matrix $\bigl(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\bigr)$ to $(5,\,3)^{\top}$?

Definition 12.1 (System of linear equations)

For a matrix $\mathbf{A}\in\mathbb{R}^{m\times n}$ and a vector $\mathbf{y}\in\mathbb{R}^m$,

$$\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$$
(12.1)

is called a system of linear equations with $m$ equations and the $n$ unknowns $x_1,\dots,x_n$. The matrix $\mathbf{A}$ is called the coefficient matrix, the vector $\mathbf{y}$ the right-hand side. Every vector $\mathbf{x}\in\mathbb{R}^n$ that satisfies (12.1) is called a solution.

Written out, row $i$ contains the equation $\textcolor{#1b7f4a}{a_{i1}x_1+\dots+a_{in}x_n}\textcolor{#15633a}{=}\textcolor{#c2410c}{y_i}$.

Worked example

The system

$$\textcolor{#1b7f4a}{\begin{pmatrix}2&1\\1&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}5\\3\end{pmatrix}}$$

has the solution $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,1)^{\top}}$: $\textcolor{#1b7f4a}{2\cdot2+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ and $\textcolor{#1b7f4a}{2+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. The coefficient matrix is familiar from Subsection 11.2, with the inverse $\bigl(\begin{smallmatrix}1&-1\\-1&2\end{smallmatrix}\bigr)$. If you multiply the system by this inverse from the left, the solution appears immediately: $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(5-3,\ -5+6)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,1)^{\top}}$.

⁠In short: A system of linear equations $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ asks which input $\mathbf{x}$ produces the output $\mathbf{y}$.

Row picture and column picture#

As with the matrix–vector product, there are two ways to read a system of equations.

Row picture. Each equation on its own describes a set of points. With two unknowns, $\textcolor{#1b7f4a}{2x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ is a line in the plane, and so is $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. A solution must satisfy both equations, that is, lie on both lines: it is their point of intersection (Fig. 38, left). With three unknowns, each equation is a plane in space.

Column picture. By the column view (7.3), $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{a}_1+\dots+x_n\mathbf{a}_n}$. So the equation asks: with which coefficients does the linear combination of the columns give the right-hand side? For the system above: $\textcolor{#1b7f4a}{x_1\,(2,\,1)^{\top}+x_2\,(1,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(5,\,3)^{\top}}$, solved by $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ and $\textcolor{#1b7f4a}{x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. This is exactly the picture on the right in Fig. 30.

The column picture immediately answers when there is a solution at all. The vectors $\mathbf{A}\mathbf{x}$ form the column space (Subsection 7.4).

Theorem 12.2 (Solvability)

The system $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ has a solution if and only if $\mathbf{y}$ lies in the column space of $\mathbf{A}$.

Worked example

The system $\textcolor{#1b7f4a}{\bigl(\begin{smallmatrix}1&2\\2&4\end{smallmatrix}\bigr)\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ is solvable for $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,6)^{\top}}$, for instance with $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1)^{\top}}$, but not for $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1)^{\top}}$: by Subsection 7.4, the column space is only the line in the direction of $(1,\,2)^{\top}$.

⁠In short: In the row picture, a solution is a point common to all equations; in the column picture, it is the choice of coefficients with which the columns give the right-hand side.

Gaussian elimination#

With two unknowns you can find the solution by inspection. With three or more you need a method that always works. The idea is the same as in school: you subtract a multiple of one equation from another so that an unknown disappears. You repeat this until the last equation contains only one unknown.

For this you write down only the numbers: the coefficient matrix and, separated by a vertical bar, the right-hand side. This table is called the augmented matrix $(\mathbf{A}\,|\,\mathbf{y})$.

Definition 12.3 (Gaussian elimination)

Gaussian elimination transforms the augmented matrix with three row operations:

  1. add a multiple of one row to another row;

  2. swap two rows;

  3. multiply a row by a nonzero number.

The goal is row echelon form: in each row, the first nonzero entry is preceded by at least one more zero than in the row above. Then you determine the unknowns from the bottom up (back substitution).

Theorem 12.4 (Row operations do not change the solutions)

A system and the system obtained from it by row operations have the same solutions.

Proof: Row operations

Every solution of the old system also satisfies the new equations, because these are sums and multiples of the old ones. But each of the three operations can also be undone: subtract the multiple again, swap the rows back, divide by the number. So, conversely, every solution of the new system also satisfies the old one.

Worked example

The system

$$\begin{aligned} x_1+2x_2+x_3&=8\\ 2x_1+x_2+x_3&=7\\ x_1+x_2+2x_3&=9 \end{aligned}$$
$$\text{has the augmented matrix}$$
$$\left(\begin{array}{ccc|c}1&2&1&8\\2&1&1&7\\1&1&2&9\end{array}\right).$$

If you subtract the first row twice from the second and once from the third, $x_1$ disappears from both. If you then swap the new second and third rows and subtract the new second row three times from the third, $x_2$ also disappears from the last row:

$$\left(\begin{array}{ccc|c}1&2&1&8\\0&-3&-1&-9\\0&-1&1&1\end{array}\right) \;\longrightarrow\; \left(\begin{array}{ccc|c}1&2&1&8\\0&-1&1&1\\0&-3&-1&-9\end{array}\right) \;\longrightarrow\; \left(\begin{array}{ccc|c}1&2&1&8\\0&-1&1&1\\0&0&-4&-12\end{array}\right).$$

From the bottom up: $\textcolor{#1b7f4a}{-4x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-12}$, so $\textcolor{#1b7f4a}{x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$; then $\textcolor{#1b7f4a}{-x_2+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, so $\textcolor{#1b7f4a}{x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$; then $\textcolor{#1b7f4a}{x_1+4+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$, so $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. The solution is $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,3)^{\top}}$, and substituting it into all three equations confirms it.

⁠In short: Gaussian elimination eliminates the unknowns step by step with row operations, which do not change the solutions, and then substitutes from the bottom up.

BackgroundWhy you do not compute an inverse to solve a system

If $\mathbf{A}$ is invertible, the solution is $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{y}}$. This is useful for reasoning but unfavorable as a way of computing. For a system with $n$ equations and $n$ unknowns, Gaussian elimination needs about $\tfrac23n^3$ basic arithmetic operations; computing the inverse costs about $2n^3$, three times as much, and the product $\mathbf{A}^{-1}\mathbf{y}$ comes on top of that. Moreover, a computer calculates with finitely many digits. The inverse can then only be represented in rounded form, and direct elimination usually gives more accurate results. So the inverse is above all a tool for thinking and deriving, not for computing.

No solution, one solution or infinitely many#

Two lines in the plane intersect in one point, are parallel or coincide (Fig. 38). Exactly two points of intersection are impossible. The same holds for every system of linear equations, no matter how large.

Theorem 12.5 (Number of solutions)

A system of linear equations has either no solution, exactly one solution or infinitely many solutions.

Proof: Number of solutions

It suffices to show: if the system has two different solutions $\mathbf{x}\ne\mathbf{x}'$, it has infinitely many. For every number $t$,

$$\textcolor{#1b7f4a}{\mathbf{A}\bigl(\mathbf{x}+t\,(\mathbf{x}'-\mathbf{x})\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}+t\,(\mathbf{A}\mathbf{x}'-\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}+t\,(\mathbf{y}-\mathbf{y})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y} ,}$$

so every point $\mathbf{x}+t\,(\mathbf{x}'-\mathbf{x})$ of the line through $\mathbf{x}$ and $\mathbf{x}'$ is a solution, and different values of $t$ give different points.

The system $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$ with right-hand side zero is called homogeneous. It always has the solution $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$. If you know a single solution $\mathbf{x}_{\mathrm s}$ of the system $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$, you get all the others by adding the solutions of the homogeneous system: $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ holds exactly when $\textcolor{#1b7f4a}{\mathbf{A}(\mathbf{x}-\mathbf{x}_{\mathrm s})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}-\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

Worked example

The three systems in Fig. 38:

  1. $\textcolor{#1b7f4a}{2x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$: exactly one solution, $(2,\,1)^{\top}$.

  2. $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$: no solution, because the same sum cannot be both $3$ and $1$.

  3. $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{2x_1+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$: the second equation is twice the first. One solution is $\textcolor{#1b7f4a}{\mathbf{x}_{\mathrm s}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,0)^{\top}}$, and the homogeneous system $\textcolor{#1b7f4a}{x_1+x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ is solved by all multiples of $(-1,\,1)^{\top}$. So all solutions are $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,0)^{\top}+t\,(-1,\,1)^{\top}}$ with arbitrary $t$.

⁠In short: A system of linear equations has no solution, exactly one or infinitely many; all solutions are one solution plus the solutions of the homogeneous system.

More equations than unknowns#

With data, the numbers of equations and unknowns are often unbalanced. Suppose you are looking for weights $w_1$ for the floor area and $w_2$ for the rooms such that the weighted sum hits the actual price exactly for three apartments. These are three equations for two unknowns.

Definition 12.6 (Overdetermined, underdetermined)

A system of linear equations with more equations than unknowns ($m>n$) is called overdetermined, one with fewer equations than unknowns ($m<n$) underdetermined.

An overdetermined system usually has no solution: two equations already fix two unknowns, and the third equation would have to hold by coincidence as well. In the column picture: for $n<m$, the column space of $n$ columns in $\mathbb{R}^m$ is only a small part of $\mathbb{R}^m$, and the right-hand side almost never lies in it. An underdetermined system, on the other hand, has infinitely many solutions if it is solvable at all: in row echelon form at least one unknown remains without a pivot of its own, and it can be chosen freely.

Worked example

For apartments 1 to 3 with the prices $200$, $130$ and $290$ thousand euros, the system reads

$$\textcolor{#1b7f4a}{60\,w_1+2\,w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{200,}$$
$$\textcolor{#1b7f4a}{40\,w_1+w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{130,}$$
$$\textcolor{#1b7f4a}{90\,w_1+4\,w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{290 .}$$

The first two equations give $\textcolor{#1b7f4a}{w_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ and $\textcolor{#1b7f4a}{w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: if you subtract the second twice from the first, $\textcolor{#1b7f4a}{-20\,w_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{-60}$ remains. Substituted into the third, however, this gives $\textcolor{#1b7f4a}{270+40}\textcolor{#15633a}{=}\textcolor{#c2410c}{310\ne290}$. The system has no solution. No pair of weights hits all three prices exactly. What to look for instead in such a case is a question of its own.

⁠In short: An overdetermined system has more equations than unknowns and is usually unsolvable; an underdetermined one has fewer and, if it is solvable, infinitely many solutions.

Exercise 28 ★★ Gaussian elimination

Solve with Gaussian elimination and check your result:

$$\textcolor{#1b7f4a}{x_1+x_2+x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{6,}$$
$$\textcolor{#1b7f4a}{2x_1+3x_2+x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{11,}$$
$$\textcolor{#1b7f4a}{x_1-x_2+2x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{5 .}$$
Solution

The augmented matrix is $\Bigl(\begin{smallmatrix}1&1&1&|&6\\2&3&1&|&11\\1&-1&2&|&5\end{smallmatrix}\Bigr)$. Subtracting the first row twice from the second and once from the third gives the rows $(0,\,1,\,-1\,|\,-1)$ and $(0,\,-2,\,1\,|\,-1)$. If you then add the new second row twice to the third, the third becomes $(0,\,0,\,-1\,|\,-3)$. The row echelon form reads

$$\textcolor{#1b7f4a}{x_1+x_2+x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{6,}$$
$$\textcolor{#1b7f4a}{x_2-x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-1,}$$
$$\textcolor{#1b7f4a}{-x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3 .}$$

From the bottom up: $\textcolor{#1b7f4a}{x_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-1+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{6-2-3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. Check: $\textcolor{#1b7f4a}{1+2+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$, $\textcolor{#1b7f4a}{2+6+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{11}$, $\textcolor{#1b7f4a}{1-2+6}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. The solution is $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,3)^{\top}}$.

Exercise 29 ★★ How many solutions?

For each system, determine the solution set and draw the row picture:

  1. $\textcolor{#1b7f4a}{x_1+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{2x_1+4x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$;

  2. $\textcolor{#1b7f4a}{x_1+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{2x_1+4x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$;

  3. $\textcolor{#1b7f4a}{x_1+2x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{x_1-x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Solution

(a) The second equation is twice the first; both describe the same line. Infinitely many solutions: with $\textcolor{#1b7f4a}{x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{t}$, we get $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3-2t}$, so $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,0)^{\top}+t\,(-2,\,1)^{\top}}$.

(b) Doubling the first equation gives $\textcolor{#1b7f4a}{2x_1+4x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$, which contradicts $\textcolor{#1b7f4a}{2x_1+4x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. The lines are parallel; there is no solution.

(c) The second equation gives $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_2}$; substituted into the first, $\textcolor{#1b7f4a}{3x_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Exactly one solution: $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1)^{\top}}$, the point of intersection of two nonparallel lines.

Exercise 30 ★★ Weights that fit

Add apartment 4 with the price $240$ thousand euros to the overdetermined system from Subsection 12.5.

  1. Which of the four apartments are hit exactly by $\textcolor{#1b7f4a}{w_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$?

  2. Write the system with four equations as $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$. What are the sizes of $\mathbf{A}$, $\mathbf{w}$ and $\mathbf{y}$? What does “no solution” mean in the column picture?

Solution

(a) With $\textcolor{#1b7f4a}{w_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{w_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: apartment 1: $\textcolor{#1b7f4a}{180+20}\textcolor{#15633a}{=}\textcolor{#c2410c}{200}$ (hit), apartment 2: $\textcolor{#1b7f4a}{120+10}\textcolor{#15633a}{=}\textcolor{#c2410c}{130}$ (hit), apartment 3: $\textcolor{#1b7f4a}{270+40}\textcolor{#15633a}{=}\textcolor{#c2410c}{310}$ instead of $290$ (not hit), apartment 4: $\textcolor{#1b7f4a}{210+30}\textcolor{#15633a}{=}\textcolor{#c2410c}{240}$ (hit). Three of the four prices are right, but not all of them.

(b) $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Biggl(\begin{smallmatrix}60&2\\40&1\\90&4\\70&3\end{smallmatrix}\Biggr)\in\mathbb{R}^{4\times2}}$, $\mathbf{w}\in\mathbb{R}^2$, $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(200,\,130,\,290,\,240)^{\top}\in\mathbb{R}^4}$. The column space of $\mathbf{A}$ consists of all combinations $w_1\mathbf{a}_1+w_2\mathbf{a}_2$ of the floor area column and the rooms column; it is a plane through the origin in $\mathbb{R}^4$. “No solution” means: the price vector $\mathbf{y}$ does not lie in this plane. No choice of the two weights produces exactly these four prices.

  • On “Systems of equations in matrix form”: A system of linear equations $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}}$ asks which input $\mathbf{x}$ produces the output $\mathbf{y}$.
  • On “Row picture and column picture”: In the row picture, a solution is a point common to all equations; in the column picture, it is the choice of coefficients with which the columns give the right-hand side.
  • On “Gaussian elimination”: Gaussian elimination eliminates the unknowns step by step with row operations, which do not change the solutions, and then substitutes from the bottom up.
  • On “No solution, one solution or infinitely many”: A system of linear equations has no solution, exactly one or infinitely many; all solutions are one solution plus the solutions of the homogeneous system.
  • On “More equations than unknowns”: An overdetermined system has more equations than unknowns and is usually unsolvable; an underdetermined one has fewer and, if it is solvable, infinitely many solutions.
