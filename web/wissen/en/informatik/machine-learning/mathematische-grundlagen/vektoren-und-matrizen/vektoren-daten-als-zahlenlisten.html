What this stage is about:

A computer can only handle numbers. This section clarifies how to describe a thing from the real world by a list of numbers and which calculations with such lists are allowed.

What you need for thisthe summation sign and indices

This chapter constantly adds up many numbers. So that you do not have to write out “$a_1+a_2+\dots$” every time, there is a shorthand.

Indices. If you have several numbers of the same kind, you number them consecutively: $a_1,a_2,\dots,a_n$. The subscript number is called an index. It only says which number in the sequence is meant and has nothing to do with the value of the number.

The summation sign. For the sum of $a_1$ through $a_n$ you write

$$\textcolor{#1b7f4a}{\sum_{i=1}^{n} a_i }\textcolor{#15633a}{=}\textcolor{#c2410c}{ a_1+a_2+\dots+a_n ,}$$
(1.1)

read “sum of $a_i$ for $i$ from $1$ to $n$”. The large Greek sigma is called the summation sign. The letter $i$ below it is the summation index: it takes the values $1,2,\dots,n$ one after another, and for each value one term is added. The summation index is a placeholder. Whether you call it $i$, $j$ or $k$ does not change the sum: $\textcolor{#1b7f4a}{\sum_{i=1}^n a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^n a_j}$.

Two rules of calculation. A sum with a summation sign is just an abbreviated way of writing an ordinary sum of finitely many numbers. Therefore the familiar rules apply to it: you may factor out a common factor (distributive law) and rearrange and group the terms in any way (commutative and associative laws). Written with the summation sign, this means: a common factor may be moved in front of the sum, and a sum of sums may be split up:

$$\textcolor{#1b7f4a}{\sum_{i=1}^n c\,a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\sum_{i=1}^n a_i ,}$$
$$\textcolor{#1b7f4a}{\sum_{i=1}^n (a_i+b_i)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=1}^n a_i+\sum_{i=1}^n b_i .}$$
(1.2)

Double sums. Numbers arranged in a table get two indices: $a_{ij}$ is the number in row $i$ and column $j$. The sum of all entries of a table with $m$ rows and $n$ columns is written as a double sum

$$\sum_{i=1}^{m}\sum_{j=1}^{n}a_{ij} .$$

You read it from the inside out: for each row $i$, the inner sum adds the numbers of this row, and the outer sum adds the row sums. Because the order does not matter for finitely many terms, you may swap the two summation signs and add column by column first.

Worked example 1

For $\textcolor{#1b7f4a}{a_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{a_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, $\textcolor{#1b7f4a}{a_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, you first write out each sum, then insert the numbers and add (Fig. 1). This gives $\textcolor{#1b7f4a}{\sum_{i=1}^3 a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ and $\textcolor{#1b7f4a}{\sum_{i=1}^3 a_i^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{30}$. In the third sum, the summation index itself is the term: $\textcolor{#1b7f4a}{\sum_{j=1}^{3}j}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$.

Worked example 2

The table with the rows $(1,\,2)$ and $(3,\,4)$ has the entries $\textcolor{#1b7f4a}{a_{11}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{a_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{a_{21}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{a_{22}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$. Added row by row, the double sum gives $\textcolor{#1b7f4a}{(1+2)+(3+4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$; added column by column, $\textcolor{#1b7f4a}{(1+3)+(2+4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$ (Fig. 2).

⁠In short: $\sum_{i=1}^n a_i$ is the sum of $a_1$ through $a_n$; the summation index $i$ is only a placeholder.

Examples and features#

If you want to learn from data, you first have a collection of things of the same kind in front of you: apartments, patients, letters, measurements on a machine. Each thing is described by the same measured quantities. Apartments, for instance, by their floor area, the number of rooms and the distance to the city center. If you write this down for several apartments, you get a table (Table 1). It accompanies the entire chapter.

Table 1: The apartment dataset of this chapter: four apartments, each described by three features. The numbers are made up.

Apartment 47032

Each row of the table belongs to one thing, each column to one measured quantity. There are fixed words for both.

Definition 1.1 (Feature, example, dataset)

A feature is a property that can be stated as a real number.

An example is a single thing described by the values of $d$ features.

A dataset is a collection of $N$ examples, all described by the same $d$ features.

Throughout the series, $N$ is the number of examples and $d$ the number of features. The examples are numbered $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,N}$, the features $\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d}$.

Two notes on the words. In databases, a single row of a table is often called a “record”; here the dataset is the whole collection, not a single row. And in this chapter the word “example” always means a thing from a dataset; calculations carried out in full are therefore called “worked examples”.

Worked example

The apartment dataset has $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ examples and $\textcolor{#1b7f4a}{d}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ features. Feature 2 is the number of rooms. For apartment 3 it has the value $4$.

Not every property is a number by itself. The district of an apartment is a name. Such properties must first be translated into numbers before you can calculate with them. In this chapter all features are already numbers.

⁠In short: A dataset consists of $N$ examples, and each example is described by the same $d$ features.

BackgroundThe same things under other names

Other texts call an example a sample, an instance or a data point, and a feature an attribute. In statistics, observation is also common for an example. The meaning is always the same: a row of the table.

Vectors#

To the computer, an apartment is nothing but its three numbers. So that you can calculate with these three numbers as with a single object, you combine them into a list. The order is fixed: first the floor area, then the rooms, then the distance.

Such a list can also be drawn if it contains only two numbers. If you take only the number of rooms $3$ and the distance $2$ of apartment 4, this is the point with the coordinates $(3,\,2)$ in a plane whose horizontal axis counts the rooms and whose vertical axis counts the kilometers. You can also picture the same list as an arrow leading from the origin to this point (Fig. 3). Both pictures describe the same two numbers.

Definition 1.2 (Vector)

A vector $\mathbf{x}$ with $d$ components is an ordered list of $d$ real numbers $x_1,\dots,x_d$, written one below the other:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_1\\\vdots\\x_d\end{pmatrix}.}$$

The number $x_j$ is called the $j$th component of $\mathbf{x}$. The set of all vectors with $d$ components is called $\mathbb{R}^d$. Two vectors are equal if they have the same number of components and all components in the same position agree.

Vectors are written in bold lowercase letters, their components in regular type. A single real number, as opposed to a vector, is called a scalar.

Column and row. In this series a vector is always a column. In running text, a column takes up a lot of space. So you write the numbers side by side and put a superscript $\top$ after them: $(x_1,\dots,x_d)^{\top}$ means the same numbers as a column. The symbol stands for transposed. It turns a row into a column and a column into a row. Conversely, $\textcolor{#1b7f4a}{\mathbf{x}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1,\,\dots,\,x_d)}$ is the vector $\mathbf{x}$ written as a row. The components are separated by commas; since decimal numbers here are written with a point, there is no risk of confusion: $(0.2,\ 0.25,\ 0.3)^{\top}$ has three components.

The examples of a dataset. Example number $i$ is the vector $\mathbf{x}_i\in\mathbb{R}^d$. The vector of an example is also called its feature vector. Its components get two indices: $x_{ij}$ is the value of feature $j$ for example $i$. So a bold letter with one index is a whole vector from a list of vectors, and a regular letter with two indices is a single number.

Worked example

Apartment 1 is the vector $\textcolor{#1b7f4a}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}\in\mathbb{R}^3}$. Its second component is $\textcolor{#1b7f4a}{x_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. The vector $(2,\,60,\,3)^{\top}$ contains the same numbers but is a different vector: the first position now holds the number $2$, and you would read it as the floor area.

⁠In short: A vector is an ordered list of numbers that can be drawn as a point or as an arrow; an example with $d$ features is a vector in $\mathbb{R}^d$.

BackgroundWhat a vector really is

A list of numbers is the vector you calculate with. Mathematically, the concept is broader: a vector is anything that can be added and multiplied by a number without leaving the kind of object. Arrows in the plane are vectors, but so are audio recordings. An audio recording captures, at equal and very short intervals, how far the air pressure currently deviates from its resting value. With $n$ such values $x[0],\dots,x[n-1]$, it is a vector in $\mathbb{R}^n$. Adding two recordings means mixing them, and multiplying a recording by a number means making it louder or quieter; both give a recording of the same length again.

An image is a vector, too. A grayscale image with $28\times28$ pixels consists of $784$ brightness values. If you read them row by row, one after another, the image is a point in $\mathbb{R}^{784}$. This picture can no longer be drawn, but you calculate with it exactly as with two or three components.

Addition and multiples#

You want to calculate with lists of measured values: add up the electricity consumption of two apartments, convert kilowatt-hours to megawatt-hours or see by how much two apartments differ. All of this happens component by component.

In the picture of arrows, adding means attaching the second arrow to the tip of the first. The arrow from the origin to the new tip is the sum (Fig. 4, left). Multiplying by a number means stretching or shrinking the arrow; a negative factor also reverses its direction (Fig. 4, right).

Definition 1.3 (Addition and multiple)

For two vectors $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ and a scalar $c$, the sum $\mathbf{u}+\mathbf{v}$ and the multiple $c\,\mathbf{u}$ are the vectors with the components

$$\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_j+v_j ,}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{u})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,u_j ,}$$
$$\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d.}$$
(1.3)

The zero vector $\mathbf{0}$ has only zeros as components. You write $-\mathbf{u}$ for $(-1)\,\mathbf{u}$ and $\mathbf{u}-\mathbf{v}$ for $\mathbf{u}+(-\mathbf{v})$.

You can only add vectors with the same number of components. Moreover, it only makes sense if the same quantity is in the same position: kilowatt-hours to kilowatt-hours, not square meters to rooms.

Because each component on its own is an ordinary calculation with numbers, the familiar rules hold: $\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{v}+\mathbf{u}}$, $\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})+\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}+(\mathbf{v}+\mathbf{q})}$, $\textcolor{#1b7f4a}{c\,(\mathbf{u}+\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{u}+c\,\mathbf{v}}$, $\textcolor{#1b7f4a}{(c+c')\,\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{u}+c'\,\mathbf{u}}$ and $\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{0}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}}$ for all vectors $\mathbf{u},\mathbf{v},\mathbf{q}\in\mathbb{R}^d$ and scalars $c,c'$.

The difference $\mathbf{u}-\mathbf{v}$ has a picture of its own. It is the arrow leading from the tip of $\mathbf{v}$ to the tip of $\mathbf{u}$, because $\textcolor{#1b7f4a}{\mathbf{v}+(\mathbf{u}-\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}}$. For two examples, it states by how much they differ in each feature.

Worked example

From January to March, apartment 1 consumed $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(200,\,250,\,300)^{\top}}$ kilowatt-hours of electricity, and apartment 2 in the same building consumed $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(150,\,100,\,120)^{\top}}$. Together they consume

$$\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(350,\,350,\,420)^{\top}\ \text{kWh}.}$$

The consumption of apartment 1 in megawatt-hours is given by the multiple $\textcolor{#1b7f4a}{0.001\,\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0.2,\ 0.25,\ 0.3)^{\top}}$. The difference $\textcolor{#1b7f4a}{\mathbf{u}-\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50,\,150,\,180)^{\top}}$ tells you how many more kilowatt-hours apartment 1 consumes than apartment 2 in each month. In the apartment dataset, $\textcolor{#1b7f4a}{\mathbf{x}_3-\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(30,\,2,\,3)^{\top}}$: apartment 3 is $30\,\mathrm m^2$ larger, has two more rooms and is $3$ km farther out than apartment 1.

⁠In short: You add vectors and multiply them by a number by doing it component by component.

Linear combinations#

Almost every calculation in this chapter takes several vectors, multiplies each one by its own number and adds the results. An average is such a calculation, and so is a mixture.

In the picture of arrows: you walk $c_1$ times the distance $\mathbf{v}_1$, then $c_2$ times the distance $\mathbf{v}_2$, and so on. Where you arrive is the result.

Definition 1.4 (Linear combination)

For vectors $\mathbf{v}_1,\dots,\mathbf{v}_k\in\mathbb{R}^d$ and scalars $c_1,\dots,c_k$,

$$\textcolor{#1b7f4a}{c_1\mathbf{v}_1+c_2\mathbf{v}_2+\dots+c_k\mathbf{v}_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{l=1}^{k}c_l\,\mathbf{v}_l}$$
(1.4)

is called a linear combination of the vectors $\mathbf{v}_1,\dots,\mathbf{v}_k$. The numbers $c_l$ are called its coefficients.

A word of caution when reading: $\mathbf{v}_l$ is bold, so it is the $l$th vector of the list, not the $l$th component of a vector.

Worked example 1

$\textcolor{#1b7f4a}{(1,\,2)^{\top}+3\,(0,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}+(0,\,3)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,5)^{\top}}$.

Worked example 2the midpoint

The linear combination $\tfrac12\mathbf{x}_1+\tfrac12\mathbf{x}_2$ of apartments 1 and 2 is

$$\textcolor{#1b7f4a}{\tfrac12\,(60,\,2,\,3)^{\top}+\tfrac12\,(40,\,1,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50,\ 1.5,\ 2)^{\top}.}$$

This is an imaginary apartment that lies exactly halfway between the two in every feature. The point lies in the middle of the connecting segment.

One linear combination is needed especially often in this chapter. If you take all $N$ examples with the coefficient $1/N$, you get the mean of the examples

$$\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1N\sum_{i=1}^{N}\mathbf{x}_i .}$$
(1.5)

It is an imagined example that has the average of all examples in every feature: its $j$-th component is the mean of the $j$-th features.

Worked example 3the mean of the examples

For the apartment dataset, $\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(65,\ 2.5,\ 3)^{\top}}$ (Fig. 5), the “average apartment”: on average $65\,\mathrm m^2$, $2.5$ rooms and $3$ km to the center.

⁠In short: A linear combination multiplies each vector by its own number and adds everything up.

BackgroundWhere the mixtures of two points lie

If, for two vectors $\mathbf{x}_1,\mathbf{x}_2$, you choose the coefficients so that they add up to $1$, that is, $(1-t)\,\mathbf{x}_1+t\,\mathbf{x}_2$ with a number $t$, then the result always lies on the line through the two points. This is because you can rewrite it as

$$\textcolor{#1b7f4a}{(1-t)\,\mathbf{x}_1+t\,\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{x}_1+t\,(\mathbf{x}_2-\mathbf{x}_1) .}$$

That is: starting from the point $\mathbf{x}_1$, go $t$ times the connecting arrow $\mathbf{x}_2-\mathbf{x}_1$. For $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ you are at $\mathbf{x}_1$, for $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ at $\mathbf{x}_2$, for $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}$ in the middle. All $t$ between $0$ and $1$ give the points of the connecting segment. You need such mixtures whenever you want to form intermediate values between two data points.

The unit vectors#

The simplest vectors have a single component $1$ and zeros everywhere else. For an example this would mean that only one feature is “switched on”, with the value $1$. In the plane they are the two arrows of length $1$ along the axes.

Definition 1.5 (Unit vector)

The $j$th unit vector $\mathbf{e}_j\in\mathbb{R}^d$ has a $1$ in position $j$ and a $0$ in every other position.

In $\mathbb{R}^2$, $\textcolor{#1b7f4a}{\mathbf{e}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{e}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,1)^{\top}}$. Every vector is a linear combination of the unit vectors, and the coefficients are exactly its components:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{e}_1+x_2\mathbf{e}_2+\dots+x_d\mathbf{e}_d}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^d x_j\,\mathbf{e}_j .}$$
(1.6)

You can see this by computing the right-hand side component by component: in position $j$ only the term $x_j\mathbf{e}_j$ contributes, namely $x_j\cdot1$. No other coefficients are possible, because they would give a different number in some position.

Worked example

$\textcolor{#1b7f4a}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{60\,\mathbf{e}_1+2\,\mathbf{e}_2+3\,\mathbf{e}_3}$, that is, $60$ times “one square meter” plus $2$ times “one room” plus $3$ times “one kilometer”.

⁠In short: The unit vector $\mathbf{e}_j$ has a one in position $j$ and zeros elsewhere; every vector is the sum $\sum_jx_j\mathbf{e}_j$.

Exercise 1 ★ Reading and writing sums

  1. Compute $\sum_{i=1}^{5}(2i-1)$ and $\sum_{i=1}^{2}\sum_{j=1}^{3}i\,j$.

  2. Write $3+6+9+12$ with a summation sign.

  3. Let $a_i$ be the floor area of apartment $i$ from Table 1. What do $\sum_{i=1}^4a_i$ and $\frac14\sum_{i=1}^4a_i$ mean, and which numbers come out?

Solution

(a) The summation index $i$ takes the values $1$ to $5$, and the terms are the odd numbers $1,3,5,7,9$:

$$\textcolor{#1b7f4a}{\sum_{i=1}^{5}(2i-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+3+5+7+9}\textcolor{#15633a}{=}\textcolor{#c2410c}{25 .}$$

In the double sum, for each fixed $i$ the inner sum is $\textcolor{#1b7f4a}{\sum_{j=1}^3i\,j}\textcolor{#15633a}{=}\textcolor{#c2410c}{i\,(1+2+3)}\textcolor{#15633a}{=}\textcolor{#c2410c}{6i}$; the factor $i$ does not depend on $j$ and, by (1.2), may be moved in front of the inner sum. Then $\textcolor{#1b7f4a}{\sum_{i=1}^2 6i}\textcolor{#15633a}{=}\textcolor{#c2410c}{6+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{18}$.

(b) The terms are the multiples of $3$: $\textcolor{#1b7f4a}{3+6+9+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=1}^43i}$. Equally correct is $3\sum_{i=1}^4i$, by the rule for common factors.

(c) $\textcolor{#1b7f4a}{\sum_{i=1}^4a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{60+40+90+70}\textcolor{#15633a}{=}\textcolor{#c2410c}{260}$ is the total floor area of all four apartments in $\mathrm m^2$, and $\textcolor{#1b7f4a}{\frac14\sum_{i=1}^4a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{65}$ is the average floor area of an apartment.

Exercise 2 ★ Calculating with vectors

  1. Compute $2\mathbf{u}-3\mathbf{v}$ for $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,0)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,1,\,2)^{\top}}$.

  2. Write $(4,\,-1,\,2)^{\top}$ as a linear combination of the unit vectors of $\mathbb{R}^3$.

  3. Find numbers $c_1,c_2$ with $\textcolor{#1b7f4a}{c_1(1,\,2)^{\top}+c_2(2,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,3)^{\top}}$. Draw the solution with arrows.

  4. Compute $\mathbf{x}_3-\mathbf{x}_2$ for the apartment dataset and describe in words what the vector says.

Solution

(a) Component by component: $\textcolor{#1b7f4a}{2\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-2,\,0)^{\top}}$ and $\textcolor{#1b7f4a}{3\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,3,\,6)^{\top}}$, so $\textcolor{#1b7f4a}{2\mathbf{u}-3\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-5,\,-6)^{\top}}$.

(b) By (1.6), the coefficients are the components: $\textcolor{#1b7f4a}{(4,\,-1,\,2)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\,\mathbf{e}_1-\mathbf{e}_2+2\,\mathbf{e}_3}$.

(c) Component by component, the condition reads $\textcolor{#1b7f4a}{c_1+2c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ and $\textcolor{#1b7f4a}{2c_1+c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Subtracting the first equation twice from the second leaves $\textcolor{#1b7f4a}{-3c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3}$, so $\textcolor{#1b7f4a}{c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ and then $\textcolor{#1b7f4a}{c_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. Check: $\textcolor{#1b7f4a}{(1,\,2)^{\top}+(2,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,3)^{\top}}$. In the drawing, you attach the arrow $(2,\,1)^{\top}$ to the tip of $(1,\,2)^{\top}$ and land at $(3,\,3)^{\top}$.

(d) $\textcolor{#1b7f4a}{\mathbf{x}_3-\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(90-40,\ 4-1,\ 6-1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50,\,3,\,5)^{\top}}$: apartment 3 is $50\,\mathrm m^2$ larger than apartment 2, has three more rooms and is $5$ km farther from the center. The vector is the arrow from the point $\mathbf{x}_2$ to the point $\mathbf{x}_3$.

Exercise 3 ★ A dataset of your own

Choose four things from your everyday life, for example foods, bicycles or songs, and three properties that you can state as a number for each thing. Measure or look up the values.

  1. Set up the table. What are $N$ and $d$? Write the second example as a vector $\mathbf{x}_2$.

  2. Which property that would also interest you is not a number? How could you translate it into numbers?

  3. Compute the mean of the examples $\bar{\mathbf{x}}$. Is there a thing that looks exactly like it?

Solution

One possible solution: four apples with the features mass in g, diameter in cm and price in cents.

(a) Suppose the table has the rows $(180,\ 7.5,\ 45)$, $(150,\ 7.0,\ 40)$, $(210,\ 8.0,\ 55)$ and $(165,\ 7.2,\ 40)$. Then $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ and $\textcolor{#1b7f4a}{d}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, and $\textcolor{#1b7f4a}{\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(150,\ 7.0,\ 40)^{\top}}$. All that matters is that each thing is described by the same three features in the same order.

(b) The variety is a name, not a number. You can translate it by introducing a separate feature for each variety that is $1$ if the apple belongs to this variety and $0$ otherwise. Simply numbering the varieties, on the other hand, is usually not a good idea: the numbers suggest an order and distances that do not exist between varieties.

(c) The mean of the examples is the average taken component by component, here $\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(176.25,\ 7.425,\ 45)^{\top}}$. There is no apple with exactly these values in the table. The mean is an imagined example, not a measured one, and for a property such as the number of rooms it can even be a value that no real thing can take, for instance $2.5$ rooms.

Examples and features
Definition 1.1 (Feature, example, dataset)

A feature is a property that can be stated as a real number.

An example is a single thing described by the values of $d$ features.

A dataset is a collection of $N$ examples, all described by the same $d$ features.

Vectors
Definition 1.2 (Vector)

A vector $\mathbf{x}$ with $d$ components is an ordered list of $d$ real numbers $x_1,\dots,x_d$, written one below the other:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_1\\\vdots\\x_d\end{pmatrix}.}$$

The number $x_j$ is called the $j$th component of $\mathbf{x}$. The set of all vectors with $d$ components is called $\mathbb{R}^d$. Two vectors are equal if they have the same number of components and all components in the same position agree.

Addition and multiples
Definition 1.3 (Addition and multiple)

For two vectors $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ and a scalar $c$, the sum $\mathbf{u}+\mathbf{v}$ and the multiple $c\,\mathbf{u}$ are the vectors with the components

$$\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_j+v_j ,}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{u})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,u_j ,}$$
$$\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d.}$$
(1.3)

The zero vector $\mathbf{0}$ has only zeros as components. You write $-\mathbf{u}$ for $(-1)\,\mathbf{u}$ and $\mathbf{u}-\mathbf{v}$ for $\mathbf{u}+(-\mathbf{v})$.

Linear combinations
Definition 1.4 (Linear combination)

For vectors $\mathbf{v}_1,\dots,\mathbf{v}_k\in\mathbb{R}^d$ and scalars $c_1,\dots,c_k$,

$$\textcolor{#1b7f4a}{c_1\mathbf{v}_1+c_2\mathbf{v}_2+\dots+c_k\mathbf{v}_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{l=1}^{k}c_l\,\mathbf{v}_l}$$
(1.4)

is called a linear combination of the vectors $\mathbf{v}_1,\dots,\mathbf{v}_k$. The numbers $c_l$ are called its coefficients.

$$\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1N\sum_{i=1}^{N}\mathbf{x}_i .}$$
(1.5)
The unit vectors
Definition 1.5 (Unit vector)

The $j$th unit vector $\mathbf{e}_j\in\mathbb{R}^d$ has a $1$ in position $j$ and a $0$ in every other position.

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{e}_1+x_2\mathbf{e}_2+\dots+x_d\mathbf{e}_d}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^d x_j\,\mathbf{e}_j .}$$
(1.6)

Key relationships
  • On “Examples and features”: A dataset consists of $N$ examples, and each example is described by the same $d$ features.
  • On “Vectors”: A vector is an ordered list of numbers that can be drawn as a point or as an arrow; an example with $d$ features is a vector in $\mathbb{R}^d$.
  • On “Addition and multiples”: You add vectors and multiply them by a number by doing it component by component.
  • On “Linear combinations”: A linear combination multiplies each vector by its own number and adds everything up.
  • On “The unit vectors”: The unit vector $\mathbf{e}_j$ has a one in position $j$ and zeros elsewhere; every vector is the sum $\sum_jx_j\mathbf{e}_j$.
