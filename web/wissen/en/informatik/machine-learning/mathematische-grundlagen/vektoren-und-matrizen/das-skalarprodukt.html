The dot product

What this stage is about:

Two vectors with the same number of components give a single number if you multiply their components pairwise and add the products. This calculation is the most common one in all of machine learning: it turns measured values into an estimate and compares data with a pattern.

The dot product of two vectors

A shopping bill works like this: quantity times price for each item, then add everything up. The same calculation with any two vectors is called the dot product.

You can picture it as a row meeting a column. The first vector is written as a row, the second as a column next to it. Then you multiply the first element of the row by the first element of the column, the second by the second, and so on, and add:

$$\textcolor{#1b7f4a}{\begin{pmatrix}1&2&3\end{pmatrix}\begin{pmatrix}4\\-1\\2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot4+2\cdot(-1)+3\cdot2}\textcolor{#15633a}{=}\textcolor{#c2410c}{8 .}$$

Definition 2.1 (Dot product)

The dot product of two vectors $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ is the number

$$\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}u_j\,v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_1v_1+u_2v_2+\dots+u_dv_d .}$$
(2.1)

The notation $\mathbf{u}^{\top}\mathbf{v}$ says exactly what happens: $\mathbf{u}^{\top}$ is $\mathbf{u}$ as a row, and the row meets the column $\mathbf{v}$. The result is a scalar, which is why the dot product is also called the scalar product.

Theorem 2.2 (Rules for the dot product)

For all $\mathbf{u},\mathbf{v},\mathbf{q}\in\mathbb{R}^d$ and every scalar $c$:

  1. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{v}^{\top}\mathbf{u}}$ (symmetric);

  2. $\textcolor{#1b7f4a}{(c\,\mathbf{u})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,(\mathbf{u}^{\top}\mathbf{v})}$ and $\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{q})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}^{\top}\mathbf{v}+\mathbf{q}^{\top}\mathbf{v}}$ (linear, and likewise in the second vector);

  3. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ju_j^2\ge0}$, and $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ only for $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

Proof: Rules for the dot product

(i) follows from $\textcolor{#1b7f4a}{u_jv_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_ju_j}$ for each component. (ii) is the sum rule (1.2): $\textcolor{#1b7f4a}{\sum_j(c\,u_j)v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\sum_ju_jv_j}$ and $\textcolor{#1b7f4a}{\sum_j(u_j+q_j)v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ju_jv_j+\sum_jq_jv_j}$. (iii) Each term $u_j^2$ is nonnegative. The sum is zero only if every term is zero, that is, if every $\textcolor{#1b7f4a}{u_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Worked example

For $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,3)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4,\,-1,\,2)^{\top}}$, we get $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ and $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{14}$ (Fig. 6). In the reverse order the result is the same number, $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\cdot1+(-1)\cdot2+2\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$, as symmetry requires.

⁠In short: The dot product multiplies two vectors component by component and adds the products; it is a number.

BackgroundOther notations for the same thing

Many books write $\mathbf{u}\cdot\mathbf{v}$ or $\langle\mathbf{u},\mathbf{v}\rangle$ instead of $\mathbf{u}^{\top}\mathbf{v}$, and the same number is also called the inner product or the scalar product. The meaning is always the same. This series writes $\mathbf{u}^{\top}\mathbf{v}$ because the notation shows that a row meets a column. This pays off as soon as tables of numbers come into play.

Weights and weighted sums

A real estate agent estimates the price of an apartment in her head roughly like this: each square meter is worth about $3$ thousand euros, each room adds another $10$ thousand euros, and each kilometer of distance from the center takes off $4$ thousand euros. So she takes each feature with its own factor and adds everything up.

The number with which a feature enters such a calculation is called its weight. A large positive weight means that each unit of this feature raises the result strongly. A negative weight means that the feature lowers the result.

Definition 2.3 (Weighted sum)

For a vector of weights $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(w_1,\dots,w_d)^{\top}}$ and an example $\mathbf{x}\in\mathbb{R}^d$, the weighted sum is

$$\textcolor{#1b7f4a}{\hat y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}w_j\,x_j .}$$
(2.2)

A fixed rule that computes a number from the features of an example is called a model. The number that the model returns for an example is called its prediction. The hat over the $y$ in $\hat y$ indicates that this is a computed estimate and not a measured value. In this chapter the weights are always given; where good weights come from is a question of its own.

Worked example

The real estate agent uses the weights $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ in thousand euros per square meter, per room and per kilometer. For apartment 1, $\textcolor{#1b7f4a}{\hat y_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{188}$ (Fig. 7), that is, $188$ thousand euros.

In the same way, the other apartments give $\textcolor{#1b7f4a}{\hat y_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{126}$, $\textcolor{#1b7f4a}{\hat y_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{286}$ and $\textcolor{#1b7f4a}{\hat y_4}\textcolor{#15633a}{=}\textcolor{#c2410c}{232}$. Each product $w_jx_j$ has the unit thousand euros, because the unit of the feature cancels against the unit in the denominator of the weight. Only for this reason may you add the three products.

⁠In short: A weighted sum is the dot product $\mathbf{w}^{\top}\mathbf{x}$ of weights and features; it is the simplest model that makes a prediction from features.

BackgroundA large weight does not mean that the feature is important

For the real estate agent, the weight of the rooms, $10$, is more than three times as large as that of the floor area, $3$. Nevertheless, for apartment 1 the floor area contributes $180$ thousand euros and the number of rooms only $20$. The reason: a weight applies per unit of the feature, and the floor area has many units. If you measure the floor area in units of $10\,\mathrm m^2$, apartment 1 is only $6$ units large, and the same model needs the weight $30$ thousand euros per $10\,\mathrm m^2$. The prediction stays the same; only the weight has become ten times as large. So how large a weight is depends on the chosen unit. If you want to know how much a feature contributes to the prediction, you have to look at the product $w_jx_j$, not at the weight alone.

Sum and mean as a dot product

Many everyday calculations are dot products with a particularly simple second vector. The ones you need most often are the sum and the average of all components.

The all-ones vector $\mathbf 1\in\mathbb{R}^n$ has only ones as components. The dot product with it simply adds up all components: $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_1+\dots+v_n}$.

Definition 2.4 (Mean)

The mean of the components of a vector $\mathbf{v}\in\mathbb{R}^n$ is

$$\textcolor{#1b7f4a}{\bar v}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\sum_{i=1}^nv_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\,\mathbf 1^{\top}\mathbf{v} .}$$
(2.3)

More calculations of this kind: the dot product with a unit vector picks out one component, $\textcolor{#1b7f4a}{\mathbf{e}_j^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_j}$, because all other products contain a zero. The dot product of a vector with itself is the sum of squares, $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_iv_i^2}$. Quantities times prices, summed up, give the amount of an invoice. And evaluating a polynomial $\textcolor{#1b7f4a}{p(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{c_1+c_2t+\dots+c_nt^{n-1}}$ at a point $t$ means forming the dot product $\mathbf{c}^{\top}\mathbf{z}$ of its coefficients $\textcolor{#1b7f4a}{\mathbf{c}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(c_1,\dots,c_n)^{\top}}$ with the powers $\textcolor{#1b7f4a}{\mathbf{z}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,t,\,t^2,\dots,t^{n-1})^{\top}}$. For $\textcolor{#1b7f4a}{p(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+2t+3t^2}$ at $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, this is $\textcolor{#1b7f4a}{(1,\,2,\,3)\,(1,\,2,\,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+4+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{17}$.

Worked example

From January to March, apartment 1 consumed $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(200,\,250,\,300)^{\top}}$ kWh of electricity (Subsection 1.4). In total this is $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{750}$ kWh, on average $\textcolor{#1b7f4a}{\bar u}\textcolor{#15633a}{=}\textcolor{#c2410c}{250}$ kWh per month (Fig. 8). The consumption in February is $\textcolor{#1b7f4a}{\mathbf{e}_2^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{250}$ kWh.

If a kilowatt-hour costs $\textcolor{#1b7f4a}{\mathbf{p}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0.32,\ 0.34,\ 0.28)^{\top}}$ euros in the three months, the electricity bill is the dot product of prices and quantities: $\textcolor{#1b7f4a}{\mathbf{p}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{233}$ euros (Fig. 9). Each product $p_ju_j$ is the amount for one month, in euros per kWh times kWh, that is, in euros.

⁠In short: The sum, the mean, picking out a component and the sum of squares are dot products with $\mathbf 1$, $\tfrac1n\mathbf 1$, $\mathbf{e}_j$ and the vector itself.

The dot product as a comparison with a pattern

The outdoor temperature is read every twelve hours, alternately at noon and at midnight. Four consecutive values form a vector, here called a time series. It is to be checked for whether it jumps back and forth from value to value, as the alternation of day and night would lead you to expect. To do this, you write the pattern you are looking for as a vector, here $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,1,\,-1)^{\top}}$, and form the dot product with the time series.

Fig. 10 shows what happens. Each value is multiplied by the pattern value at the same position. If the time series has the same sign as the pattern at a position, the product is positive; if it has the opposite sign, the product is negative. If the time series follows the pattern everywhere, only positive contributions add up to a large sum. If the time series has nothing to do with the pattern, positive and negative contributions cancel each other out.

More precisely: the contribution of position $j$ to the dot product $\mathbf{w}^{\top}\mathbf{x}$ is $w_jx_j$. It is positive if $w_j$ and $x_j$ have the same sign, and negative if they have opposite signs. The larger the magnitudes at positions with matching signs, the larger the dot product.

For sequences of numbers, this calculation has a name of its own. The sum $\sum_nx[n]\,y[n]$ of two real sequences $x[n]$ and $y[n]$ is called their cross-correlation at shift zero. If you write the values of two sequences of finite length as vectors $\mathbf{x}$ and $\mathbf{y}$, this is exactly the dot product $\mathbf{x}^{\top}\mathbf{y}$. The sum of squares of a sequence, $\sum_nx[n]^2$, is likewise $\mathbf{x}^{\top}\mathbf{x}$. So comparing with a pattern is not a new tool; it is the same calculation you use to search a long sequence of numbers for a known pattern.

Worked example

With the alternating pattern $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,1,\,-1)^{\top}}$, we get $\textcolor{#1b7f4a}{\mathbf{w}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ for $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-1,\,3,\,-2)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{w}^{\top}\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ for $\textcolor{#1b7f4a}{\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,2,\,3,\,3)^{\top}}$ (Fig. 11). With the constant pattern $\textcolor{#1b7f4a}{\mathbf 1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1,\,1,\,1)^{\top}}$ it is the other way around: $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, but $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$. So the time series $\mathbf{x}$ mainly alternates between day and night, while $\mathbf{x}'$ mainly stays constant.

The real estate agent's weighted sum is also a comparison with a pattern. Her pattern $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ describes what makes an apartment valuable: a lot of floor area, many rooms, little distance. The better an apartment fits this pattern, the higher its prediction.

⁠In short: The dot product $\mathbf{w}^{\top}\mathbf{x}$ is large if $\mathbf{x}$ has large values where the pattern $\mathbf{w}$ has large values with the same sign; it is the correlation at shift zero.

BackgroundThe correlation function consists entirely of dot products

Cross-correlation compares a sequence with a pattern not just at one position but for every possible shift. For each shift $k$, its value is a dot product: the sequence with the pattern shifted by $k$ positions. So the whole correlation function is a sequence of dot products, one per shift. Where the pattern is hidden in the sequence, the positive contributions accumulate, and the correlation function is particularly large there. This is how you find, in a long audio recording, the point where a known sound occurs, say a gong, and, in a photo, the spots that resemble a small image patch. In machine learning the shift usually stays fixed at zero: you compare an example as a whole with a pattern.

Exercise 4 ★ Checking the rules

Let $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0,\,2)^{\top}}$, $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,-1,\,1)^{\top}}$ and $\textcolor{#1b7f4a}{\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,2,\,1)^{\top}}$. Compute $\mathbf{u}^{\top}\mathbf{v}$, $\mathbf{v}^{\top}\mathbf{u}$, $\mathbf{u}^{\top}(\mathbf{v}+\mathbf{q})$, $\mathbf{u}^{\top}\mathbf{v}+\mathbf{u}^{\top}\mathbf{q}$, $(3\mathbf{u})^{\top}\mathbf{v}$ and $\mathbf{u}^{\top}\mathbf{u}$. Which rule does each comparison show?

Solution

We have $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ and $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$: the dot product is symmetric, rule (i). With $\textcolor{#1b7f4a}{\mathbf{v}+\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,1,\,2)^{\top}}$, we get $\textcolor{#1b7f4a}{\mathbf{u}^{\top}(\mathbf{v}+\mathbf{q})}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$, and $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}+\mathbf{u}^{\top}\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{5+(0+0+2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$: linearity in the second vector, rule (ii). Furthermore, $\textcolor{#1b7f4a}{(3\mathbf{u})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,0,6)\,(3,-1,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{9+0+6}\textcolor{#15633a}{=}\textcolor{#c2410c}{15}\textcolor{#15633a}{=}\textcolor{#c2410c}{3\cdot5}$, again rule (ii). Finally, $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+0+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{5>0}$, as rule (iii) requires for $\mathbf{u}\ne\mathbf{0}$.

Exercise 5 ★★ The real estate agent's estimate

Use the weights $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ from Subsection 2.2.

  1. Compute the predictions for all four apartments. What unit do they have?

  2. A wall is put up in apartment 2, so that it has two rooms with the same floor area. How does the prediction change, and why does the change not depend on the floor area?

  3. A colleague says: “For the real estate agent, the rooms count the most; they have the largest weight.” Check this statement for apartment 1 by comparing the three contributions $w_jx_{1j}$.

Solution

(a) As in Subsection 2.2: $188$, $126$, $286$ and $232$, each in thousand euros. The unit is thousand euros because every weight has the unit “thousand euros per unit of the feature” and the unit of the feature cancels in the product.

(b) Apartment 2 becomes $(40,\,2,\,1)^{\top}$. The prediction rises from $126$ to $\textcolor{#1b7f4a}{120+20-4}\textcolor{#15633a}{=}\textcolor{#c2410c}{136}$, that is, by $10$. In general, a change $\Delta x_2$ in the second feature changes the weighted sum by $w_2\,\Delta x_2$, because $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(\mathbf{x}+\Delta x_2\,\mathbf{e}_2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}+\Delta x_2\,\mathbf{w}^{\top}\mathbf{e}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}+\Delta x_2\,w_2}$. The other features play no role in this. This is the linearity of the dot product: each feature contributes on its own, without interacting with the others.

(c) The contributions for apartment 1 are $\textcolor{#1b7f4a}{w_1x_{11}}\textcolor{#15633a}{=}\textcolor{#c2410c}{180}$, $\textcolor{#1b7f4a}{w_2x_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{20}$ and $\textcolor{#1b7f4a}{w_3x_{13}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-12}$. By far the largest contribution comes from the floor area, even though its weight is the smallest in absolute value. The colleague's statement confuses the weight per unit with the contribution to the prediction; the floor area has very many units.

Exercise 6 ★★ A pattern for rising time series

A time series with four values, for example the temperature on four consecutive days, is to be checked for whether it rises. The proposed pattern is $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-3,\,-1,\,1,\,3)^{\top}}$.

  1. Compute $\mathbf{w}^{\top}\mathbf{x}$ for $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,2,3,4)^{\top}}$, $(4,3,2,1)^{\top}$, $(5,5,5,5)^{\top}$ and $(1,3,2,4)^{\top}$ and interpret the results.

  2. Why does every constant time series $c\,\mathbf1$ give exactly zero? Use $\mathbf 1^{\top}\mathbf{w}$.

Solution

(a) $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(1,2,3,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-2+3+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: the time series rises, and the result is clearly positive. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(4,3,2,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-12-3+2+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-10}$: the time series falls, and the result is just as clearly negative. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(5,5,5,5)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-15-5+5+15}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$: constant, no rise. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(1,3,2,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-3+2+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$: the time series rises overall, with a step back in the middle, and the result is somewhat smaller than for the steady rise. The pattern weights the early values negatively and the late ones positively; so it responds to whether the late values are larger than the early ones.

(b) $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-1+1+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. For a constant time series, therefore, $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(c\,\mathbf 1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{w}^{\top}\mathbf 1}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\cdot0}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Because the weights add up to zero, the pattern completely ignores a fixed amount added to all values: it measures only differences between the values. Whether it is $10$ degrees warmer on all four days does not change the result.
