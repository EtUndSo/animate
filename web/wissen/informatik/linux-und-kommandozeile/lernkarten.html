Kapitel 1: Ein Linux zum Üben: WSL, virtuelle Maschine, Live-USB-Stick

  1. BegriffBetriebssystem
    Das Betriebssystem ist die Software, die die Hardware eines Rechners verwaltet, sie den übrigen Programmen über einheitliche Dienste zur Verfügung stellt und die Programme voneinander abschirmt.
    Betriebssystem, Kernel und Distribution
  2. BegriffAnwendungsprogramm
    Ein Programm, das unter einem Betriebssystem läuft und für den Benutzer eine Aufgabe erledigt, heißt Anwendungsprogramm, kurz Programm.
    Betriebssystem, Kernel und Distribution
  3. BegriffKernel-Modus
    Im Kernel-Modus darf das laufende Programm jeden Befehl des Prozessors ausführen.
    Betriebssystem, Kernel und Distribution
  4. BegriffBenutzermodus
    Im Benutzermodus sind bestimmte Befehle gesperrt, etwa der direkte Zugriff auf Geräte und das Einstellen, welches Programm welchen Teil des Arbeitsspeichers benutzen darf.
    Betriebssystem, Kernel und Distribution
  5. Begriffprivilegierter Befehl
    Ein solcher gesperrter Befehl heißt privilegierter Befehl.
    Betriebssystem, Kernel und Distribution
  6. BegriffKernel
    Der Kernel (deutsch Kern) ist der Teil des Betriebssystems, der im Kernel-Modus läuft.
    Betriebssystem, Kernel und Distribution
  7. BegriffTreiber
    Zum Kernel gehören auch die Treiber: Programmteile, die ein bestimmtes Gerät ansteuern können, etwa eine bestimmte Netzwerkkarte oder eine bestimmte SSD.
    Betriebssystem, Kernel und Distribution
  8. BegriffSystemaufruf
    Ein Systemaufruf ist eine Anfrage eines Programms an den Kernel, einen bestimmten Dienst auszuführen, zum Beispiel eine Datei zu öffnen, Daten zu lesen oder Speicher bereitzustellen.
    Betriebssystem, Kernel und Distribution
  9. BegriffLinux
    Linux ist ein Kernel.
    Betriebssystem, Kernel und Distribution
  10. BegriffPaketverwaltung
    Zu jeder Distribution gehört eine Paketverwaltung: ein Programm, mit dem man Software aus den Quellen der Distribution installiert, aktualisiert und wieder entfernt.
    Betriebssystem, Kernel und Distribution
  11. BegriffLTS-Version
    Alle zwei Jahre im April erscheint eine LTS-Version (Long Term Support, Langzeitpflege), für die Canonical fünf Jahre lang Sicherheits- und Fehlerkorrekturen liefert.
    Betriebssystem, Kernel und Distribution
  12. BegriffPunktversion
    Eine Nummer wie 26.04.1 bezeichnet eine Punktversion: dasselbe System mit den bis dahin gesammelten Korrekturen und neuen Installationsmedien.
    Betriebssystem, Kernel und Distribution

Kapitel 2: Die Shell: erste Befehle

  1. BegriffShell
    Eine Shell ist ein Programm, das Befehle als Text entgegennimmt, sie ausführt oder von anderen Programmen ausführen lässt und danach auf den nächsten Befehl wartet.
    Terminal und Shell
  2. Begriffbash
    Unter Ubuntu, Debian und Fedora öffnet das Terminal die Shell bash, kurz für „Bourne-Again Shell“.
    Terminal und Shell
  3. Begriffaktueller Ordner
    Die Shell arbeitet immer in einem bestimmten Ordner. Dieser Ordner heißt aktueller Ordner.
    Terminal und Shell
  4. Begriffroot
    Jedes Linux-System hat ein Benutzerkonto, das alles darf: Dateien jedes anderen lesen, Systemdateien ändern, Programme installieren. Dieses Konto heißt root.
    Terminal und Shell
  5. BegriffSitzung
    Eine Sitzung ist die Zeit vom Start einer Shell in einem Terminal bis zu ihrem Ende.
    Terminal und Shell
  6. LückentextDer ______ ist nur das Fenster: Er reicht Tastendrücke weiter und zeichnet Zeichen, ohne sie zu verstehen.
    Der Terminalemulator ist nur das Fenster: Er reicht Tastendrücke weiter und zeichnet Zeichen, ohne sie zu verstehen.
    Terminal und Shell
  7. LückentextDie ______ ist das Programm, das deine Befehle liest und ausführen lässt; unter Ubuntu ist es bash.
    Die Shell ist das Programm, das deine Befehle liest und ausführen lässt; unter Ubuntu ist es bash.
    Terminal und Shell
  8. LückentextDie ______ zeigt Benutzer, Rechner und aktuellen Ordner; $ heißt gewöhnlicher Benutzer, # heißt root.
    Die Eingabeaufforderung zeigt Benutzer, Rechner und aktuellen Ordner; $ heißt gewöhnlicher Benutzer, # heißt root.
    Terminal und Shell

    Jedes Terminalfenster hat seine eigene Shell und damit seine eigene Sitzung, die mit exit endet.
    Terminal und Shell
  10. BegriffBefehlszeile
    Eine Befehlszeile ist alles, was du hinter der Eingabeaufforderung tippst, bevor du die Eingabetaste drückst.
    Der Aufbau einer Befehlszeile
  11. BegriffWörter
    Die Shell zerlegt sie an Leerzeichen in Wörter; mehrere Leerzeichen hintereinander trennen wie eines.
    Der Aufbau einer Befehlszeile
  12. BegriffBefehl
    Das erste Wort einer Befehlszeile ist der Befehl: der Name dessen, was ausgeführt werden soll.
    Der Aufbau einer Befehlszeile
  13. BegriffArgument
    Jedes Wort der Befehlszeile nach dem Befehl ist ein Argument.
    Der Aufbau einer Befehlszeile
  14. BegriffOption
    Eine Option ist ein Argument, das mit einem Minuszeichen beginnt und festlegt, wie der Befehl arbeitet.
    Der Aufbau einer Befehlszeile
  15. Begriffkurze Option
    Eine kurze Option besteht aus einem Minuszeichen und einem einzigen Buchstaben, etwa -r.
    Der Aufbau einer Befehlszeile
  16. Begrifflange Option
    Eine lange Option beginnt mit zwei Minuszeichen, auf die ein ganzes Wort folgt, etwa --kernel-release.
    Der Aufbau einer Befehlszeile
  17. BegriffOption mit Wert
    Eine Option mit Wert verlangt eine zusätzliche Angabe, etwa eine Zahl.
    Der Aufbau einer Befehlszeile
  18. LückentextDie ______ zerlegt jede Befehlszeile an den Leerzeichen in Wörter.
