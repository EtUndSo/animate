Worum es geht:

Daten sind nur ein Ausschnitt dessen, was hätte geschehen können. Dieser Abschnitt legt fest, was es heißt, aus Daten eine unbekannte Größe zu schätzen, und zeigt, dass jede Schätzung selbst eine Zufallsvariable ist: Mit anderen Daten käme ein anderer Wert heraus.

Wahrscheinlichkeitsrechnung und Statistik#

Kapitel 4 hat in eine Richtung gerechnet: Die Verteilung war gegeben, gefragt waren Wahrscheinlichkeiten für Daten. Wirft man eine Münze, die mit der Wahrscheinlichkeit $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}7}$ Kopf zeigt, zehnmal, so ist die Anzahl der Köpfe nach Kapitel 4, Abschnitt 8.3, binomialverteilt, und genau sieben Köpfe kommen mit der Wahrscheinlichkeit $\textcolor{#1b7f4a}{\binom{10}7\,0{,}7^7\,0{,}3^3}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}267}$ vor. Dieses Kapitel rechnet in die Gegenrichtung (Abb. 1). Gegeben sind zehn Würfe einer Münze mit verbogenem Rand, siebenmal Kopf, und gefragt ist, welches $\theta$ diese Münze hat. Ein solcher Schluss von beobachteten Daten auf die Verteilung, die sie erzeugt hat, heißt Statistik.

Die Gegenrichtung ist schwerer, weil sie keine eindeutige Antwort hat. Siebenmal Kopf in zehn Würfen kann von einer fairen Münze stammen, ebenso von einer Münze mit $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}8}$. Man kann nur sagen, welche Werte von $\theta$ besser und welche schlechter zu den Daten passen. Damit das eine überschaubare Frage wird, legt man vorher fest, unter welchen Verteilungen man sucht.

Definition 1.1 (Statistisches Modell)

Eine Familie von Verteilungen $\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}$, die von einer unbekannten Größe $\theta$ abhängen, heißt statistisches Modell. Die Größe $\theta$ heißt Parameter, die Menge ihrer zulässigen Werte Parameterbereich $\Theta$. Bei stetigen Daten tritt an die Stelle von $\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}$ eine Dichte $p(x\mid\theta)$.

Der senkrechte Strich wird wie in Kapitel 4, Abschnitt 3.2, „gegeben“ gelesen: $\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}$ ist die Wahrscheinlichkeit von $\textcolor{#1b7f4a}{X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x}$, wenn der Parameter den Wert $\theta$ hat. Ob $\theta$ dabei selbst zufällig ist, lässt die Schreibweise offen; Abschnitt 6 kommt darauf zurück. Besteht der Parameter aus mehreren Zahlen, schreibt man ihn als Vektor $\boldsymbol{\theta}$. In den Definitionen steht $\theta$ für einen beliebigen Parameter; in den Rechenbeispielen ist $\theta$ ohne weiteren Zusatz der Parameter einer Bernoulli-Verteilung, wie in Kapitel 4, Abschnitt 8.1.

Rechenbeispiel

Für Münzwürfe mit Kopf $=1$ und Zahl $=0$ ist das Bernoulli-Modell

$$\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\theta^x(1-\theta)^{1-x},}$$
$$x\in\{0,1\},$$
$$\textcolor{#1b7f4a}{\Theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{[0,\,1] .}$$

Für die Wägungen eines Pakets, die durch Rauschen schwanken, ist ein übliches Modell die Normalverteilung aus Kapitel 4, Abschnitt 8.5, mit der Dichte $p(x\mid\mu,\sigma^2)$ und dem Parametervektor $\textcolor{#1b7f4a}{\boldsymbol{\theta}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mu,\,\sigma^2)^{\top}}$. Hier ist $\mu$ das wahre Gewicht des Pakets, $\sigma^2$ die Varianz des Rauschens und der Parameterbereich die Menge aller Paare mit $\sigma^2>0$.

⁠Kurz gesagt: Die Statistik schließt von Daten auf die Verteilung, die sie erzeugt hat; dafür beschränkt man sich auf ein Modell, eine Familie von Verteilungen mit einem unbekannten Parameter.

HintergrundWarum man sich auf ein Modell beschränkt

Ohne Modell müsste man aus zehn Würfen auf die ganze Verteilung schließen, die hinter einer Münze steht, und aus vier Messwerten auf eine beliebige Dichte über allen reellen Zahlen. Das ist hoffnungslos: Zu wenigen Daten passen unüberschaubar viele Verteilungen. Ein Modell schrumpft die Frage auf wenige Zahlen. Bei der Münze ist das eine Annahme, die man kaum bezweifeln kann, denn ein Ja-Nein-Ergebnis ist immer Bernoulli-verteilt. Beim Wiegen ist die Normalverteilung eine echte Annahme, begründet durch den zentralen Grenzwertsatz aus Kapitel 4, Abschnitt 13.4. Abschnitt 10 liefert einen zweiten Grund. Ist das Modell falsch, so beantwortet die Statistik eine falsche Frage, und das sieht man den Zahlen nicht an. Jede Schätzung in diesem Kapitel gilt deshalb unter der Voraussetzung, dass das gewählte Modell die Daten richtig beschreibt.

Rückblick: Die Stichprobe#

Nach Kapitel 4, Abschnitt 9.6, fasst man einen Datensatz als Stichprobe auf: Die Werte $x_1,\dots,x_N$ sind Ergebnisse von $N$ Zufallsvariablen $X_1,\dots,X_N$, die unabhängig sind und alle dieselbe Verteilung haben, kurz i.i.d. Dieses Kapitel schreibt die Anzahl der Werte mit $N$, wie die Zahl der Beispiele in Kapitel 1; Kapitel 4 hat für dieselbe Rolle $n$ benutzt. Große Buchstaben stehen wie in Kapitel 4 für die Zufallsvariablen, kleine für die beobachteten Werte. Die beobachteten Werte zusammen heißen der Datensatz $\textcolor{#1b7f4a}{\mathcal D}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1,\dots,x_N)}$.

Weil die Zufallsvariablen unabhängig sind, ist die Wahrscheinlichkeit eines ganzen Datensatzes nach Kapitel 4, Abschnitt 9.5, das Produkt der einzelnen Wahrscheinlichkeiten:

$$\textcolor{#1b7f4a}{P(X_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1,\dots,X_N}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_N\mid\theta)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\prod_{i=1}^NP(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_i\mid\theta) .}$$
(1.1)

Dabei ist $\prod_{i=1}^N$ das Produktzeichen: Es multipliziert die Faktoren für $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ bis $N$, so wie das Summenzeichen sie addiert.

Rechenbeispiel

Die verbogene Münze aus dem vorigen Unterabschnitt hat in zehn Würfen die Folge

$$\textcolor{#1b7f4a}{\mathcal D}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0,\,1,\,1,\,0,\,1,\,1,\,0,\,1,\,1)}$$

ergeben, also siebenmal Kopf. Hätte sie $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}7}$, so hätte genau diese Folge nach (1.1) die Wahrscheinlichkeit $\textcolor{#1b7f4a}{0{,}7\cdot0{,}3\cdot0{,}7\cdot0{,}7\cdot0{,}3\cdot0{,}7\cdot0{,}7\cdot0{,}3\cdot0{,}7\cdot0{,}7}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}7^7\cdot0{,}3^3}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}00222}$. Die Wahrscheinlichkeit $0{,}267$ aus dem vorigen Unterabschnitt ist $120$-mal so groß, weil es $\textcolor{#1b7f4a}{\binom{10}7}\textcolor{#15633a}{=}\textcolor{#c2410c}{120}$ Folgen mit sieben Köpfen gibt.

⁠Kurz gesagt: Ein Datensatz ist eine Stichprobe aus $N$ unabhängigen, gleich verteilten Zufallsvariablen; seine Wahrscheinlichkeit ist das Produkt der Einzelwahrscheinlichkeiten.

Schätzer#

Wer $\theta$ wissen will, braucht ein Rezept, das aus den Daten eine Zahl macht. Ein naheliegendes Rezept für die Münze ist der Anteil der Köpfe, $7/10$. Aber auch andere Rezepte sind denkbar, und zunächst ist keines verboten.

Definition 1.2 (Schätzer, Schätzwert)

Ein Schätzer für einen Parameter $\theta$ ist eine Vorschrift $g$, die jeder möglichen Stichprobe eine Zahl zuordnet:

$$\textcolor{#1b7f4a}{\hat\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{g(X_1,\dots,X_N) .}$$
(1.2)

Setzt man die beobachteten Werte ein, so heißt die Zahl $g(x_1,\dots,x_N)$ der Schätzwert.

Der Hut über dem Buchstaben bedeutet wie bei der Vorhersage $\hat y$ aus Kapitel 1, Abschnitt 2.2, eine aus Daten berechnete Größe. Viele Texte schreiben für den Schätzer und für den Schätzwert dasselbe Zeichen $\hat\theta$; ob die Vorschrift mit zufälligen $X_i$ oder die Zahl aus den beobachteten $x_i$ gemeint ist, sagt der Zusammenhang. Die Definition verlangt nicht, dass der Schätzer in der Nähe von $\theta$ landet. Wie gut er das tut, ist eine eigene Frage, und Abschnitt 2 misst es.

Für Daten aus Nullen und Einsen bezeichnet dieses Kapitel die Anzahl der Einsen mit $\textcolor{#1b7f4a}{N_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ix_i}$ und die Anzahl der Nullen mit $\textcolor{#1b7f4a}{N_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{N-N_1}$.

Rechenbeispiel

Für die zehn Würfe mit $\textcolor{#1b7f4a}{N_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$ liefern vier verschiedene Schätzer für $\theta$:

  • den Anteil der Köpfe $\textcolor{#1b7f4a}{N_1/N}\textcolor{#15633a}{=}\textcolor{#c2410c}{7/10}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}7}$;

  • den ersten Wurf $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$;

  • die feste Zahl $0{,}5$, gleichgültig, was die Daten sagen;

  • den Bruch $\textcolor{#1b7f4a}{(N_1+1)/(N+2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{8/12}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}667}$.

Alle vier sind Schätzer im Sinn der Definition. Der zweite und der dritte wirken unvernünftig, und der vierte hat noch keine Begründung; die Abschnitte 2 und 6 kommen auf sie zurück.

⁠Kurz gesagt: Ein Schätzer ist eine Vorschrift, die aus den Daten eine Zahl für einen unbekannten Parameter macht; der Schätzwert ist diese Zahl für die beobachteten Daten.

Die Stichprobenverteilung#

Hätte man die Münze ein zweites Mal zehnmal geworfen, so wären vielleicht sechs oder acht Köpfe herausgekommen, und der Anteil der Köpfe hätte einen anderen Wert gehabt. Ein Schätzer hängt von zufälligen Daten ab und ist deshalb selbst eine Zufallsvariable. Man stellt sich vor, das ganze Experiment würde sehr oft wiederholt, jedes Mal mit $N$ neuen Werten, und notiert jedes Mal den Wert des Schätzers. Wie diese Werte verteilt sind, entscheidet über die Güte des Schätzers.

Definition 1.3 (Stichprobenverteilung)

Die Verteilung eines Schätzers $\textcolor{#1b7f4a}{\hat\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{g(X_1,\dots,X_N)}$ heißt seine Stichprobenverteilung.

Sie hängt vom wahren Parameter ab, von der Vorschrift $g$ und von der Zahl $N$ der Werte. Der wahre Parameter ist dabei fest; zufällig sind nur die Daten.

Rechenbeispiel

Eine Zufallsvariable $X$ nehme die Werte $1$, $2$ und $3$ je mit der Wahrscheinlichkeit $\tfrac13$ an; man kann sich einen Würfel vorstellen, dessen Seiten die Zahlen $1,1,2,2,3,3$ tragen. Ihr Erwartungswert ist $\textcolor{#1b7f4a}{\mu}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, ihre Varianz $\textcolor{#1b7f4a}{\sigma^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac13(1+0+1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac23}$. Aus ihr wird eine Stichprobe vom Umfang $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ gezogen, und geschätzt wird $\mu$ mit dem Mittelwert $\textcolor{#1b7f4a}{\bar X}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12(X_1+X_2)}$. Es gibt nur $\textcolor{#1b7f4a}{3\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{9}$ mögliche Stichproben, und wegen der Unabhängigkeit hat jede die Wahrscheinlichkeit $\textcolor{#1b7f4a}{\tfrac13\cdot\tfrac13}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac19}$. Tabelle 1 zählt sie alle auf.

Zählt man ab, wie oft jeder Mittelwert vorkommt, erhält man die Stichprobenverteilung von $\bar X$: die Werte $1$; $1{,}5$; $2$; $2{,}5$; $3$ mit den Wahrscheinlichkeiten $\tfrac19,\tfrac29,\tfrac39,\tfrac29,\tfrac19$ (Abb. 2). Ihr Erwartungswert und ihre Varianz sind nach Kapitel 4, Abschnitt 7.1 und 7.4, Summen über diese fünf Werte (Abb. 3):

$$\textcolor{#1b7f4a}{\mathbb{E}[\bar X]}\textcolor{#15633a}{=}\textcolor{#c2410c}{2,}$$
$$\textcolor{#1b7f4a}{\operatorname{Var}(\bar X)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac13 .}$$

Das passt zu Kapitel 4, Abschnitt 13.1: Der Mittelwert hat den Erwartungswert $\textcolor{#1b7f4a}{\mu}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$ und die Varianz $\textcolor{#1b7f4a}{\sigma^2/N}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac23/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac13}$.

⁠Kurz gesagt: Ein Schätzer ist eine Zufallsvariable; seine Verteilung über alle möglichen Stichproben heißt Stichprobenverteilung, und an ihr misst man, wie gut er ist.

HintergrundDie Stichprobenverteilung sieht man nie

In der Praxis hat man genau einen Datensatz und damit genau einen Wert des Schätzers. Die Stichprobenverteilung beschreibt gedachte Wiederholungen, die nie stattfinden. Trotzdem lässt sich über sie viel sagen: In kleinen Beispielen zählt man wie oben alle Stichproben ab; für Mittelwerte liefern Kapitel 4, Abschnitt 13.1, und der zentrale Grenzwertsatz ihre Varianz und ihre Form; und mit einem Rechner kann man sehr viele Datensätze aus einem angenommenen Modell erzeugen und die Werte des Schätzers auszählen. In dieser Sichtweise ist der Parameter eine feste, unbekannte Zahl, und alle Wahrscheinlichkeiten beziehen sich auf die Daten. Sie heißt frequentistisch, weil sie Wahrscheinlichkeiten als Häufigkeiten bei Wiederholungen deutet, wie Kapitel 4, Abschnitt 2.1. Abschnitt 6 stellt ihr eine zweite Sichtweise gegenüber.

Aufgabe 1 ★ Modelle und Schätzer

  1. Eine Reißzwecke landet entweder auf dem Rücken oder auf der Seite. Gib ein statistisches Modell für einen Wurf an. Was ist der Parameter, was der Parameterbereich?

  2. Acht Würfe ergeben $\textcolor{#1b7f4a}{\mathcal D}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0,\,1,\,1,\,0,\,1,\,1,\,0)}$, dabei steht $1$ für „Rücken“. Berechne die vier Schätzwerte aus dem Rechenbeispiel in Unterabschnitt 1.3.

  3. Wie wahrscheinlich ist genau diese Folge, wenn der Parameter $0{,}5$ ist? Wie wahrscheinlich, wenn er $0{,}6$ ist?

Lösung

(a) Ein Wurf hat zwei Ausgänge, also ist er Bernoulli-verteilt: $\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\theta^x(1-\theta)^{1-x}}$ für $x\in\{0,1\}$, mit $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ für „Rücken“. Der Parameter $\theta$ ist die Wahrscheinlichkeit, auf dem Rücken zu landen, der Parameterbereich ist $\textcolor{#1b7f4a}{\Theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{[0,\,1]}$. Anders als bei einer Münze gibt es keinen Grund, $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}$ zu erwarten; die Form der Zwecke bestimmt $\theta$.

(b) Es ist $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ und $\textcolor{#1b7f4a}{N_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$. Die vier Schätzwerte sind $\textcolor{#1b7f4a}{N_1/N}\textcolor{#15633a}{=}\textcolor{#c2410c}{5/8}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}625}$, der erste Wurf $\textcolor{#1b7f4a}{x_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, die feste Zahl $0{,}5$ und $\textcolor{#1b7f4a}{(N_1+1)/(N+2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{6/10}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}6}$.

(c) Unter $\theta$ hat die Folge die Wahrscheinlichkeit $\theta^5(1-\theta)^3$. Für $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}5}$ ist das $\textcolor{#1b7f4a}{0{,}5^8}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac1{256}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}00391}$, für $\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}6}$ ist es $\textcolor{#1b7f4a}{0{,}6^5\cdot0{,}4^3}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}07776\cdot0{,}064}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}00498}$.

Aufgabe 2 ★★ Eine Stichprobenverteilung abzählen

Eine faire Münze ($\textcolor{#1b7f4a}{\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}$) wird dreimal geworfen, und $\theta$ wird mit dem Anteil der Köpfe $\textcolor{#1b7f4a}{\hat\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{N_1/3}$ geschätzt.

  1. Schreibe alle acht möglichen Folgen auf und gib die Stichprobenverteilung von $\hat\theta$ an.

  2. Berechne $\mathbb{E}[\hat\theta]$ und $\operatorname{Var}(\hat\theta)$ und vergleiche mit $\theta$ und mit $\theta(1-\theta)/N$.

  3. Wie wahrscheinlich ist es, dass der Schätzwert um mindestens $0{,}3$ neben $\theta$ liegt?

Lösung

(a) Die acht Folgen sind $000$, $001$, $010$, $100$, $011$, $101$, $110$, $111$, jede mit der Wahrscheinlichkeit $\tfrac18$. Der Anteil der Köpfe ist $0$ für eine Folge, $\tfrac13$ für drei, $\tfrac23$ für drei und $1$ für eine. Die Stichprobenverteilung von $\hat\theta$ hat also die Werte $0,\tfrac13,\tfrac23,1$ mit den Wahrscheinlichkeiten $\tfrac18,\tfrac38,\tfrac38,\tfrac18$.

(b) $\textcolor{#1b7f4a}{\mathbb{E}[\hat\theta]}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac18\,(0+3\cdot\tfrac13+3\cdot\tfrac23+1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac18\cdot4}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}\textcolor{#15633a}{=}\textcolor{#c2410c}{\theta}$. Weiter ist $\textcolor{#1b7f4a}{\mathbb{E}[\hat\theta^2]}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac18\,(0+3\cdot\tfrac19+3\cdot\tfrac49+1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac18\cdot\tfrac83}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac13}$, also $\textcolor{#1b7f4a}{\operatorname{Var}(\hat\theta)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac13-\tfrac14}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac1{12}}$. Das ist $\textcolor{#1b7f4a}{\theta(1-\theta)/N}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac14/3}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac1{12}}$.

(c) Die Werte $\tfrac13$ und $\tfrac23$ liegen nur $\textcolor{#1b7f4a}{\tfrac16}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{0{,}167}$ neben $\tfrac12$, die Werte $0$ und $1$ liegen $0{,}5$ daneben. Die Wahrscheinlichkeit ist also $\textcolor{#1b7f4a}{\tfrac18+\tfrac18}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac14}$.

Definition 1.2 (Schätzer, Schätzwert)

Ein Schätzer für einen Parameter $\theta$ ist eine Vorschrift $g$, die jeder möglichen Stichprobe eine Zahl zuordnet:

$$\textcolor{#1b7f4a}{\hat\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{g(X_1,\dots,X_N) .}$$
(1.2)

Setzt man die beobachteten Werte ein, so heißt die Zahl $g(x_1,\dots,x_N)$ der Schätzwert.

Die Stichprobenverteilung
Definition 1.3 (Stichprobenverteilung)

Die Verteilung eines Schätzers $\textcolor{#1b7f4a}{\hat\theta}\textcolor{#15633a}{=}\textcolor{#c2410c}{g(X_1,\dots,X_N)}$ heißt seine Stichprobenverteilung.

Zusammenfassung

Begriffe
  • Statistik – Ein solcher Schluss von beobachteten Daten auf die Verteilung, die sie erzeugt hat, heißt Statistik.
  • statistisches Modell – Eine Familie von Verteilungen $\textcolor{#1b7f4a}{P(X}\textcolor{#15633a}{=}\textcolor{#c2410c}{x\mid\theta)}$, die von einer unbekannten Größe $\theta$ abhängen, heißt statistisches Modell.
  • Parameter, Parameterbereich – Die Größe $\theta$ heißt Parameter, die Menge ihrer zulässigen Werte Parameterbereich $\Theta$.
  • Datensatz – Die beobachteten Werte zusammen heißen der Datensatz $\textcolor{#1b7f4a}{\mathcal D}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1,\dots,x_N)}$.
  • Schätzer – Ein Schätzer für einen Parameter $\theta$ ist eine Vorschrift $g$, die jeder möglichen Stichprobe eine Zahl zuordnet.

Zusammenhänge
  • Zu „Wahrscheinlichkeitsrechnung und Statistik“: Die Statistik schließt von Daten auf die Verteilung, die sie erzeugt hat; dafür beschränkt man sich auf ein Modell, eine Familie von Verteilungen mit einem unbekannten Parameter.
  • Zu „Rückblick: Die Stichprobe“: Ein Datensatz ist eine Stichprobe aus $N$ unabhängigen, gleich verteilten Zufallsvariablen; seine Wahrscheinlichkeit ist das Produkt der Einzelwahrscheinlichkeiten.
  • Zu „Schätzer“: Ein Schätzer ist eine Vorschrift, die aus den Daten eine Zahl für einen unbekannten Parameter macht; der Schätzwert ist diese Zahl für die beobachteten Daten.
  • Zu „Die Stichprobenverteilung“: Ein Schätzer ist eine Zufallsvariable; seine Verteilung über alle möglichen Stichproben heißt Stichprobenverteilung, und an ihr misst man, wie gut er ist.
