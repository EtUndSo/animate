Kapitel 1: Programme und der Python-Interpreter

Das Wichtigste bis hier

Programme und Programmiersprachen

Begriffe
  • Programm – Ein Programm ist eine Folge von eindeutig beschriebenen Arbeitsschritten, die ein Rechner der Reihe nach ausführt, ohne nachzufragen.
  • Anweisung – Einen einzelnen Arbeitsschritt eines Programms nennt man Anweisung.
  • Prozessor – Die Schritte eines Programms führt im Rechner der Prozessor aus, ein Chip, der rechnet und den Ablauf steuert.
  • Maschinenbefehl – Ein Maschinenbefehl ist ein Befehl, den der Prozessor unmittelbar ausführen kann.
  • Maschinencode – Ein Programm, das nur aus Maschinenbefehlen besteht, heißt Maschinencode.
  • Programmiersprache – Eine Programmiersprache ist eine künstliche Sprache, in der genau festgelegt ist, welche Texte erlaubt sind und was jeder erlaubte Text bewirkt.
  • Syntax – Die Syntax einer Programmiersprache ist die Gesamtheit der Regeln, die festlegen, welche Texte in ihr erlaubt sind.
  • Semantik – Die Semantik einer Programmiersprache legt fest, was ein erlaubter Text bedeutet, also was geschieht, wenn er ausgeführt wird.
  • Quelltext – Der Quelltext eines Programms ist sein Text in einer Programmiersprache, so wie Menschen ihn schreiben und lesen.
Zusammenhänge
  • Ein Programm ist ein Rezept aus eindeutigen Schritten, das ein Rechner ohne Rückfrage ausführen kann.
  • Der Prozessor versteht nur sehr einfache Maschinenbefehle, die als Zahlen im Speicher stehen, und jede Prozessorfamilie hat ihre eigenen.
  • Eine Programmiersprache ist eine künstliche Sprache ohne Mehrdeutigkeit, in der man Programme aufschreibt.
  • Die Syntax legt die erlaubte Form fest, unabhängig davon, was ein Text bedeutet.
  • Die Semantik legt fest, was ein erlaubter Text bewirkt.
  • Der Quelltext ist das Programm in der Form, in der Menschen es schreiben; der Prozessor kann ihn nicht unmittelbar ausführen.

Vom Quelltext zur Ausführung: Compiler und Interpreter

Begriffe
  • Compiler – Ein Compiler ist ein Programm, das einen Quelltext vollständig in Maschinencode übersetzt, bevor dieser ausgeführt wird.
  • ausführbare Datei – Eine solche Datei heißt ausführbare Datei.
  • Interpreter – Ein Interpreter ist ein Programm, das einen Quelltext liest und die darin beschriebenen Schritte selbst ausführt.
  • Python – Python ist eine Programmiersprache; ihre Syntax und Semantik sind in der Sprachreferenz von Python festgelegt.
  • CPython – CPython ist das Programm, das Python-Quelltext ausführt und auf python.org angeboten wird; es ist selbst in der Sprache C geschrieben.
  • Bytecode – Der Bytecode ist eine Folge einfacher Befehle, in die CPython den ganzen Quelltext übersetzt, bevor es mit der Ausführung beginnt.
  • Interpreterschleife – Den Bytecode arbeitet anschließend ein Teil von CPython Befehl für Befehl ab: die Interpreterschleife.
Zusammenhänge
  • Ein Compiler übersetzt den ganzen Quelltext einmal vorab in eine ausführbare Datei aus Maschinencode.
  • Ein Interpreter führt den Quelltext selbst aus, ohne eine ausführbare Datei zu erzeugen.
  • Python ist die Sprache, CPython das Programm, das sie ausführt.
  • CPython übersetzt die ganze Datei zuerst in Bytecode und führt danach diesen Bytecode Befehl für Befehl aus.

Python einrichten

Begriffe
  • Python install manager – Der Python install manager ist ein Programm für Windows, das Python-Versionen herunterlädt, installiert, auflistet, entfernt und startet.
  • Versionsnummer – Eine Python-Versionsnummer hat die Form 3.14.4 und besteht aus drei Teilen.
Zusammenhänge
  • Unter Windows installierst du den Python install manager und startest Python danach mit py.
  • Unter Linux ist Python meist schon da und heißt python3.
  • Die Versionsnummer sagt, welches Python du hast; man vergleicht sie Teil für Teil.

Der interaktive Modus

Begriffe
  • interaktiven Modus – Im interaktiven Modus liest Python eine Eingabe, führt sie aus, zeigt das Ergebnis an und wartet dann auf die nächste Eingabe.
  • Wert – Ein Wert ist ein einzelnes Datum, mit dem Python arbeitet, zum Beispiel die Zahl 42 oder die Zahl 0,5.
  • Ausdruck – Ein Ausdruck ist ein Stück Quelltext, das Python zu einem Wert ausrechnen kann.
  • Auswerten – Das Ausrechnen eines Ausdrucks heißt Auswerten.
  • Zeichenkette – Eine Zeichenkette ist ein Wert, der aus Text besteht.
  • Funktion – Eine Funktion ist ein fertiges Teilprogramm mit einem Namen, das man bei Bedarf ausführen lassen kann.
  • Funktionsaufruf – Ein Funktionsaufruf lässt eine Funktion ausführen.
Zusammenhänge
  • Im interaktiven Modus tippt man hinter >>> eine Zeile, und Python antwortet sofort.
  • Ein Wert ist ein Datum wie die Zahl 42; Nachkommastellen stehen in Python hinter einem Punkt.
  • Ein Ausdruck ist Quelltext, der einen Wert ergibt; der interaktive Modus zeigt diesen Wert sofort an.
  • Python rechnet mit + - * / ** und runden Klammern nach den Regeln der Mathematik, Nachkommastellen stehen hinter einem Punkt, Einheiten kennt es nicht.
  • Das Heron-Rezept läuft im interaktiven Modus Durchgang für Durchgang und landet nach fünf Durchgängen bis auf die letzte Stelle beim eingebauten Ergebnis von 2 ** 0.5.
  • Text in geraden Anführungszeichen ist eine Zeichenkette, also ein Wert, mit dem Python nicht rechnet.
  • Eine Funktion ist ein fertiges Teilprogramm mit Namen.
  • Man ruft eine Funktion mit ihrem Namen und runden Klammern auf; print schreibt die Werte in den Klammern ins Terminal.

Skripte schreiben und ausführen

Begriffe
  • Editor – Ein Editor ist ein Programm, mit dem man reine Textdateien schreibt und speichert.
  • Skript – Ein Skript ist eine Textdatei mit Python-Quelltext, deren Name auf .py endet.
  • Kommentar – Ein Kommentar beginnt mit dem Zeichen # und reicht bis zum Ende der Zeile.
Zusammenhänge
  • Programme schreibt man mit einem Editor, der reinen Text speichert, am besten mit einem Editor für Programmierer wie VS Code oder IDLE.
  • Ein Skript ist eine .py-Datei, die man mit py datei.py oder python3 datei.py ausführt; sichtbar wird darin nur, was print ausgibt.
  • Ein Kommentar beginnt mit #, gilt bis zum Zeilenende und ist nur für Menschen da.

Fehler lesen und verstehen

Begriffe
  • Syntaxfehler – Ein Syntaxfehler ist eine Stelle im Quelltext, die gegen die Syntax der Sprache verstößt.
  • Laufzeitfehler – Ein Laufzeitfehler ist ein Fehler, der erst beim Ausführen einer Zeile auftritt.
  • Ausnahme – Eine Ausnahme ist das Ereignis, mit dem Python einen Fehler meldet.
  • Traceback – Der Traceback ist der Bericht, den Python ausgibt, wenn eine Ausnahme beim Ausführen ein Programm abbricht.
  • Logikfehler – Ein Logikfehler ist ein Fehler, bei dem ein Programm ohne Fehlermeldung läuft, aber nicht das berechnet, was gemeint war.
Zusammenhänge
  • Ein Syntaxfehler verletzt die Form; Python meldet ihn vor dem Start, und keine Zeile der Datei läuft.
  • Ein Laufzeitfehler tritt beim Ausführen einer Zeile auf; alles davor ist gelaufen, alles danach nicht.
  • Eine Ausnahme meldet einen Fehler mit Art und Beschreibung; beim Ausführen bricht sie das Programm ab.
  • Ein Traceback nennt Ort und Art einer Ausnahme; man liest ihn von unten.
  • Ein Logikfehler läuft ohne Meldung und liefert ein falsches Ergebnis; man findet ihn nur, indem man Ergebnisse prüft.

Kapitel 2: Werte, Typen und Variablen

Das Wichtigste bis hier

Objekte und Typen

Begriffe
  • Objekt – Ein Objekt ist ein Stück des Arbeitsspeichers, in dem Python einen Wert ablegt, zusammen mit der Angabe, welche Art von Wert dort liegt.
  • Typ – Der Typ eines Objekts ist die Art seines Werts.
  • Identität – Die Identität eines Objekts ist eine ganze Zahl, die das Objekt von allen anderen Objekten unterscheidet, die zur selben Zeit bestehen.
  • Methode – Eine Methode ist eine Funktion, die zu einem Typ gehört.
Zusammenhänge
  • Ein Objekt ist ein Wert im Arbeitsspeicher, der die Angabe seiner Art mit sich trägt.
  • Der Typ sagt, was für ein Wert in einem Objekt steckt und was man mit ihm tun kann; type zeigt ihn an.
  • Die Identität ist die feste Nummer eines Objekts; id zeigt sie an.
  • Eine Methode ist eine Funktion eines Typs; man ruft sie mit objekt.name() auf.

Ganze Zahlen und Rechenoperatoren

Begriffe
  • Operator – Ein Operator ist ein Zeichen, das aus Werten einen neuen Wert berechnet.
  • Operanden – Die Werte, auf die ein Operator wirkt, heißen seine Operanden.
  • Ganzzahldivision, Rest – Der Operator // heißt Ganzzahldivision, der Operator % liefert den Rest.
  • Rangfolge – Die Rangfolge der Operatoren legt fest, welcher Operator in einem Ausdruck ohne Klammern zuerst ausgeführt wird.
Formeln
  • Satz 2.5 (Ganzzahldivision und Rest) (2.1)
    $$\textcolor{#1b7f4a}{a }\textcolor{#15633a}{=}\textcolor{#c2410c}{ (a\,/\!/\,b)\cdot b + a\,\%\,b .}$$
Zusammenhänge
  • Ein int ist eine ganze Zahl beliebiger Größe; Python rechnet mit ihr exakt.
  • Ein Operator berechnet aus seinen Operanden einen neuen Wert; ist ein Operand ein float, ist es auch das Ergebnis.
  • / teilt wie in der Mathematik und liefert immer einen float.
  • // rundet den Quotienten nach unten, Richtung $-\infty$; % ist der Rest dazu und hat das Vorzeichen des rechten Operanden.
  • ** bindet stärker als ein Minus davor und wird von rechts nach links ausgewertet; ein negativer Exponent liefert einen float.
  • Potenz vor Vorzeichen vor Punktrechnung (* / // %) vor Strichrechnung; Klammern gehen vor, und im Zweifel setzt man sie.

Zahlen im Binärsystem

Begriffe
  • Basis – Sei $B\ge2$ eine natürliche Zahl, die Basis.
  • Binärzahl – Eine Binärzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$.
  • Bit – Eine Binärstelle heißt Bit, nach dem englischen binary digit.
  • Byte – Ein Byte ist eine Gruppe von 8 Bit.
  • Hexadezimalzahl – Eine Hexadezimalzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$.
  • Binärbruch – Ein Binärbruch ist eine Zahl mit Stellen rechts vom Komma im Binärsystem.
  • Verdopplungsverfahren – Für $0\le x<1$ bestimmt das Verdopplungsverfahren die Binärstellen von $x$: Man verdoppelt $x$.
Formeln
  • Definition 3.1 (Stellenwertsystem)
    $$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$
  • Definition 3.5 (Binärbruch)
    $$\textcolor{#1b7f4a}{0{,}b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$
Zusammenhänge
  • In einem Stellenwertsystem ist jede Ziffer mit dem Stellenwert ihrer Position zu multiplizieren, und alles wird addiert.
  • Eine Binärzahl hat nur die Ziffern 0 und 1, die Bits; jedes Bit zählt $2^i$.
  • Ein Byte sind 8 Bit; es kann 256 verschiedene Werte annehmen, die Zahlen 0 bis 255.
  • Fortgesetzte Division durch 2 liefert die Bits als Reste, das letzte Bit zuerst; fertig erledigen das bin und format.
  • Hexadezimal ist die Basis 16; jede Ziffer steht für vier Bits, ein Byte für zwei Ziffern.
  • Ein Binärbruch endet genau dann, wenn der gekürzte Nenner eine Zweierpotenz ist; $0{,}1$ endet nicht.
  • Verdoppeln schiebt die nächste Binärstelle vor das Komma; für $0{,}1$ ergibt das die unendliche Folge $0{,}0\,0011\,0011\ldots{}_2$.

Gleitkommazahlen: der Typ float

Begriffe
  • Gleitkommazahl – Eine Gleitkommazahl mit $p$ Binärstellen ist eine Zahl der Form $\pm\,m\cdot2^E$.
  • Mantisse – Darin ist die Mantisse $m$ eine Binärzahl mit $p$ Stellen und genau einer Stelle vor dem Komma, die 1 ist: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1{,}\ldots{}_2}$, also $1\le m<2$.
  • Exponent – Der Exponent $E$ ist eine ganze Zahl aus einem festen Bereich.
  • Exponentenfeld – Das Exponentenfeld $c$ eines float speichert den um 1023 verschobenen Exponenten.
  • Mantissenfeld – Das Mantissenfeld $t$ eines float enthält die 52 Binärstellen der Mantisse nach dem Komma.
  • Darstellungsfehler – Die Differenz zwischen dem gespeicherten Wert und $x$ heißt Darstellungsfehler.
Formeln
  • Definition 4.3 (Exponentenfeld)
    $$\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{E+1023,}$$
    $$\textcolor{#1b7f4a}{E}\textcolor{#15633a}{=}\textcolor{#c2410c}{c-1023 .}$$
  • Definition 4.4 (Mantissenfeld)
    $$\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+\frac{t}{2^{52}} .}$$
  • Das Mantissenfeld (4.1)
    $$\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s\cdot\Bigl(1+\frac{t}{2^{52}}\Bigr)\cdot2^{\,c-1023}.}$$
Zusammenhänge
  • Eine Gleitkommazahl ist Mantisse mal Zweierpotenz; mit fester Stellenzahl wächst der Abstand benachbarter Zahlen mit ihrem Betrag.
  • Ein float ist eine Gleitkommazahl mit 53 Binärstellen Mantisse, gespeichert in 64 Bit: Vorzeichen, Exponentenfeld, Mantissenfeld.
  • Das Exponentenfeld speichert $E+1023$; so kommt es ohne Vorzeichen aus.
  • Das Mantissenfeld speichert die 52 Stellen hinter dem Komma; die führende 1 ergänzt man beim Lesen.
  • hex zeigt einen float als $\pm$0x1.MantissenfeldpExponent.
  • Python speichert den nächstgelegenen float; für 0.1 ist das $\frac{3602879701896397}{2^{55}}$, um etwa $5{,}6\cdot10^{-18}$ zu groß.
  • Angezeigt wird die kürzeste Dezimalzahl, die denselben float ergibt; angezeigt ist nicht gleich gespeichert.

Rechnen mit Gleitkommazahlen

Begriffe
  • Rundungsfehler – Der dabei entstehende Unterschied heißt Rundungsfehler der Rechnung.
  • Maschinengenauigkeit – Die Maschinengenauigkeit $\varepsilon_{\mathrm M}$ ist der Abstand von 1 zum nächstgrößeren float.
  • absorbiert – Man sagt, er wird absorbiert.
  • Auslöschung – Auslöschung heißt der Verlust gültiger Stellen beim Subtrahieren zweier fast gleicher Zahlen, die schon mit Rundungsfehlern behaftet sind.
  • Überlauf – Ist das gerundete Ergebnis einer Rechnung größer, spricht man vom Überlauf, und das Ergebnis ist der besondere Wert inf (unendlich), bei negativen Ergebnissen -inf.
Formeln
  • Definition 5.2 (Maschinengenauigkeit)
    $$\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2{,}22\cdot10^{-16}.}$$
  • Satz 5.3 (Größe des Rundungsfehlers)
    $$\textcolor{#1b7f4a}{|\tilde x-x|\le\frac{\varepsilon_{\mathrm M}}{2}\,|x|}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}\,|x|}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1{,}11\cdot10^{-16}\,|x| .}$$
Zusammenhänge
  • Jede Rechnung ist exakt gerechnet und dann gerundet; die Fehler einzelner Schritte können sich über viele Schritte summieren.
  • $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}$ ist der Abstand von 1 zum nächsten float; jede Rundung ändert eine Zahl um höchstens den Bruchteil $\varepsilon_{\mathrm M}/2$ ihres Betrags.
  • Ein Summand, der kleiner ist als der halbe Abstand der float beim anderen Summanden, verschwindet beim Addieren.
  • Beim Abziehen fast gleicher, gerundeter Zahlen bleiben nur die fehlerhaften hinteren Stellen übrig.
  • Ergebnisse über $1{,}797\cdot10^{308}$ werden zu inf; mit inf rechnet Python wie mit $\infty$ weiter, nur ** meldet einen OverflowError.
  • nan ist das Ergebnis ungültiger Rechnungen und steckt jede weitere Rechnung an.

Variablen: Namen für Objekte

Begriffe
  • Zuweisung – Eine Zuweisung ist eine Anweisung der Form …
  • Variable – Ein Name, der an ein Objekt gebunden ist, heißt Variable.
  • erweiterte Zuweisung – Für einen arithmetischen Operator $\circ$ aus + - * / // % ** bedeutet die erweiterte Zuweisung name $\circ$= ausdruck bei Zahlen dasselbe wie name = name $\circ$ (ausdruck).
Zusammenhänge
  • name = ausdruck rechnet den Ausdruck aus und bindet den Namen an das Ergebnis.
  • Eine Variable ist ein Name, der an ein Objekt gebunden ist; sie entsteht mit der ersten Zuweisung.
  • Eine Zuweisung heftet ein Etikett an ein Objekt oder hängt es um; sie kopiert nichts.
  • Namen bestehen aus Buchstaben, Ziffern und _, beginnen nicht mit einer Ziffer und sind keine Schlüsselwörter; eingebaute Namen sollte man nicht neu binden.
  • x += a ist für Zahlen die Kurzform von x = x + (a); ebenso -=, *=, /=, //=, %= und **=.
  • Variablen machen aus festen Zahlen benannte Annahmen; die Formeln darunter rechnen mit den Namen.

Wahrheitswerte und Vergleiche

Begriffe
  • Vergleichsoperatoren – Die Vergleichsoperatoren vergleichen zwei Werte und liefern einen bool.
  • gleich bis auf die relative Toleranz – Zwei Zahlen $a$ und $b$ sind gleich bis auf die relative Toleranz $r$, wenn …
Formeln
  • Definition 7.4 (Vergleich mit relativer Toleranz)
    $$|a-b|\le r\cdot\max(|a|,|b|) .$$
Zusammenhänge
  • bool hat die Werte True und False; beim Rechnen zählen sie als 1 und 0.
  • ==, !=, <, <=, >, >= vergleichen zwei Werte und liefern True oder False.
  • Ergebnisse von Gleitkommarechnungen nie mit == vergleichen.
  • Gleitkommazahlen vergleicht man mit relativer Toleranz, $|a-b|\le r\max(|a|,|b|)$; in der Nähe von 0 braucht man zusätzlich eine absolute Toleranz.
  • is fragt, ob zwei Namen dasselbe Objekt meinen, == fragt, ob zwei Werte gleich sind.
  • None bedeutet „kein Wert“; man prüft darauf mit is None.

Module: math und sys

Begriffe
  • Modul – Ein Modul ist eine Datei mit fertigen Python-Definitionen, etwa Funktionen und Werten.
Zusammenhänge
  • import modul lädt ein Modul und bindet seinen Namen; modul.name greift auf seinen Inhalt zu.
  • math enthält die Funktionen des Taschenrechners für float; Winkel stehen im Bogenmaß.
  • math.isclose ist der fertige Toleranzvergleich mit $\textcolor{#1b7f4a}{r}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^{-9}}$ und ohne absolute Toleranz.
  • sys.float_info beschreibt den Typ float, math.ulp den Abstand benachbarter float; beides bestätigt die Rechnungen von Hand.

Komplexe Zahlen

Begriffe
  • Attribut – Ein Attribut ist ein Name, der an einem Objekt hängt und mit einem Punkt abgerufen wird: objekt.name.
Zusammenhänge
  • complex speichert Real- und Imaginärteil als zwei float; die imaginäre Einheit heißt 1j.
  • Ein Attribut ist ein Name am Objekt; z.real und z.imag liefern Real- und Imaginärteil.
  • cmath ist math für komplexe Zahlen; dort hat auch $\sqrt{-1}$ ein Ergebnis.
  • Betrag von Hand mit Pythagoras, Phase mit math.atan2(y, x); fertig mit abs, cmath.phase und cmath.polar.
  • z * cmath.rect(1, alpha) dreht den Punkt $z$ um den Winkel $\alpha$ um den Nullpunkt; abs und cmath.phase zeigen Abstand und Richtung.

Zeichenketten, Eingabe und Ausgabe

Begriffe
  • Verketten – Für Zeichenketten bedeutet + Aneinanderhängen, das Verketten: "Regen" + "schirm" ist "Regenschirm".
  • f-String – Ein f-String ist eine Zeichenkette mit einem f vor dem ersten Anführungszeichen.
  • Typumwandlung – Die Funktionen int, float und str erzeugen aus einem Wert ein neues Objekt mit dem Typ ihres Namens. Das heißt Typumwandlung.
Zusammenhänge
  • Bei Zeichenketten verkettet +, * wiederholt, und len zählt die Zeichen.
  • Ein f-String setzt Werte in {...} in einen Text ein; hinter dem Doppelpunkt legt eine Formatangabe Stellen und Form fest.
  • input fragt nach einer Zeile und liefert sie als str.
  • int, float und str wandeln ausdrücklich um; int schneidet Nachkommastellen ab.
  • round rundet zur nächsten Zahl und bei genauen Hälften zur geraden; int(x + 0.5) klappt nur für positive Zahlen und rundet Hälften immer auf.
  • float(input(...)) liest eine Zahl, ein f-String gibt das Ergebnis mit passend vielen Stellen aus.

Kapitel 3: Entscheidungen und Schleifen

Das Wichtigste bis hier

Bedingungen: Vergleiche und logische Operatoren

Begriffe
  • verketteter Vergleich – Stehen mehrere Vergleichsoperatoren hintereinander, etwa a < b <= c, so heißt der Ausdruck ein verketteter Vergleich.
  • Kurzschlussauswertung – Bei a and b wird b nur ausgewertet, wenn a wahr ist; bei a or b nur, wenn a falsch ist. Diese Regel heißt Kurzschlussauswertung.
  • Wahrheitswert – Jedes Objekt hat einen Wahrheitswert, True oder False; die Typumwandlung bool(x) zeigt ihn an.
Zusammenhänge
  • Ein Vergleich ist ein Ausdruck, dessen Wert True oder False ist.
  • a <= x <= b prüft wie in der Mathematik, ob x zwischen a und b liegt.
  • Zeichenketten vergleicht Python Zeichen für Zeichen nach ihren Nummern; "10" < "9" ist wahr, deshalb Eingaben erst umwandeln, dann vergleichen.
  • not kehrt einen Wahrheitswert um.
  • a and b ist nur wahr, wenn beide wahr sind.
  • a or b ist wahr, sobald einer der beiden wahr ist.
  • not vor and vor or, alle nach den Vergleichen; im Zweifel Klammern.
  • and und or werten den rechten Operanden nur aus, wenn er das Ergebnis noch ändern kann; die schützende Bedingung gehört deshalb nach links.
  • Von den bisher bekannten Werten gelten Null, None, False und die leere Zeichenkette als falsch, alle anderen als wahr.
  • and und or liefern einen ihrer Operanden; wert or ersatz ersetzt jeden falschen Wert, auch eine echte Null.

Entscheidungen: if, elif und else

Begriffe
  • bedingte Anweisung – Eine bedingte Anweisung hat die Form …
  • Kopfzeile – Die erste Zeile heißt Kopfzeile; sie beginnt mit if und endet mit einem Doppelpunkt.
  • Block – Ein Block ist eine Folge von Anweisungen, die alle gleich weit eingerückt sind und auf eine Kopfzeile folgen, also auf eine Zeile mit einem Doppelpunkt am Ende.
Zusammenhänge
  • if Bedingung: führt die eingerückten Zeilen darunter nur aus, wenn die Bedingung wahr ist.
  • Die Einrückung bestimmt, welche Zeilen zu einer Kopfzeile gehören; ein Block endet dort, wo eine Zeile wieder weiter links beginnt.
  • else gibt den Block an, der läuft, wenn die Bedingung falsch ist.
  • Bei if, elif und else läuft genau der Block der ersten wahren Bedingung, sonst der else-Block.
  • == statt =, Doppelpunkt am Ende, jede Teilbedingung vollständig ausschreiben, Gleitkommazahlen mit Toleranz, Eingaben erst umwandeln.
  • Drei sich ausschließende Bereiche einer Größe sind ein Fall für if, elif und else.

Wiederholen mit while

Begriffe
  • Schleife – Eine Anweisung, die einen Block wiederholt, heißt Schleife.
  • while-Schleife – Eine while-Schleife hat die Form …
  • Durchlauf – Eine einzelne Ausführung des Blocks heißt Durchlauf.
  • Endlosschleife – Eine Endlosschleife ist eine Schleife, deren Bedingung nie falsch wird.
Zusammenhänge
  • while Bedingung: wiederholt den Block, solange die Bedingung vor dem Durchlauf wahr ist.
  • Ändert der Block nichts, wovon die Bedingung abhängt, läuft die Schleife endlos; Strg+C bricht sie mit KeyboardInterrupt ab.
  • Eine Schleife nie mit != oder == auf einen float warten lassen; ganzzahlig zählen und den float daraus berechnen.
  • while ist die richtige Schleife, wenn man die Zahl der Durchläufe vorher nicht kennt, sondern nur das Ziel.

Zählen mit for und range

Begriffe
  • for-Schleife – Eine for-Schleife hat die Form …
  • Schleifenvariable – Der Name heißt die Schleifenvariable.
Formeln
  • Definition 4.2 (range)
    $$\textcolor{#1b7f4a}{\mathtt{len}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\max\Bigl(0,\Bigl\lceil\frac{\mathtt{stop}-\mathtt{start}}{\mathtt{schritt}}\Bigr\rceil\Bigr).}$$
Zusammenhänge
  • for k in range(n): führt den Block für $\textcolor{#1b7f4a}{k}\textcolor{#15633a}{=}\textcolor{#c2410c}{0,1,\ldots,n-1}$ aus.
  • range(start, stop, schritt) zählt von start in Schritten bis vor stop; der Stopp gehört nie dazu.
  • Für Schritte mit Gleitkommazahlen zählt range ganzzahlig, und den Wert berechnet man aus dem Zähler.
  • for, wenn die Folge der Werte vorher feststeht; while, wenn nur das Ziel feststeht.

Schleifen steuern, verschachteln und Ergebnisse sammeln

Begriffe
  • verschachtelt – Steht eine Schleife im Block einer anderen, heißen die beiden verschachtelt.
  • Akkumulator – Ein Akkumulator ist ein Name, der vor einer Schleife an einen Startwert gebunden wird und in jedem Durchlauf mit dem neuen Wert verrechnet wird, zum Beispiel mit summe = summe + wert.
Zusammenhänge
  • break beendet eine Schleife sofort, typisch nach einem Fund.
  • continue überspringt den Rest des laufenden Durchlaufs, die Schleife läuft weiter.
  • In verschachtelten Schleifen läuft die innere bei jedem Durchlauf der äußeren ganz durch; break verlässt nur die innere.
  • Ein Akkumulator startet vor der Schleife mit 0 (Summe, Anzahl) oder 1 (Produkt) und nimmt in jedem Durchlauf einen Wert auf.
  • Der Mittelwert ist ein Summen-Akkumulator geteilt durch die Anzahl, das Maximum ein Akkumulator, der nur bei einem größeren Wert ersetzt wird.

Lösungen durch Probieren: Raten und Prüfen, Näherung mit Toleranz

Begriffe
  • Raten und Prüfen, erschöpfende Suche – Raten und Prüfen, auch erschöpfende Suche genannt, geht die möglichen Lösungen in einer festen Reihenfolge durch und prüft jede.
  • Näherung – Eine Zahl $g$ ist eine Näherung von $\sqrt a$ mit der Toleranz $\varepsilon>0$, wenn $|g^2-a|<\varepsilon$ ist.
  • Schrittverfahren – Das einfachste Verfahren, eine solche Näherung zu finden, heißt hier Schrittverfahren: Man beginnt bei $\textcolor{#1b7f4a}{g}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ und erhöht $g$ in festen Schritten der Schrittweite $h$, bis $|g^2-a|<\varepsilon$ ist.
Zusammenhänge
  • Raten und Prüfen findet sicher eine Lösung oder zeigt, dass es keine gibt, braucht aber so viele Schritte, wie es Kandidaten gibt.
  • Mit Gleitkommazahlen sucht man keine exakte Lösung, sondern eine, die eine Toleranz einhält.
  • Die Schrittweite muss kleiner sein als der Bereich, den die Toleranz zulässt, und deshalb wächst die Schrittzahl mit $a/\varepsilon$.

Die Bisektion

Begriffe
  • Bisektion – Die Bisektion wiederholt, solange $\mathit{hi}-\mathit{lo}>\varepsilon$ ist.
Formeln
  • Satz 7.3 (Schrittzahl der Bisektion)
    $$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$
Zusammenhänge
  • Die Bisektion ersetzt in jedem Schritt die Intervallgrenze, die auf derselben Seite der Nullstelle liegt wie die Mitte, durch die Mitte.
  • Mit dem Startintervall $[0,\max(1,a)]$ findet die Bisektion $\sqrt2$ in 41 Schritten auf zwölf Stellen.
  • Die Bisektion braucht $\lceil\log_2(L/\varepsilon)\rceil$ Schritte; jede Verzehnfachung der Genauigkeit kostet nur etwa 3,3 Schritte mehr.

Das Newton-Verfahren

Begriffe
  • Newton-Verfahren – Das Newton-Verfahren für eine Nullstelle einer differenzierbaren Funktion $f$ beginnt mit einem Startwert $g_0$ und berechnet daraus nacheinander …
  • quadratische Konvergenz – Ist $\delta_n$ etwa $10^{-p}$, hat $g_n$ also etwa $p$ gültige Dezimalstellen, dann ist $\delta_{n+1}$ höchstens etwa $10^{-2p}/2$: Aus $p$ gültigen Stellen werden etwa $2p$. Diese Eigenschaft heißt quadratische Konvergenz.
Formeln
  • Definition 8.1 (Newton-Verfahren)
    $$\textcolor{#1b7f4a}{g_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g_n-\frac{f(g_n)}{f'(g_n)},}$$
  • Satz 8.2 (Fehler des Newton-Schritts für die Wurzel)
    $$\textcolor{#1b7f4a}{d_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{d_n^2}{2g_n}.}$$
Zusammenhänge
  • Das Newton-Verfahren springt in jedem Schritt zur Nullstelle der Tangente.
  • Für die Wurzel ist der Newton-Schritt das Heron-Rezept $\frac12(g+a/g)$, und es braucht für $\sqrt2$ fünf Schritte.
  • Beim Newton-Verfahren wird der Fehler in jedem Schritt quadriert, die Zahl der gültigen Stellen verdoppelt sich.
  • Newton braucht eine Ableitung ungleich null, einen Startwert nahe der Lösung und eine passende Toleranz; dann ist es sehr schnell, sonst kann es kreisen, kriechen oder endlos laufen.
  • math.sqrt liefert in einem Aufruf das Ergebnis, das die Verfahren von Hand nur näherungsweise und mit sorgfältig gewählter Toleranz erreichen.
