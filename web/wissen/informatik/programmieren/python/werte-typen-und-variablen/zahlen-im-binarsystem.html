Worum es geht:

Rechner speichern Zahlen als Folgen von Nullen und Einsen. Dieser Abschnitt erklärt das Binärsystem, zeigt, wie man von Hand und mit Python umrechnet, und klärt, welche Brüche sich im Binärsystem mit endlich vielen Stellen schreiben lassen.

Das Stellenwertsystem#

Um zu verstehen, wie ein Rechner Zahlen speichert, muss man zuerst genau sagen, was eine Ziffernfolge wie 4705 eigentlich bedeutet. Dann lässt sich dieselbe Idee auf andere Grundzahlen als 10 übertragen.

Tausender, Hunderter, Zehner, Einer. In 4705 steht die 4 für vier Tausender, die 7 für sieben Hunderter, die 0 für keinen Zehner und die 5 für fünf Einer. Jede Stelle ist zehnmal so viel wert wie die rechts neben ihr.

Definition 3.1 (Stellenwertsystem)

Sei $B\ge2$ eine natürliche Zahl, die Basis. Im Stellenwertsystem zur Basis $B$ steht eine Folge von Ziffern $z_{n-1}\ldots z_1z_0$ mit $0\le z_i<B$ für die Zahl

$$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$

Die Zahl $B^i$ heißt der Stellenwert der Stelle $i$. Gezählt wird von rechts, beginnend bei $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Beispiel

Im gewohnten Dezimalsystem ist $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: $\textcolor{#1b7f4a}{4705}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\cdot10^3+7\cdot10^2+0\cdot10^1+5\cdot10^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{4000+700+0+5}$.

⁠Kurz gesagt: In einem Stellenwertsystem ist jede Ziffer mit dem Stellenwert ihrer Position zu multiplizieren, und alles wird addiert.

Die Binärzahl#

Eine Speicherzelle des Rechners unterscheidet nur zwei Zustände, wie ein Lichtschalter: an oder aus. Für Zahlen braucht man deshalb ein Stellenwertsystem mit nur zwei Ziffern.

Schalter, die verdoppeln. Man stelle sich eine Reihe von Schaltern vor. Der rechte zählt 1, der nächste 2, dann 4, 8, 16: Jeder zählt doppelt so viel wie sein rechter Nachbar. Die Zahl ist die Summe der Werte aller eingeschalteten Schalter.

Definition 3.2 (Binärzahl)

Eine Binärzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. Ihre Ziffern sind 0 und 1.

Eine Binärstelle heißt Bit, nach dem englischen binary digit. Die Bits einer Zahl bezeichnet das Kapitel mit $b_i$, gezählt von rechts ab $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Damit man eine Binärzahl nicht mit einer Dezimalzahl verwechselt, schreibt man die Basis als kleine Zahl dahinter: $10011_2$. Der Wert ist

$$\textcolor{#1b7f4a}{b_{n-1}\ldots b_1b_0\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}b_i\,2^i .}$$

Beispiel

$10011_2$ hat die Bits $\textcolor{#1b7f4a}{b_4}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{b_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, $\textcolor{#1b7f4a}{b_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, $\textcolor{#1b7f4a}{b_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{b_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. Die Rechnung steht Schritt für Schritt in Abb. 3: Die Zahl ist 19.

In Python schreibt man eine Binärzahl mit dem Präfix 0b. Der interaktive Modus zeigt sie als Dezimalzahl an, denn das Objekt ist ein gewöhnlicher int:

Konsole
>>> 0b10011
19
>>> type(0b10011)
<class 'int'>

Die Methode bit_length eines int sagt, wie viele Bits die Zahl ohne führende Nullen braucht:

Konsole
>>> (19).bit_length()
5

⁠Kurz gesagt: Eine Binärzahl hat nur die Ziffern 0 und 1, die Bits; jedes Bit zählt $2^i$.

Das Byte#

Ein einzelnes Bit kann nur zwei Werte unterscheiden. Speicher und Datenübertragung arbeiten deshalb mit Gruppen von Bits fester Größe.

Definition 3.3 (Byte)

Ein Byte ist eine Gruppe von 8 Bit.

Mit $n$ Bit lassen sich $2^n$ verschiedene Muster bilden, denn jedes Bit verdoppelt die Zahl der Möglichkeiten. Ein Byte hat also $\textcolor{#1b7f4a}{2^8}\textcolor{#15633a}{=}\textcolor{#c2410c}{256}$ Muster und kann die ganzen Zahlen von 0 bis 255 darstellen. Speichergrößen zählt man in Byte: Eine Zahl aus 64 Bit belegt 8 Byte.

Beispiel

Die größte Zahl in einem Byte hat alle acht Bits gesetzt. Ihr Wert ist die Summe aller acht Stellenwerte (Abb. 4):

Das Ergebnis ist um eins kleiner als der nächste Stellenwert $\textcolor{#1b7f4a}{2^8}\textcolor{#15633a}{=}\textcolor{#c2410c}{256}$. Das gilt für jede Zahl aus lauter Einsen: $n$ Einsen ergeben $2^n-1$, so wie im Dezimalsystem $\textcolor{#1b7f4a}{999}\textcolor{#15633a}{=}\textcolor{#c2410c}{10^3-1}$ ist.

⁠Kurz gesagt: Ein Byte sind 8 Bit; es kann 256 verschiedene Werte annehmen, die Zahlen 0 bis 255.

Ins Binärsystem umrechnen: erst von Hand, dann fertig#

Abb. 3 rechnet von binär nach dezimal. Für die Gegenrichtung gibt es ein Verfahren, das nur Ganzzahldivision und Rest braucht.

Die Idee. Teilt man eine ganze Zahl $n\ge0$ durch 2, ist der Rest das letzte Bit $b_0$: Alle anderen Stellenwerte $2,4,8,\ldots$ sind gerade, nur $b_0\cdot1$ kann einen ungeraden Anteil liefern. Der Quotient $n\,/\!/\,2$ enthält die übrigen Bits, um eine Stelle nach rechts gerückt. Teilt man ihn wieder durch 2, ist der Rest $b_1$, und so weiter, bis der Quotient 0 ist.

Von Hand. Die Reste, von unten nach oben gelesen, sind die Bits. Im interaktiven Modus erledigt divmod jeden Schritt:

Konsole
>>> divmod(19, 2)
(9, 1)
>>> divmod(9, 2)
(4, 1)
>>> divmod(4, 2)
(2, 0)
>>> divmod(2, 2)
(1, 0)
>>> divmod(1, 2)
(0, 1)
$n$$n\,/\!/\,2$$n\,\%\,2$Bit
1991$b_0$
941$b_1$
420$b_2$
210$b_3$
101$b_4$

Von unten gelesen: $\textcolor{#1b7f4a}{b_4b_3b_2b_1b_0}\textcolor{#15633a}{=}\textcolor{#c2410c}{10011}$, also $\textcolor{#1b7f4a}{19}\textcolor{#15633a}{=}\textcolor{#c2410c}{10011_2}$.

Fertig. Python bringt die Umwandlung mit. Die Funktion bin liefert die Binärdarstellung als Zeichenkette mit dem Präfix 0b; die Funktion format mit der Angabe "b" liefert sie ohne Präfix, mit "08b" auf acht Stellen mit führenden Nullen aufgefüllt. Für den Rückweg nimmt die Funktion int eine Zeichenkette und die Basis:

Konsole
>>> bin(19)
'0b10011'
>>> format(19, "b")
'10011'
>>> format(19, "08b")
'00010011'
>>> int("10011", 2)
19
>>> bin(-19)
'-0b10011'

Negative Zahlen schreibt Python mit einem Minus vor dem Präfix, so wie man sie auch im Dezimalsystem schreibt.

Vergleich. Von Hand und fertig stehen dieselben Bits da: $10011$. Der fertige Weg ist kürzer und macht keine Lesefehler beim Umdrehen der Reste; den Weg von Hand braucht man, um zu verstehen, warum die Reste die Bits sind.

⁠Kurz gesagt: Fortgesetzte Division durch 2 liefert die Bits als Reste, das letzte Bit zuerst; fertig erledigen das bin und format.

Die Hexadezimalzahl#

Bitfolgen werden schnell lang und unübersichtlich: $0011111111111011$ liest niemand fehlerfrei vor. Man braucht eine kürzere Schreibweise, aus der man die Bits trotzdem sofort ablesen kann.

Vier Bits sind eine Ziffer. Vier Bits haben $\textcolor{#1b7f4a}{2^4}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$ Muster. Gibt man jedem dieser 16 Muster ein eigenes Zeichen, kann man jede Bitfolge in Vierergruppen zerlegen und jede Gruppe durch ein Zeichen ersetzen.

Definition 3.4 (Hexadezimalzahl)

Eine Hexadezimalzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$. Die Ziffern sind 0 bis 9 und a bis f für die Werte 10 bis 15.

Weil $\textcolor{#1b7f4a}{16}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^4}$ ist, steht jede Hexadezimalziffer für genau vier Bits:

01234567
89abcdef
10001001101010111100110111101111

Ein Byte sind also genau zwei Hexadezimalziffern.

Beispiel

$\textcolor{#1b7f4a}{255}\textcolor{#15633a}{=}\textcolor{#c2410c}{1111\,1111_2}$ ist hexadezimal $\mathtt{ff}_{16}$, denn $\textcolor{#1b7f4a}{15\cdot16+15}\textcolor{#15633a}{=}\textcolor{#c2410c}{255}$. Die lange Bitfolge vom Anfang zerlegt man von rechts in Vierergruppen: $\textcolor{#1b7f4a}{0011\;1111\;1111\;1011_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathtt{3ffb}_{16}}$. In Python schreibt man Hexadezimalzahlen mit dem Präfix 0x; hex wandelt um, int mit der Basis 16 wandelt zurück:

Konsole
>>> 0xff
255
>>> hex(255)
'0xff'
>>> int("3ffb", 16)
16379
>>> bin(0x3ffb)
'0b11111111111011'

Bei bin fehlen die beiden führenden Nullen der ersten Vierergruppe; Python lässt führende Nullen weg.

⁠Kurz gesagt: Hexadezimal ist die Basis 16; jede Ziffer steht für vier Bits, ein Byte für zwei Ziffern.

Binärbrüche#

Preise, Gewichte und Temperaturen haben Nachkommastellen. Auch sie muss ein Rechner mit Nullen und Einsen schreiben können.

Stellen rechts vom Komma. Im Dezimalsystem bedeuten die Stellen rechts vom Komma Zehntel, Hundertstel, Tausendstel. Im Binärsystem halbiert sich der Stellenwert von Stelle zu Stelle: Halbe, Viertel, Achtel, Sechzehntel.

Definition 3.5 (Binärbruch)

Ein Binärbruch ist eine Zahl mit Stellen rechts vom Komma im Binärsystem. Die Stelle $k$ rechts vom Komma hat den Stellenwert $2^{-k}$:

$$\textcolor{#1b7f4a}{0{,}b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$

Beispiel

$\textcolor{#1b7f4a}{0{,}101_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot\tfrac12+0\cdot\tfrac14+1\cdot\tfrac18}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac58}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}625}$ und $\textcolor{#1b7f4a}{0{,}011_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac14+\tfrac18}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac38}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}375}$.

Nicht jeder Bruch hat einen endlichen Binärbruch. Im Dezimalsystem ist das vertraut: $\textcolor{#1b7f4a}{\frac14}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}25}$ endet, $\textcolor{#1b7f4a}{\frac13}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}333\ldots}$ nicht. Welche Zahlen im Binärsystem enden, sagt der folgende Satz.

Satz 3.6 (Endliche Binärbrüche)

Eine Zahl $x$ lässt sich genau dann als Binärbruch mit endlich vielen Stellen schreiben, wenn es eine ganze Zahl $p\ge0$ gibt, sodass $x\cdot2^p$ eine ganze Zahl ist.

Beweis: Komma verschieben

Multiplizieren mit $2^p$ verschiebt im Binärsystem das Komma um $p$ Stellen nach rechts, so wie Multiplizieren mit $10^p$ im Dezimalsystem.

Hat $x$ höchstens $p$ Stellen rechts vom Komma, steht nach dem Verschieben keine Stelle mehr rechts vom Komma, und $x\cdot2^p$ ist ganz.

Ist umgekehrt $\textcolor{#1b7f4a}{x\cdot2^p}\textcolor{#15633a}{=}\textcolor{#c2410c}{n}$ ganz, hat $n$ eine endliche Binärdarstellung. Verschiebt man darin das Komma um $p$ Stellen nach links, erhält man $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{n\cdot2^{-p}}$ mit höchstens $p$ Stellen rechts vom Komma.

Anwendung auf $\frac38$ und $\frac1{10}$. $\textcolor{#1b7f4a}{\frac38\cdot2^3}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ ist ganz, also endet der Binärbruch, und zwar nach drei Stellen. Für $\frac1{10}$ ist $\textcolor{#1b7f4a}{\frac1{10}\cdot2^p}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{2^{p}}{10}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{2^{p-1}}{5}}$. Eine Zweierpotenz ist aber nie durch 5 teilbar, denn ihre einzigen Primfaktoren sind Zweien. Für kein $p$ ist das ganz: $0{,}1$ hat im Binärsystem unendlich viele Stellen. Dasselbe gilt für jeden gekürzten Bruch, in dessen Nenner ein anderer Primfaktor als 2 steckt, etwa $\textcolor{#1b7f4a}{0{,}2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac15}$ und $\textcolor{#1b7f4a}{0{,}3}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac3{10}}$.

⁠Kurz gesagt: Ein Binärbruch endet genau dann, wenn der gekürzte Nenner eine Zweierpotenz ist; $0{,}1$ endet nicht.

Das Verdopplungsverfahren#

Wie sehen die unendlich vielen Binärstellen von $0{,}1$ aus? Für die Stellen rechts vom Komma gibt es ein Verfahren, das dem Teilen durch 2 bei ganzen Zahlen entspricht.

Die Idee. Multipliziert man einen Binärbruch $0{,}b_{-1}b_{-2}b_{-3}\ldots{}_2$ mit 2, rückt das Komma eine Stelle nach rechts: Es entsteht $b_{-1}{,}b_{-2}b_{-3}\ldots{}_2$. Vor dem Komma steht jetzt die erste Stelle $b_{-1}$, also 0 oder 1, und dahinter der Rest. Mit dem Rest wiederholt man das.

Definition 3.7 (Verdopplungsverfahren)

Für $0\le x<1$ bestimmt das Verdopplungsverfahren die Binärstellen von $x$: Man verdoppelt $x$. Der ganzzahlige Teil des Ergebnisses, 0 oder 1, ist die nächste Stelle; mit dem Anteil rechts vom Komma macht man weiter. Das Verfahren endet, wenn dieser Anteil 0 ist.

Beispiel 1$0{,}625$

$\textcolor{#1b7f4a}{2\cdot0{,}625}\textcolor{#15633a}{=}\textcolor{#c2410c}{1{,}25}$, Stelle 1, weiter mit $0{,}25$. $\textcolor{#1b7f4a}{2\cdot0{,}25}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}5}$, Stelle 0. $\textcolor{#1b7f4a}{2\cdot0{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{1{,}0}$, Stelle 1, Rest 0, fertig: $\textcolor{#1b7f4a}{0{,}625}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}101_2}$, wie im letzten Unterabschnitt.

Beispiel 2$0{,}1$

Damit sich keine Rundung einschleicht, rechnet man mit dem Bruch $\frac{z}{10}$ und verdoppelt nur den ganzzahligen Zähler $z$. Ist $2z\ge10$, ist die Stelle 1 und man zieht 10 ab; sonst ist die Stelle 0:

SchrittBruchverdoppeltStelle

2$2/10$$4/10$0

4$8/10$$\textcolor{#1b7f4a}{16/10}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+6/10}$1

In Schritt 6 steht derselbe Bruch $2/10$ wie in Schritt 2. Von da an wiederholt sich alles, und die Stellen $0011$ kehren endlos wieder:

$$\textcolor{#1b7f4a}{0{,}1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}0\,0011\,0011\,0011\ldots{}_2 .}$$

Wie nahe man $0{,}1$ mit den ersten Stellen kommt, zeigt die Summe der Stellenwerte. Die Einsen kommen paarweise: an den Stellen 4 und 5, dann 8 und 9, dann 12 und 13 und so weiter. Ein Paar an den Stellen $4k$ und $4k+1$ ist $\textcolor{#1b7f4a}{2^{-4k}+2^{-(4k+1)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3\cdot2^{-(4k+1)}}$ wert. Die ersten vier Paare, also die ersten 17 Stellen, ergeben (Abb. 5)

Die Summe kommt $0{,}1$ immer näher, erreicht es aber mit keiner endlichen Zahl von Stellen. Der Fehler nach den 17 Stellen ist $\textcolor{#1b7f4a}{0{,}1-\frac{13107}{131072}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{655360}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}1\cdot2^{-16}}$: Hinter Stelle 17 steht wieder dasselbe Muster wie in $0{,}1$ selbst, nur um 16 Stellen nach rechts gerückt.

⁠Kurz gesagt: Verdoppeln schiebt die nächste Binärstelle vor das Komma; für $0{,}1$ ergibt das die unendliche Folge $0{,}0\,0011\,0011\ldots{}_2$.

HintergrundWarum sich die Stellen wiederholen müssen

Im Verfahren für $0{,}1$ steht nach jedem Schritt ein Bruch $\frac{z}{10}$ mit einem Zähler $z$ von 0 bis 9. Es gibt also nur zehn mögliche Zustände. Spätestens nach zehn Schritten muss einer davon zum zweiten Mal auftreten, und weil jeder Schritt nur vom aktuellen Bruch abhängt, wiederholt sich von da an alles. Dasselbe Argument zeigt, dass jeder Bruch $\frac{z}{q}$ in jedem Stellenwertsystem entweder endet oder periodisch wird, mit einer Periode von weniger als $q$ Stellen. Im Dezimalsystem kennt man das von $\textcolor{#1b7f4a}{\frac17}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}\overline{142857}}$.

Aufgabe 10 ★★ Endlich oder nicht?

Entscheide mit Satz 3.6, welche Zahlen einen endlichen Binärbruch haben, und gib ihn gegebenenfalls an: $0{,}75$; $0{,}2$; $0{,}375$; $\frac13$; $0{,}05$; $12{,}5$.

Lösung

Nach Satz 3.6 kommt es darauf an, ob der gekürzte Nenner eine Zweierpotenz ist:

  • $\textcolor{#1b7f4a}{0{,}75}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac34}$, Nenner $\textcolor{#1b7f4a}{4}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^2}$: endlich, $0{,}11_2$.

  • $\textcolor{#1b7f4a}{0{,}2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac15}$: Nenner 5, nicht endlich.

  • $\textcolor{#1b7f4a}{0{,}375}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac38}$, Nenner $2^3$: endlich, $0{,}011_2$.

  • $\frac13$: Nenner 3, nicht endlich.

  • $\textcolor{#1b7f4a}{0{,}05}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1{20}}$, Nenner $\textcolor{#1b7f4a}{20}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\cdot5}$ enthält 5: nicht endlich.

  • $\textcolor{#1b7f4a}{12{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{25}2}$: endlich, $\textcolor{#1b7f4a}{12{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{8+4+\frac12}\textcolor{#15633a}{=}\textcolor{#c2410c}{1100{,}1_2}$.

Aufgabe 11 ★★ Wie fein wiegt eine Küchenwaage?

Eine digitale Küchenwaage speichert jedes Gewicht als ganze Zahl aus 12 Bit. Der Bereich von 0 bis $5\,\mathrm{kg}$ wird dabei in gleich breite Stufen geteilt, eine Stufe für jedes Bitmuster.

  1. Wie viele Stufen gibt es, und welche Zahl speichert die Waage höchstens?

  2. Wie breit ist eine Stufe in Gramm? Rechne mit Python.

  3. Ist die Stufenbreite in Kilogramm ein endlicher Binärbruch? Begründe mit Satz 3.6.

Lösung

(a) 12 Bit haben $\textcolor{#1b7f4a}{2^{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4096}$ Muster, also 4096 Stufen. Die größte Zahl ist $\textcolor{#1b7f4a}{4095}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{12}-1}$, zwölf Einsen.

(b)

Konsole
>>> 2 ** 12
4096
>>> 5 / 4096 * 1000
1.220703125

Eine Stufe ist $1{,}220703125\,\mathrm g$ breit: Gewichte, die weniger als eine Stufe auseinanderliegen, kann diese Waage nicht sicher unterscheiden.

(c) $\textcolor{#1b7f4a}{\frac5{4096}\cdot2^{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ ist ganz, also ist die Stufenbreite ein endlicher Binärbruch: $\textcolor{#1b7f4a}{\frac{5}{4096}}\textcolor{#15633a}{=}\textcolor{#c2410c}{101_2\cdot2^{-12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}000000000101_2}$. Deshalb zeigt Python auch keine Rundungsstellen: Das Ergebnis ist exakt, denn auch $\textcolor{#1b7f4a}{1{,}220703125}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{625}{512}}$ hat einen Nenner, der eine Zweierpotenz ist.

Zusammenfassung

Begriffe
  • Basis – Sei $B\ge2$ eine natürliche Zahl, die Basis.
  • Binärzahl – Eine Binärzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$.
  • Bit – Eine Binärstelle heißt Bit, nach dem englischen binary digit.
  • Byte – Ein Byte ist eine Gruppe von 8 Bit.
  • Hexadezimalzahl – Eine Hexadezimalzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$.
2 weitere zeigen
  • Binärbruch – Ein Binärbruch ist eine Zahl mit Stellen rechts vom Komma im Binärsystem.
  • Verdopplungsverfahren – Für $0\le x<1$ bestimmt das Verdopplungsverfahren die Binärstellen von $x$: Man verdoppelt $x$.
Formeln
  • Definition 3.1 (Stellenwertsystem)
    $$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$
  • Definition 3.5 (Binärbruch)
    $$\textcolor{#1b7f4a}{0{,}b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$
Zusammenhänge
  • In einem Stellenwertsystem ist jede Ziffer mit dem Stellenwert ihrer Position zu multiplizieren, und alles wird addiert.
  • Eine Binärzahl hat nur die Ziffern 0 und 1, die Bits; jedes Bit zählt $2^i$.
  • Ein Byte sind 8 Bit; es kann 256 verschiedene Werte annehmen, die Zahlen 0 bis 255.
  • Fortgesetzte Division durch 2 liefert die Bits als Reste, das letzte Bit zuerst; fertig erledigen das bin und format.
  • Hexadezimal ist die Basis 16; jede Ziffer steht für vier Bits, ein Byte für zwei Ziffern.
2 weitere zeigen
  • Ein Binärbruch endet genau dann, wenn der gekürzte Nenner eine Zweierpotenz ist; $0{,}1$ endet nicht.
  • Verdoppeln schiebt die nächste Binärstelle vor das Komma; für $0{,}1$ ergibt das die unendliche Folge $0{,}0\,0011\,0011\ldots{}_2$.
