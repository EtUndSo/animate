Das Wichtigste bis hier

  • Jeder Wert ist ein Objekt mit Typ, Identität und Wert; type und id zeigen Typ und Identität. Der Typ legt fest, was erlaubt ist; Methoden ruft man mit objekt.name() auf.

  • int ist exakt und beliebig groß. / liefert immer einen float; // rundet nach $-\infty$, und es gilt $\textcolor{#1b7f4a}{a}\textcolor{#15633a}{=}\textcolor{#c2410c}{(a\,/\!/\,b)\cdot b+a\,\%\,b}$ mit dem Rest im Vorzeichen von $b$. ** geht vor dem Vorzeichen und gruppiert von rechts.

  • Binärzahl: $\sum b_i2^i$; Bit, Byte (8 Bit, 0 bis 255), hexadezimal (4 Bit je Ziffer). Ein Bruch endet binär genau dann, wenn sein gekürzter Nenner eine Zweierpotenz ist; $\textcolor{#1b7f4a}{0{,}1}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}0\,0011\,0011\ldots{}_2}$.

  • float = binary64: $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s(1+t/2^{52})\cdot2^{c-1023}}$, 53 Stellen Mantisse, Bereich bis $1{,}8\cdot10^{308}$. Gespeichert wird der nächste float, bei Gleichstand der mit gerader Mantisse; 0.1 ist $3602879701896397/2^{55}$. Angezeigt wird die kürzeste Dezimalzahl, die denselben float ergibt.

  • Jede Rechnung wird gerundet, relativ höchstens um $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}}$; $\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2{,}2\cdot10^{-16}}$. Fehler summieren sich, kleine Summanden werden absorbiert, fast gleiche Zahlen löschen sich aus. Überlauf ergibt inf, ungültige Rechnungen nan.

  • Eine Zuweisung bindet einen Namen an ein Objekt und kopiert nichts. Namen: Buchstaben, Ziffern, _, keine Ziffer vorn, kein Schlüsselwort. x += a heißt x = x + (a).

  • Vergleiche liefern bool. Gleitkommazahlen vergleicht man mit Toleranz, $|a-b|\le\max(r\max(|a|,|b|),t_{\mathrm{abs}})$, fertig mit math.isclose. is prüft die Identität, etwa x is None.

  • import modul bindet einen Modulnamen; math für reelle, cmath für komplexe Funktionen, sys.float_info für die Grenzen des float.

  • complex: zwei float, imaginäre Einheit 1j, Attribute real und imag; Betrag abs, Phase cmath.phase oder von Hand math.atan2(y, x).

  • Text: + verkettet, * wiederholt, len zählt; f-Strings mit Formatangaben; input liefert immer str; int, float, str wandeln um; round rundet zur nächsten, bei Hälften zur geraden Zahl.

Die Antwort in drei Sätzen

  1. Jeder Wert ist ein Objekt, dessen Typ festlegt, wie der Wert gespeichert wird und was man mit ihm tun kann; Namen sind nur Etiketten, die eine Zuweisung an Objekte heftet.

  2. Ein int speichert ganze Zahlen exakt mit beliebig vielen Stellen, ein float speichert jede Zahl als Binärbruch mit 53 Stellen mal einer Zweierpotenz, deshalb ist schon $0{,}1$ nur genähert und jedes Rechenergebnis relativ um bis zu $2^{-53}$ gerundet.

  3. Daraus folgen die Arbeitsregeln: Gleitkommazahlen mit Toleranz vergleichen, Rundungsfehler bei vielen Schritten und beim Abziehen fast gleicher Zahlen erwarten, und Text und Zahlen ausdrücklich ineinander umwandeln.

Ein Prinzip hinter allen Ergebnissen. Fast alles in diesem Kapitel folgt daraus, dass der Typ eines Objekts festlegt, wie sein Wert im Speicher steht: als Ziffernfolge beliebiger Länge, als Binärbruch mit 53 Stellen und einem Exponenten, als Paar solcher Binärbrüche oder als Folge von Zeichen. Aus dieser Darstellung ergeben sich die Rechenregeln.
