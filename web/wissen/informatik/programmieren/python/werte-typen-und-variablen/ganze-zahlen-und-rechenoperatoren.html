Ganze Zahlen und Rechenoperatoren

  • Deutsch
  • English
  • Español
  • Français
  • Türkçe
  • 中文
Worum es geht:

Ganze Zahlen sind der einfachste Zahlentyp von Python. Dieser Abschnitt zeigt, wie groß sie werden können, welche Rechenoperatoren Python kennt und wie es ganzzahlig teilt, auch bei negativen Zahlen.

Der Typ int

Stückzahlen, Punktestände, Seitenzahlen, Kontonummern: Vieles im Alltag ist ganzzahlig. Dort will man exakt rechnen, ohne jede Rundung, auch wenn die Zahlen sehr groß werden.

Ziffern, so viele wie nötig. Auf Papier schreibt man eine ganze Zahl mit so vielen Ziffern, wie sie braucht. Eine dreistellige Zahl braucht drei Ziffern, eine dreißigstellige dreißig. Genau so geht Python mit ganzen Zahlen um.

Definition 2.1 (Der Typ int)

Der Typ int umfasst die ganzen Zahlen $\ldots,-2,-1,0,1,2,\ldots$ Ein Objekt vom Typ int hat keine feste Größe: Es wird so groß, wie die Zahl es verlangt, und ist nur durch den Arbeitsspeicher begrenzt. Addieren, Subtrahieren und Multiplizieren zweier int liefert immer das exakte Ergebnis als int.

Man schreibt einen int als Folge von Ziffern ohne Punkt, negative Zahlen mit einem Minus davor. Lange Zahlen darf man mit Unterstrichen gliedern: 1_000_000 ist dieselbe Zahl wie 1000000.

Beispiel

$2^{100}$ hat 31 Stellen und wird exakt ausgerechnet. Auch eine Rechnung, bei der eine kleine Zahl zwischen zwei riesigen steht, geht nicht verloren:

Konsole
>>> 2 ** 100
1267650600228229401496703205376
>>> 10 ** 20 + 1 - 10 ** 20
1
>>> 1_000_000 * 1_000_000
1000000000000

⁠Kurz gesagt: Ein int ist eine ganze Zahl beliebiger Größe; Python rechnet mit ihr exakt.

HintergrundWarum ein int in Python nie überläuft

Ein Prozessor rechnet mit ganzen Zahlen fester Größe. Eine übliche Größe reicht bis $18\,446\,744\,073\,709\,551\,615$; was darüber hinausgeht, schneidet der Maschinenbefehl ab, und das Ergebnis ist falsch. Die ganzzahligen Typen der Sprache C haben solche festen Grenzen.

CPython speichert einen int deshalb nicht als eine einzige Maschinenzahl, sondern wie eine Zahl auf Papier: als Folge von Ziffern. Nur ist die Basis nicht 10, sondern $\textcolor{#1b7f4a}{2^{30}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\,073\,741\,824}$. Jede „Ziffer“ ist eine Zahl von 0 bis $2^{30}-1$ und belegt ein eigenes Speicherwort; das Vorzeichen steht getrennt davor. Wird eine Zahl größer, hängt CPython weitere Ziffern an. Gerechnet wird wie beim schriftlichen Rechnen in der Schule: Ziffer für Ziffer mit Übertrag, jeder Schritt mit gewöhnlichen Maschinenbefehlen. Der Preis ist Zeit: Eine Addition großer Zahlen braucht viele Maschinenbefehle statt eines einzigen.

HintergrundEine Grenze gibt es doch: 4300 Dezimalstellen bei der Umwandlung in Text

Rechnen kann Python mit beliebig großen int. Für die Anzeige muss es die Zahl aber in Dezimalziffern umwandeln, und das ist bei riesigen Zahlen viel aufwendiger als jede Addition: Der Aufwand wächst deutlich schneller als die Zahl der Stellen. Ein Angreifer könnte einem Server, der Zahlen aus Texten liest, eine Zahl mit Millionen Stellen schicken und ihn damit lange beschäftigen. Seit Python 3.11 verweigert Python deshalb Umwandlungen mit mehr als 4300 Dezimalstellen. Die Lücke ist unter der Kennung CVE-2020-10735 öffentlich beschrieben.

Konsole
>>> 10 ** 5000
Traceback (most recent call last):
  File "<python-input-0>", line 1, in <module>
    10 ** 5000
    ~~~^^~~~~~
ValueError: Exceeds the limit (4300 digits) for integer string conversion; use sys.set_int_max_str_digits() to increase the limit

Ausgerechnet ist die Zahl; nur die Anzeige scheitert. Die Meldung nennt den Weg, die Grenze zu verschieben. Umwandlungen in Systeme mit einer Zweierpotenz als Basis sind ausgenommen, weil sie schnell gehen.

Operator und Operand

Kapitel 1 hat die Zeichen + - * / ** Rechenzeichen genannt (Kapitel 1, Abschnitt 4.4). Python kennt weitere solche Zeichen, und es gibt einen allgemeinen Namen für sie.

Eine kleine Maschine. Ein Rechenzeichen nimmt Werte entgegen und gibt einen neuen Wert heraus, wie eine kleine Maschine mit Eingängen und einem Ausgang.

Definition 2.2 (Operator und Operand)

Ein Operator ist ein Zeichen, das aus Werten einen neuen Wert berechnet.

Die Werte, auf die ein Operator wirkt, heißen seine Operanden.

Ein Operator mit zwei Operanden heißt zweistellig, einer mit nur einem Operanden einstellig. In 7 - 2 ist das Minus zweistellig, in -7 einstellig: Es macht aus 7 die Zahl $-7$.

Python hat sieben arithmetische Operatoren:

OperatorBedeutungBeispiel
+Addition7 + 2 ergibt 9
-Subtraktion; einstellig: Vorzeichen7 - 2 ergibt 5
*Multiplikation7 * 2 ergibt 14
/Division7 / 2 ergibt 3.5
//Ganzzahldivision7 // 2 ergibt 3
%Rest7 % 2 ergibt 1
**Potenz7 ** 2 ergibt 49

Welchen Typ das Ergebnis hat. Sind beide Operanden ein int, ist auch das Ergebnis ein int, mit einer Ausnahme: Die Division / liefert immer einen float. Ist mindestens ein Operand ein float, verwandelt Python den anderen ebenfalls in einen float, und das Ergebnis ist ein float:

Konsole
>>> 7 + 2
9
>>> 7 + 0.5
7.5
>>> 2 * 3.0
6.0

⁠Kurz gesagt: Ein Operator berechnet aus seinen Operanden einen neuen Wert; ist ein Operand ein float, ist es auch das Ergebnis.

Die Division

Preis durch Gewicht, Strecke durch Zeit: Die gewöhnliche Division braucht man ständig, und sie soll das Ergebnis liefern, das man aus der Mathematik kennt.

Definition 2.3 (Division)

Der Operator / teilt den linken Operanden durch den rechten. Das Ergebnis ist immer ein float, auch wenn beide Operanden ein int sind und die Division aufgeht.

Beispiel

Das erklärt die Beobachtung aus Kapitel 1, dass 12 / 4 die Antwort 3.0 liefert:

Konsole
>>> 7 / 2
3.5
>>> 12 / 4
3.0
>>> 1 / 3
0.3333333333333333
>>> 7 / 0
Traceback (most recent call last):
  File "<python-input-3>", line 1, in <module>
    7 / 0
    ~~^~~
ZeroDivisionError: division by zero

Durch null teilen geht nicht; Python meldet einen ZeroDivisionError. Teilt man einen float durch null, lautet die Beschreibung in Python 3.13 float division by zero, ab Python 3.14 wie bei ganzen Zahlen division by zero.

⁠Kurz gesagt: / teilt wie in der Mathematik und liefert immer einen float.

HintergrundWarum / auch bei ganzen Zahlen einen float liefert

In den alten Versionen 2.x der Sprache Python ergab 7 / 2 die ganze Zahl 3, wie in C: Bei zwei ganzen Zahlen wurde ganzzahlig geteilt, bei Gleitkommazahlen gewöhnlich. Das Ergebnis hing also davon ab, welchen Typ die Werte gerade hatten, und nicht davon, was der Programmierer meinte. Eine Rechnung wie „Summe der Noten durch ihre Anzahl“ lieferte mit den Noten 4.0 und 5.0 den Wert 4,5, mit denselben Noten als 4 und 5 still den Wert 4. Weil man in Python nirgends festlegt, welchen Typ ein Wert haben muss, gerieten ganze Zahlen leicht in solche Rechnungen.

Mit Python 3.0 (2008) wurde die Bedeutung deshalb getrennt: / teilt immer wie in der Mathematik, und wer ganzzahlig teilen will, schreibt dafür einen eigenen Operator. Ein Ausdruck bedeutet seitdem dasselbe, egal ob ganze Zahlen oder Gleitkommazahlen in ihn hineinkommen.

Ganzzahldivision und Rest

125 Minuten sind 2 Stunden und 5 Minuten. Für solche Rechnungen braucht man zwei Zahlen: wie oft 60 ganz in 125 passt, und was übrig bleibt.

Vielfache auf dem Zahlenstrahl. Man markiert auf dem Zahlenstrahl alle Vielfachen des Teilers, etwa alle Vielfachen von 2. Jede ganze Zahl $a$ liegt dann entweder auf einem Vielfachen oder zwischen zweien. Das nächste Vielfache links von $a$ (oder $a$ selbst) ist $q\cdot2$; der Abstand von dort bis $a$ ist der Rest (Abb. 2). Für $\textcolor{#1b7f4a}{a}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$ ist das Vielfache $\textcolor{#1b7f4a}{6}\textcolor{#15633a}{=}\textcolor{#c2410c}{3\cdot2}$ und der Rest 1. Für $\textcolor{#1b7f4a}{a}\textcolor{#15633a}{=}\textcolor{#c2410c}{-7}$ ist das nächste Vielfache links $\textcolor{#1b7f4a}{-8}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-4)\cdot2}$, nicht $-6$, und der Rest ist wieder 1.

Definition 2.4 (Ganzzahldivision und Rest)

Für ganze Zahlen $a$ und $b\ne0$ ist a // b die größte ganze Zahl, die nicht größer ist als $a/b$. Das ist der Quotient, nach unten gerundet, also in Richtung $-\infty$.

Der Rest ist a % b $=a-(a\,/\!/\,b)\cdot b$.

Der Operator // heißt Ganzzahldivision, der Operator % liefert den Rest. Aus der Definition folgen zwei Regeln, die man sich merken sollte.

Satz 2.5 (Ganzzahldivision und Rest)

Für alle ganzen Zahlen $a$ und $b\ne0$ gilt

$$\textcolor{#1b7f4a}{a }\textcolor{#15633a}{=}\textcolor{#c2410c}{ (a\,/\!/\,b)\cdot b + a\,\%\,b .}$$
(2.1)

Für $b>0$ liegt der Rest im Bereich $0\le a\,\%\,b<b$, für $b<0$ im Bereich $b<a\,\%\,b\le0$. Der Rest hat also immer das Vorzeichen von $b$ oder ist null.

Beweis: aus der Definition

(2.1) ist die Definition des Rests, nach $a$ aufgelöst. Sei $b>0$ und $\textcolor{#1b7f4a}{q}\textcolor{#15633a}{=}\textcolor{#c2410c}{a\,/\!/\,b}$. Weil $q$ die größte ganze Zahl mit $q\le a/b$ ist, gilt $q\le a/b<q+1$. Multipliziert man mit $b>0$, folgt $qb\le a<qb+b$, also $0\le a-qb<b$, und $a-qb$ ist der Rest. Für $b<0$ dreht die Multiplikation beide Ungleichungen um: $qb\ge a>qb+b$, also $0\ge a-qb>b$.

Beispiel

Zuerst positive Zahlen, dann negative:

Konsole
>>> 125 // 60
2
>>> 125 % 60
5
>>> -7 // 2
-4
>>> -7 % 2
1
>>> 7 // -2
-4
>>> 7 % -2
-1

Die Probe mit (2.1): $\textcolor{#1b7f4a}{2\cdot60+5}\textcolor{#15633a}{=}\textcolor{#c2410c}{125}$, $\textcolor{#1b7f4a}{(-4)\cdot2+1}\textcolor{#15633a}{=}\textcolor{#c2410c}{-7}$ und $\textcolor{#1b7f4a}{(-4)\cdot(-2)+(-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$. Bei $-7\,/\!/\,2$ ist $\textcolor{#1b7f4a}{-7/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3{,}5}$, und die größte ganze Zahl, die nicht größer ist, ist $-4$, nicht $-3$.

Die eingebaute Funktion divmod liefert beide Ergebnisse auf einmal, zuerst den Quotienten, dann den Rest. Beide Operatoren funktionieren auch mit Gleitkommazahlen:

Konsole
>>> divmod(125, 60)
(2, 5)
>>> divmod(-7, 2)
(-4, 1)
>>> 7.5 // 2
3.0
>>> 7.5 % 2
1.5

⁠Kurz gesagt: // rundet den Quotienten nach unten, Richtung $-\infty$; % ist der Rest dazu und hat das Vorzeichen des rechten Operanden.

HintergrundWarum Python Richtung $-\infty$ rundet und nicht Richtung null

In C rundet die ganzzahlige Division Richtung null: Dort ist $\textcolor{#1b7f4a}{-7/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3}$, und damit die Gleichung (2.1) gilt, muss der Rest $-1$ sein. Python rundet nach unten, weil dann der Rest für $b>0$ immer zwischen 0 und $b-1$ liegt, egal welches Vorzeichen $a$ hat. Das ist genau die Eigenschaft, die man bei allem braucht, was sich periodisch wiederholt:

  • ⁠Uhrzeit: Zählt eine Uhr Sekunden seit einem Bezugszeitpunkt, ist t % 86400 die Sekunde des Tages, auch für Zeitpunkte vor dem Bezugszeitpunkt, also für negative $t$. Eine Sekunde vor Mitternacht ist -1 % 86400, das ergibt 86399, also 23:59:59.

  • ⁠Winkel: Eine Drehung um $-90^\circ$ endet in derselben Richtung wie eine Drehung um $270^\circ$. -90 % 360 ergibt 270, jeder Winkel landet im Bereich von $0^\circ$ bis unter $360^\circ$.

Hat man sich für diesen Rest entschieden, liegt der Quotient fest: Nach (2.1) ist $\textcolor{#1b7f4a}{q}\textcolor{#15633a}{=}\textcolor{#c2410c}{(a-r)/b}$, und das ist der abgerundete Quotient. In der Zahlentheorie ist dieselbe Wahl üblich. Dass C anders rechnet, hat vermutlich geschichtliche Gründe: Die Rechenwerke der damaligen Prozessoren teilten Richtung null, und seit 1999 schreibt die Norm der Sprache C diese Rundung fest vor.

Die Potenz

Zehnerpotenzen für sehr große und sehr kleine Zahlen, Zweierpotenzen für Speichergrößen, Quadrate für Flächen, Zinseszinsen: Potenzen kommen in vielen Rechnungen vor. Kapitel 1 hat ** mit positiven ganzen Exponenten benutzt und 2 ** 0.5 für die Wurzel. Für den Typ des Ergebnisses, für negative Exponenten und für Minuszeichen in der Nähe gelten eigene Regeln.

Definition 2.6 (Potenz)

a ** b ist $a$ hoch $b$. Sind $a$ und $b$ ein int und ist $b\ge0$, ist das Ergebnis ein int; ist $b$ ein negativer int, ist es ein float. Ist einer der Operanden ein float, ist das Ergebnis ebenfalls ein float; nur eine negative Basis mit einem nicht ganzzahligen Exponenten liefert etwas anderes. Außerdem gilt:

  • ** bindet stärker als ein Minuszeichen links davon: -2 ** 2 ist $\textcolor{#1b7f4a}{-(2^2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-4}$.

  • Mehrere ** wertet Python von rechts nach links aus: 2 ** 3 ** 2 ist $\textcolor{#1b7f4a}{2^{(3^2)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^9}\textcolor{#15633a}{=}\textcolor{#c2410c}{512}$.

Beispiel

Negative Exponenten, Minuszeichen und Potenztürme:

Konsole
>>> 2 ** -1
0.5
>>> 10 ** -3
0.001
>>> -2 ** 2
-4
>>> (-2) ** 2
4
>>> 2 ** 3 ** 2
512
>>> (2 ** 3) ** 2
64
>>> 0 ** 0
1

0 ** 0 ist in Python festgelegt als 1, wie in den meisten Programmiersprachen.

⁠Kurz gesagt: ** bindet stärker als ein Minus davor und wird von rechts nach links ausgewertet; ein negativer Exponent liefert einen float.

HintergrundWarum Python die Potenz so liest wie die Mathematik

Beide Regeln stammen aus der mathematischen Schreibweise. $-2^2$ bedeutet dort $\textcolor{#1b7f4a}{-(2^2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-4}$; wer $(-2)^2$ meint, setzt Klammern. Ein Potenzturm $a^{b^c}$ bedeutet $a^{(b^c)}$, weil die andere Lesart keinen Turm braucht: $\textcolor{#1b7f4a}{(a^b)^c}\textcolor{#15633a}{=}\textcolor{#c2410c}{a^{b\cdot c}}$ schreibt man einfacher mit einem einzigen Exponenten. Python übernimmt beides, damit Formeln aus dem Lehrbuch ohne Umdenken in den Quelltext wandern können. Ein Minus rechts vom Operator gehört dagegen zum Exponenten: 2 ** -1 ist $\textcolor{#1b7f4a}{2^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}5}$.

Die Rangfolge

Ein Ausdruck wie 2 + 3 * 4 ** 2 // 5 enthält vier Operatoren. Python braucht eine feste Regel, in welcher Reihenfolge es sie anwendet.

Definition 2.7 (Rangfolge)

Die Rangfolge der Operatoren legt fest, welcher Operator in einem Ausdruck ohne Klammern zuerst ausgeführt wird. Für die arithmetischen Operatoren gilt, vom stärksten zum schwächsten:

RangOperatorenbei gleichem Rang
1**von rechts nach links
2einstelliges + und -
3* / // %von links nach rechts
4zweistelliges + und -von links nach rechts

Klammern gehen allem vor.

Beispiel

2 + 3 * 4 ** 2 // 5 wertet Python so aus: zuerst die Potenz $\textcolor{#1b7f4a}{4^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$, dann von links nach rechts $\textcolor{#1b7f4a}{3\cdot16}\textcolor{#15633a}{=}\textcolor{#c2410c}{48}$ und $\textcolor{#1b7f4a}{48\,/\!/\,5}\textcolor{#15633a}{=}\textcolor{#c2410c}{9}$, zuletzt $\textcolor{#1b7f4a}{2+9}\textcolor{#15633a}{=}\textcolor{#c2410c}{11}$. Bei 12 / 3 / 2 haben beide Operatoren denselben Rang, also gilt $\textcolor{#1b7f4a}{(12/3)/2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$:

Konsole
>>> 2 + 3 * 4 ** 2 // 5
11
>>> 100 - 7 % 3 * 2
98
>>> 12 / 3 / 2
2.0
>>> -3 ** 2
-9

In der zweiten Zeile ist $\textcolor{#1b7f4a}{7\,\%\,3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, dann $\textcolor{#1b7f4a}{1\cdot2}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, zuletzt $\textcolor{#1b7f4a}{100-2}\textcolor{#15633a}{=}\textcolor{#c2410c}{98}$.

⁠Kurz gesagt: Potenz vor Vorzeichen vor Punktrechnung (* / // %) vor Strichrechnung; Klammern gehen vor, und im Zweifel setzt man sie.
