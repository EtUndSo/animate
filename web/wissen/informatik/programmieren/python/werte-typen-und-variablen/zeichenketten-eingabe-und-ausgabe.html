Worum es geht:

Ein Programm soll nach Werten fragen und Ergebnisse ordentlich formatiert ausgeben. Dieser Abschnitt zeigt, wie man mit Zeichenketten rechnet, Zahlen formatiert in Text einsetzt, Eingaben liest, Text und Zahlen ineinander umwandelt und rundet. Zum Schluss entsteht ein kleiner Rechner für das Lauftempo.

Zeichenketten verketten und vervielfachen#

Kapitel 1 hat die Zeichenkette als Wert aus Text eingeführt (Kapitel 1, Abschnitt 4.6); ihr Typ heißt str. Auch mit Text kann man einiges rechnen: Teile zusammensetzen, Linien aus Strichen bauen, die Länge bestimmen.

Definition 10.1 (Operatoren und Länge von Zeichenketten)

Für Zeichenketten bedeutet + Aneinanderhängen, das Verketten: "Regen" + "schirm" ist "Regenschirm". * mit einem int wiederholt die Zeichenkette. Die eingebaute Funktion len liefert die Zahl der Zeichen.

Beispiel

Verketten, wiederholen, zählen:

Konsole
>>> "Regen" + "schirm"
'Regenschirm'
>>> "ha" * 3
'hahaha'
>>> "-" * 20
'--------------------'
>>> len("Regen")
5
>>> len("Größe")
5
>>> len("")
0
>>> "4" + "2"
'42'

"" ist die leere Zeichenkette, mit null Zeichen. "4" + "2" ergibt den Text '42', nicht die Zahl 6: Für str bedeutet + Verketten, egal, was in der Zeichenkette steht.

⁠Kurz gesagt: Bei Zeichenketten verkettet +, * wiederholt, und len zählt die Zeichen.

Der f-String#

print("Preis pro kg in Euro:", kilopreis) druckt 16 Stellen, wo zwei Nachkommastellen genügen. Für eine ordentliche Ausgabe will man Zahlen mitten in einen Text setzen und dabei bestimmen, wie viele Stellen erscheinen.

Ein Formular mit Lücken. Man schreibt den Text einmal hin und lässt Lücken; in jede Lücke kommt ein ausgerechneter Wert, in der gewünschten Form.

Definition 10.2 (f-String)

Ein f-String ist eine Zeichenkette mit einem f vor dem ersten Anführungszeichen. Jeder Ausdruck in geschweiften Klammern {...} wird ausgewertet, und sein Wert wird als Text an diese Stelle gesetzt.

Hinter dem Ausdruck kann, durch einen Doppelpunkt getrennt, eine Formatangabe stehen. Sie legt fest, wie der Wert als Text erscheint:

FormatangabeBedeutungBeispiel und Ergebnis
.2f2 Nachkommastellenf"{3.14159:.2f}" ergibt 3.14
.3ewissenschaftlichf"{0.0125:.3e}" ergibt 1.250e-02
8.3fmindestens 8 Zeichen breitf"{3.14159:8.3f}" ergibt 3.142
5dganze Zahl, 5 Zeichen breitf"{42:5d}" ergibt 42
,.2fmit Tausendertrennungf"{1234567.891:,.2f}" ergibt 1,234,567.89
.1%als Prozentf"{0.256:.1%}" ergibt 25.6%
08bbinär mit 8 Stellenf"{19:08b}" ergibt 00010011
xhexadezimalf"{255:x}" ergibt ff

Steht hinter dem Ausdruck ein Gleichheitszeichen, f"{gewicht=}", setzt Python den Ausdruck selbst, ein = und den Wert ein; das ist praktisch zum Nachsehen von Zwischenwerten. Die Formatangaben sind dieselben wie bei der Funktion format aus Unterabschnitt 3.4. Wie in allen Python-Ausgaben steht der Dezimalpunkt als Punkt und die Tausendertrennung als Komma.

Beispiel

Zeilen für den Kassenbon an der Käsetheke, mit Kilopreis und Gewicht:

Konsole
>>> kilopreis = 26.4
>>> gewicht = 0.125
>>> f"Gewicht = {gewicht} kg, also {gewicht * 1000:.1f} g"
'Gewicht = 0.125 kg, also 125.0 g'
>>> f"Preis = {kilopreis * gewicht:.2f} Euro"
'Preis = 3.30 Euro'
>>> f"Pro Gramm: {kilopreis / 1000:.3e} Euro"
'Pro Gramm: 2.640e-02 Euro'
>>> f"{gewicht=}"
'gewicht=0.125'
>>> print(f"Zu zahlen: {kilopreis * gewicht:.2f} Euro")
Zu zahlen: 3.30 Euro

Der interaktive Modus zeigt einen f-String als Zeichenkette mit Apostrophen; erst print gibt den reinen Text aus.

Den gespeicherten Wert von 0.1, fertig. In Unterabschnitt 4.6 hat die Rechnung mit $5^{55}$ von Hand die 55 Nachkommastellen des gespeicherten Werts von 0.1 geliefert. Mit einer Formatangabe geht es direkt:

Konsole
>>> f"{0.1:.20f}"
'0.10000000000000000555'
>>> f"{0.1:.55f}"
'0.1000000000000000055511151231257827021181583404541015625'

Dieselben Stellen wie von Hand. Eine Formatangabe rundet nur die Anzeige; der Wert des Objekts bleibt, wie er ist.

⁠Kurz gesagt: Ein f-String setzt Werte in {...} in einen Text ein; hinter dem Doppelpunkt legt eine Formatangabe Stellen und Form fest.

Die Eingabe mit input#

Bisher stehen alle Werte im Quelltext. Ein Rechner für den Alltag soll aber die Zahlen erfragen, mit denen er rechnet.

Definition 10.3 (input)

Die eingebaute Funktion input schreibt den Text in ihren Klammern als Frage ins Terminal, wartet, bis der Benutzer eine Zeile eintippt und Enter drückt, und liefert diese Zeile als Zeichenkette, ohne das Enter.

Beispiel

Im interaktiven Modus erscheint die Frage, und dahinter tippt man die Antwort, hier 5:

Konsole
>>> gaeste = input("Anzahl Gäste: ")
Anzahl Gäste: 5
>>> gaeste
'5'
>>> type(gaeste)
<class 'str'>
>>> gaeste * 2
'55'

input liefert immer eine Zeichenkette, auch wenn man eine Zahl eintippt. gaeste * 2 wiederholt deshalb den Text, statt zu rechnen. Mit einer Eingabe zu rechnen, verlangt einen weiteren Schritt.

⁠Kurz gesagt: input fragt nach einer Zeile und liefert sie als str.

Die Typumwandlung#

Der Text '5' soll zur Zahl 5 werden, die Zahl 42 zum Text '42'. Python wandelt nie von selbst um (Unterabschnitt 1.2); man muss es ausdrücklich verlangen.

Definition 10.4 (Typumwandlung)

Die Funktionen int, float und str erzeugen aus einem Wert ein neues Objekt mit dem Typ ihres Namens. Das heißt Typumwandlung.

  • int(text) und float(text) lesen eine Zahl aus einer Zeichenkette; Leerzeichen am Rand sind erlaubt. Passt der Text nicht, melden sie einen ValueError.

  • int(x) macht aus einem float eine ganze Zahl, indem es die Nachkommastellen abschneidet, also in Richtung null rundet.

  • str(x) liefert den Text, den print für $x$ ausgeben würde.

Beispiel

Umwandlungen, die gelingen, und zwei, die scheitern:

Konsole
>>> int("42")
42
>>> int(" 42 ")
42
>>> float("4.2")
4.2
>>> float("1e3")
1000.0
>>> int("4.2")
Traceback (most recent call last):
  File "<python-input-4>", line 1, in <module>
    int("4.2")
    ~~~^^^^^^^
ValueError: invalid literal for int() with base 10: '4.2'
>>> float("2,5")
Traceback (most recent call last):
  File "<python-input-5>", line 1, in <module>
    float("2,5")
    ~~~~~^^^^^^^
ValueError: could not convert string to float: '2,5'
>>> str(42) + "1"
'421'
>>> int(3.99)
3
>>> int(-3.99)
-3

int("4.2") scheitert, weil 4.2 keine ganze Zahl ist; int(float("4.2")) ginge. float("2,5") scheitert am Komma: Python erwartet den Dezimalpunkt, auch bei Eingaben. Für Zahlen aus input ist das typische Muster deshalb float(input("...")).

⁠Kurz gesagt: int, float und str wandeln ausdrücklich um; int schneidet Nachkommastellen ab.

HintergrundWarum Python Text und Zahl nicht von selbst umwandelt

Was sollte "2" + 3 ergeben, den Text '23' oder die Zahl 5? Manche Sprachen entscheiden sich still für eine der beiden Möglichkeiten, JavaScript etwa für '23'. Dann rechnet ein Programm mit eingelesenen Zahlen falsch, ohne dass es jemand merkt. Python folgt dem Grundsatz, bei Mehrdeutigkeit nicht zu raten: Es meldet einen TypeError und zwingt dazu, mit int, float oder str zu sagen, was gemeint ist. Zwischen Zahlentypen wandelt Python dagegen sehr wohl von selbst um (Unterabschnitt 2.2), denn dort ist die Bedeutung eindeutig: $2+3{,}0$ ist $5{,}0$.

Runden: erst von Hand, dann fertig#

3 * 1.1 ergibt 3.3000000000000003, der Preis von drei Kapiteln zu je $1{,}10$ Euro mit einem Rundungsrest. Ein solches Ergebnis will man auf eine ganze Zahl oder auf wenige Stellen runden, und zwar nicht nur in der Anzeige, sondern als Wert, mit dem man weiterrechnet.

Von Hand. int schneidet ab. Addiert man vorher $0{,}5$, wird aus dem Abschneiden ein Runden: $\textcolor{#1b7f4a}{2{,}7+0{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{3{,}2}$ wird zu 3, $\textcolor{#1b7f4a}{2{,}2+0{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{2{,}7}$ zu 2. Das ist die Schulregel „ab 5 aufrunden“:

Konsole
>>> int(2.7 + 0.5)
3
>>> int(2.5 + 0.5)
3
>>> int(3.5 + 0.5)
4
>>> int(-2.7 + 0.5)
-2

Die letzte Zeile ist falsch: $-2{,}7$ liegt näher an $-3$. Weil int Richtung null abschneidet, funktioniert der Trick nur für positive Zahlen.

Fertig. Die eingebaute Funktion round rundet richtig, auch bei negativen Zahlen.

Definition 10.5 (round)

round(x) liefert die ganze Zahl, die $x$ am nächsten liegt. Liegt $x$ genau in der Mitte zwischen zwei ganzen Zahlen, liefert round die gerade von beiden. round(x, n) rundet auf $n$ Nachkommastellen und liefert einen float.

Konsole
>>> round(2.7)
3
>>> round(-2.7)
-3
>>> round(2.5)
2
>>> round(3.5)
4
>>> round(-2.5)
-2
>>> round(3.14159, 2)
3.14
>>> round(2.675, 2)
2.67
>>> f"{2.675:.20f}"
'2.67499999999999982236'

round(2.675, 2) ergibt $2{,}67$ und nicht $2{,}68$, und das ist kein Fehler: Der gespeicherte Wert von 2.675 liegt knapp unter $2{,}675$, wie die letzte Zeile zeigt, also ist $2{,}67$ die nächste Zahl mit zwei Nachkommastellen. Wer abrunden oder aufrunden will, nimmt math.floor oder math.ceil.

Vergleich.

$x$int(x + 0.5)round(x)
$2{,}7$33
$2{,}5$32
$3{,}5$44
$-2{,}5$$-2$$-2$
$-2{,}7$$-2$$-3$

Die beiden Wege unterscheiden sich an zwei Stellen: bei genauen Hälften wie $2{,}5$, wo round zur geraden Zahl geht, und bei negativen Zahlen, wo der Weg von Hand falsch ist. Der fertige Weg ist für alle Zahlen richtig und folgt derselben Regel wie die Rundung der float in Unterabschnitt 4.6.

⁠Kurz gesagt: round rundet zur nächsten Zahl und bei genauen Hälften zur geraden; int(x + 0.5) klappt nur für positive Zahlen und rundet Hälften immer auf.

HintergrundWarum zur geraden Zahl gerundet wird

Die Schulregel rundet jede genaue Hälfte auf. Bei vielen gerundeten Werten summiert sich das zu einem Fehler, der immer in dieselbe Richtung zeigt. Ein Beispiel: $\textcolor{#1b7f4a}{0{,}5+1{,}5+2{,}5+3{,}5}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$. Nach der Schulregel gerundet ergibt die Summe $\textcolor{#1b7f4a}{1+2+3+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$. Zur geraden Zahl gerundet ergibt sie $\textcolor{#1b7f4a}{0+2+2+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$: Die Hälfte der Fälle geht nach oben, die andere nach unten, und im Mittel heben sich die Fehler auf. Deshalb rundet IEEE 754 in der Grundeinstellung jede Rechnung mit float bei Gleichstand zur geraden Mantisse, und Python übernimmt dieselbe Regel für round. Es verhindert außerdem, dass ein Wert, den man immer wieder abzieht und hinzuzählt, langsam in eine Richtung wandert.

Anwendung: ein Rechner für das Lauftempo#

Mit input, float und einem f-String lässt sich ein kleines Werkzeug für Läuferinnen und Läufer schreiben: Es fragt nach Strecke und Zeit eines Laufs und gibt das Tempo auf zwei Arten aus, in Kilometern pro Stunde und in Minuten pro Kilometer, der beim Laufen üblichen Angabe. Teilt man die Minuten durch die Kilometer, kommt die zweite Angabe direkt heraus; für die erste rechnet man die Minuten vorher in Stunden um.

tempo.pyPython
# Temporechner: Tempo eines Laufs auf zwei Arten
strecke = float(input("Strecke in km: "))
zeit = float(input("Zeit in min: "))

km_pro_h = strecke / (zeit / 60)     # Minuten in Stunden umrechnen
min_pro_km = zeit / strecke          # min / km ergibt min pro km

print(f"Tempo: {km_pro_h:.2f} km/h")
print(f"Zeit pro km: {min_pro_km:.2f} min")

Beim Start fragt das Skript nacheinander die beiden Werte ab; eingetippt sind hier 5.2 und 27:

Windows (PowerShell)Konsole
PS> py tempo.py
Strecke in km: 5.2
Zeit in min: 27
Tempo: 11.56 km/h
Zeit pro km: 5.19 min
LinuxKonsole
$ python3 tempo.py
Strecke in km: 5.2
Zeit in min: 27
Tempo: 11.56 km/h
Zeit pro km: 5.19 min

Tippt man 5,2 mit Komma, bricht das Skript mit dem ValueError aus Unterabschnitt 10.4 ab. Wie man solche Eingaben abfängt und erneut fragt, ist eine eigene Fähigkeit, die dieses Kapitel nicht braucht.

⁠Kurz gesagt: float(input(...)) liest eine Zahl, ein f-String gibt das Ergebnis mit passend vielen Stellen aus.

Fülle die Tabelle für $\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{0{,}5}$; $1{,}5$; $-0{,}5$; $-1{,}5$; $4{,}49$ aus: int(x + 0.5), round(x), math.floor(x), int(x). Erst vorhersagen, dann prüfen. Bei welchen Werten liefern alle vier Spalten dasselbe?

Aufgabe 40 ★★ Ein Pegelrechner

Schreibe ein Skript pegel.py, das nach zwei Schalldrücken in Pascal fragt, einem leisen und einem lauten, und ausgibt, um welchen Faktor der laute größer ist (mit zwei Nachkommastellen) und um wie viel Dezibel (mit einer Nachkommastelle), $20\log_{10}(p_\mathrm{laut}/p_\mathrm{leise})$ wie in Aufgabe 30. Teste es mit $0{,}02\,\mathrm{Pa}$ und $1{,}2\,\mathrm{Pa}$.

Lösung
pegel.pyPython
# Pegelrechner: zwei Schalldrücke als Faktor und in Dezibel
import math

p_leise = float(input("Leiser Schalldruck in Pa: "))
p_laut = float(input("Lauter Schalldruck in Pa: "))

faktor = p_laut / p_leise
pegel_db = 20 * math.log10(faktor)    # Unterschied in dB

print(f"Faktor: {faktor:.2f}")
print(f"Unterschied: {pegel_db:.1f} dB")

Aufgabe 41 ★ Ein Fehler beim Einlesen

Ein Skript enthält die Zeilen strecke = input("Strecke in km: ") und print("Doppelte Strecke:", strecke * 2). Für die Eingabe 5 gibt es 55 aus. Erkläre das Verhalten und behebe den Fehler. Was gibt dein verbessertes Skript für die Eingabe 2.5 aus?

Lösung

input liefert immer einen str (Unterabschnitt 10.3). strecke * 2 wiederholt deshalb den Text '5', statt zu rechnen. Abhilfe: die Eingabe mit float umwandeln.

einlesen.pyPython
# Eine Strecke einlesen und verdoppeln, mit Typumwandlung
strecke = float(input("Strecke in km: "))
print("Doppelte Strecke:", strecke * 2)
LinuxKonsole
$ python3 einlesen.py
Strecke in km: 2.5
Doppelte Strecke: 5.0

Mit int statt float wäre die Eingabe 2.5 mit einem ValueError gescheitert, deshalb ist float die richtige Wahl für Strecken und andere Zahlen mit Nachkommastellen.

Zusammenfassung

Begriffe
  • Verketten – Für Zeichenketten bedeutet + Aneinanderhängen, das Verketten: "Regen" + "schirm" ist "Regenschirm".
  • f-String – Ein f-String ist eine Zeichenkette mit einem f vor dem ersten Anführungszeichen.
  • Typumwandlung – Die Funktionen int, float und str erzeugen aus einem Wert ein neues Objekt mit dem Typ ihres Namens. Das heißt Typumwandlung.
Zusammenhänge
  • Zu „Zeichenketten verketten und vervielfachen“: Bei Zeichenketten verkettet +, * wiederholt, und len zählt die Zeichen.
  • Zu „Der f-String“: Ein f-String setzt Werte in {...} in einen Text ein; hinter dem Doppelpunkt legt eine Formatangabe Stellen und Form fest.
  • Zu „Die Eingabe mit input“: input fragt nach einer Zeile und liefert sie als str.
  • Zu „Die Typumwandlung“: int, float und str wandeln ausdrücklich um; int schneidet Nachkommastellen ab.
  • Zu „Runden: erst von Hand, dann fertig“: round rundet zur nächsten Zahl und bei genauen Hälften zur geraden; int(x + 0.5) klappt nur für positive Zahlen und rundet Hälften immer auf.
  • Zu „Anwendung: ein Rechner für das Lauftempo“: float(input(...)) liest eine Zahl, ein f-String gibt das Ergebnis mit passend vielen Stellen aus.
