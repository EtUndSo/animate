Kapitel 1: Programme und der Python-Interpreter

Programme und Programmiersprachen

Das Programm
Definition 1.1 (Programm)

Ein Programm ist eine Folge von eindeutig beschriebenen Arbeitsschritten, die ein Rechner der Reihe nach ausführt, ohne nachzufragen.

Was der Prozessor versteht: Maschinenbefehle
Definition 1.2 (Maschinenbefehl)

Ein Maschinenbefehl ist ein Befehl, den der Prozessor unmittelbar ausführen kann. Er steht im Speicher als Zahl; an dieser Zahl erkennt der Prozessor, was zu tun ist.

Die Programmiersprache
Definition 1.3 (Programmiersprache)

Eine Programmiersprache ist eine künstliche Sprache, in der genau festgelegt ist, welche Texte erlaubt sind und was jeder erlaubte Text bewirkt.

Die Syntax
Definition 1.4 (Syntax)

Die Syntax einer Programmiersprache ist die Gesamtheit der Regeln, die festlegen, welche Texte in ihr erlaubt sind.

Die Semantik
Definition 1.5 (Semantik)

Die Semantik einer Programmiersprache legt fest, was ein erlaubter Text bedeutet, also was geschieht, wenn er ausgeführt wird.

Der Quelltext
Definition 1.6 (Quelltext)

Der Quelltext eines Programms ist sein Text in einer Programmiersprache, so wie Menschen ihn schreiben und lesen.

Vom Quelltext zur Ausführung: Compiler und Interpreter

Der Compiler
Definition 2.1 (Compiler)

Ein Compiler ist ein Programm, das einen Quelltext vollständig in Maschinencode übersetzt, bevor dieser ausgeführt wird. Das Ergebnis wird als eigene Datei gespeichert, die ohne den Compiler läuft.

Der Interpreter
Definition 2.2 (Interpreter)

Ein Interpreter ist ein Programm, das einen Quelltext liest und die darin beschriebenen Schritte selbst ausführt. Er erzeugt keine ausführbare Datei und muss deshalb bei jedem Start des Programms dabei sein.

Python und CPython
Definition 2.3 (Python und CPython)

Python ist eine Programmiersprache; ihre Syntax und Semantik sind in der Sprachreferenz von Python festgelegt. CPython ist das Programm, das Python-Quelltext ausführt und auf python.org angeboten wird; es ist selbst in der Sprache C geschrieben.

Der Bytecode
Definition 2.4 (Bytecode)

Der Bytecode ist eine Folge einfacher Befehle, in die CPython den ganzen Quelltext übersetzt, bevor es mit der Ausführung beginnt. Die Befehle sind für eine gedachte Maschine entworfen, nicht für einen wirklichen Prozessor.

Python einrichten

Python unter Windows: der Python install manager

Der Python install manager ist ein Programm für Windows, das Python-Versionen herunterlädt, installiert, auflistet, entfernt und startet. Man bedient ihn im Terminal mit dem Befehl py.

Die Versionsnummer
Definition 3.2 (Versionsnummer)

Eine Python-Versionsnummer hat die Form 3.14.4 und besteht aus drei Teilen:

  • der Hauptversion, hier 3;

  • der Unterversion, hier 14; jedes Jahr im Oktober erscheint eine neue Unterversion mit neuen Sprachmitteln;

  • der Fehlerbehebungsnummer, hier 4; sie wächst, wenn eine Unterversion Korrekturen bekommt, ohne dass sich die Sprache ändert.

Der interaktive Modus

Der interaktive Modus
Definition 4.1 (Interaktiver Modus)

Im interaktiven Modus liest Python eine Eingabe, führt sie aus, zeigt das Ergebnis an und wartet dann auf die nächste Eingabe.

Der Wert
Definition 4.2 (Wert)

Ein Wert ist ein einzelnes Datum, mit dem Python arbeitet, zum Beispiel die Zahl 42 oder die Zahl 0,5.

Der Ausdruck
Definition 4.3 (Ausdruck)

Ein Ausdruck ist ein Stück Quelltext, das Python zu einem Wert ausrechnen kann.

Rechnen wie mit dem Taschenrechner
>>> 2,5 * 2
↗
Das Rezept im interaktiven Modus: erst von Hand, dann fertig
>>> (1 + 2/1) / 2
>>> (_ + 2/_) / 2
↗
>>> 2 ** 0.5
↗
Text als Wert: die Zeichenkette
Definition 4.4 (Zeichenkette)

Eine Zeichenkette ist ein Wert, der aus Text besteht. Im Quelltext steht sie zwischen zwei geraden Anführungszeichen, "Hallo", oder zwischen zwei Apostrophen, 'Hallo'.

Die Funktion
Definition 4.5 (Funktion)

Eine Funktion ist ein fertiges Teilprogramm mit einem Namen, das man bei Bedarf ausführen lassen kann.

Der Funktionsaufruf: print
Definition 4.6 (Funktionsaufruf)

Ein Funktionsaufruf lässt eine Funktion ausführen. Man schreibt ihren Namen, dahinter runde Klammern und in die Klammern die Werte, mit denen die Funktion arbeiten soll, durch Kommas getrennt.

Skripte schreiben und ausführen

Der Editor
Definition 5.1 (Editor)

Ein Editor ist ein Programm, mit dem man reine Textdateien schreibt und speichert. Ein Editor für Programmierer hilft zusätzlich beim Schreiben von Quelltext: Er färbt ihn nach seiner Syntax ein, markiert Verstöße gegen die Syntax schon beim Tippen und kann ein Programm auf Knopfdruck ausführen.

Das Skript
Definition 5.2 (Skript)

Ein Skript ist eine Textdatei mit Python-Quelltext, deren Name auf .py endet. Python führt ein Skript aus, indem es die Datei übersetzt und ihre Zeilen dann von oben nach unten je einmal ausführt.

$ python3 ausdruck.py
↗
Der Kommentar
Definition 5.3 (Kommentar)

Ein Kommentar beginnt mit dem Zeichen # und reicht bis zum Ende der Zeile. Python überliest ihn vollständig.

Fehler lesen und verstehen

Der Syntaxfehler
Definition 6.1 (Syntaxfehler)

Ein Syntaxfehler ist eine Stelle im Quelltext, die gegen die Syntax der Sprache verstößt. Python meldet ihn, bevor irgendeine Zeile der Datei ausgeführt wird.

Der Laufzeitfehler
Definition 6.2 (Laufzeitfehler)

Ein Laufzeitfehler ist ein Fehler, der erst beim Ausführen einer Zeile auftritt. Alle Zeilen davor sind schon gelaufen; das Programm bricht an dieser Stelle ab.

Die Ausnahme
Definition 6.3 (Ausnahme)

Eine Ausnahme ist das Ereignis, mit dem Python einen Fehler meldet. Sie hat eine Art, zum Beispiel ZeroDivisionError, und eine Beschreibung, zum Beispiel division by zero. Tritt sie beim Ausführen auf, bricht sie das Programm an dieser Stelle ab.

Der Traceback
Definition 6.4 (Traceback)

Der Traceback ist der Bericht, den Python ausgibt, wenn eine Ausnahme beim Ausführen ein Programm abbricht. Er nennt die Stelle im Quelltext, an der die Ausnahme auftrat, und in seiner letzten Zeile die Art und die Beschreibung der Ausnahme.

>>> 5 / 0
↗
Der Logikfehler
Definition 6.5 (Logikfehler)

Ein Logikfehler ist ein Fehler, bei dem ein Programm ohne Fehlermeldung läuft, aber nicht das berechnet, was gemeint war.

Das Wichtigste bis hier

Die Antwort in drei Sätzen

  1. Ein Programm ist ein Rezept aus eindeutigen Schritten, das man in einer Programmiersprache als Quelltext aufschreibt, weil der Prozessor nur Maschinenbefehle versteht und Alltagssprache mehrdeutig ist.

  2. Python-Quelltext tippt man entweder im interaktiven Modus Zeile für Zeile ein, der jeden Wert sofort anzeigt, oder man speichert ihn als Skript, das man mit py bzw. python3 startet und das nur mit print etwas ausgibt.

  3. CPython übersetzt zuerst die ganze Datei und führt sie dann aus; deshalb verhindert ein Syntaxfehler jede Ausführung, ein Laufzeitfehler bricht erst in seiner Zeile ab, und ein Logikfehler fällt nur auf, wenn man das Ergebnis prüft.

Kapitel 2: Werte, Typen und Variablen

Objekte und Typen

Das Objekt
Definition 1.1 (Objekt)

Ein Objekt ist ein Stück des Arbeitsspeichers, in dem Python einen Wert ablegt, zusammen mit der Angabe, welche Art von Wert dort liegt.

Der Typ
Definition 1.2 (Typ)

Der Typ eines Objekts ist die Art seines Werts. Er legt fest, welche Werte das Objekt haben kann und was man mit ihm tun kann. Die Funktion type liefert den Typ eines Objekts.

Die Identität
Definition 1.3 (Identität)

Die Identität eines Objekts ist eine ganze Zahl, die das Objekt von allen anderen Objekten unterscheidet, die zur selben Zeit bestehen. Sie ändert sich nicht, solange das Objekt besteht. Die Funktion id liefert sie.

Die Methode
Definition 1.4 (Methode)

Eine Methode ist eine Funktion, die zu einem Typ gehört. Man ruft sie für ein Objekt auf, indem man hinter das Objekt einen Punkt, den Namen der Methode und runde Klammern schreibt.

Ganze Zahlen und Rechenoperatoren

Der Typ int
Definition 2.1 (Der Typ int)

Der Typ int umfasst die ganzen Zahlen $\ldots,-2,-1,0,1,2,\ldots$ Ein Objekt vom Typ int hat keine feste Größe: Es wird so groß, wie die Zahl es verlangt, und ist nur durch den Arbeitsspeicher begrenzt. Addieren, Subtrahieren und Multiplizieren zweier int liefert immer das exakte Ergebnis als int.

Operator und Operand
Definition 2.2 (Operator und Operand)

Ein Operator ist ein Zeichen, das aus Werten einen neuen Wert berechnet.

Die Werte, auf die ein Operator wirkt, heißen seine Operanden.

>>> 7 + 2
>>> 7 + 0.5
>>> 2 * 3.0
↗
Die Division
Definition 2.3 (Division)

Der Operator / teilt den linken Operanden durch den rechten. Das Ergebnis ist immer ein float, auch wenn beide Operanden ein int sind und die Division aufgeht.

Ganzzahldivision und Rest
Definition 2.4 (Ganzzahldivision und Rest)

Für ganze Zahlen $a$ und $b\ne0$ ist a // b die größte ganze Zahl, die nicht größer ist als $a/b$. Das ist der Quotient, nach unten gerundet, also in Richtung $-\infty$.

Der Rest ist a % b $=a-(a\,/\!/\,b)\cdot b$.

Satz 2.5 (Ganzzahldivision und Rest)

Für alle ganzen Zahlen $a$ und $b\ne0$ gilt

$$\textcolor{#1b7f4a}{a }\textcolor{#15633a}{=}\textcolor{#c2410c}{ (a\,/\!/\,b)\cdot b + a\,\%\,b .}$$
(2.1)

Für $b>0$ liegt der Rest im Bereich $0\le a\,\%\,b<b$, für $b<0$ im Bereich $b<a\,\%\,b\le0$. Der Rest hat also immer das Vorzeichen von $b$ oder ist null.

>>> divmod(125, 60)
>>> divmod(-7, 2)
>>> 7.5 // 2
>>> 7.5 % 2
↗
Die Potenz
Definition 2.6 (Potenz)

a ** b ist $a$ hoch $b$. Sind $a$ und $b$ ein int und ist $b\ge0$, ist das Ergebnis ein int; ist $b$ ein negativer int, ist es ein float. Ist einer der Operanden ein float, ist das Ergebnis ebenfalls ein float; nur eine negative Basis mit einem nicht ganzzahligen Exponenten liefert etwas anderes. Außerdem gilt:

  • ** bindet stärker als ein Minuszeichen links davon: -2 ** 2 ist $\textcolor{#1b7f4a}{-(2^2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{-4}$.

  • Mehrere ** wertet Python von rechts nach links aus: 2 ** 3 ** 2 ist $\textcolor{#1b7f4a}{2^{(3^2)}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^9}\textcolor{#15633a}{=}\textcolor{#c2410c}{512}$.

Die Rangfolge
Definition 2.7 (Rangfolge)

Die Rangfolge der Operatoren legt fest, welcher Operator in einem Ausdruck ohne Klammern zuerst ausgeführt wird. Für die arithmetischen Operatoren gilt, vom stärksten zum schwächsten:

RangOperatorenbei gleichem Rang
1**von rechts nach links
2einstelliges + und -
3* / // %von links nach rechts
4zweistelliges + und -von links nach rechts

Klammern gehen allem vor.

Zahlen im Binärsystem

Das Stellenwertsystem
Definition 3.1 (Stellenwertsystem)

Sei $B\ge2$ eine natürliche Zahl, die Basis. Im Stellenwertsystem zur Basis $B$ steht eine Folge von Ziffern $z_{n-1}\ldots z_1z_0$ mit $0\le z_i<B$ für die Zahl

$$\textcolor{#1b7f4a}{z_{n-1}B^{n-1}+\dots+z_1B^1+z_0B^0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=0}^{n-1}z_i\,B^i .}$$

Die Zahl $B^i$ heißt der Stellenwert der Stelle $i$. Gezählt wird von rechts, beginnend bei $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Die Binärzahl
Definition 3.2 (Binärzahl)

Eine Binärzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. Ihre Ziffern sind 0 und 1.

>>> 0b10011
>>> type(0b10011)
↗
>>> (19).bit_length()
↗
Das Byte
Definition 3.3 (Byte)

Ein Byte ist eine Gruppe von 8 Bit.

Ins Binärsystem umrechnen: erst von Hand, dann fertig
>>> divmod(19, 2)
>>> divmod(9, 2)
>>> divmod(4, 2)
>>> divmod(2, 2)
>>> divmod(1, 2)
↗
>>> bin(19)
>>> format(19, "b")
>>> format(19, "08b")
>>> int("10011", 2)
>>> bin(-19)
↗
Die Hexadezimalzahl
Definition 3.4 (Hexadezimalzahl)

Eine Hexadezimalzahl ist eine Zahl im Stellenwertsystem zur Basis $\textcolor{#1b7f4a}{B}\textcolor{#15633a}{=}\textcolor{#c2410c}{16}$. Die Ziffern sind 0 bis 9 und a bis f für die Werte 10 bis 15.

Binärbrüche
Definition 3.5 (Binärbruch)

Ein Binärbruch ist eine Zahl mit Stellen rechts vom Komma im Binärsystem. Die Stelle $k$ rechts vom Komma hat den Stellenwert $2^{-k}$:

$$\textcolor{#1b7f4a}{0{,}b_{-1}b_{-2}\ldots b_{-m}\,{}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{k=1}^{m}b_{-k}\,2^{-k} .}$$

Satz 3.6 (Endliche Binärbrüche)

Eine Zahl $x$ lässt sich genau dann als Binärbruch mit endlich vielen Stellen schreiben, wenn es eine ganze Zahl $p\ge0$ gibt, sodass $x\cdot2^p$ eine ganze Zahl ist.

Das Verdopplungsverfahren
Definition 3.7 (Verdopplungsverfahren)

Für $0\le x<1$ bestimmt das Verdopplungsverfahren die Binärstellen von $x$: Man verdoppelt $x$. Der ganzzahlige Teil des Ergebnisses, 0 oder 1, ist die nächste Stelle; mit dem Anteil rechts vom Komma macht man weiter. Das Verfahren endet, wenn dieser Anteil 0 ist.

Gleitkommazahlen: der Typ float

Die Gleitkommadarstellung
Definition 4.1 (Gleitkommazahl)

Eine Gleitkommazahl mit $p$ Binärstellen ist eine Zahl der Form $\pm\,m\cdot2^E$.

Darin ist die Mantisse $m$ eine Binärzahl mit $p$ Stellen und genau einer Stelle vor dem Komma, die 1 ist: $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1{,}\ldots{}_2}$, also $1\le m<2$.

Der Exponent $E$ ist eine ganze Zahl aus einem festen Bereich.

Der Typ float
Definition 4.2 (Der Typ float)

Ein Objekt vom Typ float speichert eine Gleitkommazahl im Format binary64 der Norm IEEE 754. Die Mantisse hat $\textcolor{#1b7f4a}{p}\textcolor{#15633a}{=}\textcolor{#c2410c}{53}$ Binärstellen, der Exponent liegt im Bereich $-1022\le E\le1023$. Die Zahl belegt 64 Bit, aufgeteilt in drei Felder:

  • 1 Bit Vorzeichen $s$: $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ für positive, $\textcolor{#1b7f4a}{s}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ für negative Zahlen;

  • 11 Bit Exponentenfeld $c$;

  • 52 Bit Mantissenfeld $t$.

Das Exponentenfeld
Definition 4.3 (Exponentenfeld)

Das Exponentenfeld $c$ eines float speichert den um 1023 verschobenen Exponenten:

$$\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{E+1023,}$$
$$\textcolor{#1b7f4a}{E}\textcolor{#15633a}{=}\textcolor{#c2410c}{c-1023 .}$$

Gewöhnliche Zahlen haben $1\le c\le2046$. Die Werte $\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ und $\textcolor{#1b7f4a}{c}\textcolor{#15633a}{=}\textcolor{#c2410c}{2047}$ sind für besondere Fälle reserviert.

Das Mantissenfeld
Definition 4.4 (Mantissenfeld)

Das Mantissenfeld $t$ eines float enthält die 52 Binärstellen der Mantisse nach dem Komma. Liest man sie als ganze Zahl $t$, ist die Mantisse

$$\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+\frac{t}{2^{52}} .}$$

$$\textcolor{#1b7f4a}{x}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-1)^s\cdot\Bigl(1+\frac{t}{2^{52}}\Bigr)\cdot2^{\,c-1023}.}$$
(4.1)
Einen float in seine Felder zerlegen
>>> (6.5).hex()
>>> (-0.75).hex()
↗
Der Darstellungsfehler
Definition 4.5 (Rundung und Darstellungsfehler)

Ist eine Zahl $x$ nicht als float darstellbar, speichert Python den float, der $x$ am nächsten liegt. Liegt $x$ genau in der Mitte zwischen zwei float, nimmt Python den, dessen letztes Mantissenbit 0 ist. Die Differenz zwischen dem gespeicherten Wert und $x$ heißt Darstellungsfehler.

>>> (0.1).hex()
>>> (0.1).as_integer_ratio()
>>> 2 ** 55
↗
>>> 3602879701896397 * 5 ** 55
↗
Die kürzeste Darstellung
Definition 4.6 (Kürzeste Darstellung)

Der interaktive Modus und print zeigen einen float als die kürzeste Dezimalzahl, die beim Eintippen genau diesen float ergibt.

Rechnen mit Gleitkommazahlen

Der Rundungsfehler einer Rechnung
Definition 5.1 (Korrekt gerundete Rechnung)

Für die Grundrechenarten $+$, $-$, $\cdot$, $/$ und die Quadratwurzel verlangt IEEE 754: Das Ergebnis ist das exakte Ergebnis der gespeicherten Werte, gerundet nach derselben Regel wie beim Speichern, also auf den nächsten float und bei Gleichstand zur geraden Mantisse. Der dabei entstehende Unterschied heißt Rundungsfehler der Rechnung.

Die Maschinengenauigkeit
Definition 5.2 (Maschinengenauigkeit)

Die Maschinengenauigkeit $\varepsilon_{\mathrm M}$ ist der Abstand von 1 zum nächstgrößeren float:

$$\textcolor{#1b7f4a}{\varepsilon_{\mathrm M}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-52}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{2{,}22\cdot10^{-16}.}$$

Satz 5.3 (Größe des Rundungsfehlers)

Liegt eine Zahl $x\ne0$ im Bereich der gewöhnlichen float, unterscheidet sich der gerundete Wert $\tilde x$ von $x$ höchstens um

$$\textcolor{#1b7f4a}{|\tilde x-x|\le\frac{\varepsilon_{\mathrm M}}{2}\,|x|}\textcolor{#15633a}{=}\textcolor{#c2410c}{2^{-53}\,|x|}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1{,}11\cdot10^{-16}\,|x| .}$$

Ein float hat also etwa 16 gültige Dezimalstellen.

>>> 1.4142135623730951 - 1.414213562373095
↗
Die Absorption
Definition 5.4 (Absorption)

Ist $|b|$ kleiner als der halbe Abstand der float in der Nähe von $a$, dann ergibt $a+b$ wieder $a$: Der kleine Summand geht vollständig verloren. Man sagt, er wird absorbiert.

Die Auslöschung
Definition 5.5 (Auslöschung)

Auslöschung heißt der Verlust gültiger Stellen beim Subtrahieren zweier fast gleicher Zahlen, die schon mit Rundungsfehlern behaftet sind. Die Subtraktion selbst ist dabei oft exakt; die vorhandenen Fehler werden aber relativ zum kleinen Ergebnis groß.

Der Überlauf: inf
Definition 5.6 (Überlauf und inf)

Der größte float ist $\textcolor{#1b7f4a}{(2-2^{-52})\cdot2^{1023}}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{1{,}797\cdot10^{308}}$. Ist das gerundete Ergebnis einer Rechnung größer, spricht man vom Überlauf, und das Ergebnis ist der besondere Wert inf (unendlich), bei negativen Ergebnissen -inf.

Das ungültige Ergebnis: nan
Definition 5.7 (nan)

nan (englisch not a number, keine Zahl) ist der float, den eine Rechnung ohne sinnvolles Ergebnis liefert, etwa $\infty-\infty$ oder $0\cdot\infty$. Fast jede Rechnung mit nan ergibt wieder nan.

Variablen: Namen für Objekte

Die Zuweisung
Definition 6.1 (Zuweisung)

Eine Zuweisung ist eine Anweisung der Form

⁠name = ausdruck

Python wertet den Ausdruck rechts aus und verbindet dann den Namen links mit dem Objekt, das dabei entstanden ist. Man sagt: Der Name wird an das Objekt gebunden.

Die Variable
Definition 6.2 (Variable)

Ein Name, der an ein Objekt gebunden ist, heißt Variable. Der Wert der Variablen ist der Wert dieses Objekts.

Neu binden statt kopieren
Satz 6.3 (Zuweisung kopiert nicht)

Eine Zuweisung legt nie eine Kopie eines Objekts an. y = x bindet y an dasselbe Objekt, an das x gebunden ist. Eine spätere Zuweisung an x bindet nur x neu; y bleibt an seinem Objekt.

Die Namensregeln
Definition 6.4 (Namensregeln)

Ein Name besteht aus Buchstaben, Ziffern und dem Unterstrich _. Er darf nicht mit einer Ziffer beginnen und kein Schlüsselwort sein. Groß- und Kleinbuchstaben sind verschieden: Wert und wert sind zwei Namen.

>>> print = 5
>>> print("Hallo")
↗
Die erweiterte Zuweisung
Definition 6.5 (Erweiterte Zuweisung)

Für einen arithmetischen Operator $\circ$ aus + - * / // % ** bedeutet die erweiterte Zuweisung name $\circ$= ausdruck bei Zahlen dasselbe wie name = name $\circ$ (ausdruck).

Variablen im Skript
PS> py rezept_variablen.py
↗
$ python3 rezept_variablen.py
↗

Wahrheitswerte und Vergleiche

Der Typ bool
Definition 7.1 (Der Typ bool)

Der Typ bool hat genau zwei Werte, True (wahr) und False (falsch). Beide sind Schlüsselwörter.

Die Vergleichsoperatoren
Definition 7.2 (Vergleichsoperatoren)

Die Vergleichsoperatoren vergleichen zwei Werte und liefern einen bool:

==gleich!=ungleich
<kleiner<=kleiner oder gleich
>größer>=größer oder gleich

Sie haben einen niedrigeren Rang als alle arithmetischen Operatoren: Python rechnet beide Seiten zuerst aus und vergleicht dann.

Gleitkommazahlen nicht auf Gleichheit prüfen
Satz 7.3 (Gleichheit von float)

Zwei float sind für == genau dann gleich, wenn sie denselben Wert haben, also bis auf die letzte Binärstelle übereinstimmen. Zwei Rechenwege, die mathematisch dasselbe ergeben, liefern wegen der Rundung oft verschiedene float. Und nan ist zu keinem Wert gleich, nicht einmal zu sich selbst.

Der Vergleich mit Toleranz
Definition 7.4 (Vergleich mit relativer Toleranz)

Zwei Zahlen $a$ und $b$ sind gleich bis auf die relative Toleranz $r$, wenn

$$|a-b|\le r\cdot\max(|a|,|b|) .$$

>>> max(2, 7.5, 3)
>>> a = 0.1 + 0.2
>>> b = 0.3
>>> abs(a - b) <= 1e-9 * max(abs(a), abs(b))

Verkettete Vergleiche
Definition 1.1 (Verketteter Vergleich)

Stehen mehrere Vergleichsoperatoren hintereinander, etwa a < b <= c, so heißt der Ausdruck ein verketteter Vergleich. Er ergibt True genau dann, wenn jeder der einzelnen Vergleiche a < b und b <= c True ergibt. Den mittleren Ausdruck b wertet Python dabei nur einmal aus, und ergibt schon ein früherer Vergleich False, wertet es die weiteren nicht mehr aus.

Zeichenketten vergleichen
Definition 1.2 (Vergleich von Zeichenketten)

Zwei Zeichenketten sind gleich (==), wenn sie aus denselben Zeichen in derselben Reihenfolge bestehen; Groß- und Kleinbuchstaben sind verschiedene Zeichen. Für < und die übrigen Größenvergleiche geht Python die beiden Ketten Zeichen für Zeichen von links durch. Am ersten Zeichen, in dem sie sich unterscheiden, entscheidet die Nummer des Zeichens: Die Kette mit der kleineren Nummer ist die kleinere. Ist eine Kette der Anfang der anderen, ist sie die kleinere.

Der Operator not
Definition 1.3 (not)

not ist ein einstelliger Operator. not x ergibt True, wenn x den Wert False hat, und False, wenn x den Wert True hat.

Der Operator and
Definition 1.4 (and)

and ist ein zweistelliger Operator. a and b ergibt True genau dann, wenn a und b beide True sind.

Der Operator or
Definition 1.5 (or)

or ist ein zweistelliger Operator. a or b ergibt True genau dann, wenn mindestens einer der beiden Operanden True ist.

Die Rangfolge der logischen Operatoren
Definition 1.6 (Rangfolge)

Von fester zu loser bindend: Rechenoperatoren, dann Vergleiche, dann not, dann and, zuletzt or. and bindet also stärker als or, so wie Mal stärker bindet als Plus.

Die Kurzschlussauswertung
Definition 1.7 (Kurzschlussauswertung)

Python wertet a and b und a or b von links aus und hört auf, sobald das Ergebnis feststeht. Bei a and b wird b nur ausgewertet, wenn a wahr ist; bei a or b nur, wenn a falsch ist. Diese Regel heißt Kurzschlussauswertung.

Der Wahrheitswert von Objekten
Definition 1.8 (Wahrheitswert)

Jedes Objekt hat einen Wahrheitswert, True oder False; die Typumwandlung bool(x) zeigt ihn an. Von den bisher bekannten Werten haben genau diese den Wahrheitswert False: False, None, die Null jedes Zahlentyps (0, 0.0, -0.0, 0j) und die leere Zeichenkette "". Alle anderen haben den Wahrheitswert True. Wo Python eine Bedingung erwartet, etwa bei not, benutzt es den Wahrheitswert des Objekts.

Was and und or als Ergebnis liefern
Definition 1.9 (Ergebnis von and und or)

a and b ergibt a selbst, wenn a falsch ist, und sonst b. a or b ergibt a selbst, wenn a wahr ist, und sonst b. Das Ergebnis ist also immer einer der beiden Operanden, unverändert. not x ergibt dagegen immer True oder False.

Entscheidungen: if, elif und else

Die bedingte Anweisung if
Definition 2.1 (Bedingte Anweisung)

Eine bedingte Anweisung hat die Form

if Bedingung: Anweisungen

Die erste Zeile heißt Kopfzeile; sie beginnt mit if und endet mit einem Doppelpunkt. Darunter stehen eine oder mehrere Anweisungen, weiter eingerückt als die Kopfzeile. Python wertet die Bedingung aus und bestimmt ihren Wahrheitswert (Unterabschnitt 1.9). Ist er True, führt Python die eingerückten Anweisungen aus, sonst überspringt es sie. In beiden Fällen geht es danach mit der nächsten Zeile weiter, die wieder so weit links steht wie die Kopfzeile.

Der Block und die Einrückung
Definition 2.2 (Block)

Ein Block ist eine Folge von Anweisungen, die alle gleich weit eingerückt sind und auf eine Kopfzeile folgen, also auf eine Zeile mit einem Doppelpunkt am Ende. Er endet vor der ersten Zeile, die weniger weit eingerückt ist. Ein Block darf selbst Kopfzeilen mit eigenen, noch weiter eingerückten Blöcken enthalten. Üblich sind vier Leerzeichen je Ebene; so empfiehlt es der Stilleitfaden für Python, PEP 8.

>>> if temp > 20:

Die Alternative else
Definition 2.3 (else)

Auf den Block einer bedingten Anweisung darf eine Zeile else: folgen, genau so weit eingerückt wie das zugehörige if, und danach ein eigener Block. Er läuft genau dann, wenn die Bedingung falsch ist. Von den beiden Blöcken läuft also immer genau einer.

Mehrere Fälle: elif
Definition 2.4 (elif)

Zwischen dem Block eines if und einem möglichen else dürfen beliebig viele Zeilen elif Bedingung: mit je einem Block stehen, alle so weit eingerückt wie das if. elif ist eine Abkürzung von „else if“. Python prüft die Bedingungen von oben nach unten. Den Block der ersten Bedingung, die wahr ist, führt es aus und überspringt alle übrigen. Ist keine wahr, läuft der Block nach else, falls es eines gibt.

Wiederholen mit while

Die while-Schleife
Definition 3.1 (while-Schleife)

Eine while-Schleife hat die Form

while Bedingung: Block

Python prüft den Wahrheitswert der Bedingung. Ist er True, führt es den Block aus und kehrt danach zur Kopfzeile zurück, um die Bedingung erneut zu prüfen. Ist er False, geht es mit der ersten Zeile nach dem Block weiter. Eine einzelne Ausführung des Blocks heißt Durchlauf. Die Bedingung wird vor jedem Durchlauf geprüft; ist sie schon beim ersten Mal falsch, läuft der Block kein einziges Mal.

Definition 3.2 (Endlosschleife)

Eine Endlosschleife ist eine Schleife, deren Bedingung nie falsch wird. Ein Programm in einer Endlosschleife bricht man mit Strg+C ab, also mit gedrückter Steuerungstaste und der Taste C. Python beendet das Programm dann mit der Ausnahme KeyboardInterrupt und einem Traceback (Kapitel 1, Abschnitte 6.3 und 6.4).

Zählen mit for und range

Die for-Schleife
Definition 4.1 (for-Schleife)

Eine for-Schleife hat die Form

for name in range(n): Block

Dabei liefert range(n) für eine ganze Zahl $n$ die ganzen Zahlen $0, 1, \ldots, n-1$ der Reihe nach. Die Schleife bindet name nacheinander an jede dieser Zahlen und führt jedes Mal den Block aus; nach der letzten Zahl geht es nach dem Block weiter. Der Name heißt die Schleifenvariable. Allgemein steht nach in ein Objekt, das der Reihe nach Werte liefert; in diesem Abschnitt ist es immer ein range.

Die Zahlenfolge range
Definition 4.2 (range)

range gibt es mit einem, zwei oder drei ganzzahligen Argumenten: range(stop), range(start, stop) und range(start, stop, schritt). Fehlt start, ist er 0; fehlt schritt, ist er 1. Die Folge besteht aus den Zahlen $\mathtt{start}$, $\mathtt{start}+\mathtt{schritt}$, $\mathtt{start}+2\cdot\mathtt{schritt}$, …, solange sie bei positivem Schritt kleiner als stop und bei negativem Schritt größer als stop sind. stop selbst gehört nie dazu. Ist schon start nicht mehr vor stop, ist die Folge leer. len liefert die Zahl der Elemente, für positiven Schritt

$$\textcolor{#1b7f4a}{\mathtt{len}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\max\Bigl(0,\Bigl\lceil\frac{\mathtt{stop}-\mathtt{start}}{\mathtt{schritt}}\Bigr\rceil\Bigr).}$$

Schleifen steuern, verschachteln und Ergebnisse sammeln

Abbrechen mit break
Definition 5.1 (break)

Die Anweisung break im Block einer Schleife beendet diese Schleife sofort. Der Rest des Blocks wird übersprungen, ebenso alle weiteren Durchläufe, und das Programm geht mit der ersten Zeile nach der Schleife weiter.

Überspringen mit continue
Definition 5.2 (continue)

Die Anweisung continue im Block einer Schleife beendet nur den laufenden Durchlauf. Der Rest des Blocks wird übersprungen. Eine for-Schleife macht mit dem nächsten Wert weiter, eine while-Schleife mit der nächsten Prüfung ihrer Bedingung.

Verschachtelte Schleifen
Definition 5.3 (Verschachtelte Schleife)

Steht eine Schleife im Block einer anderen, heißen die beiden verschachtelt. Die Schleife im Block heißt die innere, die andere die äußere. Bei jedem Durchlauf der äußeren Schleife läuft die innere vollständig. Hat die äußere $m$ Durchläufe und die innere jeweils $n$, läuft der Block der inneren Schleife $m\cdot n$-mal. break und continue wirken nur auf die innerste Schleife, deren Block sie enthält.

Das Akkumulator-Muster
Definition 5.4 (Akkumulator)

Ein Akkumulator ist ein Name, der vor einer Schleife an einen Startwert gebunden wird und in jedem Durchlauf mit dem neuen Wert verrechnet wird, zum Beispiel mit summe = summe + wert. Nach der Schleife ist er an das Ergebnis gebunden. Der Startwert ist das Ergebnis für den Fall, dass die Schleife keinen einzigen Durchlauf hat: 0 für eine Summe und eine Anzahl, 1 für ein Produkt.

Definition 6.2 (Näherung mit Toleranz)

Eine Zahl $g$ ist eine Näherung von $\sqrt a$ mit der Toleranz $\varepsilon>0$, wenn $|g^2-a|<\varepsilon$ ist. Die Toleranz $\varepsilon$ legt fest, wie genau „nahe genug“ ist; sie ist eine frei gewählte Zahl und hat nichts mit der Maschinengenauigkeit $\varepsilon_{\mathrm M}$ zu tun.

Die Bisektion

Das Bisektionsverfahren
Definition 7.2 (Bisektion)

Gegeben sind eine stetige Funktion $f$, zwei Zahlen $\mathit{lo}<\mathit{hi}$ mit $f(\mathit{lo})<0\le f(\mathit{hi})$ und eine Toleranz $\varepsilon>0$. Die Bisektion wiederholt, solange $\mathit{hi}-\mathit{lo}>\varepsilon$ ist:

  1. Berechne die Mitte $\textcolor{#1b7f4a}{m}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathit{lo}+\mathit{hi})/2}$.

  2. Ist $f(m)<0$, setze $\textcolor{#1b7f4a}{\mathit{lo}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$, sonst $\textcolor{#1b7f4a}{\mathit{hi}}\textcolor{#15633a}{=}\textcolor{#c2410c}{m}$.

Das Ergebnis ist die Mitte des letzten Intervalls. Ist das Vorzeichen andersherum, $f(\mathit{lo})>0\ge f(\mathit{hi})$, vertauscht man in Schritt 2 die beiden Fälle.

Die Schrittzahl der Bisektion
Satz 7.3 (Schrittzahl der Bisektion)

Beginnt die Bisektion mit einem Intervall der Breite $\textcolor{#1b7f4a}{L}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathit{hi}-\mathit{lo}}$, so ist das Intervall nach $n$ Schritten $L/2^n$ breit. Ist $L>\varepsilon$, endet sie nach

$$\textcolor{#1b7f4a}{n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\Bigl\lceil\log_2\frac{L}{\varepsilon}\Bigr\rceil}$$

Schritten, und die zurückgegebene Mitte ist höchstens $\varepsilon/2$ von einer Nullstelle entfernt.

Das Newton-Verfahren

Das Newton-Verfahren
Definition 8.1 (Newton-Verfahren)

Das Newton-Verfahren für eine Nullstelle einer differenzierbaren Funktion $f$ beginnt mit einem Startwert $g_0$ und berechnet daraus nacheinander

$$\textcolor{#1b7f4a}{g_{n+1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{g_n-\frac{f(g_n)}{f'(g_n)},}$$

solange $|f(g_n)|$ größer als eine Toleranz $\varepsilon$ ist. $g_{n+1}$ ist die Nullstelle der Tangente an der Stelle $g_n$; dazu muss $f'(g_n)\ne0$ sein.

Satz 8.2 (Fehler des Newton-Schritts für die Wurzel)
