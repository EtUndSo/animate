De qué trata esta etapa:

Dos vectores de la misma longitud dan un único número si se multiplican sus componentes por parejas y se suman los productos. Este cálculo es el más frecuente de todo el aprendizaje automático: convierte valores medidos en una estimación y compara datos con un patrón.

El producto escalar de dos vectores#

Una cuenta de la compra se hace así: cantidad por precio para cada artículo y, después, sumarlo todo. El mismo cálculo con dos vectores cualesquiera se llama producto escalar.

Puede imaginarse como el encuentro de una fila con una columna. El primer vector se escribe como fila; el segundo, como columna a su lado. Después se multiplica el primer elemento de la fila por el primero de la columna, el segundo por el segundo, y así sucesivamente, y se suma:

$$\textcolor{#1b7f4a}{\begin{pmatrix}1&2&3\end{pmatrix}\begin{pmatrix}4\\-1\\2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1\cdot4+2\cdot(-1)+3\cdot2}\textcolor{#15633a}{=}\textcolor{#c2410c}{8 .}$$

Definición 2.1 (Producto escalar)

El producto escalar de dos vectores $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ es el número

$$\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}u_j\,v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_1v_1+u_2v_2+\dots+u_dv_d .}$$
(2.1)

La notación $\mathbf{u}^{\top}\mathbf{v}$ dice exactamente lo que ocurre: $\mathbf{u}^{\top}$ es $\mathbf{u}$ como fila, y la fila se encuentra con la columna $\mathbf{v}$. El resultado es un escalar; de ahí el nombre.

Teorema 2.2 (Reglas de cálculo del producto escalar)

Para todos los $\mathbf{u},\mathbf{v},\mathbf{q}\in\mathbb{R}^d$ y todo escalar $c$ se cumple:

  1. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{v}^{\top}\mathbf{u}}$ (simétrico);

  2. $\textcolor{#1b7f4a}{(c\,\mathbf{u})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,(\mathbf{u}^{\top}\mathbf{v})}$ y $\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{q})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}^{\top}\mathbf{v}+\mathbf{q}^{\top}\mathbf{v}}$ (lineal, igualmente en el segundo vector);

  3. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ju_j^2\ge0}$, y $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ solo para $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

Demostración: Reglas de cálculo del producto escalar

(i) se deduce de $\textcolor{#1b7f4a}{u_jv_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_ju_j}$ para cada componente. (ii) es la regla de las sumas (1.2): $\textcolor{#1b7f4a}{\sum_j(c\,u_j)v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\sum_ju_jv_j}$ y $\textcolor{#1b7f4a}{\sum_j(u_j+q_j)v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ju_jv_j+\sum_jq_jv_j}$. (iii) Ningún sumando $u_j^2$ es negativo. La suma solo es cero si cada sumando es cero, es decir, si cada $\textcolor{#1b7f4a}{u_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$.

Ejemplo numérico

Para $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2,\,3)^{\top}}$ y $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(4,\,-1,\,2)^{\top}}$ se tiene $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ y $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{14}$ (fig. 6). En el orden inverso se obtiene el mismo número, $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\cdot1+(-1)\cdot2+2\cdot3}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$, como exige la simetría.

⁠En resumen: El producto escalar multiplica dos vectores componente por componente y suma los productos; es un número.

ContextoOtras notaciones para lo mismo

En muchos libros aparece $\mathbf{u}\cdot\mathbf{v}$ o $\langle\mathbf{u},\mathbf{v}\rangle$ en lugar de $\mathbf{u}^{\top}\mathbf{v}$; en inglés se llama dot product o inner product. Se trata del mismo número. Esta serie escribe $\mathbf{u}^{\top}\mathbf{v}$ porque así se ve en la propia notación que una fila se encuentra con una columna. Esto compensa en cuanto entran en juego tablas de números.

Pesos y sumas ponderadas#

Una agente inmobiliaria estima mentalmente el precio de una vivienda más o menos así: cada metro cuadrado vale unos $3$ mil euros, cada habitación aporta otros $10$ mil euros y cada kilómetro de distancia al centro resta $4$ mil euros. Es decir, toma cada característica con un factor propio y lo suma todo.

El número con el que una característica entra en un cálculo así se llama su peso. Un peso grande y positivo significa que cada unidad de esa característica aumenta mucho el resultado. Un peso negativo significa que la característica reduce el resultado.

Definición 2.3 (Suma ponderada)

Para un vector de pesos $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(w_1,\dots,w_d)^{\top}}$ y un ejemplo $\mathbf{x}\in\mathbb{R}^d$, la suma ponderada es

$$\textcolor{#1b7f4a}{\hat y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}w_j\,x_j .}$$
(2.2)

Una regla de cálculo fija que, a partir de las características de un ejemplo, calcula un número se llama un modelo. El número que el modelo da para un ejemplo se llama su predicción. El «sombrero» sobre la $y$ de $\hat y$ indica que se trata de un valor estimado mediante un cálculo y no de un valor medido. En este capítulo, los pesos siempre vienen dados; de dónde salen unos buenos pesos es una cuestión aparte.

Ejemplo numérico

La agente inmobiliaria usa los pesos $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ en miles de euros por metro cuadrado, por habitación y por kilómetro. Para la vivienda 1 se tiene $\textcolor{#1b7f4a}{\hat y_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{188}$ (fig. 7), es decir, $188$ mil euros.

Para las demás viviendas se obtiene igualmente $\textcolor{#1b7f4a}{\hat y_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{126}$, $\textcolor{#1b7f4a}{\hat y_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{286}$ y $\textcolor{#1b7f4a}{\hat y_4}\textcolor{#15633a}{=}\textcolor{#c2410c}{232}$. Cada producto $w_jx_j$ tiene como unidad los miles de euros, porque la unidad de la característica se simplifica con la unidad del denominador del peso. Solo por eso pueden sumarse los tres productos.

⁠En resumen: Una suma ponderada es el producto escalar $\mathbf{w}^{\top}\mathbf{x}$ de pesos y características; es el modelo más sencillo que hace una predicción a partir de características.

ContextoUn peso grande no significa que la característica sea importante

En el caso de la agente inmobiliaria, el peso de las habitaciones, $10$, es más del triple que el de la superficie, $3$. Aun así, en la vivienda 1 la superficie aporta $180$ mil euros y el número de habitaciones solo $20$. La razón: un peso vale por unidad de la característica, y la superficie tiene muchas unidades. Si se mide la superficie en unidades de $10\,\mathrm m^2$, la vivienda 1 mide solo $6$ unidades, y el mismo modelo necesita el peso de $30$ mil euros por $10\,\mathrm m^2$. La predicción sigue siendo la misma; solo el peso se ha hecho diez veces mayor. El tamaño de un peso depende, por tanto, de la unidad elegida. Si se quiere saber cuánto aporta una característica a la predicción, hay que mirar el producto $w_jx_j$, no el peso por sí solo.

Suma y media como producto escalar#

Muchos cálculos cotidianos son productos escalares con un segundo vector especialmente sencillo. Lo que más se necesita es la suma y el promedio de todas las componentes.

El vector de unos $\mathbf 1\in\mathbb{R}^n$ tiene solo unos como componentes. El producto escalar con él simplemente suma todas las componentes: $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_1+\dots+v_n}$.

Definición 2.4 (Media)

La media de las componentes de un vector $\mathbf{v}\in\mathbb{R}^n$ es

$$\textcolor{#1b7f4a}{\bar v}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\sum_{i=1}^nv_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\,\mathbf 1^{\top}\mathbf{v} .}$$
(2.3)

Otros cálculos de este tipo: el producto escalar con un vector unitario selecciona una componente, $\textcolor{#1b7f4a}{\mathbf{e}_j^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{v_j}$, pues todos los demás productos contienen un cero. El producto escalar de un vector consigo mismo es la suma de los cuadrados, $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_iv_i^2}$. Las cantidades por los precios, sumadas, dan el importe de la factura. Y evaluar un polinomio $\textcolor{#1b7f4a}{p(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{c_1+c_2t+\dots+c_nt^{n-1}}$ en un punto $t$ significa formar el producto escalar $\mathbf{c}^{\top}\mathbf{z}$ de sus coeficientes $\textcolor{#1b7f4a}{\mathbf{c}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(c_1,\dots,c_n)^{\top}}$ con las potencias $\textcolor{#1b7f4a}{\mathbf{z}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,t,\,t^2,\dots,t^{n-1})^{\top}}$. Para $\textcolor{#1b7f4a}{p(t)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+2t+3t^2}$ en el punto $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, esto es $\textcolor{#1b7f4a}{(1,\,2,\,3)\,(1,\,2,\,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+4+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{17}$.

Ejemplo numérico

La vivienda 1 ha consumido de enero a marzo $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(200,\,250,\,300)^{\top}}$ kWh de electricidad (subsección 1.4). En total son $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{750}$ kWh, en promedio $\textcolor{#1b7f4a}{\bar u}\textcolor{#15633a}{=}\textcolor{#c2410c}{250}$ kWh al mes (fig. 8). El consumo de febrero es $\textcolor{#1b7f4a}{\mathbf{e}_2^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{250}$ kWh.

Si el kilovatio hora cuesta en los tres meses $\textcolor{#1b7f4a}{\mathbf{p}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0{,}32;\ 0{,}34;\ 0{,}28)^{\top}}$ euros, la factura de la luz es el producto escalar de precios y cantidades: $\textcolor{#1b7f4a}{\mathbf{p}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{233}$ euros (fig. 9). Cada producto $p_ju_j$ es el importe de un mes, en euros por kWh multiplicados por kWh, es decir, en euros.

⁠En resumen: La suma, la media, la selección de una componente y la suma de cuadrados son productos escalares con $\mathbf 1$, $\tfrac1n\mathbf 1$, $\mathbf{e}_j$ y el propio vector.

El producto escalar como comparación con un patrón#

La temperatura exterior se lee cada doce horas, alternando entre el mediodía y la medianoche. Cuatro valores seguidos forman un vector, al que aquí se llama serie temporal. Se quiere comprobar si salta arriba y abajo de un valor al siguiente, como cabe esperar por la alternancia del día y la noche. Para ello se escribe el patrón buscado como vector, aquí $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,1,\,-1)^{\top}}$, y se forma el producto escalar con la serie temporal.

Lo que ocurre lo muestra la fig. 10. Cada valor se multiplica por el valor del patrón en la misma posición. Si la serie temporal tiene en una posición el mismo signo que el patrón, el producto es positivo; si tiene el signo contrario, es negativo. Si la serie temporal sigue al patrón en todas partes, se acumulan solo contribuciones positivas en una suma grande. Si la serie temporal no tiene nada que ver con el patrón, las contribuciones positivas y negativas se compensan entre sí.

Dicho con precisión: la contribución de la posición $j$ al producto escalar $\mathbf{w}^{\top}\mathbf{x}$ es $w_jx_j$. Es positiva si $w_j$ y $x_j$ tienen el mismo signo, y negativa si tienen signos contrarios. Cuanto mayores sean los valores absolutos en las posiciones con signo coincidente, mayor será el producto escalar.

Para secuencias de números, este cálculo tiene un nombre propio. La suma $\sum_nx[n]\,y[n]$ de dos secuencias reales $x[n]$ e $y[n]$ se llama su correlación cruzada con desplazamiento cero. Si se escriben los valores de dos secuencias de longitud finita como vectores $\mathbf{x}$ y $\mathbf{y}$, esto es exactamente el producto escalar $\mathbf{x}^{\top}\mathbf{y}$. La suma de cuadrados de una secuencia, $\sum_nx[n]^2$, es igualmente $\mathbf{x}^{\top}\mathbf{x}$. La comparación con un patrón no es, por tanto, una herramienta nueva, sino el mismo cálculo con el que se busca un patrón conocido en una secuencia larga de números.

Ejemplo numérico

Con el patrón alternante $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,1,\,-1)^{\top}}$ se tiene $\textcolor{#1b7f4a}{\mathbf{w}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ para $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-1,\,3,\,-2)^{\top}}$ y $\textcolor{#1b7f4a}{\mathbf{w}^{\top}\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ para $\textcolor{#1b7f4a}{\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,2,\,3,\,3)^{\top}}$ (fig. 11). Con el patrón constante $\textcolor{#1b7f4a}{\mathbf 1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,1,\,1,\,1)^{\top}}$ ocurre al revés: $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, pero $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{x}'}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$. La serie temporal $\mathbf{x}$, por tanto, alterna sobre todo entre el día y la noche; $\mathbf{x}'$ es sobre todo constante.

También la suma ponderada de la agente inmobiliaria es una comparación con un patrón. Su patrón $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ describe lo que hace valiosa una vivienda: mucha superficie, muchas habitaciones, poca distancia. Cuanto mejor encaja una vivienda con este patrón, mayor es su predicción.

⁠En resumen: El producto escalar $\mathbf{w}^{\top}\mathbf{x}$ es grande si $\mathbf{x}$ tiene valores grandes allí donde el patrón $\mathbf{w}$ tiene valores grandes del mismo signo; es la correlación con desplazamiento cero.

ContextoLa función de correlación consta solo de productos escalares

La correlación cruzada no compara una secuencia con un patrón en una sola posición, sino para cada desplazamiento posible. Para cada desplazamiento $k$, su valor es un producto escalar: la secuencia con el patrón desplazado $k$ posiciones. La función de correlación entera es, por tanto, una sucesión de productos escalares, uno por desplazamiento. Donde el patrón está contenido en la secuencia, se acumulan las contribuciones positivas, y la función de correlación es allí especialmente grande. Así se encuentra, en una grabación de sonido larga, el punto en que aparece un sonido conocido, por ejemplo un gong, y, en una foto, los lugares que se parecen a un pequeño recorte de imagen. En el aprendizaje automático, el desplazamiento suele quedar fijo en cero: se compara un ejemplo en su conjunto con un patrón.

Ejercicio 4 ★ Comprobar las reglas de cálculo

Sean $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0,\,2)^{\top}}$, $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,-1,\,1)^{\top}}$ y $\textcolor{#1b7f4a}{\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,2,\,1)^{\top}}$. Calcula $\mathbf{u}^{\top}\mathbf{v}$, $\mathbf{v}^{\top}\mathbf{u}$, $\mathbf{u}^{\top}(\mathbf{v}+\mathbf{q})$, $\mathbf{u}^{\top}\mathbf{v}+\mathbf{u}^{\top}\mathbf{q}$, $(3\mathbf{u})^{\top}\mathbf{v}$ y $\mathbf{u}^{\top}\mathbf{u}$. ¿Qué regla de cálculo muestra cada comparación?

Solución

Se tiene $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$ y $\textcolor{#1b7f4a}{\mathbf{v}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$: el producto escalar es simétrico, la regla (i). Con $\textcolor{#1b7f4a}{\mathbf{v}+\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,1,\,2)^{\top}}$ se tiene $\textcolor{#1b7f4a}{\mathbf{u}^{\top}(\mathbf{v}+\mathbf{q})}\textcolor{#15633a}{=}\textcolor{#c2410c}{3+0+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$, y $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}+\mathbf{u}^{\top}\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{5+(0+0+2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{7}$: linealidad en el segundo vector, la regla (ii). Además, $\textcolor{#1b7f4a}{(3\mathbf{u})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,0,6)\,(3,-1,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{9+0+6}\textcolor{#15633a}{=}\textcolor{#c2410c}{15}\textcolor{#15633a}{=}\textcolor{#c2410c}{3\cdot5}$, también la regla (ii). Por último, $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+0+4}\textcolor{#15633a}{=}\textcolor{#c2410c}{5>0}$, como exige la regla (iii) para $\mathbf{u}\ne\mathbf{0}$.

Ejercicio 5 ★★ La estimación de la agente inmobiliaria

Usa los pesos $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,10,\,-4)^{\top}}$ de la subsección 2.2.

  1. Calcula las predicciones para las cuatro viviendas. ¿Qué unidad tienen?

  2. En la vivienda 2 se levanta un tabique; después tiene dos habitaciones con la misma superficie. ¿Cómo cambia la predicción, y por qué el cambio no depende de la superficie?

  3. Un compañero dice: «Para la agente inmobiliaria, lo que más cuenta son las habitaciones; tienen el peso más grande». Comprueba la afirmación con la vivienda 1 comparando las tres contribuciones $w_jx_{1j}$.

Solución

(a) Como en la subsección 2.2: $188$, $126$, $286$ y $232$, en cada caso en miles de euros. La unidad son miles de euros, porque cada peso tiene la unidad «miles de euros por unidad de la característica», y la unidad de la característica se simplifica en el producto.

(b) La vivienda 2 pasa a ser $(40,\,2,\,1)^{\top}$. La predicción sube de $126$ a $\textcolor{#1b7f4a}{120+20-4}\textcolor{#15633a}{=}\textcolor{#c2410c}{136}$, es decir, en $10$. En general, si la segunda característica cambia en $\Delta x_2$, la suma ponderada cambia en $w_2\,\Delta x_2$, pues $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(\mathbf{x}+\Delta x_2\,\mathbf{e}_2)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}+\Delta x_2\,\mathbf{w}^{\top}\mathbf{e}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}+\Delta x_2\,w_2}$. Las demás características no influyen en ello. Esa es la linealidad del producto escalar: cada característica contribuye por sí sola, sin interacción con las demás.

(c) Las contribuciones en la vivienda 1 son $\textcolor{#1b7f4a}{w_1x_{11}}\textcolor{#15633a}{=}\textcolor{#c2410c}{180}$, $\textcolor{#1b7f4a}{w_2x_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{20}$ y $\textcolor{#1b7f4a}{w_3x_{13}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-12}$. Con diferencia, la mayor contribución es la de la superficie, aunque su peso es, en valor absoluto, el menor. La afirmación del compañero confunde el peso por unidad con la contribución a la predicción; la superficie tiene muchísimas unidades.

Ejercicio 6 ★★ Un patrón para series temporales crecientes

Se quiere comprobar si una serie temporal con cuatro valores, por ejemplo la temperatura en cuatro días seguidos, crece. Como patrón se propone $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(-3,\,-1,\,1,\,3)^{\top}}$.

  1. Calcula $\mathbf{w}^{\top}\mathbf{x}$ para $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,2,3,4)^{\top}}$, $(4,3,2,1)^{\top}$, $(5,5,5,5)^{\top}$ y $(1,3,2,4)^{\top}$, e interpreta los resultados.

  2. ¿Por qué toda serie temporal constante $c\,\mathbf1$ da exactamente cero? Usa $\mathbf 1^{\top}\mathbf{w}$.

Solución

(a) $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(1,2,3,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-2+3+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$: la serie temporal crece, y el resultado es claramente positivo. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(4,3,2,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-12-3+2+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{-10}$: la serie temporal decrece, y el resultado es igual de claramente negativo. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(5,5,5,5)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-15-5+5+15}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$: constante, sin subida. $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(1,3,2,4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-3+2+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$: la serie temporal crece en conjunto, con un retroceso en el medio, y el resultado es algo menor que con la subida regular. El patrón pondera negativamente los valores tempranos y positivamente los tardíos; reacciona, por tanto, a si los valores tardíos son mayores que los tempranos.

(b) $\textcolor{#1b7f4a}{\mathbf 1^{\top}\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3-1+1+3}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Por eso, para una serie temporal constante, $\textcolor{#1b7f4a}{\mathbf{w}^{\top}(c\,\mathbf 1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{w}^{\top}\mathbf 1}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\cdot0}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Como los pesos suman cero, el patrón ignora por completo una cantidad fija que se suma a todos los valores: solo mide diferencias entre los valores. Que haga $10$ grados más de calor en los cuatro días no cambia el resultado.

El producto escalar de dos vectores
Definición 2.1 (Producto escalar)

El producto escalar de dos vectores $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ es el número

$$\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}u_j\,v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_1v_1+u_2v_2+\dots+u_dv_d .}$$
(2.1)
Teorema 2.2 (Reglas de cálculo del producto escalar)

Para todos los $\mathbf{u},\mathbf{v},\mathbf{q}\in\mathbb{R}^d$ y todo escalar $c$ se cumple:

  1. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{v}^{\top}\mathbf{u}}$ (simétrico);

  2. $\textcolor{#1b7f4a}{(c\,\mathbf{u})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,(\mathbf{u}^{\top}\mathbf{v})}$ y $\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{q})^{\top}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}^{\top}\mathbf{v}+\mathbf{q}^{\top}\mathbf{v}}$ (lineal, igualmente en el segundo vector);

  3. $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_ju_j^2\ge0}$, y $\textcolor{#1b7f4a}{\mathbf{u}^{\top}\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ solo para $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

Pesos y sumas ponderadas
Definición 2.3 (Suma ponderada)

Para un vector de pesos $\textcolor{#1b7f4a}{\mathbf{w}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(w_1,\dots,w_d)^{\top}}$ y un ejemplo $\mathbf{x}\in\mathbb{R}^d$, la suma ponderada es

$$\textcolor{#1b7f4a}{\hat y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{w}^{\top}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^{d}w_j\,x_j .}$$
(2.2)
Suma y media como producto escalar
Definición 2.4 (Media)

La media de las componentes de un vector $\mathbf{v}\in\mathbb{R}^n$ es

$$\textcolor{#1b7f4a}{\bar v}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\sum_{i=1}^nv_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1n\,\mathbf 1^{\top}\mathbf{v} .}$$
(2.3)

Relaciones clave
  • Sobre «El producto escalar de dos vectores»: El producto escalar multiplica dos vectores componente por componente y suma los productos; es un número.
  • Sobre «Pesos y sumas ponderadas»: Una suma ponderada es el producto escalar $\mathbf{w}^{\top}\mathbf{x}$ de pesos y características; es el modelo más sencillo que hace una predicción a partir de características.
  • Sobre «Suma y media como producto escalar»: La suma, la media, la selección de una componente y la suma de cuadrados son productos escalares con $\mathbf 1$, $\tfrac1n\mathbf 1$, $\mathbf{e}_j$ y el propio vector.
  • Sobre «El producto escalar como comparación con un patrón»: El producto escalar $\mathbf{w}^{\top}\mathbf{x}$ es grande si $\mathbf{x}$ tiene valores grandes allí donde el patrón $\mathbf{w}$ tiene valores grandes del mismo signo; es la correlación con desplazamiento cero.
