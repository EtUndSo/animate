De qué trata esta etapa:

Algunas aplicaciones lineales pueden deshacerse; otras, no. Esta sección introduce la matriz que no cambia nada y la matriz inversa, que invierte una aplicación, y aclara cuándo existe.

La matriz identidad#

Entre todas las aplicaciones lineales hay una que no hace nada en absoluto: lleva cada vector a sí mismo. Sus columnas son, según (8.2), las imágenes de los vectores unitarios, es decir, los propios vectores unitarios.

Definición 11.1 (Matriz identidad)

La matriz identidad $\mathbf{I}_n\in\mathbb{R}^{n\times n}$ es la matriz diagonal con solo unos en la diagonal. Sus columnas son $\mathbf{e}_1,\dots,\mathbf{e}_n$.

Si el tamaño está claro, se escribe abreviadamente $\mathbf{I}$. Para todo vector $\mathbf{x}\in\mathbb{R}^n$, $\textcolor{#1b7f4a}{\mathbf{I}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{x}}$, y para toda matriz $\mathbf{A}\in\mathbb{R}^{m\times n}$, $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{I}_n}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}}$ y también $\textcolor{#1b7f4a}{\mathbf{I}_m\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}}$. La matriz identidad desempeña en el producto de matrices el papel del número $1$.

Ejemplo numérico
$$\textcolor{#1b7f4a}{\mathbf{I}_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\mathbf{I}_3\begin{pmatrix}60\\2\\3\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}60\\2\\3\end{pmatrix}.}$$

⁠En resumen: La matriz identidad tiene unos en la diagonal y ceros en el resto; como aplicación, deja cada vector sin cambios.

La matriz inversa#

Una rotación de $90^\circ$ se deshace girando $90^\circ$ hacia atrás. Un estiramiento al doble se deshace comprimiendo a la mitad. En ambos casos existe una segunda aplicación que anula la primera: aplicadas una tras otra, las dos juntas no hacen nada.

Definición 11.2 (Matriz inversa)

Una matriz cuadrada $\mathbf{A}\in\mathbb{R}^{n\times n}$ se llama invertible si existe una matriz $\mathbf{A}^{-1}\in\mathbb{R}^{n\times n}$ con

$$\textcolor{#1b7f4a}{\mathbf{A}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I} .}$$
(11.1)

La matriz $\mathbf{A}^{-1}$ se llama la inversa de $\mathbf{A}$.

Existe como mucho una matriz así. En efecto, si $\mathbf{B}$ y $\mathbf{C}$ son ambas inversas de $\mathbf{A}$, entonces $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}\mathbf{I}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}(\mathbf{A}\mathbf{C})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{B}\mathbf{A})\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{C}}$. Por eso se puede hablar de la inversa. Si se conoce, cualquier resultado $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ puede recalcularse hacia atrás: $\textcolor{#1b7f4a}{\mathbf{A}^{-1}\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{x}}$.

Ejemplo numérico

$$\textcolor{#1b7f4a}{\begin{pmatrix}2&1\\1&1\end{pmatrix}\begin{pmatrix}1&-1\\-1&2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}2-1&-2+2\\1-1&-1+2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}1&0\\0&1\end{pmatrix},}$$

y lo mismo en el otro orden, así que $\textcolor{#1b7f4a}{\bigl(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\bigr)^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&-1\\-1&2\end{smallmatrix}\bigr)}$. El estiramiento tiene la inversa $\textcolor{#1b7f4a}{\operatorname{diag}(2;\,0{,}5)^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}(0{,}5;\,2)}$; la rotación de $90^\circ$, la rotación de $-90^\circ$, $\textcolor{#1b7f4a}{\bigl(\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\bigr)^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}0&1\\-1&0\end{smallmatrix}\bigr)}$.

⁠En resumen: La inversa $\mathbf{A}^{-1}$ deshace la aplicación $\mathbf{A}$: $\textcolor{#1b7f4a}{\mathbf{A}^{-1}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$.

ContextoLa inversa de una matriz diagonal

Una matriz diagonal $\operatorname{diag}(\mathbf{v})$ multiplica cada componente por su propio factor $v_j$. Esto se deshace dividiendo cada componente por su factor: $\textcolor{#1b7f4a}{\operatorname{diag}(\mathbf{v})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}(1/v_1,\dots,1/v_n)}$. Es posible si y solo si ningún factor es cero. Un factor $\textcolor{#1b7f4a}{v_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ borra la componente $j$, y lo que se ha borrado no puede recuperarlo ningún cálculo.

La inversa de una matriz $2\times2$#

Para las matrices $2\times2$ hay una fórmula sencilla. Se intercambian las dos entradas de la diagonal, se pone un signo menos delante de las otras dos y se divide por un número que se forma a partir de las cuatro entradas.

Teorema 11.3 (Inversa de una matriz $2\times2$)

La matriz $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}a&b\\c&d\end{smallmatrix}\bigr)}$ es invertible si y solo si $ad-bc\ne0$, y entonces

$$\textcolor{#1b7f4a}{\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.}$$
(11.2)
Deducción: Inversa de una matriz $2\times2$

Multiplicando se obtiene

$$\textcolor{#1b7f4a}{\begin{pmatrix}a&b\\c&d\end{pmatrix}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}ad-bc&-ab+ba\\cd-dc&-cb+da\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(ad-bc)\,\mathbf{I} ,}$$

y lo mismo en el otro orden. Si $ad-bc\ne0$, se divide por este número y se obtiene (11.1). Si $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$, $\mathbf{A}$ lleva el vector $(d,\,-c)^{\top}$ a $\textcolor{#1b7f4a}{(ad-bc,\ cd-dc)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, e igualmente $(b,\,-a)^{\top}$ a $\mathbf{0}$. Al menos uno de los dos no es el vector nulo, salvo que las cuatro entradas sean cero, y entonces $\mathbf{A}$ es de todos modos la matriz nula. Pero una matriz que lleva un vector $\mathbf{x}\ne\mathbf{0}$ a $\mathbf{0}$ no tiene inversa: si la tuviera, sería $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{0}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

Ejemplo numérico

Para $\bigl(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\bigr)$, $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{2-1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, así que la inversa es $\bigl(\begin{smallmatrix}1&-1\\-1&2\end{smallmatrix}\bigr)$, como antes. Para $\bigl(\begin{smallmatrix}3&1\\1&2\end{smallmatrix}\bigr)$, $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, y la inversa es $\tfrac15\bigl(\begin{smallmatrix}2&-1\\-1&3\end{smallmatrix}\bigr)$.

⁠En resumen: Una matriz $2\times2$ es invertible si y solo si $ad-bc\ne0$; la inversa es $\frac{1}{ad-bc}\bigl(\begin{smallmatrix}d&-b\\-c&a\end{smallmatrix}\bigr)$.

Reglas de cálculo para inversas#

Quien ejecuta dos aplicaciones una tras otra y quiere deshacer el resultado tiene que anular primero la segunda. Por eso, al invertir un producto, el orden se invierte.

Teorema 11.4 (Reglas de cálculo para inversas)

Si $\mathbf{A},\mathbf{B}\in\mathbb{R}^{n\times n}$ son invertibles y $c\ne0$, también $\mathbf{A}\mathbf{B}$, $\mathbf{A}^{\top}$, $\mathbf{A}^{-1}$ y $c\,\mathbf{A}$ son invertibles, y se cumple

$$\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}^{-1}\mathbf{A}^{-1},}$$
$$\textcolor{#1b7f4a}{(\mathbf{A}^{\top})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{-1})^{\top},}$$
$$\textcolor{#1b7f4a}{(\mathbf{A}^{-1})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A},}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{A})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac1c\,\mathbf{A}^{-1}.}$$
Deducción: Reglas de cálculo para inversas

En cada caso se comprueba que el producto con el candidato da la matriz identidad. Para el producto: $\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})(\mathbf{B}^{-1}\mathbf{A}^{-1})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}(\mathbf{B}\mathbf{B}^{-1})\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$, e igualmente $\textcolor{#1b7f4a}{(\mathbf{B}^{-1}\mathbf{A}^{-1})(\mathbf{A}\mathbf{B})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$. Para la traspuesta: $\textcolor{#1b7f4a}{\mathbf{A}^{\top}(\mathbf{A}^{-1})^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{-1}\mathbf{A})^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$, y lo mismo en el otro orden. Las dos últimas reglas se siguen directamente de (11.1).

Una regla que sería cómoda no se cumple: $(\mathbf{A}+\mathbf{B})^{-1}$ no es, en general, $\mathbf{A}^{-1}+\mathbf{B}^{-1}$. Ya con números, $\textcolor{#1b7f4a}{\frac{1}{2+4}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac16}$, pero $\textcolor{#1b7f4a}{\frac12+\frac14}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac34}$.

Ejemplo numérico

Para $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\bigr)}$ y $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}3&1\\1&2\end{smallmatrix}\bigr)}$, $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}7&4\\4&3\end{smallmatrix}\bigr)}$, con $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{21-16}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, así que $\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac15\bigl(\begin{smallmatrix}3&-4\\-4&7\end{smallmatrix}\bigr)}$. Lo mismo da

$$\textcolor{#1b7f4a}{\mathbf{B}^{-1}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac15\begin{pmatrix}2&-1\\-1&3\end{pmatrix}\begin{pmatrix}1&-1\\-1&2\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac15\begin{pmatrix}3&-4\\-4&7\end{pmatrix}.}$$

⁠En resumen: La inversa de un producto es el producto de las inversas en orden inverso, $\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}^{-1}\mathbf{A}^{-1}}$.

ContextoUna imagen para el orden inverso

Quien por la mañana se pone primero un jersey y luego una chaqueta, por la noche se quita primero la chaqueta y luego el jersey. Deshacer recorre los pasos hacia atrás. La aplicación $\mathbf{A}\mathbf{B}$ es «primero $\mathbf{B}$, después $\mathbf{A}$»; para anularla hay que anular primero $\mathbf{A}$ y después $\mathbf{B}$, es decir, aplicar primero $\mathbf{A}^{-1}$ y después $\mathbf{B}^{-1}$. Escrito como matriz, con el paso ejecutado primero a la derecha, eso es $\mathbf{B}^{-1}\mathbf{A}^{-1}$. La imagen solo sirve en lo que se refiere al orden; no explica por qué existe una inversa.

Cuándo no hay inversa#

La matriz $\operatorname{diag}(1;\,0)$ aplasta el plano sobre el eje $x_1$ (fig. 32). Los puntos $(1,\,5)^{\top}$ y $(1,\,-2)^{\top}$ van a parar ambos a $(1,\,0)^{\top}$. Quien solo ve el resultado $(1,\,0)^{\top}$ no puede saber de qué punto procede. La segunda componente se ha perdido, y ningún cálculo la recupera.

Teorema 11.5 (Sin inversa)

Si existe un vector $\mathbf{x}\ne\mathbf{0}$ con $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, $\mathbf{A}$ no es invertible.

Demostración: Sin inversa

Si hubiera una inversa, sería $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{0}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, en contradicción con $\mathbf{x}\ne\mathbf{0}$.

Intuitivamente: con $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, para todo $\mathbf{u}$ los dos vectores distintos $\mathbf{u}$ y $\mathbf{u}+\mathbf{x}$ van a parar al mismo lugar, pues $\textcolor{#1b7f4a}{\mathbf{A}(\mathbf{u}+\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{u}+\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{u}}$. Dos entradas con la misma salida no pueden distinguirse. Una matriz cuadrada que no es invertible se llama singular.

Ejemplo numérico

Para $\bigl(\begin{smallmatrix}1&2\\2&4\end{smallmatrix}\bigr)$, $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{4-4}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. En efecto, $\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-1)^{\top}}$ se lleva a $\textcolor{#1b7f4a}{(2-2,\ 4-4)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, y los vectores distintos $(1,\,1)^{\top}$ y $(3,\,0)^{\top}$ van a parar ambos a $(3,\,6)^{\top}$.

Para los datos, esto significa: un cálculo que, por ejemplo, a partir del número de dormitorios y del de salones solo forma el número total de habitaciones ya no puede separar los dos números. En las matrices $2\times2$, este es exactamente el caso $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ de la subsección 11.3.

⁠En resumen: Si una matriz lleva un vector $\mathbf{x}\ne\mathbf{0}$ a $\mathbf{0}$, pierde información y no tiene inversa; se llama entonces singular.

Ejercicio 26 ★ Calcular inversas

  1. Calcula las inversas de $\bigl(\begin{smallmatrix}4&3\\1&1\end{smallmatrix}\bigr)$ y $\bigl(\begin{smallmatrix}1&2\\3&4\end{smallmatrix}\bigr)$ y haz en cada caso la comprobación.

  2. ¿Para qué número $t$ no es invertible $\bigl(\begin{smallmatrix}2&t\\4&6\end{smallmatrix}\bigr)$? Indica para ese caso un vector $\mathbf{x}\ne\mathbf{0}$ con $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

  3. Indica la inversa de $\operatorname{diag}(4;\,-1;\,0{,}5)$.

Solución

(a) Para $\bigl(\begin{smallmatrix}4&3\\1&1\end{smallmatrix}\bigr)$ se tiene $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{4-3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, y la inversa es $\bigl(\begin{smallmatrix}1&-3\\-1&4\end{smallmatrix}\bigr)$. Comprobación: $\textcolor{#1b7f4a}{\bigl(\begin{smallmatrix}4&3\\1&1\end{smallmatrix}\bigr)\bigl(\begin{smallmatrix}1&-3\\-1&4\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}4-3&-12+12\\1-1&-3+4\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$. Para $\bigl(\begin{smallmatrix}1&2\\3&4\end{smallmatrix}\bigr)$ se tiene $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{4-6}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2}$, y la inversa es $\textcolor{#1b7f4a}{-\tfrac12\bigl(\begin{smallmatrix}4&-2\\-3&1\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}-2&1\\1{,}5&-0{,}5\end{smallmatrix}\bigr)}$. Comprobación: $\textcolor{#1b7f4a}{\bigl(\begin{smallmatrix}1&2\\3&4\end{smallmatrix}\bigr)\bigl(\begin{smallmatrix}-2&1\\1{,}5&-0{,}5\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}-2+3&1-1\\-6+6&3-2\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$.

(b) $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{12-4t}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ para $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Entonces la matriz es $\bigl(\begin{smallmatrix}2&3\\4&6\end{smallmatrix}\bigr)$; su segunda fila es el doble de la primera. El vector $(3,\,-2)^{\top}$ va a parar a $\textcolor{#1b7f4a}{(6-6,\ 12-12)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$.

(c) $\textcolor{#1b7f4a}{\operatorname{diag}(4;\,-1;\,0{,}5)^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\operatorname{diag}(0{,}25;\,-1;\,2)}$: cada entrada diagonal se sustituye por su inverso.

Ejercicio 27 ★★ Argumentar con inversas

  1. Comprueba $\textcolor{#1b7f4a}{(\mathbf{C}^{\top})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{C}^{-1})^{\top}}$ para $\textcolor{#1b7f4a}{\mathbf{C}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&2\\3&4\end{smallmatrix}\bigr)}$.

  2. Sea $\mathbf{A}$ invertible y $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf 0}$. Demuestra que entonces $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf 0}$.

  3. Con números, de $\textcolor{#1b7f4a}{ab}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ se sigue que $\textcolor{#1b7f4a}{a}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ o $\textcolor{#1b7f4a}{b}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. Demuestra con $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\bigr)}$ que para matrices esto no se cumple. ¿Por qué no contradice esto el apartado (b)?

Solución

(a) $\textcolor{#1b7f4a}{\mathbf{C}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}-2&1\\1{,}5&-0{,}5\end{smallmatrix}\bigr)}$, del ejercicio anterior; por tanto, $\textcolor{#1b7f4a}{(\mathbf{C}^{-1})^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}-2&1{,}5\\1&-0{,}5\end{smallmatrix}\bigr)}$. Por otro lado, $\textcolor{#1b7f4a}{\mathbf{C}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}1&3\\2&4\end{smallmatrix}\bigr)}$, con $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2}$; por tanto, $\textcolor{#1b7f4a}{(\mathbf{C}^{\top})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{-\tfrac12\bigl(\begin{smallmatrix}4&-3\\-2&1\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}-2&1{,}5\\1&-0{,}5\end{smallmatrix}\bigr)}$. Ambas coinciden.

(b) Se multiplica $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf 0}$ por la izquierda por $\mathbf{A}^{-1}$: $\textcolor{#1b7f4a}{\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}\mathbf{B}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf 0}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf 0}$.

(c) $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\bigr)\bigl(\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}0\cdot0+1\cdot0&0\cdot1+1\cdot0\\0&0\end{smallmatrix}\bigr)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf 0}$, aunque $\mathbf{A}\ne\mathbf 0$. Geométricamente, $\mathbf{A}$ envía el vector $\mathbf{e}_2$ a $\mathbf{e}_1$, y $\mathbf{e}_1$ a $\mathbf{0}$; aplicada dos veces, todo acaba en el vector nulo. Esto no contradice el apartado (b), pues $\mathbf{A}$ no es invertible: $\textcolor{#1b7f4a}{ad-bc}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$. La conclusión de (b) necesita la inversa.

La matriz identidad
Definición 11.1 (Matriz identidad)

La matriz identidad $\mathbf{I}_n\in\mathbb{R}^{n\times n}$ es la matriz diagonal con solo unos en la diagonal. Sus columnas son $\mathbf{e}_1,\dots,\mathbf{e}_n$.

La matriz inversa
Definición 11.2 (Matriz inversa)

Una matriz cuadrada $\mathbf{A}\in\mathbb{R}^{n\times n}$ se llama invertible si existe una matriz $\mathbf{A}^{-1}\in\mathbb{R}^{n\times n}$ con

$$\textcolor{#1b7f4a}{\mathbf{A}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{-1}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I} .}$$
(11.1)

La matriz $\mathbf{A}^{-1}$ se llama la inversa de $\mathbf{A}$.

La inversa de una matriz $2\times2$
Teorema 11.3 (Inversa de una matriz $2\times2$)

La matriz $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\bigl(\begin{smallmatrix}a&b\\c&d\end{smallmatrix}\bigr)}$ es invertible si y solo si $ad-bc\ne0$, y entonces

$$\textcolor{#1b7f4a}{\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.}$$
(11.2)
Reglas de cálculo para inversas
Teorema 11.4 (Reglas de cálculo para inversas)

Si $\mathbf{A},\mathbf{B}\in\mathbb{R}^{n\times n}$ son invertibles y $c\ne0$, también $\mathbf{A}\mathbf{B}$, $\mathbf{A}^{\top}$, $\mathbf{A}^{-1}$ y $c\,\mathbf{A}$ son invertibles, y se cumple

$$\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}^{-1}\mathbf{A}^{-1},}$$
$$\textcolor{#1b7f4a}{(\mathbf{A}^{\top})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}^{-1})^{\top},}$$
$$\textcolor{#1b7f4a}{(\mathbf{A}^{-1})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A},}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{A})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac1c\,\mathbf{A}^{-1}.}$$
Cuándo no hay inversa
Teorema 11.5 (Sin inversa)

Si existe un vector $\mathbf{x}\ne\mathbf{0}$ con $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{0}}$, $\mathbf{A}$ no es invertible.

Resumen

Términos
  • matriz identidad – La matriz identidad $\mathbf{I}_n\in\mathbb{R}^{n\times n}$ es la matriz diagonal con solo unos en la diagonal.
  • invertible – Una matriz cuadrada $\mathbf{A}\in\mathbb{R}^{n\times n}$ se llama invertible si existe una matriz $\mathbf{A}^{-1}\in\mathbb{R}^{n\times n}$ con …
  • inversa – La matriz $\mathbf{A}^{-1}$ se llama la inversa de $\mathbf{A}$.
  • singular – Una matriz cuadrada que no es invertible se llama singular.

Relaciones clave
  • Sobre «La matriz identidad»: La matriz identidad tiene unos en la diagonal y ceros en el resto; como aplicación, deja cada vector sin cambios.
  • Sobre «La matriz inversa»: La inversa $\mathbf{A}^{-1}$ deshace la aplicación $\mathbf{A}$: $\textcolor{#1b7f4a}{\mathbf{A}^{-1}\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{A}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$.
  • Sobre «La inversa de una matriz $2\times2$»: Una matriz $2\times2$ es invertible si y solo si $ad-bc\ne0$; la inversa es $\frac{1}{ad-bc}\bigl(\begin{smallmatrix}d&-b\\-c&a\end{smallmatrix}\bigr)$.
  • Sobre «Reglas de cálculo para inversas»: La inversa de un producto es el producto de las inversas en orden inverso, $\textcolor{#1b7f4a}{(\mathbf{A}\mathbf{B})^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{B}^{-1}\mathbf{A}^{-1}}$.
  • Sobre «Cuándo no hay inversa»: Si una matriz lleva un vector $\mathbf{x}\ne\mathbf{0}$ a $\mathbf{0}$, pierde información y no tiene inversa; se llama entonces singular.
