De qué trata esta etapa:

Un ordenador solo sabe manejar números. Esta sección aclara cómo se describe una cosa del mundo real mediante una lista de números y qué cálculos están permitidos con tales listas.

Lo que necesitasel signo de sumatorio y los índices

En este capítulo se suman constantemente muchos números. Para no tener que escribir cada vez «$a_1+a_2+\dots$», existe una notación abreviada.

Índices. Si se tienen varios números del mismo tipo, se numeran correlativamente: $a_1,a_2,\dots,a_n$. El número escrito como subíndice se llama índice. Solo indica qué lugar ocupa el número en cuestión y no tiene nada que ver con su valor.

El signo de sumatorio. Para la suma de $a_1$ a $a_n$ se escribe

$$\textcolor{#1b7f4a}{\sum_{i=1}^{n} a_i }\textcolor{#15633a}{=}\textcolor{#c2410c}{ a_1+a_2+\dots+a_n ,}$$
(1.1)

que se lee «suma de $a_i$ para $i$ desde $1$ hasta $n$». La gran sigma griega se llama signo de sumatorio. La letra $i$ que hay debajo es el índice de sumación: toma sucesivamente los valores $1,2,\dots,n$, y por cada valor se añade un sumando. El índice de sumación es un marcador de posición. Llamarlo $i$, $j$ o $k$ no cambia la suma: $\textcolor{#1b7f4a}{\sum_{i=1}^n a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^n a_j}$.

Dos reglas de cálculo. Una suma con signo de sumatorio no es más que una suma ordinaria de un número finito de números, escrita de forma abreviada. Por eso valen para ella las reglas conocidas: se puede sacar factor común (propiedad distributiva) y reordenar y agrupar los sumandos a voluntad (propiedades conmutativa y asociativa). Escrito con el signo de sumatorio, esto significa que un factor común puede ponerse delante de la suma y que una suma de sumas puede separarse:

$$\textcolor{#1b7f4a}{\sum_{i=1}^n c\,a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\sum_{i=1}^n a_i ,}$$
$$\textcolor{#1b7f4a}{\sum_{i=1}^n (a_i+b_i)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=1}^n a_i+\sum_{i=1}^n b_i .}$$
(1.2)

Sumas dobles. Los números dispuestos en una tabla llevan dos índices: $a_{ij}$ es el número de la fila $i$ y la columna $j$. La suma de todas las entradas de una tabla con $m$ filas y $n$ columnas se escribe como suma doble

$$\sum_{i=1}^{m}\sum_{j=1}^{n}a_{ij} .$$

Se lee de dentro hacia fuera: para cada fila $i$, la suma interior suma los números de esa fila; la suma exterior suma las sumas de las filas. Como con un número finito de sumandos el orden no importa, se pueden intercambiar los dos signos de sumatorio y sumar primero por columnas.

Ejemplo numérico 1

Para $\textcolor{#1b7f4a}{a_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{a_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{5}$, $\textcolor{#1b7f4a}{a_3}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, cada suma se escribe primero desarrollada; después se sustituyen los números y se suma (fig. 1). Así, $\textcolor{#1b7f4a}{\sum_{i=1}^3 a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{8}$ y $\textcolor{#1b7f4a}{\sum_{i=1}^3 a_i^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{30}$. En la tercera suma, el propio índice de sumación es el sumando: $\textcolor{#1b7f4a}{\sum_{j=1}^{3}j}\textcolor{#15633a}{=}\textcolor{#c2410c}{6}$.

Ejemplo numérico 2

La tabla con las filas $(1,\,2)$ y $(3,\,4)$ tiene las entradas $\textcolor{#1b7f4a}{a_{11}}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, $\textcolor{#1b7f4a}{a_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$, $\textcolor{#1b7f4a}{a_{21}}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, $\textcolor{#1b7f4a}{a_{22}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$. Sumando por filas, la suma doble da $\textcolor{#1b7f4a}{(1+2)+(3+4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$; por columnas, $\textcolor{#1b7f4a}{(1+3)+(2+4)}\textcolor{#15633a}{=}\textcolor{#c2410c}{10}$ (fig. 2).

⁠En resumen: $\sum_{i=1}^n a_i$ es la suma de $a_1$ a $a_n$; el índice de sumación $i$ es solo un marcador de posición.

Ejemplos y características#

Quien quiere aprender a partir de datos tiene primero ante sí una colección de cosas del mismo tipo: viviendas, pacientes, cartas, mediciones en una máquina. Cada cosa se describe mediante las mismas magnitudes medidas. Las viviendas, por ejemplo, mediante su superficie, el número de habitaciones y la distancia al centro de la ciudad. Si se anota esto para varias viviendas, se obtiene una tabla (tabla 1), que acompaña a todo el capítulo.

Cada fila de la tabla corresponde a una cosa; cada columna, a una magnitud medida. Para ambas hay términos fijos.

Definición 1.1 (Característica, ejemplo, conjunto de datos)

Una característica es una propiedad que puede expresarse mediante un número real.

Un ejemplo es una cosa individual descrita por los valores de $d$ características.

Un conjunto de datos es una colección de $N$ ejemplos, todos descritos por las mismas $d$ características.

En toda la serie se cumple: $N$ es el número de ejemplos y $d$ el número de características. Los ejemplos se numeran con $\textcolor{#1b7f4a}{i}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,N}$; las características, con $\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d}$.

Dos aclaraciones sobre los términos. En las bases de datos, una sola fila de una tabla se llama a menudo «registro»; aquí, el conjunto de datos es la colección entera. Y la palabra «ejemplo» designa en este capítulo siempre una cosa de un conjunto de datos; por eso, los cálculos resueltos paso a paso se llaman «ejemplo numérico».

Ejemplo numérico

El conjunto de datos de viviendas tiene $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ ejemplos y $\textcolor{#1b7f4a}{d}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ características. La característica 2 es el número de habitaciones. En la vivienda 3 tiene el valor $4$.

No toda propiedad es de por sí un número. El barrio de una vivienda es un nombre. Tales propiedades hay que traducirlas primero a números antes de poder calcular con ellas. En este capítulo, todas las características ya son números.

⁠En resumen: Un conjunto de datos consta de $N$ ejemplos, y cada ejemplo está descrito por las mismas $d$ características.

ContextoLas mismas cosas con otros nombres

En los textos en inglés, un ejemplo se llama example, sample, instance o data point; una característica, feature o attribute; y el conjunto de datos, dataset. También en español son habituales «muestra», «instancia», «punto de datos» u «observación» para un ejemplo. Siempre se refieren a lo mismo: una fila de la tabla.

Vectores#

Para el ordenador, una vivienda no es otra cosa que sus tres números. Para poder calcular con estos tres números como con un único objeto, se reúnen en una lista. El orden es fijo: primero la superficie, después las habitaciones, después la distancia.

Una lista así también puede dibujarse si solo contiene dos números. Si de la vivienda 4 se toman solo el número de habitaciones $3$ y la distancia $2$, se obtiene el punto de coordenadas $(3,\,2)$ en un plano cuyo eje horizontal cuenta las habitaciones y cuyo eje vertical cuenta los kilómetros. La misma lista puede imaginarse también como una flecha que va del origen a ese punto (fig. 3). Ambas imágenes describen los mismos dos números.

Definición 1.2 (Vector)

Un vector $\mathbf{x}$ con $d$ componentes es una lista ordenada de $d$ números reales $x_1,\dots,x_d$, escritos uno debajo de otro:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_1\\\vdots\\x_d\end{pmatrix}.}$$

El número $x_j$ se llama la $j$-ésima componente de $\mathbf{x}$. El conjunto de todos los vectores con $d$ componentes se llama $\mathbb{R}^d$. Dos vectores son iguales si tienen el mismo número de componentes y todas las componentes coinciden en la misma posición.

Los vectores se escriben en negrita y en minúscula; sus componentes, en tipo normal. Un único número real se llama, a diferencia de un vector, un escalar.

Columna y fila. En esta serie, un vector es siempre una columna. En el texto corrido, una columna ocupa mucho espacio. Por eso se escriben los números uno al lado de otro y se pone detrás un $\top$ en superíndice: $(x_1,\dots,x_d)^{\top}$ significa los mismos números como columna. El signo se lee traspuesto. Convierte una fila en una columna y una columna en una fila. A la inversa, $\textcolor{#1b7f4a}{\mathbf{x}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(x_1,\,\dots,\,x_d)}$ es el vector $\mathbf{x}$ escrito como fila. Si un vector contiene números decimales, las componentes se separan con punto y coma, para no confundir la coma decimal con la coma separadora: $(0{,}2;\ 0{,}25;\ 0{,}3)^{\top}$ tiene tres componentes.

Los ejemplos de un conjunto de datos. El ejemplo número $i$ es el vector $\mathbf{x}_i\in\mathbb{R}^d$. El vector de un ejemplo se llama también su vector de características. Sus componentes llevan dos índices: $x_{ij}$ es el valor de la característica $j$ en el ejemplo $i$. Una letra en negrita con un índice es, por tanto, un vector entero de una lista de vectores; una letra normal con dos índices, un único número.

Ejemplo numérico

La vivienda 1 es el vector $\textcolor{#1b7f4a}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}\in\mathbb{R}^3}$. Su segunda componente es $\textcolor{#1b7f4a}{x_{12}}\textcolor{#15633a}{=}\textcolor{#c2410c}{2}$. El vector $(2,\,60,\,3)^{\top}$ contiene los mismos números, pero es otro vector: en la primera posición está ahora el número $2$, y ese se leería como superficie.

⁠En resumen: Un vector es una lista ordenada de números que puede dibujarse como punto o como flecha; un ejemplo con $d$ características es un vector de $\mathbb{R}^d$.

ContextoQué es en realidad un vector

Una lista de números es el vector con el que se calcula. En matemáticas, el concepto es más amplio: un vector es todo lo que puede sumarse y multiplicarse por un número sin salirse del tipo de objeto. Las flechas del plano entran en esta categoría, pero también las grabaciones de sonido. Una grabación de sonido registra, a intervalos iguales y muy cortos, cuánto se desvía en cada momento la presión del aire de su valor en reposo. Con $n$ de estos valores $x[0],\dots,x[n-1]$, es un vector de $\mathbb{R}^n$. Sumar dos grabaciones significa mezclarlas, y multiplicar una grabación por un número significa subirle o bajarle el volumen; ambas operaciones dan de nuevo una grabación de la misma longitud.

También una imagen es un vector. Una imagen en escala de grises de $28\times28$ píxeles consta de $784$ valores de luminosidad. Si se leen fila por fila, uno tras otro, la imagen es un punto de $\mathbb{R}^{784}$. Esta idea ya no puede dibujarse, pero se calcula con ella exactamente igual que con dos o tres componentes.

Suma y múltiplo#

Con listas de valores medidos se quiere calcular: sumar el consumo eléctrico de dos viviendas, convertir kilovatios hora en megavatios hora o ver en cuánto se diferencian dos viviendas. Todo ello se hace componente por componente.

En la imagen de las flechas, sumar significa colocar la segunda flecha en la punta de la primera. La flecha del origen a la nueva punta es la suma (fig. 4, izquierda). Multiplicar por un número significa alargar o acortar la flecha; un factor negativo, además, le da la vuelta (fig. 4, derecha).

Definición 1.3 (Suma y múltiplo)

Para dos vectores $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ y un escalar $c$, la suma $\mathbf{u}+\mathbf{v}$ y el múltiplo $c\,\mathbf{u}$ son los vectores con las componentes

$$\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_j+v_j ,}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{u})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,u_j ,}$$
$$\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d.}$$
(1.3)

El vector nulo $\mathbf{0}$ tiene solo ceros como componentes. Se escribe $-\mathbf{u}$ para $(-1)\,\mathbf{u}$ y $\mathbf{u}-\mathbf{v}$ para $\mathbf{u}+(-\mathbf{v})$.

Solo se pueden sumar vectores con el mismo número de componentes. Además, solo tiene sentido si en la misma posición está la misma magnitud: kilovatios hora con kilovatios hora, no metros cuadrados con habitaciones.

Como cada componente es por sí sola un cálculo ordinario con números, valen las reglas conocidas: $\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{v}+\mathbf{u}}$, $\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})+\mathbf{q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}+(\mathbf{v}+\mathbf{q})}$, $\textcolor{#1b7f4a}{c\,(\mathbf{u}+\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{u}+c\,\mathbf{v}}$, $\textcolor{#1b7f4a}{(c+c')\,\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,\mathbf{u}+c'\,\mathbf{u}}$ y $\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{0}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}}$ para todos los vectores $\mathbf{u},\mathbf{v},\mathbf{q}\in\mathbb{R}^d$ y escalares $c,c'$.

La diferencia $\mathbf{u}-\mathbf{v}$ tiene una interpretación propia. Es la flecha que va de la punta de $\mathbf{v}$ a la punta de $\mathbf{u}$, pues $\textcolor{#1b7f4a}{\mathbf{v}+(\mathbf{u}-\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}}$. Para dos ejemplos, indica en cuánto se diferencian en cada característica.

Ejemplo numérico

La vivienda 1 ha consumido de enero a marzo $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(200,\,250,\,300)^{\top}}$ kilovatios hora de electricidad; la vivienda 2, en el mismo edificio, $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(150,\,100,\,120)^{\top}}$. Juntas consumen

$$\textcolor{#1b7f4a}{\mathbf{u}+\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(350,\,350,\,420)^{\top}\ \text{kWh}.}$$

El consumo de la vivienda 1 en megavatios hora lo da el múltiplo $\textcolor{#1b7f4a}{0{,}001\,\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0{,}2;\ 0{,}25;\ 0{,}3)^{\top}}$. La diferencia $\textcolor{#1b7f4a}{\mathbf{u}-\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50,\,150,\,180)^{\top}}$ indica cuántos kilovatios hora más que la vivienda 2 consume la vivienda 1 en cada mes. En el conjunto de datos de viviendas, $\textcolor{#1b7f4a}{\mathbf{x}_3-\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(30,\,2,\,3)^{\top}}$: la vivienda 3 es $30\,\mathrm m^2$ más grande, tiene dos habitaciones más y está $3$ km más lejos del centro que la vivienda 1.

⁠En resumen: Los vectores se suman y se multiplican por un número componente por componente.

Combinaciones lineales#

Casi todos los cálculos de este capítulo toman varios vectores, multiplican cada uno por un número propio y suman los resultados. Un promedio es un cálculo así; una mezcla, también.

En la imagen de las flechas: se recorre $c_1$ veces el trayecto $\mathbf{v}_1$, luego $c_2$ veces el trayecto $\mathbf{v}_2$, y así sucesivamente. El lugar al que se llega es el resultado.

Definición 1.4 (Combinación lineal)

Dados vectores $\mathbf{v}_1,\dots,\mathbf{v}_k\in\mathbb{R}^d$ y escalares $c_1,\dots,c_k$, la suma

$$\textcolor{#1b7f4a}{c_1\mathbf{v}_1+c_2\mathbf{v}_2+\dots+c_k\mathbf{v}_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{l=1}^{k}c_l\,\mathbf{v}_l}$$
(1.4)

se llama una combinación lineal de los vectores $\mathbf{v}_1,\dots,\mathbf{v}_k$. Los números $c_l$ se llaman sus coeficientes.

Atención al leer: $\mathbf{v}_l$ está en negrita; es, por tanto, el $l$-ésimo vector de la lista, no la $l$-ésima componente de un vector.

Ejemplo numérico 1

$\textcolor{#1b7f4a}{(1,\,2)^{\top}+3\,(0,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,2)^{\top}+(0,\,3)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,5)^{\top}}$.

Ejemplo numérico 2el punto medio

La combinación lineal $\tfrac12\mathbf{x}_1+\tfrac12\mathbf{x}_2$ de las viviendas 1 y 2 es

$$\textcolor{#1b7f4a}{\tfrac12\,(60,\,2,\,3)^{\top}+\tfrac12\,(40,\,1,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50;\ 1{,}5;\ 2)^{\top}.}$$

Es una vivienda imaginaria que, en cada característica, está exactamente a medio camino entre las dos. El punto está en el centro del segmento de unión.

Hay una combinación lineal que se necesita con especial frecuencia en este capítulo. Si se toman todos los $N$ ejemplos con el coeficiente $1/N$, se obtiene la media de los ejemplos

$$\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1N\sum_{i=1}^{N}\mathbf{x}_i .}$$
(1.5)

Es un ejemplo imaginario que, en cada característica, tiene el promedio de todos los ejemplos: su componente $j$-ésima es la media de las $j$-ésimas características.

Ejemplo numérico 3la media de los ejemplos

Para el conjunto de datos de viviendas, $\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(65;\ 2{,}5;\ 3)^{\top}}$ (fig. 5), la «vivienda media»: en promedio, $65\,\mathrm m^2$, $2{,}5$ habitaciones y $3$ km hasta el centro.

⁠En resumen: Una combinación lineal multiplica cada vector por un número propio y lo suma todo.

ContextoDónde están las mezclas de dos puntos

Si para dos vectores $\mathbf{x}_1,\mathbf{x}_2$ se eligen los coeficientes de modo que su suma sea $1$, es decir, $(1-t)\,\mathbf{x}_1+t\,\mathbf{x}_2$ con un número $t$, el resultado está siempre en la recta que pasa por los dos puntos. En efecto, puede reescribirse como

$$\textcolor{#1b7f4a}{(1-t)\,\mathbf{x}_1+t\,\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{x}_1+t\,(\mathbf{x}_2-\mathbf{x}_1) .}$$

Es decir: partiendo del punto $\mathbf{x}_1$, avanzar $t$ veces la flecha de unión $\mathbf{x}_2-\mathbf{x}_1$. Para $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ se está en $\mathbf{x}_1$; para $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, en $\mathbf{x}_2$; para $\textcolor{#1b7f4a}{t}\textcolor{#15633a}{=}\textcolor{#c2410c}{\tfrac12}$, en el centro. Todos los $t$ entre $0$ y $1$ dan los puntos del segmento de unión. Estas mezclas se necesitan siempre que se quieren obtener valores intermedios entre dos puntos de datos.

Los vectores unitarios#

Los vectores más sencillos tienen una única componente $1$ y, por lo demás, solo ceros. En un ejemplo significaría que solo una característica está «encendida», y además con el valor $1$. En el plano son las dos flechas de longitud $1$ a lo largo de los ejes.

Definición 1.5 (Vector unitario)

El $j$-ésimo vector unitario $\mathbf{e}_j\in\mathbb{R}^d$ tiene un $1$ en la posición $j$ y un $0$ en todas las demás posiciones.

En $\mathbb{R}^2$, $\textcolor{#1b7f4a}{\mathbf{e}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,0)^{\top}}$ y $\textcolor{#1b7f4a}{\mathbf{e}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,1)^{\top}}$. Todo vector es una combinación lineal de los vectores unitarios, y los coeficientes son exactamente sus componentes:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{e}_1+x_2\mathbf{e}_2+\dots+x_d\mathbf{e}_d}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^d x_j\,\mathbf{e}_j .}$$
(1.6)

Se ve calculando el lado derecho componente por componente: en la posición $j$ solo aporta algo el sumando $x_j\mathbf{e}_j$, y en concreto $x_j\cdot1$. Otros coeficientes no son posibles, pues darían en alguna posición un número distinto.

Ejemplo numérico

$\textcolor{#1b7f4a}{\mathbf{x}_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{(60,\,2,\,3)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{60\,\mathbf{e}_1+2\,\mathbf{e}_2+3\,\mathbf{e}_3}$, es decir, $60$ veces «un metro cuadrado» más $2$ veces «una habitación» más $3$ veces «un kilómetro».

⁠En resumen: El vector unitario $\mathbf{e}_j$ tiene un uno en la posición $j$ y ceros en las demás; todo vector es la suma $\sum_jx_j\mathbf{e}_j$.

  1. Calcula $\sum_{i=1}^{5}(2i-1)$ y $\sum_{i=1}^{2}\sum_{j=1}^{3}i\,j$.

  2. Escribe $3+6+9+12$ con un signo de sumatorio.

  3. Sea $a_i$ la superficie de la vivienda $i$ de la tabla 1. ¿Qué significan $\sum_{i=1}^4a_i$ y $\frac14\sum_{i=1}^4a_i$, y qué números salen?

Solución

(a) El índice de sumación $i$ toma los valores de $1$ a $5$, y los sumandos son los números impares $1,3,5,7,9$:

$$\textcolor{#1b7f4a}{\sum_{i=1}^{5}(2i-1)}\textcolor{#15633a}{=}\textcolor{#c2410c}{1+3+5+7+9}\textcolor{#15633a}{=}\textcolor{#c2410c}{25 .}$$

En la suma doble, para cada $i$ fijo, la suma interior es $\textcolor{#1b7f4a}{\sum_{j=1}^3i\,j}\textcolor{#15633a}{=}\textcolor{#c2410c}{i\,(1+2+3)}\textcolor{#15633a}{=}\textcolor{#c2410c}{6i}$; el factor $i$ no depende de $j$ y, según (1.2), puede ponerse delante de la suma interior. Después, $\textcolor{#1b7f4a}{\sum_{i=1}^2 6i}\textcolor{#15633a}{=}\textcolor{#c2410c}{6+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{18}$.

(b) Los sumandos son los múltiplos de $3$: $\textcolor{#1b7f4a}{3+6+9+12}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{i=1}^43i}$. Igual de correcto es $3\sum_{i=1}^4i$, según la regla de los factores comunes.

(c) $\textcolor{#1b7f4a}{\sum_{i=1}^4a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{60+40+90+70}\textcolor{#15633a}{=}\textcolor{#c2410c}{260}$ es la superficie total de las cuatro viviendas en $\mathrm m^2$, y $\textcolor{#1b7f4a}{\frac14\sum_{i=1}^4a_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{65}$ es la superficie media de una vivienda.

Ejercicio 2 ★ Calcular con vectores

  1. Calcula $2\mathbf{u}-3\mathbf{v}$ para $\textcolor{#1b7f4a}{\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(1,\,-1,\,0)^{\top}}$ y $\textcolor{#1b7f4a}{\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,1,\,2)^{\top}}$.

  2. Escribe $(4,\,-1,\,2)^{\top}$ como combinación lineal de los vectores unitarios de $\mathbb{R}^3$.

  3. Encuentra números $c_1,c_2$ con $\textcolor{#1b7f4a}{c_1(1,\,2)^{\top}+c_2(2,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,3)^{\top}}$. Dibuja la solución con flechas.

  4. Calcula $\mathbf{x}_3-\mathbf{x}_2$ para el conjunto de datos de viviendas y describe con palabras lo que expresa el vector.

Solución

(a) Componente a componente: $\textcolor{#1b7f4a}{2\mathbf{u}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-2,\,0)^{\top}}$ y $\textcolor{#1b7f4a}{3\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(0,\,3,\,6)^{\top}}$, así que $\textcolor{#1b7f4a}{2\mathbf{u}-3\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(2,\,-5,\,-6)^{\top}}$.

(b) Según (1.6), los coeficientes son las componentes: $\textcolor{#1b7f4a}{(4,\,-1,\,2)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{4\,\mathbf{e}_1-\mathbf{e}_2+2\,\mathbf{e}_3}$.

(c) Componente a componente, la condición dice $\textcolor{#1b7f4a}{c_1+2c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$ y $\textcolor{#1b7f4a}{2c_1+c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$. Si se resta dos veces la primera ecuación de la segunda, queda $\textcolor{#1b7f4a}{-3c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-3}$, es decir, $\textcolor{#1b7f4a}{c_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$ y, después, $\textcolor{#1b7f4a}{c_1}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$. Comprobación: $\textcolor{#1b7f4a}{(1,\,2)^{\top}+(2,\,1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(3,\,3)^{\top}}$. En el dibujo se coloca la flecha $(2,\,1)^{\top}$ en la punta de $(1,\,2)^{\top}$ y se llega a $(3,\,3)^{\top}$.

(d) $\textcolor{#1b7f4a}{\mathbf{x}_3-\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(90-40,\ 4-1,\ 6-1)^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(50,\,3,\,5)^{\top}}$: la vivienda 3 tiene $50\,\mathrm m^2$ más que la vivienda 2, tres habitaciones más y está $5$ km más lejos del centro. El vector es la flecha que va del punto $\mathbf{x}_2$ al punto $\mathbf{x}_3$.

Ejercicio 3 ★ Un conjunto de datos propio

Elige cuatro cosas de tu vida cotidiana, por ejemplo alimentos, bicicletas o canciones, y tres propiedades que puedas indicar como número para cada cosa. Mide o busca los valores.

  1. Crea la tabla. ¿Cuánto valen $N$ y $d$? Escribe el segundo ejemplo como vector $\mathbf{x}_2$.

  2. ¿Qué propiedad que también te interesaría no es un número? ¿Cómo podría traducirse a números?

  3. Calcula la media de los ejemplos $\bar{\mathbf{x}}$. ¿Hay alguna cosa que tenga exactamente ese aspecto?

Solución

Una solución posible: cuatro manzanas con las características masa en g, diámetro en cm y precio en céntimos.

(a) Supongamos que la tabla tiene las filas $(180;\ 7{,}5;\ 45)$, $(150;\ 7{,}0;\ 40)$, $(210;\ 8{,}0;\ 55)$ y $(165;\ 7{,}2;\ 40)$. Entonces $\textcolor{#1b7f4a}{N}\textcolor{#15633a}{=}\textcolor{#c2410c}{4}$ y $\textcolor{#1b7f4a}{d}\textcolor{#15633a}{=}\textcolor{#c2410c}{3}$, y $\textcolor{#1b7f4a}{\mathbf{x}_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{(150;\ 7{,}0;\ 40)^{\top}}$. Lo único importante es que cada cosa se describa con las mismas tres características en el mismo orden.

(b) La variedad es un nombre, no un número. Puede traducirse introduciendo para cada variedad una característica propia que vale $1$ si la manzana es de esa variedad y $0$ en caso contrario. Numerar sin más las variedades, en cambio, no suele ser buena idea: los números simulan un orden y unas distancias que entre variedades no existen.

(c) La media de los ejemplos es, componente a componente, el promedio; aquí, $\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{(176{,}25;\ 7{,}425;\ 45)^{\top}}$. En la tabla no hay ninguna manzana con exactamente estos valores. La media es un ejemplo imaginario, no medido, y en una propiedad como el número de habitaciones puede ser incluso un valor que ninguna cosa real puede tomar, por ejemplo $2{,}5$ habitaciones.

Todas las fórmulas del módulo
Ejemplos y características
Definición 1.1 (Característica, ejemplo, conjunto de datos)

Una característica es una propiedad que puede expresarse mediante un número real.

Un ejemplo es una cosa individual descrita por los valores de $d$ características.

Un conjunto de datos es una colección de $N$ ejemplos, todos descritos por las mismas $d$ características.

Vectores
Definición 1.2 (Vector)

Un vector $\mathbf{x}$ con $d$ componentes es una lista ordenada de $d$ números reales $x_1,\dots,x_d$, escritos uno debajo de otro:

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}x_1\\\vdots\\x_d\end{pmatrix}.}$$

El número $x_j$ se llama la $j$-ésima componente de $\mathbf{x}$. El conjunto de todos los vectores con $d$ componentes se llama $\mathbb{R}^d$. Dos vectores son iguales si tienen el mismo número de componentes y todas las componentes coinciden en la misma posición.

Suma y múltiplo
Definición 1.3 (Suma y múltiplo)

Para dos vectores $\mathbf{u},\mathbf{v}\in\mathbb{R}^d$ y un escalar $c$, la suma $\mathbf{u}+\mathbf{v}$ y el múltiplo $c\,\mathbf{u}$ son los vectores con las componentes

$$\textcolor{#1b7f4a}{(\mathbf{u}+\mathbf{v})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{u_j+v_j ,}$$
$$\textcolor{#1b7f4a}{(c\,\mathbf{u})_j}\textcolor{#15633a}{=}\textcolor{#c2410c}{c\,u_j ,}$$
$$\textcolor{#1b7f4a}{j}\textcolor{#15633a}{=}\textcolor{#c2410c}{1,\dots,d.}$$
(1.3)

El vector nulo $\mathbf{0}$ tiene solo ceros como componentes. Se escribe $-\mathbf{u}$ para $(-1)\,\mathbf{u}$ y $\mathbf{u}-\mathbf{v}$ para $\mathbf{u}+(-\mathbf{v})$.

Combinaciones lineales
Definición 1.4 (Combinación lineal)

Dados vectores $\mathbf{v}_1,\dots,\mathbf{v}_k\in\mathbb{R}^d$ y escalares $c_1,\dots,c_k$, la suma

$$\textcolor{#1b7f4a}{c_1\mathbf{v}_1+c_2\mathbf{v}_2+\dots+c_k\mathbf{v}_k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{l=1}^{k}c_l\,\mathbf{v}_l}$$
(1.4)

se llama una combinación lineal de los vectores $\mathbf{v}_1,\dots,\mathbf{v}_k$. Los números $c_l$ se llaman sus coeficientes.

$$\textcolor{#1b7f4a}{\bar{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac1N\sum_{i=1}^{N}\mathbf{x}_i .}$$
(1.5)
Los vectores unitarios
Definición 1.5 (Vector unitario)

El $j$-ésimo vector unitario $\mathbf{e}_j\in\mathbb{R}^d$ tiene un $1$ en la posición $j$ y un $0$ en todas las demás posiciones.

$$\textcolor{#1b7f4a}{\mathbf{x}}\textcolor{#15633a}{=}\textcolor{#c2410c}{x_1\mathbf{e}_1+x_2\mathbf{e}_2+\dots+x_d\mathbf{e}_d}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_{j=1}^d x_j\,\mathbf{e}_j .}$$
(1.6)

Resumen

Términos
  • característica – Una característica es una propiedad que puede expresarse mediante un número real.
  • ejemplo – Un ejemplo es una cosa individual descrita por los valores de $d$ características.
  • conjunto de datos – Un conjunto de datos es una colección de $N$ ejemplos, todos descritos por las mismas $d$ características.
  • vector – Un vector $\mathbf{x}$ con $d$ componentes es una lista ordenada de $d$ números reales $x_1,\dots,x_d$, escritos uno debajo de otro.
  • componente – El número $x_j$ se llama la $j$-ésima componente de $\mathbf{x}$.

Relaciones clave
  • Sobre «Ejemplos y características»: Un conjunto de datos consta de $N$ ejemplos, y cada ejemplo está descrito por las mismas $d$ características.
  • Sobre «Vectores»: Un vector es una lista ordenada de números que puede dibujarse como punto o como flecha; un ejemplo con $d$ características es un vector de $\mathbb{R}^d$.
  • Sobre «Suma y múltiplo»: Los vectores se suman y se multiplican por un número componente por componente.
  • Sobre «Combinaciones lineales»: Una combinación lineal multiplica cada vector por un número propio y lo suma todo.
  • Sobre «Los vectores unitarios»: El vector unitario $\mathbf{e}_j$ tiene un uno en la posición $j$ y ceros en las demás; todo vector es la suma $\sum_jx_j\mathbf{e}_j$.
