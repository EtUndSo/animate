Capítulo 1: Vectores y matrices

  1. Términocaracterística
    Una característica es una propiedad que puede expresarse mediante un número real.
    Vectores: datos como listas de números
  2. Términoejemplo
    Un ejemplo es una cosa individual descrita por los valores de $d$ características.
    Vectores: datos como listas de números
  3. Términoconjunto de datos
    Un conjunto de datos es una colección de $N$ ejemplos, todos descritos por las mismas $d$ características.
    Vectores: datos como listas de números
  4. Términovector
    Un vector $\mathbf{x}$ con $d$ componentes es una lista ordenada de $d$ números reales $x_1,\dots,x_d$, escritos uno debajo de otro.
    Vectores: datos como listas de números
  5. Términocomponente
    El número $x_j$ se llama la $j$-ésima componente de $\mathbf{x}$.
    Vectores: datos como listas de números
  6. Términoescalar
    Un único número real se llama, a diferencia de un vector, un escalar.
    Vectores: datos como listas de números
  7. Términotraspuesto
    El signo se lee traspuesto.
    Vectores: datos como listas de números
  8. Términovector de características
    El vector de un ejemplo se llama también su vector de características.
    Vectores: datos como listas de números
  9. Términovector nulo
    El vector nulo $\mathbf{0}$ tiene solo ceros como componentes.
    Vectores: datos como listas de números
  10. Términocoeficientes

    Vectores: datos como listas de números
  11. Términovector unitario
