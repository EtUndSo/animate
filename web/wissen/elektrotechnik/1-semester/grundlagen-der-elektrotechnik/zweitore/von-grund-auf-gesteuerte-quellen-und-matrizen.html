Von Grund auf: Gesteuerte Quellen und Matrizen

Eine ideale Quelle aus Kapitel 5 liefert einen festen Wert. Eine gesteuerte Quelle liefert einen Wert, der einer anderen Spannung oder einem anderen Strom an anderer Stelle der Schaltung proportional ist. Ihr Schaltzeichen ist eine Raute. Die Abkürzungen kommen aus dem Englischen (voltage bzw. current controlled voltage bzw. current source).

NameKürzelGesetzFaktor
spannungsgesteuerte SpannungsquelleVCVS$\textcolor{#1b7f4a}{U}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mu\,U_\mathrm{s}}$ohne Einheit
stromgesteuerte SpannungsquelleCCVS$\textcolor{#1b7f4a}{U}\textcolor{#15633a}{=}\textcolor{#c2410c}{r\,I_\mathrm{s}}$in $\Omega$
spannungsgesteuerte StromquelleVCCS$\textcolor{#1b7f4a}{I}\textcolor{#15633a}{=}\textcolor{#c2410c}{g\,U_\mathrm{s}}$in S
stromgesteuerte StromquelleCCCS$\textcolor{#1b7f4a}{I}\textcolor{#15633a}{=}\textcolor{#c2410c}{\beta\,I_\mathrm{s}}$ohne Einheit

Der Index s steht für die steuernde Größe. Das bekannteste Beispiel ist der Bipolartransistor (Kapitel 10): Ein kleiner Basisstrom steuert einen großen Kollektorstrom. Die Energie dafür kommt aus der Versorgungsspannung, das Steuersignal liefert nur die Information. Steuergröße und Quelle sitzen an verschiedenen Stellen, deshalb ist jede gesteuerte Quelle von Natur aus ein Zweitor.

Eine Matrix ist ein rechteckiges Zahlenschema, hier fast immer mit zwei Zeilen und zwei Spalten. Fett gedruckte Buchstaben stehen für Matrizen und für Spalten aus zwei Größen. Beim Multiplizieren wird jede Zeile der linken Matrix mit jeder Spalte der rechten verrechnet, Element mal Element, dann addiert:

$$\textcolor{#1b7f4a}{\begin{pmatrix}a&b\\c&d\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}a\,x+b\,y\\c\,x+d\,y\end{pmatrix},}$$
$$\textcolor{#1b7f4a}{\begin{pmatrix}a&b\\c&d\end{pmatrix}\begin{pmatrix}e&f\\g&h\end{pmatrix}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}a\,e+b\,g&a\,f+b\,h\\c\,e+d\,g&c\,f+d\,h\end{pmatrix}.}$$

Bei zwei Matrizen kommt es auf die Reihenfolge an. Addiert werden Matrizen Element für Element. Die Zahl $\textcolor{#1b7f4a}{\det\mathbf M}\textcolor{#15633a}{=}\textcolor{#c2410c}{a\,d-b\,c}$ heißt Determinante. Ist sie nicht null, gibt es die inverse Matrix, die $\textcolor{#1b7f4a}{\mathbf y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf M\,\mathbf x}$ nach $\mathbf x$ auflöst:

$$\textcolor{#1b7f4a}{\mathbf x}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf M^{-1}\mathbf y,}$$
$$\textcolor{#1b7f4a}{\mathbf M^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{1}{a\,d-b\,c}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.}$$

Das Produkt $\mathbf M\,\mathbf M^{-1}$ ist die Einheitsmatrix $\mathbf 1$ mit Einsen auf der Diagonale und Nullen sonst. Sie ändert nichts, womit man sie multipliziert.

Zusammenfassung

Begriffe
  • gesteuerte Quelle – Eine gesteuerte Quelle liefert einen Wert, der einer anderen Spannung oder einem anderen Strom an anderer Stelle der Schaltung proportional ist.
  • Matrix – Eine Matrix ist ein rechteckiges Zahlenschema, hier fast immer mit zwei Zeilen und zwei Spalten.
  • Determinante – Die Zahl $\textcolor{#1b7f4a}{\det\mathbf M}\textcolor{#15633a}{=}\textcolor{#c2410c}{a\,d-b\,c}$ heißt Determinante.
  • inverse Matrix – Ist sie nicht null, gibt es die inverse Matrix, die $\textcolor{#1b7f4a}{\mathbf y}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf M\,\mathbf x}$ nach $\mathbf x$ auflöst.
  • Einheitsmatrix – Das Produkt $\mathbf M\,\mathbf M^{-1}$ ist die Einheitsmatrix $\mathbf 1$ mit Einsen auf der Diagonale und Nullen sonst.
