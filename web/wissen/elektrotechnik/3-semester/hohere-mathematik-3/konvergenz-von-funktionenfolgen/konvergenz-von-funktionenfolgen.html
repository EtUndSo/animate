Worum es geht#

Schwierige Funktionen kennt man oft nur über Näherungen. Die Funktion $\mathrm{e}^x$ lässt sich durch Summen immer weiterer Potenzen annähern, eine Simulation nähert einen Spannungsverlauf Schritt für Schritt an. So entsteht eine Folge von Funktionen $f_1,f_2,f_3,\dots$, die sich einer Zielfunktion nähert. Die Frage dieses Kapitels lautet: Wann darf man mit der Zielfunktion so rechnen wie mit den Näherungen? Bleibt sie stetig, wenn alle Näherungen stetig sind? Darf man erst integrieren und dann zum Grenzwert gehen? Darf man eine unendliche Summe Glied für Glied ableiten? Der Nutzen: Man erkennt, wann eine Näherung überall gut ist und wann sie nur an jeder Stelle einzeln gut aussieht.

Der Weg führt über acht Begriffe. Eine Funktionenfolge ist eine Folge, deren Glieder Funktionen sind. Die punktweise Konvergenz prüft jede Stelle einzeln, die gleichmäßige Konvergenz prüft den größten Abstand über alle Stellen. Eine Funktionenreihe ist eine unendliche Summe von Funktionen. Der Konvergenzradius sagt, wie weit um ihren Mittelpunkt eine Potenzreihe konvergiert. Die Supremumsnorm misst die Größe einer Funktion durch ihren größten Betrag. Vollständigkeit heißt, dass in einem Raum jede Folge, deren Glieder einander beliebig nahe kommen, einen Grenzwert hat. Die Konvergenz im quadratischen Mittel misst den Abstand durch ein Integral über die quadrierte Abweichung.

So arbeitest du mit diesem Kapitel. Die Abschnitte bauen aufeinander auf, jeder neue Begriff hat einen eigenen Unterabschnitt mit Beispiel. Kästen zum Aufklappen enthalten Hintergrund (warum etwas so ist und woher es kommt), Herleitungen und Hinweise zur Simulation; zum Weiterlesen braucht man sie nicht. Versuche die Aufgaben (★ bis ★★★) zuerst selbst, die Lösung klappst du direkt unter der Aufgabe auf.
