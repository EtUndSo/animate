L’essentiel jusqu’ici

  • Vecteurs orthonormés : $\textcolor{#1b7f4a}{\mathbf{Q}^{\top}\mathbf{Q}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{I}}$ ; les coordonnées sont des produits scalaires $\textcolor{#1b7f4a}{c_i}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{q}_i^{\top}\mathbf{x}}$ ; les matrices orthogonales conservent les longueurs et les angles. Si $\mathbf{Q}$ n’est pas carrée, $\mathbf{Q}\mathbf{Q}^{\top}\ne\mathbf{I}$.

  • Projection sur une droite : $\textcolor{#1b7f4a}{\hat{\mathbf{y}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\frac{\mathbf{a}^{\top}\mathbf{y}}{\mathbf{a}^{\top}\mathbf{a}}\,\mathbf{a}}$ ; le reste est perpendiculaire à $\mathbf{a}$, et $\hat{\mathbf{y}}$ est le point le plus proche. Les matrices de projection vérifient $\textcolor{#1b7f4a}{\mathbf{P}^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{P}}$, les matrices de projection orthogonale en outre $\textcolor{#1b7f4a}{\mathbf{P}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{P}}$.

  • Meilleure solution approchée : le résidu $\textcolor{#1b7f4a}{\mathbf{r}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{y}-\mathbf{A}\hat{\mathbf{x}}}$ est perpendiculaire à l’espace des colonnes, donc $\textcolor{#1b7f4a}{\mathbf{A}^{\top}\mathbf{A}\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\mathbf{y}}$ ; elle est unique exactement lorsque les colonnes sont indépendantes.

  • Projection sur un sous-espace : $\textcolor{#1b7f4a}{\mathbf{P}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{Q}\mathbf{Q}^{\top}}$ ; Gram-Schmidt fournit $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{Q}\mathbf{R}}$, et $\textcolor{#1b7f4a}{\mathbf{R}\hat{\mathbf{x}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{Q}^{\top}\mathbf{y}}$.

  • Les formes quadratiques $\mathbf{x}^{\top}\mathbf{A}\mathbf{x}$ ne dépendent que de la partie symétrique ; on reconnaît cuvette, gouttière et selle en complétant le carré.

  • Valeurs propres : $\textcolor{#1b7f4a}{\mathbf{A}\mathbf{v}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\lambda\mathbf{v}}$, $\textcolor{#1b7f4a}{\det(\mathbf{A}-\lambda\mathbf{I})}\textcolor{#15633a}{=}\textcolor{#c2410c}{0}$ ; trace $=\sum\lambda_i$, $\textcolor{#1b7f4a}{\det}\textcolor{#15633a}{=}\textcolor{#c2410c}{\prod\lambda_i}$ ; les rotations ont des valeurs propres complexes.

  • $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{S}\boldsymbol{\Lambda}\mathbf{S}^{-1}}$ découple, $\textcolor{#1b7f4a}{\mathbf{A}^k}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{S}\boldsymbol{\Lambda}^k\mathbf{S}^{-1}}$. Cas symétrique : $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^{\top}}$ avec des $\lambda_i$ réels et des axes principaux perpendiculaires, demi-axes $1/\sqrt{\lambda_i}$.

  • Définie positive $\Leftrightarrow$ toutes les valeurs propres $>0$ $\Leftrightarrow$ tous les pivots $>0$ $\Leftrightarrow$ tous les mineurs principaux dominants $>0$ ; $\mathbf{A}^{\top}\mathbf{A}$ est semi-définie positive ; décomposition de Cholesky $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf L\mathbf L^{\top}}$.

  • Décomposition en valeurs singulières $\textcolor{#1b7f4a}{\mathbf{A}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{U}\mathbf{D}\mathbf{V}^{\top}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_jd_j\mathbf{u}_j\mathbf{v}_j^{\top}}$ pour toute matrice : tourner, étirer, tourner ; les $d_j^2$ sont les valeurs propres de $\mathbf{A}^{\top}\mathbf{A}$, $\textcolor{#1b7f4a}{\lVert\mathbf{A}\rVert_2}\textcolor{#15633a}{=}\textcolor{#c2410c}{d_1}$.

  • $\textcolor{#1b7f4a}{\lVert\mathbf{A}\rVert_F^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum_jd_j^2}$ ; $\mathbf{A}_k$ est la meilleure approximation de rang $k$, avec l’erreur $d_{k+1}$ en norme spectrale.

  • $\textcolor{#1b7f4a}{\mathbf{A}^+}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{V}\mathbf{D}^+\mathbf{U}^{\top}}$ fournit la meilleure solution approchée la plus courte ; cas particuliers : $(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}$ et $\mathbf{A}^{\top}(\mathbf{A}\mathbf{A}^{\top})^{-1}$.

  • $\textcolor{#1b7f4a}{\kappa(\mathbf{A})}\textcolor{#15633a}{=}\textcolor{#c2410c}{d_1/d_n}$ borne l’amplification des erreurs relatives ; $1/\kappa$ est la distance relative à la singularité ; $\textcolor{#1b7f4a}{\kappa(\mathbf{A}^{\top}\mathbf{A})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\kappa(\mathbf{A})^2}$.

La réponse en trois phrases

  1. Un système d’équations sans solution se résout au mieux en projetant perpendiculairement le second membre sur l’espace des colonnes : le résidu est alors perpendiculaire à toutes les colonnes, ce qui donne les équations normales, et d’après Pythagore, aucun autre point n’est plus proche.

  2. Les vecteurs propres sont les directions qu’une matrice ne fait qu’étirer ; dans leur base, la matrice devient diagonale, et pour les matrices symétriques, ils forment un repère orthogonal sur lequel on lit l’allure de toute forme quadratique.

  3. Toute matrice est une somme, ordonnée par taille, de briques $d_j\mathbf{u}_j\mathbf{v}_j^{\top}$ de rang $1$ : les $k$ premières donnent la meilleure approximation de rang $k$, et le rapport $d_1/d_n$ indique à quel point des erreurs dans les données peuvent fausser la solution.

Un principe derrière tous les résultats. Presque tout dans ce chapitre découle d’un seul principe : dans un repère orthogonal, un carré de longueur se décompose, d’après Pythagore, en parts indépendantes, et le plus court chemin vers une droite, un plan ou un sous-espace est le chemin perpendiculaire.
