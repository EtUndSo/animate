L’essentiel jusqu’ici

  • Dérivée : $\textcolor{#1b7f4a}{f'(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{\lim_{h\to0}\frac{f(x+h)-f(x)}{h}}$ ; près de $x$, $\textcolor{#1b7f4a}{f(x+h)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f(x)+f'(x)h}$, avec une erreur qui disparaît plus vite que $h$. Avec la dérivée seconde : $\textcolor{#1b7f4a}{f(x+h)}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f(x)+f'(x)h+\tfrac12f''(x)h^2}$.

  • Règle de dérivation en chaîne : $\textcolor{#1b7f4a}{(f\circ g)'(x)}\textcolor{#15633a}{=}\textcolor{#c2410c}{f'(g(x))\,g'(x)}$ ; pour de longues chaînes, le produit de tous les facteurs. Fonction logistique : $\textcolor{#1b7f4a}{\sigma'}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sigma(1-\sigma)\le\tfrac14}$.

  • Gradient $\nabla f\in\mathbb{R}^d$ en colonne ; $\textcolor{#1b7f4a}{f(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f(\mathbf{x})+\nabla f(\mathbf{x})^{\top}\mathbf{h}}$ si $f$ est différentiable ; les dérivées partielles seules ne suffisent pas.

  • Dérivée directionnelle $\textcolor{#1b7f4a}{D_{\mathbf{u}}f}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f^{\top}\mathbf{u}}$ ; plus forte montée dans la direction $\nabla f$, avec la pente $\lVert\nabla f\rVert$ (Cauchy-Schwarz) ; $\nabla f$ est perpendiculaire aux lignes de niveau ; $-\nabla f$ ne pointe vers le point le plus bas que pour des lignes de niveau rondes.

  • Matrice jacobienne $\mathbf{J}_{\mathbf{g}}\in\mathbb{R}^{m\times n}$, une ligne par sortie : $\textcolor{#1b7f4a}{\mathbf{g}(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\mathbf{g}(\mathbf{x})+\mathbf{J}_{\mathbf{g}}\mathbf{h}}$ ; pour $\mathbf{A}\mathbf{x}+\mathbf{b}$, elle vaut $\mathbf{A}$, pour des fonctions appliquées terme à terme, elle est diagonale.

  • Règle de dérivation en chaîne : $\textcolor{#1b7f4a}{\mathbf{J}_{\mathbf f\circ\mathbf{g}}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{J}_{\mathbf f}\mathbf{J}_{\mathbf{g}}}$, composante par composante une somme sur tous les chemins ; $\textcolor{#1b7f4a}{\nabla(f\circ\mathbf{g})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{J}_{\mathbf{g}}^{\top}\nabla f}$.

  • $\textcolor{#1b7f4a}{\nabla(\mathbf{a}^{\top}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{a}}$, $\textcolor{#1b7f4a}{\nabla(\mathbf{x}^{\top}\mathbf{A}\mathbf{x})}\textcolor{#15633a}{=}\textcolor{#c2410c}{(\mathbf{A}+\mathbf{A}^{\top})\mathbf{x}}$, $\textcolor{#1b7f4a}{\nabla\lVert\mathbf{y}-\mathbf{A}\mathbf{x}\rVert^2}\textcolor{#15633a}{=}\textcolor{#c2410c}{-2\mathbf{A}^{\top}(\mathbf{y}-\mathbf{A}\mathbf{x})}$, $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}(\mathbf{u}^{\top}\mathbf{A}\mathbf{v})}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{u}\mathbf{v}^{\top}}$ ; à rebours à travers $\textcolor{#1b7f4a}{\mathbf{y}}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}\mathbf{x}}$ avec $\textcolor{#1b7f4a}{F}\textcolor{#15633a}{=}\textcolor{#c2410c}{f(\mathbf{A}\mathbf{x})}$ : $\textcolor{#1b7f4a}{\nabla_{\mathbf{A}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\nabla f(\mathbf{y})\,\mathbf{x}^{\top}}$, $\textcolor{#1b7f4a}{\nabla_{\mathbf{x}}F}\textcolor{#15633a}{=}\textcolor{#c2410c}{\mathbf{A}^{\top}\nabla f(\mathbf{y})}$.

  • Matrice hessienne $\mathbf{H}_f$, symétrique d’après Schwarz ; $\textcolor{#1b7f4a}{f(\mathbf{x}+\mathbf{h})}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{ f+\nabla f^{\top}\mathbf{h}+\tfrac12\mathbf{h}^{\top}\mathbf{H}_f\mathbf{h}}$ ; la courbure dans la direction $\mathbf{u}$ est $\mathbf{u}^{\top}\mathbf{H}_f\mathbf{u}$, comprise entre la plus petite et la plus grande valeur propre.

  • Graphe de calcul : opérations de base, évaluation avant avec valeurs stockées, dérivées locales sur les arêtes.

  • Mode direct : valeurs tangentes, une passe par direction ($\mathbf{J}\dot{\mathbf{x}}$). Mode inverse : adjoints $\textcolor{#1b7f4a}{\bar a}\textcolor{#15633a}{=}\textcolor{#c2410c}{\sum\bar b\,\partial b/\partial a}$ à partir de $\textcolor{#1b7f4a}{\bar f}\textcolor{#15633a}{=}\textcolor{#c2410c}{1}$, une passe pour le gradient complet, coût : un petit multiple d’une évaluation, prix : la mémoire.

  • Numérique : erreur de la différence avant $\textcolor{#1b7f4a}{}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\tfrac12f''h}$, de la différence centrée $\textcolor{#1b7f4a}{}\textcolor{#15633a}{\approx}\textcolor{#c2410c}{\tfrac16f'''h^2}$ ; l’arrondi croît comme $\varepsilon_{\mathrm M}/h$, d’où la courbe en V ; vérification du gradient avec l’erreur relative : au-dessus de $10^{-2}$ faux, en dessous de $10^{-7}$ bon.

La réponse en trois phrases

  1. C’est son approximation linéaire qui dit comment un nombre réagit à de petites modifications de ses entrées : chaque entrée apporte sa dérivée partielle multipliée par sa variation, et les contributions s’additionnent pour donner le produit scalaire avec le gradient.

  2. D’après l’inégalité de Cauchy-Schwarz, ce produit scalaire est, pour des pas de longueur fixe, le plus grand dans la direction du gradient, qui pointe donc dans la direction de plus forte montée et est perpendiculaire aux lignes de niveau.

  3. Si le nombre résulte d’une longue chaîne d’étapes de calcul, sa dérivée est un produit de matrices jacobiennes, donc une somme sur tous les chemins, et le mode inverse calcule ce produit en partant du nombre, avec des vecteurs lignes, de sorte qu’il fournit toutes les dérivées à la fois pour un petit multiple du coût d’une seule évaluation.

Un principe derrière tous les résultats. Presque tout dans ce chapitre découle d’un principe : suffisamment près d’un point, toute fonction différentiable est linéaire. Dérivée, gradient et matrice jacobienne sont cette approximation linéaire, la règle de dérivation en chaîne monte en série des approximations linéaires en multipliant leurs matrices, et le mode direct et le mode inverse sont deux façons de parenthéser ce produit.
