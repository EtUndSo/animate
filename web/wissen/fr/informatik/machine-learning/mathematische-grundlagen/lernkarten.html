Chapitre 1 : Vecteurs et matrices

  1. Termecaractéristique
    Une caractéristique est une propriété que l’on peut indiquer par un nombre réel.
    Vecteurs : les données comme listes de nombres
  2. Termeexemple
    Un exemple est une chose individuelle, décrite par les valeurs de $d$ caractéristiques.
    Vecteurs : les données comme listes de nombres
  3. Termejeu de données
    Un jeu de données est une collection de $N$ exemples, tous décrits par les mêmes $d$ caractéristiques.
    Vecteurs : les données comme listes de nombres
  4. Termevecteur
    Un vecteur $\mathbf{x}$ à $d$ composantes est une liste ordonnée de $d$ nombres réels $x_1,\dots,x_d$, écrits les uns sous les autres.
    Vecteurs : les données comme listes de nombres
  5. Termecomposante
    Le nombre $x_j$ s’appelle la $j$-ième composante de $\mathbf{x}$.
    Vecteurs : les données comme listes de nombres
  6. Termescalaire
    Par opposition à un vecteur, on appelle un nombre réel isolé un scalaire.
    Vecteurs : les données comme listes de nombres
  7. Termetransposé
    Le signe se lit transposé.
    Vecteurs : les données comme listes de nombres
  8. Termevecteur de caractéristiques
    On appelle aussi le vecteur d’un exemple son vecteur de caractéristiques.

  9. Termevecteur nul
    Le vecteur nul $\mathbf{0}$ n’a que des zéros comme composantes.

  10. Termecoefficients

Chapitre 3 : Dérivée, gradient et règle de dérivation en chaîne

  1. Termesécante
    Une telle droite passant par deux points d’une courbe s’appelle une sécante.
    La dérivée
  2. Termelimite
    De manière générale, une grandeur qui dépend de $h$ a pour limite $c$ quand $h\to0$ si elle est arbitrairement proche de $c$ dès que $h$ est suffisamment proche de $0$ sans être égal à $0$.
    La dérivée
  3. Termedérivable
    Une fonction $f$ est dite dérivable en $x$ si le taux d’accroissement a une limite quand $h\to0$.
    La dérivée
  4. Termetangente
    La droite passant par $(x,\,f(x))$ de pente $f'(x)$ s’appelle la tangente au graphe.
    La dérivée
  5. Termepoint anguleux
    Une exception typique est un point anguleux : un point où le graphe se poursuit sans saut, mais avec à sa gauche une autre pente qu’à sa droite.
    La dérivée
  6. Termeapproximation linéaire
