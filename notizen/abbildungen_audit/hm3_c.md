- **Was zu sehen ist:** Achsen k von 0 bis 10, Betrag y von 0 bis 7. Für die Reihe Σ x^k (c_k = 1, x₀ = 0) drei Stem-Folgen: |x|^k mit x = 0,8 (fällt, 0,8^10 ≈ 0,107), x = 1 (konstant 1), x = 1,2 (wächst, 1,2^10 ≈ 6,19). Eine Beschriftung „R = 1“.

### V10 [A] Das Fourier-Polynom als gleitender Mittelwert: warum es überschwingt
- **Artikel:** content/hm3/07-fourier-reihen/09-punktweise-konvergenz.md
- **Stelle:** Die Idee — „Setzt man die c_k ein, wird das Fourier-Polynom selbst ein gewichteter Mittelwert von f: T_N f(x) = 1/(2π) ∫ D_N(x−y) f(y) dy“ und Zusatz Gibbs-Phänomen — „Die erste Spitze neben einem Sprung bleibt für große N bei rund 9 % der Sprunghöhe …“
